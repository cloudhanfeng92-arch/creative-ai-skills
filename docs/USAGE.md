# 使用说明

## 基本调用

```text
使用 $skill-name，说明你要做什么，并附上素材和限制。
```

Skill 的英文名称就是目录名。可从各目录的 `README.md` 复制完整示例。

## 如何写需求

提供以下信息中与你的任务相关的部分：

- **主题**：故事、产品、人物、场景或文章观点。
- **输入素材**：参考图、产品图、视频或已有文案。
- **结果**：图片、分镜表、提示词、视频、音乐或文章。
- **规格**：数量、时长、比例、语言、目标平台。
- **约束**：必须保留的角色或产品特征、不能修改的文字、预算与审批要求。

示例：

```text
使用 $tech-product-tvc-ad，根据我上传的耳机照片制作20秒广告。
横屏16:9，主题是清晨通勤。只使用已给出的产品卖点。
先展示脚本和分镜，生成付费素材前告诉我预计费用。
```

## 生成与发布

只要提示词时请明确写“只输出提示词”。需要成品时写清楚格式、数量和时长。部分 Skill 明确要求在图片、视频或音乐生成前确认，请按其实际步骤操作。

社媒和海艺应用类工作流可能涉及外部发布。若只要准备材料，请明确写“仅草稿，先不发布”；需要发布时，指定账号、平台和要发布的内容。

## 常见问题

**安装后没有出图？**

检查宿主是否具有 Skill 所需的图像工具、相关平台登录与额度。Skill 文件不能替代模型服务。

**缺少工具、命令或模型？**

先按依赖说明配置；平台已变更时，以当前官方说明和 CLI 帮助为准。不要把不存在的工具当成已执行成功。

**为什么有些 Skill 有确认步骤？**

这是工作流中的既有约定，通常用于确认提示词、参考素材或生成额度，具体见对应 `SKILL.md`。

**脚本能直接运行吗？**

脚本用途、参数和依赖各不相同。先阅读其所属 Skill，再运行 `--help`（如果支持）。打包校验不等于所有服务集成已验证。
