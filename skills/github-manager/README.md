# GitHub 仓库管理

使用本地 Git 与 GitHub CLI 管理仓库、代码、Issue、PR、Release、Tag 和 Actions，发布前执行敏感信息扫描。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/github-manager 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/github-manager) 安装 `skills/github-manager`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $github-manager，检查这个项目的 Git 状态，把已完成改动提交并上传到现有 GitHub 仓库。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- 本地 Git
- GitHub CLI（gh）及目标账号授权

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
