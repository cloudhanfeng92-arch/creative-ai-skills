# 财报与业绩事件分析

沿用已加载的 [共同研究规则](../research-core.md)，沿用其身份识别、时效、证据和权限要求。
选择数据源时读取 [MCP 路由](../mcp-routing.md)。
需要计算细节时，仅读取 [分析方法](../analysis-method.md) 中与财报口径、现金质量或本次事件相关的部分。

## 触发边界

- 用于“这份季报怎么样”“业绩为何变动”“是否超预期”“财报后有哪些新变化”等特定披露事件。
- 覆盖正式财报、预告、快报及修订公告，但明确各自审计、完整性和确定性差异；预告范围不能伪装成最终数值。
- 综合长期经营研究交给 [基本面模块](fundamental-analysis.md)；本模块不默认输出目标价或交易点位。

## 工作流程

### 1. 锁定披露与比较基准

- 找到公告原文，记录发布日期/时间、报告期间、披露类型、审计状态、修订版本与财报币种。
- 同时读取影响结论的附注、审计意见、会计政策变更和重述；只取得摘要时标明分析范围。
- 选择可比的上年同期、上一期间及披露前可得预期；不将自然季度默认等同于公司的财务季度。

### 2. 统一累计、单季和 TTM

- 明确每个收入、利润和现金流数字是单季还是年初累计；同比比较同口径期间，环比考虑季节性。
- 累计转单季时使用本期累计减上一累计，检查合并范围及重述一致性；年度减前三季所得第四季标为“推算”，不是另行披露的单季报表。
- TTM 流量可由最近年度加本年累计减上年同期累计计算；资产、现金、债务等时点余额不能按此公式累加。
- 使用重述后的可比数据，并说明原报告与重述差异；无法取得匹配基期时不要强算同比。
- 基数为零、负值或接近零时，优先解释增减额、扭亏或亏损扩大，避免误导性的增长百分比。

### 3. 拆解利润变化

- 按业务拆分销量、价格、产品结构、汇率、并表和费用率等驱动，区分经营改善与会计或一次性影响。
- 对照收入、毛利、经营利润、归母利润及适用的扣非/调整后利润；非 GAAP 或管理层调整指标注明调整项目并与法定口径勾稽。
- 区分已披露原因与分析推断；没有分部利润、产销或成本拆分时，不编造归因比例。
- 注意减值、补助、投资收益、税率、少数股东损益和股份数变化对净利/EPS 的影响。

### 4. 检查现金与资产负债证据

- 经营现金流与利润对照，结合应收、应付、合同资产/负债及税费说明现金转换；区分季节性和持续恶化。
- 存货、应收和减值结论回到附注原文，核对分类、计提、账龄或周转口径；余额上升并不自动证明需求变弱或收入造假。
- 查看资本开支、有息债务、受限现金和短期偿付变化；选取真正改变本次业绩判断的项目，不重复整份基本面报告。

### 5. 判断预期差与披露后变化

- “超/低于预期”须给出可追溯的披露前预测来源、采样日期、样本及口径；只找到披露后上调预测时，不可倒用为此前共识。
- 没有可靠市场预期时，分别比较公司此前指引、业绩预告或历史趋势，明确不能据此断言市场整体预期差。
- 区分已实现业绩、管理层未来指引与分析者情景假设；关注指引区间、中点、适用期间及后续更新。
- 用户要求股价反应时核验披露时间、当地交易状态与对应价格窗口；盘后公告不得拿此前收盘涨跌当作公告反应。
- 价格反应标明基准、窗口、币种及数据时间，必要时对比市场/行业；同时发生其他事件时，不把全部涨跌归因于财报。

## 输出

先给“本次披露最重要的新变化”，随后用紧凑表呈现关键指标、期间口径、同比/对比和原文来源。
补充变化驱动、现金与资产风险、预期对照及下一次需要验证的指标；用户未要求时不机械增加股价反应或估值。
事实附来源；推断说明计算/归因依据；风险给出触发条件与证据范围。保留数据缺口和口径冲突，不把短期业绩变化等同于长期趋势。
