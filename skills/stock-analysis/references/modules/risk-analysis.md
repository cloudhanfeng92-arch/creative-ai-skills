# 风险因素与仓位约束

沿用已加载的 [共同研究规则](../research-core.md)。按需读 [MCP 路由](../mcp-routing.md) 和 [仓位计算口径](../analysis-method.md)。

## 识别任务与边界

区分公司风险排查、已有持仓风险、拟新增交易的损失情景。确认标的与投资期限；已有持仓沿用用户数据。只做公司风险研究时无需先索要个人资金。

## 风险分析

1. **业务与财务**：收入集中、竞争/替代、需求周期、现金转化、债务期限、融资缺口、担保质押、稀释与表外事项；证据以最新披露原文为主。
2. **治理与事件**：关联交易、控制权、高管变化、审计意见、监管/诉讼。区分风险线索、已立案、裁决和实际财务影响，不把数据库标签直接当成违法结论。
3. **估值与预期**：市场隐含的增长、利润率和倍数是否脆弱；指出哪些假设下调会改变合理价值。
4. **交易与流动性**：波动、盘口/成交、停牌、涨跌停、跳空、交易单位和当日卖出限制，按具体证券和最新规则核实。
5. **组合与资金**：相关行业/因子敞口、币种、期限错配和现金需求。缺少持仓明细或历史数据时不伪造组合相关性、VaR或最大回撤。

每项重要风险说明“来源与日期、发生机制、暴露条件、可能影响、缓解方式、需要监测的证据”。将事实与压力假设分开，不把情景损失当成发生概率或损失上限。不为凑清单把普通不确定性描述成已确认危机。

## 情景与行动

优先提出最有力的反面论证及论点失效条件。价格止损、时间止损和基本面失效可以分别讨论，说明各自目的；不能把用户买入成本当作合理估值或必然回本位置。

具体新增买入数量仅在用户资金、现金、现有单股敞口、风险预算、仓位上限和入场/退出假设足够时计算；不得擅自设置“默认适合你的 1% 风险”。跨币种先核实汇率，全部金额换算至同一币种并保留来源和时间。

使用 `python3 ../../scripts/risk_plan.py --help` 查看参数；脚本路径相对此模块文件所在目录，执行时解析为绝对路径。脚本按风险预算、剩余仓位额度和可用现金三项上限取最小并向下整手。

脚本只支持新增普通股票做多、无杠杆；费用为每边比例估计，不含全部税费或最低佣金。确认输出的限制检查，若目标净收益非正，不能将其写成正向收益机会。已有仓位风险与新增仓位预算分开，不把后者当成整个组合损失上限。

无 shell 时按共享公式展示输入及算式；无可靠价格时仅做标明历史基准或假设的情景，不输出当前可执行数量。脚本计算不产生订单，也不证明投资适当性。

## 输出

- 风险结论及证据充分度；最重要的三到五项风险优先。
- 每项风险的证据、影响路径、失效/触发条件及应对选择。
- 用户请求时给明示假设的压力情景、资金预算、费用与可行数量。
- 待验证事项和下次复核事件；说明止损不保证成交，实际亏损可因跳空等超出试算。

不自动加杠杆、摊平、交易或创建监控。用户明确要求提醒时按共同规则调用宿主调度。
