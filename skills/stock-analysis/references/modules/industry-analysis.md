# 行业与产业链分析

沿用已加载的 [共同研究规则](../research-core.md)，沿用其身份识别、时效、证据和权限要求。
选择数据源时读取 [MCP 路由](../mcp-routing.md)。
需要方法补充时，仅读取 [分析方法](../analysis-method.md) 中与本次行业、可比样本或估值适用性相关的部分。

## 触发边界

- 用于“行业处在什么阶段”“产业链谁受益”“供需与价格怎么看”“同行格局和估值方法有什么差别”。
- 单家公司内部经营质量交给 [基本面模块](fundamental-analysis.md)，某次业绩披露交给 [财报与业绩模块](earnings-analysis.md)，具体公司的估值区间交给 [估值模块](valuation.md)。
- 行业比较不自动扩展为全市场选股；用户未要求时不生成买入名单或交易点位。

## 工作流程

### 1. 定义行业与样本

- 锁定产业边界、地区、时间范围、统计分类和上下游环节；区分终端行业、技术概念与股票标签。
- 说明公司样本如何进入：主营暴露、收入占比、产业位置、地区和阶段；无法确认实际业务暴露时不得仅凭概念标签归类。
- 列明实际覆盖的公司与数据缺失，区分样本观察和整体行业结论，不声称完成全市场扫描。
- 行业规模、市占率和增速必须采用一致的地域、产品、时间和计量单位，避免混用出货额、出货量、装机量与收入。

### 2. 绘制产业链与利润分配

- 用简短表或必要的小图呈现上游投入、中游制造/服务、下游客户及关键约束，突出价值创造和议价环节。
- 解释技术壁垒、认证周期、渠道、客户集中、资本强度和替代路线如何影响利润分配；不把技术先进直接等同于商业回报。
- 比较样本的规模、份额、成本、产品结构、客户与产能位置，注意关联交易和垂直整合导致的统计重复。

### 3. 判断供需、价格与周期

- 需求侧拆分存量替换、渗透率、客户资本开支、终端销量和区域变化；意向订单、正式订单、交付与确认收入分别处理。
- 供给侧区分规划、在建、投产、有效产能与利用率，考虑良率、认证、资本约束和退出周期。
- 联合观察价格、库存、交期、开工率、订单与毛利，解释领先/同步/滞后关系；单一指标回升不能直接证明景气反转。
- 区分周期、季节性、结构性替代和政策拉动；统计频率、样本变更及数据滞后影响判断时直接说明。
- 对供需预测使用明确情景，列出关键假设与可观察的反证，不把产能公告简单加总为确定供给。

### 4. 核查政策与竞争变化

- 政策回到发布机关原文，区分征求意见、正式发布、生效、实施细则与实际执行；标题和新闻表述不能替代适用条件。
- 将政策影响连接到收入、成本、资本开支、准入或竞争格局，注明传导路径与受益/受损边界。
- 跟踪新进入者、集中度、贸易限制、技术替代与客户自研，区分已发生变化、计划和行业预测。
- 研报、协会与企业口径分别标注，核对样本及利益关系；多份转述同一上游报告不算独立验证。

### 5. 选择估值框架与观察指标

- 根据现金流、盈利周期和资产属性讨论 PE、PB、EV/EBITDA、PS、DCF 等适用条件，避免跨行业统一倍数排行。
- 同行倍数比较对齐估值日期、币种、历史/预测期、会计口径及资本结构；极端或负分母说明失效，不用“低倍数”自动判断便宜。
- 行业景气判断与市场已反映的预期分开；需要个股公允价值时将假设与样本交给 [估值模块](valuation.md)。
- 形成少量领先指标、关键时间节点和会改变结论的反证；宏观背景仅在存在明确传导关系时加入。

## 输出

先给行业阶段判断及适用范围，再按需要呈现产业链、供需驱动、竞争样本、政策影响与估值框架。
用一张紧凑样本表说明业务位置、可比指标、期间和来源；对于整体统计，另列统计范围，避免把公司样本误作行业总量。
事实附来源，推断附传导逻辑与假设，风险附触发条件及影响环节；结尾保留关键缺口与观察指标，不机械堆叠公司清单。
