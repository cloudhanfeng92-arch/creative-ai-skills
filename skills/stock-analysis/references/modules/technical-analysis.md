# 股票技术分析

沿用已加载的 [共享研究规则](../research-core.md)。
需要选择行情、网页或 MCP 工具时，再读 [工具路由](../mcp-routing.md)。
需要计算指标时，按需读 [分析与计算口径](../analysis-method.md) 的技术计算部分。

## 确定分析口径

- 确认股票、交易所、币种、分析时点和用户关注期限；区分日内、波段与长期趋势。
- 沿用用户指定周期；没有指定时选择能回答问题的周期并说明，不混合不同周期信号。
- 先确定本次允许的数据年龄，再核验报价时间、延迟、交易状态及最近有效交易日。
- 抓取时间不替代报价时间；旧快照只能支持对应日期的历史分析，不能生成即时买卖指令。
- 分清现价、常规交易时段收盘价及盘前盘后价格，明确各自的时间基准。

## 检查历史行情

- 取得与问题匹配的 OHLCV，注明起止日期、周期、样本数、来源与复权方式。
- 检查时间递增、重复记录、缺行、异常价格及非负成交量；缺失交易日不得补造行情。
- 核查拆股、分红和停牌；比较同一复权口径的数据，不把复权支撑位直接当作可下单价格。
- 成交量须注明股或手，成交额须注明币种和单位；不能把成交额当成交量或跨源直接拼接。
- 已完成 K 线与正在形成的 K 线分开；说明最新一根是否完整，不用未完信号冒充收盘确认。
- 不把半日或盘中成交量与完整交易日均量直接比较为放量、缩量。
- 缺乏可核验历史数据时，保留数据缺口与观察条件，不编造走势、指标或支撑阻力位。

## 选择少量指标

- 只选能回答问题的趋势、动量或波动指标；多个相似指标不能算作独立支持证据。
- SMA(n) 至少需要 n 根已完成收盘价；窗口不足时写不可计算。
- RSI、ATR 与 MACD 记录算法、初始化、暖机长度和样本数；不足则降低判断强度或不计算。
- 指标同名不代表口径相同；比较前核查 MACD 柱值定义、复权及供应商算法。
- 把历史价格结构与量价配合放在指标前面；不以单次金叉、超卖或背离直接推出买入。
- 支撑、阻力和突破区间必须对应可核查的历史结构、窗口与价格口径，并说明如何确认。
- 区分盘中触及、收盘突破与后续回踩；选择适合用户期限的确认条件，不假定一定出现。

## 形成条件判断

- 先说明趋势、关键结构和证据充分度，再给最有力的反面证据；证据冲突时展示冲突。
- 说明量价或波动变化支持什么推断，以及哪种价格行为会推翻该推断。
- 趋势描述历史状态；不写必涨、必跌、保证止损或未经校准的胜率。
- 涉及财报、停牌或重大事件时说明技术信号的局限，按任务需要核查事件原文。
- 只有数据支持时给观察区间及条件；不为凑齐行动方案凭空生成入场价、止损价或目标价。
- 具体股数需要用户资金、风险预算及仓位约束，并核查交易单位；技术信号不能代替这些输入。

## 交付

- 用简短结论回答问题，附分析时点、行情截至时间、周期、复权方式及来源。
- 展示关键结构、少量指标及计算口径，并区分事实、推断与未来触发情景。
- 给出成立条件、失效条件和下一次核验点；数据不足时明确哪些问题仍不能判断。
- 图表如有必要，轴、币种、时间和未完成 K 线应可辨认；不以平滑效果掩盖缺失数据。
- 输出研究建议，不连接交易账户、不下单；只有用户明确要求时才处理跟踪或提醒。
