# 股票估值

沿用已加载的 [共享研究规则](../research-core.md)。
需要选择财务、行情或 MCP 工具时，再读 [工具路由](../mcp-routing.md)。
涉及财务调整和模型计算时，按需读 [分析与计算口径](../analysis-method.md) 的业务、财务和估值部分。

## 锁定估值对象与基准

- 确认公司、证券类别、交易所和币种；ADR、不同股类、上市主体与经营主体不能混算。
- 确认估值时点与适用期限，分别记录报价时间、财报报告期、披露日及预测期间。
- 使用当时已公开的信息；历史估值不得引入估值日以后才公布的数据。
- 核实价格、股本、汇率及财务口径；区分元与万元、百万与十亿、每股与总额。
- 实时价格无法核实时，可做注明价格日期的历史估值；不能声称代表当前可执行买点。

## 选择适合行业的方法

- 优先选能解释公司价值的少量方法，说明适用性；不强制每家公司都做 DCF。
- PE 明确历史、TTM 或预测口径及基本或摊薄 EPS；不得混用不同期间的利润和股本。
- 亏损公司的负 PE 不能作为便宜的证据；一次性收益或利润异常时解释失真并换用合适指标。
- PB 结合资产质量、减值、资本要求与回报率；低 PB 不自动代表低估。
- 企业价值倍数区分 EV 与股权价值，核查净债务、少数股东权益及其他必要调整。
- 银行、保险、地产、周期股和亏损成长公司采用各自可解释的指标，不硬套普通工业企业模型。
- 同业比较统一期间、准则、币种及业务结构；历史均值或同业中位数不是天然合理价格。
- 每项关键输入链接原文或注明数据工具、时点；一致预期、管理层目标与自建假设分别标识。

## 现金流折现

- 先选择 FCFF 或 FCFE 并保持全模型一致，注明显式预测期和现金流发生时点。
- FCFF 用 WACC 折现得到企业价值，再按适用口径调整净债务等项目得到股权价值。
- FCFE 用股权资本成本折现得到股权价值；不能再机械扣一遍已反映的净债务。
- 解释收入、利润率、税率、资本开支、折旧与营运资金假设，以及它们如何进入现金流。
- 折现率与现金流保持币种、名义或实际、税前或税后口径一致。
- 永续增长终值使用同口径的下一期现金流，并要求折现率 r 大于增长率 g；不满足则停止该模型。
- 出口倍数终值要说明选择依据，不把增长终值与出口倍数终值相加。
- 单列终值占比及其敏感性，避免小幅假设变化被隐藏为精确的单点价格。
- 股权价值除以匹配的摊薄股份数；核查期权、可转债、回购及潜在稀释，避免重复调整。

## 情景与证据缺口

- 以明确假设给出悲观、基准、乐观区间，检查增长、利润率、倍数或折现率的敏感性。
- 不凭空赋予情景概率；结果的小数精度不得超过输入可信度。
- 来源不足时只给标明假设的情景区间或估值框架，不将演示数字包装为公司真实价值。
- 缺少关键输入时说明哪些结论不能计算；不得用零填补未知净债务、现金流或股份数。
- 解释最有力的反面证据及估值失效条件，例如盈利质量恶化、再融资压力或长期增长变化。

## 交付

- 先给估值判断及适用期限，随后列方法、关键输入来源、价值区间和主要敏感变量。
- 将模型价值、相对估值和实际交易买点分开；估值折价不保证短期上涨或一定实现回归。
- 与价格比较时注明价格日期；买入条件还需结合证据更新、资金需求和用户风险约束。
- 明确下一次复核事件；重大披露或模型假设变化后重新估值，不沿用旧结论作新证据。
- 不执行交易，不承诺收益；具体仓位需另有经用户确认的资金与风险约束。
