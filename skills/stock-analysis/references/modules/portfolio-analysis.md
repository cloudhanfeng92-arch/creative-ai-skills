# 股票组合分析

沿用已加载的 [共享研究规则](../research-core.md)。
需要选择持仓估值、行情或 MCP 工具时，再读 [工具路由](../mcp-routing.md)。
需要新增股票仓位试算时，按需读 [分析与计算口径](../analysis-method.md) 的仓位部分。

## 明确组合与目标

- 沿用用户已给的期限、收益目标、资金用途、风险预算和限制；仅询问影响结论的缺失汇总信息。
- 分清全部投资组合、某个账户和本次可用现金，记录分析实际覆盖范围。
- 核对证券代码、市场、股数、持仓币种、现价、现金、组合净值及数据时点。
- 成本用于损益解释，现价用于当前市值与权重；不把买入成本当作合理价值或当前风险敞口。
- 不要求账户密码、完整资产证明或交易凭证；不把持仓写入全局记忆或外传。

## 统一金额与时点

- 选定组合报告币种，使用有来源及时间的汇率换算持仓、现金和相关金额。
- 不直接加总不同币种；各市场休市时间不同，说明估值时点和价格新旧差异。
- 持仓市值为股数乘同口径现价；拆股、公司行动和 ADR 比例必须匹配持仓单位。
- 区分净资产、证券市值、现金和借款，核查加总关系，避免把现金或负债重复计入。
- 全部持仓与分母完整时才能计算组合权重；只有部分持仓时明确是已披露部分的占比。
- 缺少股数、现价或总净值时不造持仓比例；必要时给用户补全所需的最少字段。
- 未知现金、负债或持仓不能填零；未知资产可能影响结论，应说明覆盖缺口。

## 识别集中度与共同风险

- 分析单一证券、发行人、行业、地区和币种集中度，区分直接敞口与穿透后敞口。
- 同公司不同上市证券、行业相近股票及 ETF 成分可能重叠，不以股票数量代替分散程度。
- 因子判断说明依据，例如成长、利率、商品、汇率与流动性暴露；没有模型时只作定性分析。
- 计算相关性前取得同频率、同窗口、足够长度及同收益定义的数据，处理交易日错位和汇率口径。
- 记录样本数、缺失处理和计算期间；样本不足、非同步交易或停牌较多时不报告伪精确相关性。
- 历史低相关不保证压力期分散有效；共同财报、监管、融资或宏观冲击单独检查。
- 缺持仓明细或必要历史数据时，不生成组合总波动、VaR、最大回撤或“整体低风险”结论。
- 情景压力测试需列假设及覆盖范围，不把情景损失称作最大可能损失或发生概率。

## 制定有条件的再平衡

- 结合投资期限、资金需求、可承受损失、现有敞口和仓位上限制定方案，不默认满仓或加杠杆。
- 区分新资金分配、减仓腾挪与观点变化；列出触发条件、目标范围、约束和复核时点。
- 具体加减仓数量需要足够的现价、现金、完整约束及用户风险预算；缺失时先给条件框架。
- 计入适用的税费、交易单位、流动性、结算与交易限制；跨币种另核对换汇成本。
- 单笔新增普通股票做多试算可运行 `python3 ../../scripts/risk_plan.py --help`（路径相对此模块文件所在目录，执行时解析为绝对路径） 查看参数。
- 按共享计算口径传入同币种的净值、现金、既有市值、入场价、情景止损和目标价及费用等全部参数。
- 脚本仅试算一笔新增做多，不用于多资产最优化、卖出、杠杆或衍生品；多个结果仍须核查组合合计约束。
- 止损情景预算不等于最大损失保证；跳空、停牌、滑点或无法成交可能使实际损失超出试算。

## 交付

- 先说明组合最重要的问题、证据覆盖程度和建议优先级，避免用无依据的综合评分替代分析。
- 明确价格、汇率及净值时点；只有字段足够时展示市值、权重、现金和敞口表。
- 说明再平衡条件、执行顺序的理由、失效条件及下一次复核事件；数字不足时不补造股数。
- 不登录账户、不下单、不自动调仓；仅在用户明确要求时处理保存、持续跟踪或提醒。
