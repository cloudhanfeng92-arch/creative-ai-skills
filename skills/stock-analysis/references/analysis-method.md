# 分析与计算口径

需要深度个股研究、估值、技术分析或具体仓位试算时读取。按行业与用户期限选择项目，不机械补齐全部指标。

## 业务、财务和估值

- 解释业务驱动、客户与供应链集中度、竞争优势、周期敏感性；区分可验证的增长与管理层愿景。
- 使用最新已公开报告；记录报告期、披露日、币种、单位、合并范围和准则。同比比较相同期间，季度与累计期间不可混用。标出一次性损益、股权激励、稀释与重述。
- 检查经营现金流与利润差异、资本开支、营运资金、净债务、债务到期与再融资风险。银行/保险等金融公司采用行业适配指标，不直接套用工业企业自由现金流逻辑。
- TTM 若从累计数据构造，使用“上年度全年 + 本期累计 − 去年同期累计”，先核对口径。缺任何项则不伪造 TTM。
- PE = 股价 / 同口径每股收益。注明历史/TTM/预测、基本/摊薄口径。亏损或异常低利润时标“不适用”或解释失真。PB 同样需检查账面价值质量。
- 企业价值与股权价值分开。EV 倍数需把净债务、少数股东权益等适用调整项处理后再得到股权价值；ADR、不同股类、汇率和股本单位不能混用。
- 按问题选择可比倍数、历史估值、分部估值或 DCF，不强制 DCF。预测指标标为假设/一致预期并给来源；历史中位数不天然等于合理价格。
- 用悲观/基准/乐观情景检查增长、利润率或适用倍数变化。只对有来源或明确推导的变量给值；展示估值敏感性，不凭空给情景概率或上涨胜率。
- 不依赖实时价格的判断（如债务违约、财报风险）可照常给出；依赖现价的收益空间、入场和盈亏比必须绑定价格日期。

## 技术计算

保留原始数据日期、来源、周期、复权方式和单位；计算前校验时间递增、无重复、OHLC 合理、成交量非负。不把成交额当成交量，不把“手”误当“股”。停牌缺行不填造为交易日。拆股/分红时统一 OHLC 调整方式；不混用复权收盘价和未复权最高/最低价。

优先少量与问题有关的指标：

- SMA(n) 为最近 n 根已完成 K 线收盘价均值；样本不足返回“不可计算”。
- RSI(14) 如使用 Wilder 算法：以最初 14 个价格变化的平均上涨/下跌初始化，然后以 1/14 平滑；至少 15 个收盘价。上涨/下跌均为零时注明采用 RSI=50 的中性约定。
- ATR(14)：TR = max(high−low, abs(high−前收), abs(low−前收))；从完整 TR 序列初始化 Wilder 平滑。标明初始化和样本量。
- MACD(12,26,9)：注明 EMA 初始化方式与暖机长度；供应商柱状值可能为 DIF−DEA 或其两倍，不混比。

盘中未完成 K 线与已完成 K 线分开；不把半天成交量与完整日均量直接比较为缩量。技术信号描述历史价格状态，不构成独立买入依据。支撑/阻力用可核查结构与区间，注明观察窗口；不为输出完整编造“精确支撑价”。

## 新增普通股票做多仓位试算

`../scripts/risk_plan.py` 使用 Python 3 标准库与 Decimal；只试算一笔新增买入，不支持做空、杠杆、期权、卖出零股或组合优化。

所有参数显式提供。`capital` 为本次风险管理使用的组合总资金/净值；`available-cash` 为可用于本次交易的现金；`existing-value` 为已持有该证券的当前市值。三者与 entry/stop/target 必须同币种。不把总资产代替可投资资金，不把损失预算误当最大回撤保证。

`risk-pct` 为新增交易的止损情景预算占 capital 的百分比；`max-position-pct` 为已有加新增该证券市值的比例上限。传 `1` 代表 1%，`20` 代表 20%。这些数值来自用户约束或明确标注的假设示范；示范不能被写成适合用户的建议。

每边费用率 c = cost-bps / 10000。新增股份上限按以下三项取最小，再向下取整至允许交易单位：

```
风险额度 = capital × risk-pct / 100
剩余仓位额度 = max(0, capital × max-position-pct / 100 − existing-value)
每股止损情景亏损 = entry − stop + (entry + stop) × c
每股目标情景收益 = target − entry − (entry + target) × c
风险限制股数 = 风险额度 / 每股止损情景亏损
仓位限制股数 = 剩余仓位额度 / entry
现金限制股数 = available-cash / (entry × (1+c))
```

使用 `python3 <技能目录>/scripts/risk_plan.py --help` 查看全部必填项。以下是合成数字功能演示，与任何股票无关：

```sh
python3 <技能目录>/scripts/risk_plan.py \
  --capital 100000 --available-cash 50000 --existing-value 10000 \
  --max-position-pct 20 --risk-pct 1 \
  --entry 10 --stop 9 --target 12 \
  --lot-size 100 --cost-bps 5 --currency CNY
```

`lot-size` 必须核对具体证券；不默认所有 A 股都是 100 股或所有港股交易单位相同。费用以每边相同比率近似，未自动建模最低佣金、非对称税费和汇兑费。参数为零时明示忽略费用。

净盈亏比为每股目标情景收益 / 每股止损情景亏损，不是获利概率。费用使目标净收益不为正时不能描述为正向收益机会。跳空、涨跌停、停牌、流动性和滑点可使实际损失超出试算，不保证“最多亏损 X”。最终数量还须满足现有组合敞口与用户全部约束。

## 追溯与更新

用户要求保存/跟踪时，在指定工作目录保存简短 JSON 或表格：证券与市场、分析时点、行情时点、来源、报告期、论点、反证、触发条件、失效条件、下次核查事件。未经请求不把持仓写入全局记忆或上传外部服务。更新报告说明与上次相比发生了什么，不把前次观点当作新证据。
