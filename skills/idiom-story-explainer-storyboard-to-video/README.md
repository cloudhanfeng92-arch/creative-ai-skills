# 成语故事讲解视频

把成语、寓言或历史小故事制作成分镜、视频、旁白与字幕方案。

## 使用方式

先按仓库[安装指南](../../docs/INSTALL.md)安装本目录，再在支持 Skill 的 AI 助手中输入：

```text
使用 $idiom-story-explainer-storyboard-to-video，把“刻舟求剑”制作成30秒科普短片，先展示故事结构与分镜。
```

## 输入与结果

示例中的主题、时长、画幅和参考素材可替换为自己的需求。涉及参考图或视频时，请同时提供可访问的素材。具体必填项、默认值与交付格式见 [SKILL.md](SKILL.md)。

## 工具与环境

按 SKILL.md 的具体步骤使用宿主提供的文本、图像分析或生成工具。工具、账号、模型权限和额度需要单独准备；安装 Skill 本身不会安装这些服务。部分流程需要先确认提示词与生成费用，请遵循原 Skill 的步骤。
