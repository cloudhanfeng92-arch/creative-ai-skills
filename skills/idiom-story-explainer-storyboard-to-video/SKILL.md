# 成语故事讲解视频

## Skill 定位

只负责：**将用户给的一个成语/小故事种子（故事文本 + 角色图/道具图/场景图，均可选）自动转化为一套可执行的科普讲解短片制作方案（解析故事剧本 → 补齐场景/道具/角色三视图 → 逐幕图生视频提示词 → 参考图生视频 → 配乐+旁白讲解+统一字幕剪辑合成），并在每次消耗积分前询问用户确认。**

适用范围：**全历史阶段、各类题材**的成语典故、寓言、民间故事、历史小故事的科普讲解短片（不限于三国，先秦寓言至近现代小故事均可）。整体叙事更接近"剧情故事+讲解科普"的融合形态，而非单纯人物传记。

不负责：最终成片的多幕拼接渲染合成本身（本 skill 产出按序独立的单幕视频片段、配乐提示词、讲解文案与字幕文本，实际拼接、混音、压制由剪辑软件完成）、跨集连续性管理（如需系列化多集成语合集，由上层项目文档单独维护角色/世界观锚点后传入本 skill）。

---

## 输入

字段 是否必填 说明 `story_text` ✅ 必填 成语或小故事文本：成语/故事名称 + 出处/所处年代 + 故事情节梗概（起因→经过→转折→结果→寓意/道理）。**题材不限，涵盖成语典故、寓言、历史小故事、民间故事等，人物/故事不限三国，涵盖全历史阶段** `character_image` ⬜ 选填 主角/相关重要角色参考图。**有则直接作为后续「参考图生视频」阶段的参考图**，不再重复生成该角色的三视图；未提供且剧本中确有需要（如反复出场的配角）则在图片生成阶段补齐**角色三视图** `prop_image` ⬜ 选填 关键道具参考图（如故事核心道具：一支箭、一口锅、一块玉等）。有则直接使用；未提供且分镜脚本中出现关键道具时，由本 skill 补齐 `scene_image` ⬜ 选填 场景参考图。有则直接使用；未提供且分镜脚本中出现新场景时，由本 skill 按设定生成 `scene_count`（幕数） ⬜ 选填 **固定 1–16 幕**。用户可指定具体幕数；未指定则由本 skill 依据 `story_text` 情节复杂度自动拆分出合适的幕数（简单成语故事可能仅需 1–4 幕，情节复杂的故事可拆分至接近16幕），并向用户展示确认 `act_duration` ⬜ 选填 单幕时长，**固定区间 10–15秒**，用户可指定统一时长或允许逐幕浮动；未指定则由本 skill 依据该幕镜头密度在 10–15秒区间内自动确定，并在展示分镜脚本时逐幕标注实际时长 `style_reference` ⬜ 选填 画风参考文字或图片；未提供时依故事题材推荐合适画风（如寓言类可推荐水墨/国漫风，历史小故事推荐UE5写实史诗风），并向用户确认 `narration_voice_ref` ⬜ 选填 旁白音色参考。**若用户指定参考某位已上传角色的音色，则采用该角色音色**；未指定则默认依故事题材推荐合适的讲解音色（如寓言类推荐"亲和讲故事音色"，历史故事推荐"沉稳纪录片解说音色"），并向用户确认 `subtitle_font_style` ⬜ 选填 字幕字体风格倾向；未提供则依故事题材自动推荐（如古风故事推荐书法感/衬线字体，现代寓言推荐清晰易读的黑体类字体），**全片统一，不得逐幕更换** `image_model` ⬜ 选填 生图模型，默认 GPT image2 `video_model` ⬜ 选填 生视频模型与分辨率，默认 Seedance 2.0，720P，**参考图生视频模式**

## ⚠️ 核心术语澄清（务必不要弄混）

- **【图生视频提示词】** = Step 三输出的、**以「幕」为单位的一整段连续自然语言导演提示词**（画风锁定六维度 + 完整出场人物 + 完整场景设定 + 完整分镜序列 + 音效 + 台词 + 画面纯净声明）。这份文字**就是**直接喂给生视频模型（参考图生视频模式）的输入，全片描述范围严格对应该幕固定的 **10–15秒**（具体秒数以该幕确定值为准）。
- 【生图阶段提示词】只用于 Step 二 —— 为**场景 / 道具 / 缺失的角色三视图**生成静态参考图，与图生视频提示词是完全不同的两份文字，绝不可互相替代或混淆。
- 【讲解旁白文案】【字幕文本】【配乐提示词】是 Step 五（剪辑合成阶段）单独产出的三份文字，均不属于图生视频提示词，也不写入图生视频提示词内部。

## 输入使用

**严格遵守：**

- 每幕时长固定在 **10–15秒** 区间内（具体取值依该幕镜头密度确定），时间轴固定从第1s计至该幕确定的时长末尾，首镜从1s起始，末镜须覆盖至该幕时长终点；全片固定 **1–16幕**，幕数由用户指定或本 skill 依情节自动拆分，幕序严格按故事情节顺序（起因→经过→转折→结果→寓意升华）排列
- 一旦确定画风（用户提供或本 skill 推荐并经确认），必须先输出一次完整【画风锁定】声明（六维度：画风类型/色调倾向/渲染质感/物理表达规则/视觉特效语言/镜头参数风格），全片禁止中途切换或混用
- `character_image` 若已提供，图片生成阶段**不得**再为该角色生成三视图；未提供、但分镜脚本中确有需要清晰呈现该角色外观的（主角或反复出场的重要配角），才补齐**角色三视图**（正面/侧面/背面），且必须与用户已上传的其他参考图画风保持严格一致
- 图片生成阶段**只能**生成以下三类之一：①场景图（缺失时）；②分镜脚本中出现的关键道具图（且仅限缺失、无参考图可用）；③剧情需要但用户未提供参考图的主角/配角**角色三视图**。禁止生成逐镜头关键帧图、禁止生成与剧情无关的图像
- 每次调用生图或生视频接口前，**必须向用户展示即将执行的内容（提示词/积分消耗数量）并等待确认**，未确认不得执行；这一确认要求同样适用于 Step 四（视频生成）、Step 五中如涉及 AI 配乐/AI 配音生成的每一次调用
- 视频生成固定采用**参考图生视频模式**：以 `character_image`（用户提供或 Step 二 补齐的角色三视图）+ `scene_image` + `prop_image`（如有）作为参考图，连同该幕完整的图生视频提示词一并提交给生视频模型，一次性生成该幕对应时长（10–15秒区间内）的视频片段
- 剪辑合成阶段（Step 五）**必须**包含：配乐、讲解旁白、字幕，三者缺一不可；讲解旁白核心用途是**讲解/科普该成语或小故事**（含出处、寓意、道理），文字须精简、紧扣对应画面
- 字幕字体**全片统一**，风格须符合故事题材调性，不得逐幕更换

**仅作参考：**

- 幕数在用户未指定时由本 skill 依情节复杂度自动判断（1–16幕区间内），单幕时长在用户未指定时由本 skill 依镜头密度在10–15秒区间内自动确定，均可在 Step 一 结果展示后由用户直接调整
- 分镜脚本中未指定的镜头调度细节（景别、运镜、切镜节奏、镜头数量）由本 skill 按「镜头数量分配原则」自主决策，无需用户逐条确认
- 旁白文案的具体措辞、字幕字体的具体名称、配乐的具体风格，本 skill 会给出建议方案，用户可在展示后直接反馈调整，无需逐字确认

## 内部流程和 Knowhow

### 一、成语/故事剧本解析

**目标：** 将 `story_text` 转化为结构完整、按情节顺序排列的 1–16 幕故事剧本骨架，突出该成语/故事最具画面感、最适合讲解科普的关键节点。

执行步骤：

1. 从 `story_text` 中提取故事名称、出处/年代、核心情节（起因→经过→转折→结果）与寓意/道理；若信息不完整，可依据常见典故版本合理补全过渡性细节，但不得杜撰与该成语/故事核心寓意相悖的情节
2. 按「起因铺垫 → 情节展开 → 冲突/转折 → 高潮 → 结果/寓意升华」的叙事弧线，将全片情节拆分为 **1–16幕**（幕数依用户指定或情节复杂度自动判断，简单成语可能只需1–4幕），幕序严格按情节时间顺序排列
3. 为每一幕拟定标题，格式固定为：**"第X幕：情节名称（意境/寓意关键词）"**（要求凝练、有画面感、贴合该成语/故事出处），例如"第一幕：井底之蛙（坐井观天）"式的短语意境副标题
4. 确定画风：若有 `style_reference` 或参考图可供判断，直接进入画风锁定；否则依故事题材（寓言/成语典故/历史小故事等）推荐合适画风基准，向用户展示确认
5. 确定讲解旁白音色基准：若用户指定参考某角色音色则采用该角色音色；否则依故事题材推荐默认讲解音色基准，向用户展示确认
6. 输出【画风锁定】六维度基准声明 + 【幕序总览】（1–16幕标题列表 + 每幕对应情节阶段标签 + 每幕预计时长）

**开场钩子规则（每幕开场前1.5秒内）：** 每幕必须在开场即进入该阶段最具画面感/最具悬念的场景切入点，禁止用大段环境介绍做铺垫式开场。

**台词规则：** 只允许**短句台词**，直接嵌入对应镜头的画面内容描述中；单句台词原则上不超过15字，禁止长篇独白，禁止在段落末尾另起清单罗列台词——**故事讲解的核心信息由 Step 五 的旁白承担，画面内台词只做情境点缀，不承担科普讲解功能**。

**禁止：** 静态叙事、脱离画面的说明式旁白替代行动、偏离该成语/故事公认寓意的情节杜撰、非按情节顺序排列幕序。

### 二、场景 / 道具 / 角色三视图生成（仅限缺失素材，按需触发）

**角色锚点（Character Anchor，每幕每个出场角色必填）**

```
- 面部特征：五官特征、肤色、须发/年龄感——首次出场详写；后续幕只写本幕新增变化
  （若已提供 character_image，此处描述须与参考图一致，作为参考图生视频阶段的文字辅助锚点）
- 服装：材质、颜色、形制细节、本幕对应的状态变化
- 道具：名称及当前状态，无则写"无"
- 当前状态：情绪/动作意图，一句话概括
```

**场景锚点（Location Anchor，每幕必填）**

```
- 地点：具体场景名称
- 环境：空间结构、氛围元素、可互动元素
- 光源：时段/光色/方向
```

若该场景无 `scene_image` 且为分镜脚本中首次出现的场景，标记为「待生成场景图」。

**触发条件（仅此三种情况可以进入图片生成阶段，其余一律不生成）：**

1. 分镜脚本中出现的场景，用户未提供 `scene_image`
2. 分镜脚本中出现关键道具（推动剧情或视觉重要性高），且无任何参考图可用
3. 分镜脚本中确有需要清晰呈现外观的主角或反复出场的重要配角，用户未提供 `character_image` —— 此时生成该角色的**三视图**（正面/侧面/背面），用于后续参考图生视频阶段保持角色一致性

**严禁：**

- 为已有 `character_image` 的角色重复生成三视图
- 生成逐镜头分镜关键帧图（本 skill 不做逐镜出图，出图仅服务于「补全参考图」这一个目的）
- 生成与剧情无关的图像
- 新生成的图像画风与用户已上传的参考图（如有）不一致

**执行步骤：**

1. 汇总本片所有「待生成场景图」「待生成道具图」「待生成角色三视图」清单，向用户展示
2. 对每一张待生成图，先给出**生图提示词**（结构：主体/道具/角色三视图描述 + 环境或材质细节 + 【画风锁定】六维度关键词浓缩 + 光影 + 若为角色三视图需注明"与已上传参考图风格一致"或依画风锁定描述 + 画面纯净声明），询问用户确认后再调用生图模型
3. 生成结果作为该场景/道具/角色后续「参考图生视频」阶段的参考图使用

### 三、逐幕图生视频提示词生成 ★核心产出，务必不要与 Step 二 的生图提示词混淆★

**核心规则（最高优先级）：**

图生视频提示词**以「幕」为单位**产出，每一幕固定生成一段 **10–15秒**（该幕确定时长）视频（Seedance 2.0 参考图生视频模式一次调用生成整幕内容），因此每一幕的图生视频提示词必须是**该幕的完整分镜脚本原文**，包含：

```
第X幕：情节名称（意境/寓意关键词）—— 固定时长X秒（10–15秒区间内）

出场人物：
角色A（面部特征、服装、道具）
角色B（……）

【画风锁定】六维度（逐条完整展开，逐字复用 Step 一/二 的基准声明，不得省略或简写）

场景设定：地点 / 环境 / 光源

分镜序列（1s–X s，本幕内全部镜头，按「镜头数量分配原则」确定镜头数）
每镜包含：
  🎥 时间码（如 1s–3s）
  景别：ELS / LS / MS / CU 等
  镜头运动：dolly in / dolly out / tracking / orbit / slow pan / tilt /
            handheld micro shake / rack focus 等
  转场（如有）：Match cut / Hard cut on action / Whip pan transition / Dissolve
  画面内容：角色动作 + 环境反应 + 光影变化 + 材质细节（若本镜有台词，直接嵌入此处，
            格式：角色名（状态）："短句台词"）
  动作承接：与上一镜头动作连续
  (SFX: ……) 至少标注本镜关键音效

画面纯净声明：无字幕 / 无UI叠加 / 无水印 / 无任何文字与字符
```

这份文字**就是**这一幕对应的图生视频提示词，产出一次即可，既作为剧本存档，也直接作为参考图生视频阶段的输入提示词——**不需要也不应该**另外再拆分或简化成别的结构。

**时长铁律：** 每一幕固定 **10–15秒**（用户指定或本 skill 依镜头密度确定），首镜从1s起始，末镜必须覆盖至该幕时长终点；提示词描述的内容范围也必须固定对应这一时长，不得只覆盖部分镜头或延伸到下一幕。**镜头数量随该幕确定的时长（10秒或15秒或区间内其他值）相应增减**，时长越长镜头数量上限越高。

**镜头数量分配原则（决定该幕内部切镜密度，由剧情节奏与该幕时长共同决定，非固定数量）：**

场景类型 参考镜头数（按10–15秒区间浮动） 镜头逻辑 冲突/戏剧爆发段 5–8镜 快速切镜强化冲击感，每镜1–2秒，动作碎片化呈现 情节推进/铺垫段 3–6镜 中速节奏，单镜2–4秒，保留情节完整性 对话/情绪交锋段 3–5镜 少切镜，单镜3–5秒，正反打克制使用 寓意升华/结尾定格段 1–3镜 极少切镜，允许单镜5秒以上，镜头缓慢运动或静止凝视，适合承接旁白点题 环境建立/过渡段 2–3镜 用于时代或空间背景交代，禁止无效切镜 高潮爆点瞬间 可用单镜慢动作 允许单一镜头拉长至3–5秒，慢动作强化冲击力

切镜判断标准——每次切镜前必须能回答以下三问之一，均无法回答"是"则禁止切镜：这次切镜传递了新的视觉信息？这次切镜改变了情绪强度？这次切镜推进了叙事？

**呼吸节奏（强制）：** 每一幕整体须遵循"张力积累 → 爆发/点题 → 短暂释放"的波形节奏；每幕至少含1个明确爆点或寓意点题瞬间。

**幕间衔接规则（红线）：**

要素 规则 动作连续 上幕末镜动作 → 下幕首镜动作，逻辑顺承 空间连续 角色位置/朝向一致，禁止无因由的空间跳跃 状态延续 情绪/道具/服装状态不得无故重置 情节走向延续 阶段推进必须符合该成语/故事的公认情节因果

### 四、参考图生视频（成片生成）

**执行原则：** 严格按幕顺序（第一幕→最后一幕，与情节时间顺序一致）逐幕生成，参考图生视频模式固定使用 Seedance 2.0，720P。

**每幕生成前必须：**

1. 展示该幕完整的图生视频提示词（即 Step 三 的产出，逐字，不做任何精简）
2. 明确列出本次将使用的参考图（角色参考图 + 场景参考图 + 道具参考图，缺一不可则说明原因）
3. 展示预计消耗积分数量

### 五、剪辑合成（配乐 + 讲解旁白 + 统一字幕 + 拼接）

本 skill 不做多幕视频的实际拼接渲染，但需**产出完整的剪辑合成方案**，供用户在剪辑软件中执行，或调用下游 AI 配乐/AI 配音工具生成对应素材（涉及 AI 生成调用同样需先展示内容与积分消耗，等待确认）：

1. **配乐方案**：依【画风锁定】与故事情节情绪曲线（铺垫轻快/悬疑→冲突紧张→转折→结果释然/警醒→寓意升华），给出配乐风格提示词（乐器编制、节奏、情绪走向），标注建议使用的幕数区间
2. **讲解旁白文案**：为每一幕配一段精简讲解旁白，**文字须紧扣该幕画面内容**，文字不要太多，确保能在对应时长内念完，核心功能是**讲解/科普该成语或小故事**（出处、情节、寓意/道理），语言凝练、口语化、适合科普讲解语境，避免与画面内容平铺直叙式重复；结尾幕旁白须明确点出该成语/故事的寓意或道理；旁白音色采用 `narration_voice_ref`（用户指定的角色音色或依题材推荐的默认讲解音色）；逐幕列出"旁白文案 + 建议配音时长（应落在该幕10–15秒时长内）"
3. **字幕方案**：字幕文本与旁白文案一致（或做适度精简以便阅读），标注建议使用的**字体**——须符合故事题材调性（如古风成语典故推荐书法感/衬线字体，现代寓言推荐清晰易读的黑体类字体），**全片统一使用同一字体，不得逐幕更换**，具体字体名称依用户设备/软件可用字体给出建议，并可在展示后调整
4. **拼接说明**：各幕文件按序标注幕数、时长、对应情节阶段，提供拼接顺序、旁白/字幕对轨建议、转场衔接提示（依 Step 三 已设计好的动作/空间/状态连续性，直接顺序衔接即可）
