# 理念与审美｜V2.1

> V2.1 的上位原则：任务正确性、空间成立性和可见因果优先于固定审美套路。Skill 的职责不是堆术语，而是把用户的创作意图编译成模型可执行的视觉关系。

## 一句话总纲

**先判断任务，再建立关系；先锁结构，再做观看；先解决可见问题，再使用风格手段。**

# 1. 任务本体优先

人物、产品、场景、资产、海报、照片的成功标准不同。

任何电影感、去 AI、极简、厚涂、构图套路都不能覆盖任务本体。

对于 Scene / Environment：
1. 先判断 L / M / S 控制尺度；
2. 建立空间为什么这样形成、如何使用；
3. 必要时建立世界身份与功能地编；
4. 锁定 Camera；
5. 最后才做构图、光影、色彩、成像与 Prompt 压缩。

# 2. 关系与因果优先于元素清单

不要从“画面里要有什么”直接推导场景。

优先判断：
- 什么决定了空间结构；
- 哪些关系能让第一读取成立；
- 哪些元素是结构结果，而不是装饰性追加；
- 哪些信息在当前尺度实际可见。

Reference 可以内部推导完整逻辑，最终 Prompt 只保留真正改变结果的少量可见关系。

# 3. 空间设计与摄影表达分离

空间设计回答：
- 什么在哪里；
- 为什么在那里；
- 如何连接；
- 如何被使用；
- 如何长期生长或维护。

摄影表达回答：
- 摄影机在哪里；
- 看什么；
- 视线如何经过画面；
- 什么被强调、遮挡或弱化；
- 光和成像如何帮助观看。

摄影可以揭示空间，但不得为了构图重新发明空间。

# 4. 世界身份来自系统，不只来自装饰

架空、奇幻、科幻或强文化身份场景中，世界观应进入：
- 建筑语法；
- 公共设施；
- 门窗、灯具、交通、排水、标识等基础系统；
- 功能性物件；
- 少量稳定重复的材料 / 形状 / 符号语法。

旗帜、徽记、雕像、发光物只能辅助，不足以独立承担世界身份。

世界身份不能牺牲场景功能和现实尺度。

# 5. 真实感服从生命周期

真实不是“更脏、更旧、更破”。

- Active / Maintained：完整、可用、持续维护，允许局部新旧差异和行为解释得通的使用状态。
- Active / Worn：结构仍可用，工作热点可更粗粝，但通行与主操作仍清楚。
- Inactive / Abandoned / Ruined：只有设定允许时才开放积尘、侵蚀、垃圾、植物侵入、坍塌等结果。

**古老 ≠ 废弃；整洁 ≠ AI；真实 ≠ 脏乱。**

# 6. 信息密度必须有功能依据

场景不应全图同频。

宏观层：由 `16` 决定复杂区 / 过渡区 / 安静区。  
局部地编层：由 `18` 根据行为热点组织功能物。

高频使用区可以信息更丰富，但主通道、主工作面和关键空间关系必须保持可读。

# 7. 电影感来自观看关系

电影感不等于固定风格包。

不默认：
- 青橙；
- 唯一暖灯；
- 极端光比；
- 雾和神光；
- 浅景深；
- 前景遮挡；
- anamorphic；
- film grain；
- 极端高低机位。

电影化首先解决：

**Camera Position → Viewing Subject → Visual Route → Depth / Light Hierarchy → task-appropriate imaging**

其中任何手段都必须服从用户 Camera 与场景结构。

# 8. 构图是工具，不是模板

三分、三角、对角线、S 曲线、对称、框景、前景遮挡等都是条件工具。

平视、居中、中景、无前景本身都不是错误。

构图只在以下情况使用：
- 用户明确指定；
- 已成立空间天然呈现；
- 能解决当前明确的视觉问题。

# 9. 材质描述匹配尺度

远景不写微观磨损；城市鸟瞰不控制抽屉边缘；小空间也不需要把每种材质写成百科。

材质只保留：
- 身份所需主材质；
- 当前距离可见的表面响应；
- 生命周期允许的状态差异。

不要用“精确磨损控制”替代功能使用状态。

# 10. 自检闭环

失败结果先归因：
- 身份 / 尺度 / 结构；
- 世界身份；
- Camera；
- 构图；
- 电影影像；
- 材质 / 物理；
- Prompt 过载。

一次只修主要失败层，已通过层保持锁定。

# 11. 语言与版本纪律

- Midjourney Prompt 默认使用规范英文 ASCII。
- 中文用于讨论、诊断与说明。
- 未指定版本时默认 `--v 8.2`。
- 不把旧母版参数迁移成全局默认。
- 最终清除异常 Unicode、随机外语、无功能元话语。

# 12. 多轮状态继承

修改时先重建：
- 当前有效参考图及职责；
- 当前锁定项；
- 本轮修改变量；
- 已废弃信息。

最终只交付当前有效版本，不保留修改历史。
