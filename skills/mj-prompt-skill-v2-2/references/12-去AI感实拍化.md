# 去 AI 感与物理可信度｜Repair Reference

> 本文件只负责**诊断当前最明显的物理可信度缺口并做局部修复**。它不是风格模板，也不是第二套摄影系统。

# 1. 路由边界

场景任务中：
- Scene Structure / Use State / Camera 服从 `16-场景设计与环境编译.md`。
- 世界身份、Activity Cluster 与功能地编服从 `18-世界身份与功能地编.md`。
- 已启用电影化时，Viewing Route / Lighting / Color / Atmosphere / Focus / DOF / Exposure / Optical Response 服从 `17-电影摄影执行与成像.md`。
- 本文件只修复没有被上述状态解决的材质、表面、物理、人体或未来硬件可信度问题。

不得因为“去 AI”自动加入：
- 破败、积灰、垃圾、锈蚀、墙皮脱落
- film grain / halation / flare / anamorphic streak
- shallow depth of field
- foreground obstruction
- handheld / crooked framing
- teal-orange grading
- heavy fog / god rays

高维护、崭新、洁净、精致的空间同样可以真实。

# 2. 先诊断，不做全套

一次 repair 优先只处理 1–3 个最明显问题。

| Failure Code | 典型症状 | 首选修复 |
|---|---|---|
| `material-uniformity` | 所有表面同一抛光度、塑料 PBR 感 | 区分材料微观结构、反射特性、接缝与表面处理 |
| `wear-mismatch` | 正常运营空间被全局做旧 | 按生命周期收回破损，只保留维护层次与接触磨损 |
| `lighting-unphysical` | 无来源补光、所有区域同亮 | 若非电影化，补真实光源与衰减；电影化任务返回 `17` |
| `exposure-unphysical` | 亮暗全都完美可读、HDR 感 | 电影化任务返回 `17`；普通照片按真实动态范围处理 |
| `optical-overperfect` | 全画幅算法级锐利、无真实焦点 | 电影化任务返回 `17`；普通照片按摄影语境修正 |
| `color-too-clean` | 色块分区过工整、材质固有色各自抢眼 | 建立环境综合色偏移与自然反射污染 |
| `skin-plasticity` | 油亮、蜡感、磨皮、数字人 | 修皮肤微观结构、局部反射与自然色差 |
| `future-hud-cliche` | 悬浮 HUD、满屏蓝光、无实体设备 | 改为实体硬件、嵌入式屏、按钮、接口、线缆与维护结构 |
| `physics-break` | 物体漂浮、接触无重量、结构不受力 | 明确重力、支撑、接触、连接和材料受力结果 |
| `world-identity-weak` | 架空场景只靠旗帜 / 徽记，像现实城市换皮 | 返回 `18` 重建 World Identity，不在本文件堆装饰 |
| `set-dressing-random` | 道具平均散落、杂而无功能 | 返回 `18` 用 Activity Cluster / Behavior Hotspot Density 重编 |

如果问题属于 Camera、Composition、Cinematic Imaging，本文件不自行补救，返回对应权威 Reference。

# 3. Material Repair｜材质写成可见原因

优先结构：

**material + surface treatment + microstructure + reflection behavior + state-consistent variation**

避免只写：
- realistic metal
- premium material
- ultra-detailed texture
- high-end PBR
- photorealistic surface

可见描述示例：
- **brushed metal**：fine directional brushing, muted directional reflection, narrow highlights on exposed edges, darker recesses
- **aged hardwood**：visible grain, low-gloss rubbed edges at frequent contact points, repaired joints, slight color variation between replaced boards
- **painted steel cabinet**：matte painted surface, small chips limited to handles and corners, subtle denting and uneven sheen
- **plaster / masonry**：fine aggregate, repaired patches, slight tonal variation, localized hairline cracks only when structurally plausible
- **glass / coated polycarbonate**：soft environment reflection, minor smears or wiping traces where handled, dark edge seals
- **woven fabric**：visible weave, soft folds governed by gravity, wear concentrated on folds / cuffs / contact points

不同材料不应拥有同一高光宽度、粗糙度或老化程度。

# 4. Use-state Repair｜真实不等于破败

## Active / Maintained
优先：
- intact structure
- usable work surfaces
- functioning fixtures
- localized repairs / replacement layers
- touch-polished handles, step edges, desk fronts
- small non-uniform material differences

不要自动出现大面积：rust / grime / debris / peeling / crumbling / mold。

## Active / Worn
允许更多长期使用痕迹，但仍保持：
- circulation clear
- equipment usable
- repairs visible
- damage localized rather than global

## Abandoned / Ruined
只有场景状态明确允许时，才使用结构破损、失修、积尘、侵蚀等强信号。

维修 / 修复类空间的明显破损优先归属于**待修工件**，不是工作室本体。

# 5. Skin / Human Repair

当人物出现且有塑料 / 数字人问题时，优先修复：
- natural matte-to-subtle-oil variation rather than full-face gloss
- visible pores / fine skin texture at appropriate shot distance
- slight natural color variation around nose, cheeks, lips, eyelids
- small asymmetry in brows / hairline / expression
- hair strands and flyaways consistent with hairstyle
- scene-motivated light instead of beauty frontal fill

避免把“真实”理解成必须丑化、疲惫化、加伤疤或加污渍。

# 6. Hard-Sci-Fi Repair

如果未来空间漂向“伪科技”优先把抽象发光替换成实体功能：
- embedded physical screens with dark glass when inactive
- buttons, switches, knobs, valves, ports
- seals, hinges, fasteners, cable management, access panels
- matte engineered metal / composite / rubber / glass differentiation
- restrained status lights with functional purpose

HUD / hologram 只有任务明确需要时出现。

# 7. Color Contamination｜自然综合色差

真实环境中的颜色会受到：
- dominant illumination
- reflected surfaces
- atmosphere
- material roughness
- exposure

影响。

因此避免每件物体都保持干净、独立、饱和的“产品色”。

Repair 时只需要写当前最关键的环境综合色关系，不建立另一套调色系统；电影化场景的最终 Color Field 仍由 `17` 决定。

# 8. Repair Output Rule

最终只 materialize 当前缺口对应的修复句。

例如：
- 材质假 → 只替换材质描述
- 高维护空间被做旧 → 删除全局破损词，改成局部接触磨损 / 维护层次
- 未来空间 HUD 化 → 替换为实体硬件关系
- 人脸塑料 → 只修皮肤与受光

不要在最终 Prompt 末尾追加“去 AI 感套餐”。
