# 六维选型库

> 六条互不绑定的独立轴：S画风 · G色调 · L光影 · C构图 · F质感 · M材质。逐维挑选、自由重组——换任意一维，同一题材就是全新气质。

**调用顺序**：①先确定当前任务目标；②只读取真正相关的轴；③各轴只提供候选语言，不覆盖任务专用权威 Reference；④最终只 materialize 会造成可见差异的选择；⑤交付前过自检。


## 场景任务接口（高优先级）

V2.1 路由提示：本库是候选集，不是自动套用的审美预设。风格必须来自本轮用户/有效风格参考；构图方案须由 `16` 先锁主导视觉关系、Camera Contract 与场景结构。只有指定或天然符合时使用三分、对角、三角、S 曲线、框景等，不新增场景实体配合模板；电影光学由启用时的 `17` 处理。

场景任务调用六维库时，只做“选型”，不把六个维度各写一段。
- 场景任务的物理机位与画面组织由 `references/16-场景设计与环境编译.md` 主导；C 构图库仅在用户明确要求，或已成立空间天然适合某种构图关系时辅助使用，不自动套模板。
- 架空 / 历史文明身份与功能地编由 `references/18-世界身份与功能地编.md` 主导；六维库不得另建第二套世界观装饰或地编规则。
- 明确电影化场景的最终 Lighting / Color / Focus / Depth of Field / Exposure / Optical Response 由 `references/17-电影摄影执行与成像.md` 主导；G / L / F 只作为候选，不再另写第二套。
- `10-电影视觉美学体系.md` 只提供电影风格坐标，不与 `17` 并列输出灯光系统。
- M 材质只补最能建立题材身份的材料表现，不生成完整材料百科。
- F 质感只在当前画面确实存在“塑料 / 数字感”风险时选取，不默认叠加胶片、光学瑕疵和做旧。
- 宽画幅由 `--ar` 控制，不因选择电影感自动加入 anamorphic widescreen / letterbox 语义。

## S 画风库

- S1 油画厚涂：可见笔刷、叠色飞白、边缘不数码光滑——史诗风景/浓烈情绪
- S2 写实电影级CG/概念艺术：近实拍材质响应、受控尺度与光影、按环境条件决定空气透视——魔幻/废土/科幻宏大叙事
- S3 超现实观念：现实材质做违背物理的排布（悬浮/螺旋/文字具象化）
- S4 电影实拍胶片感：35mm颗粒、微褪色、光学呼吸、像电影截图非摆拍——叙事/历史/战争/犯罪
- S5 时尚编辑/艺术摄影：控光、雕塑化造型、极简背景、服饰廓形为主体
- S6 长曝光慢门摄影：环境拖影流动、唯一主体清晰
- S7 东方古风情绪人像：湿发/局部脸/逆光发丝/暗背景/东方织物
- S8 胶片慢门写实人像：让时间流动、只让一人静止
- S9 平面/拼贴/海报：仅明确要海报KV时用

## G 色调库（具体色板，不只给"冷暖"）

- G1 青灰冷调：钢蓝青灰低饱和雾感几无暖色——疏离冷峻孤独
- G2 暖褐金：赭石琥珀古金微褪色——怀旧宿命诗意
- G3 墨绿自然：苔藓灰草绿压场去艳——原始静谧苍凉
- G4 黑金：近黑主域＋受控暖金 / 米黄强调——内省、仪式、权威
- G5 红黑极简：纯黑＋一条高饱和正红——危险复仇神圣暴力
- G6 霓虹赛博：暗底＋青/品红/紫/琥珀彩色光分区——迷幻危险地下
- G7 冷蓝＋暖火双色：冷青环境为主、橙火保持有限面积——战争、冲突、绝境
- G8 黑白高反差：去色硬对比颗粒——抽象力量仪式
- G9 强互补编辑色：墨绿×酒红/青蓝×朱红一大一小——张力惊艳
- G10 章节式变调：同组前段冷末段转暖——叙事弧线转折
- G11 焦糖褪色单色：卡其驼暖棕统一罩染、像晒旧人像胶片——温暖抽离
- G12 火红概念单色＋纯黑剪影：背景橙→红干净渐变、人物压纯黑——专辑封面感
- G13 褪色军绿/橄榄灰：墨绿＋灰做旧
- G14 高调米灰银白：冷白高调柔和漫射无硬影——空灵脆弱圣洁

**色彩使用规则**：饱和度与色域服从当前题材和风格目标。避免无理由让所有区域保持同等高饱和；强调色是否存在、出现几处以及面积大小均按任务决定。

## L 光影库（光型/布法，独立选型）

- L1 低调单束塑形光：大面积近黑只一束顶/侧光雕主体——内省/仪式/压迫/舞台
- L2 逆光剪影＋轮廓镶边：光源在背后、主体压深色剪影、肩线发丝镶亮边、正面不补光——宿命/孤独/史诗/去个体化
- L3 体积光/丁达尔（必须有介质）：光被雾尘烟水切成斜射光束、束中悬浮颗粒——神圣/神秘/希望；无介质不写光束
- L4 彩色凝胶/霓虹分区光：不同方向不同色光按空间分区
- L5 雾霭散射柔光：无明确光源方向无硬影、靠明度层次空气透视——苍凉/静谧/疏离
- L6 实用暖源/烛光（伦勃朗）：画面内可见烛/灯为源、暖摇曳暗、面部三角光斑
- L7 冷暖双源对撞：冷环境光铺底＋一处暖源、冷暖在主体上交界
- L8 湿面反射/反弹光：湿地积水把光源拉长倒影、向上微弹冷光补下缘
- L9 长曝光光流：运动光源人群拉丝、静止主体受恒定光
- L10 黄金时刻低角度暖光：低角度暖金长投影暖包裹
- L11 强主光大光比：单一方向硬主光、受光面与背光面形成明显分离；是否存在唯一最亮点由当前任务决定
- L12 逆光＋介质 / 湿面光学：只有存在真实逆光与雾尘水汽 / 湿面时，才候选体积束、轻微眩光或焦散；不自动组合全部效果
- L13 自发光/能量体配纯黑：发光体在深黑里由内向外衰减、暗场是发光前提
- L14 运动光学/慢门光条：长曝或径向变焦把光拉成条、主体可纯剪影
- L15 硬表面金属侧光：硬侧/顶光在金属舱体分锐利受光面与深黑结构面、棱线窄高光线、窗灯暖点
- L16 高调逆光冷暖分层：整体明亮、受光面暖金背光面冷蓝、靠冷暖而非明暗分层

**光影候选规则**：先判断可信光源与综合色关系；需要强戏剧性时再选择高反差或特殊光型。明确电影化场景的最终 Lighting / Value / Exposure 统一交给 `17`。

**场景任务例外**：不强制“唯一最亮点”或“逆光优先”。场景先建立少量大尺度 Value Groups，并让真实光源解释空间；局部高光只能强化已经成立的功能 / 空间层级，不能为了焦点制造舞台聚光。

## C 构图库（结构＋人物呈现）

### 场景构图接口（V2.1）

场景任务默认**不加载 C1–C21 作为起点**。先由 `references/16-场景设计与环境编译.md` 完成 Scene Read、Scene Structure、Use State、Viewpoint 与 Visual Organization；只有用户明确指定构图法，或空间本身天然匹配时才调用本构图库。

C1–C21 在场景任务中只作为辅助语言：
- 用户明确要求某种构图时使用；
- 已成立空间天然呈现某种关系时，可以轻量强化；
- 只描述已有的几何事实，不为了匹配构图法新增桥、道路、楼梯、建筑或前景框；
- 视觉重心可以是区域，不要求单一物体；
- “更重要”不自动等于更高、更大、更居中或位于构图顶点；
- Visual Flow 是结果，不要求所有线条汇聚到一个点。

如果使用构图术语，最终 Prompt 优先翻译成具体可见关系，并确保 Scene Identity 与功能逻辑不被改变。

- C1 中轴对称/一点透视纵深——秩序/神圣/仪式
- C2 人 vs 巨物尺度：极小人对极大建筑/雕像/浪潮——敬畏孤独宿命
- C3 框架/包围：前景伞/窗/门/廊/文字把主体框住——压迫聚焦
- C4 阵列重复韵律：相同元素成排成环——仪式规模超现实
- C5 负空间留白：主体占小面积大片同质空场——孤独诗意
- C6 高位平面组织：当用户已明确高机位，或 `16` 已锁定高位 Camera Contract 时，可利用地面 / 台面 / 阵列关系形成平面化秩序
- C7 两极景别：仅当叙事确实需要强尺度对比时使用大远景 / 极近特写；中景本身不是错误
- C8 人物弱化：背影/剪影/局部/不看镜头——情绪符号
- C9 引导线纵深：路/阶/廊/光束/河岸引向主体或远方
- C10 动静/虚实对比：慢门动vs静、虚前景vs实主体
- C11 低位垂直压迫：仅当用户已明确低机位，或 `16` 已锁定低位 Camera Contract 时，用垂直体量与上方结构强化压迫
- C12 斜向层级展开：在已锁定的高位斜俯 Camera 中，用前后层级和阵列关系展开空间；本条不自行决定机位
- C13 径向放射/变焦汇聚：线条四周向中心灭点放射（坠落/隧道/旋涡/光束）
- C14 超长一点透视纵深：廊/轴/峡谷/舱道向远方重复缩小
- C15 巨物出框压迫：巨构占满被画框裁切（不完整更压迫）、人压底/缘做尺度标点
- C16 倾斜荷兰角/对角线动势：故意倾斜、主体沿对角排布——不安与动势
- C17 前景遮挡临场层：虚化前景挡一下配中景主体＋远景退层
- C18 中心对称神圣聚焦：仅宗教/能量/神圣母题、主体绝对居中向心对称
- C19 三角 / 金字塔层级：主要体量形成稳定三角轮廓，视觉重心位于顶点或核心交汇——宏大、稳定、权重清楚
- C20 三分 / 偏心平衡：主体落在约三分交点或偏离中心，由次要体量 / 地貌平衡画面——自然、观察式、避免僵硬居中
- C21 S 曲线有机纵深：河岸、道路、山脊、廊道形成连续 S 形路径，由近至远引导视线——自然景观、城市岸线、有机生长

**机位态度总纲**：C1–C21 只描述构图关系，不承担场景物理机位执行。场景 Camera Height / Direction / Pitch / Distance / Focal Class 统一由 `16` 锁定；用户明确高俯、低仰、顶视、POV 时，任何构图模板都无权改写。平视、居中、无前景并非错误，只在它们与任务意图冲突时才调整。

## F 质感库（候选，按需 0–2 项）

- F1 油画厚涂：笔触叠色飞白颜料肌理
- F2 35mm胶片：细颗粒微褪色高光晕开光学呼吸
- F3 数字电影干净：清晰、克制、低噪点；空间层次通过真实光线、空气透视或焦点关系建立，不强制体积雾
- F4 慢门拖影：运动方向拉丝
- F5 老影像/CRT：扫描线雪花噪点信号不稳
- F6 条件性光学响应：只有镜头与光源条件支持时，候选自然边缘柔化、轻微眩光、焦外或变形镜头特征；电影化场景由 `17` 决定
- F7 湿润finish：水膜雨丝水雾、湿面拉长高光
- F8 颗粒/噪点/做旧：只在照片 / 电影截图 / 明确胶片语境需要时使用；场景美术图不把 film grain 当作默认“去AI”解药
- F9 黑白银盐：银盐颗粒硬灰阶

## M 材质库（一律"成因式"写法）

**最高原则：不靠“真实金属 / 高级质感 / 极致细节”等结论词代替可见材料信息。只写当前尺度真正可见且会改变结果的材料、表面处理、纹理与反光；磨损 / 老化仅在生命周期与镜头距离允许时加入，不要求每种材质都写微观磨损。**

- M1 金属：明确锻造 / 拉丝 / 喷砂 / 涂层等表面处理与对应反射；磨损、氧化、积垢只在生命周期允许时加入
- M2 丝/绸/纱：重磅垂坠反柔光、深陷暗褶间夹一线流动高光、随动作飘起有惯性
- M3 棉麻/粗织/斗篷呢：纤维粗粝吸光边缘起毛褶皱硬挺
- M4 石/砖：可见接缝、矿物颗粒 / 层理与自然反射差异；裂隙、苔藓、冲刷、包浆按环境和维护状态选择
- M5 木：木纹、榫卯 / 接缝、低至中等反光与使用区色差；漆面剥落只在状态允许时加入
- M6 苔藓/植被包覆：绒状层叠阴湿深浅斑驳呈吞噬覆盖之势
- M7 玻璃/彩窗/酒瓶：透折射透色光洒地边缘高光线瓶身环境倒影
- M8 水/雨/积水：皮肤面料凝成连续水膜、高光拉成细长亮线、积水面竖向拉长光源倒影
- M9 纸：泛黄卷边可见纤维薄处透光悬浮翻转有正反面
- M10 皮肤/毛发：按景别保留自然毛孔 / 绒毛与局部反射差异，不磨皮不塑料；头发的湿润、成绺、逆光或碎发只在当前状态成立时使用
- M11 皮革：天然纹理折痕哑光磨损包浆

**状态差异服从使用与生命周期。** 近距离任务确实需要磨损时，可优先放在有行为依据的接触位置；中远景不做精确微观磨损控制。不同材料可以有不同完成度，但不要用全场均匀做旧制造“真实”。
