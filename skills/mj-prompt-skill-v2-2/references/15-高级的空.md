# 高级的空（极简留白配方）

> 学自"布谷鸟"教程：怎么写 Prompt 让画面有"高级的空"。核心——元素少但不空，每个元素各司其职；不是加细节，是先定三问。

## 五元素分工论

| 元素 | 负责什么 |
|---|---|
| 建筑/结构 | 画面骨架（宫墙、亭子、茶室） |
| 树/自然元素 | 打破秩序（视觉重心） |
| 人物 | 比例尺（告诉你这墙多大） |
| 天气 | 情绪（雪/光/雾） |
| 颜色 | 记忆点 |

## 六维拆解公式

```
Scene场景 + Structure主结构 + Nature自然元素 + Scale尺度 + Weather天气 + Color配色
```

**示例（中式宫墙）**：
```
a long coral-red palace wall 一整面珊瑚红宫墙
+ deep emerald-green roof line 深绿琉璃瓦屋檐
+ a single ancient wisteria tree 一棵紫藤古树（视觉重心）
+ pale ivory steps 米白石阶（留出呼吸感）
+ late spring afternoon light 晚春午后光线
+ coral red / emerald green / violet purple 三主色强对比
```

## 三句真经

1. **不是加细节，是先定三问**：谁最大、谁最亮、哪里最安静
2. **配色按场景换血**：
   - 雪景：cinnabar red 朱红 + ice blue 冰蓝 + charcoal black 炭黑
   - 湖边亭子：sapphire blue 蓝宝石蓝 + saturated gold 金黄 + muted vermilion 暗朱红
   - 春/宫廷：coral red 珊瑚红 + emerald green 翡翠绿 + violet purple 紫
3. **Prompt写得像美术指导，先搭建画面的关系，电影感自然出现**

## 可复用模板（MJ 纯英文）

```
A lone [structure, e.g. long coral-red palace wall with deep emerald-green roof line],
a single [nature element, e.g. ancient wisteria tree] as the visual anchor,
a tiny human figure for scale,
pale [color] steps / empty ground for breathing room,
[time & weather light, e.g. late spring afternoon light / soft snowfall / morning mist],
three-color palette with strong contrast: [A], [B], [C],
minimal composition, vast negative space, quiet stillness,
[去AI感：胶片颗粒/光学瑕疵/材质成因式，见 references/12]

```

## 与 Skill 的挂接

- 与 `05-东方美学词库索引` 的"诗意山水/留白"体系同频，东方配色优先用传统色名（朱砂/石青/鎏金…）
- 与 `10-电影视觉美学体系` 的 C5 负空间留白构图、G14 高调银白互为补充
- 极简场景同样适用光影铁律：一个最亮点、一处饱和锚点、暗部敢黑
