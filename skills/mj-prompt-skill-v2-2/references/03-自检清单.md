# 自检清单｜V2.2

> 只检查会明显改变结果的问题。检查项不能再次变成 Prompt 内容。

# 0. 场景任务失败阻断门

- [ ] **Style**：风格来源是本轮明确指定、被赋予职责的当前风格参考或确定的媒介；`DEFAULT_VISUAL_STYLE = NONE`，未默认写 CG/摄影/电影截图。
- [ ] **Identity**：主体的关键外形、类别、数量、连接与功能锚点在本轮机位可以被读取，且未被艺术技法重新发明。
- [ ] **Causal**：复杂主体的必需部件存在可读支撑/传动/连接或相应可见关系；现实性依本轮风格决定。
- [ ] **Design Intent**：有一个明确主导视觉关系，构图展示它而不修改场景空间事实。
- [ ] **Camera Decision**：用户未锁机位时，内部比较过至少两个可行观察点；选定镜头兼顾身份、结构与美感；用户已锁机位则不重选。
- [ ] **Media Translation**：电影化（仅明确要求时）与用户媒介兼容；手绘效果保留笔触/边缘/色层而不是强制写入相机胶片词。
- [ ] **Style Signals**：文字风格和图像风格共用 `19` 的视觉语言；已选的主风格锚点有具体可见后果，没有只列风格名、形容词和多个相近技法。
- [ ] **Reference Scope**：风格图不自动覆盖场景、地标、人物、结构与镜头；只有用户授权的形态设计规律才可迁移，具体参考对象不复制。
- [ ] **Reference Portability**：聊天图片没有被冒充为 MJ 在线链接；Style Reference 不被误写为普通 Image Prompt。

# 1. 通用 Gate

1. **Task**：是否为以场景 / 环境为主体的任务，且没有将非场景请求强行编译为 Scene。
2. **Current Constraints**：本轮画幅、参考图职责、身份、结构、Camera、用途是否全部保留。
3. **Reference Roles**：每张当前参考图职责是否唯一，是否发生跨图属性串用。
4. **Routing**：是否只调用必要 Reference；同一维度是否只有一个执行权威。
5. **Language**：MJ Prompt 是否规范英文 ASCII，无异常 Unicode、随机外语和聊天级指代。
6. **Negative**：是否只针对真实高风险，正向与 `--no` 是否互相冲突。
7. **Model Contract**：用户没指定版本时是否存在 `--v 8.2`；用户指定其它版本时是否正确覆盖；V8.2 是否未使用 `--q`。
8. **Delete Test**：删掉一句后若无法预测明确画面变化，优先删除。

# 2. Scene QA

## 2.1 Identity

- [ ] 第一眼就是目标场景 / 空间类型。
- [ ] 身份来自结构、工作流或系统关系，而不只靠标签、旗帜、徽记、道具清单。
- [ ] 最强视觉信号没有把场景带向相邻错误原型。

## 2.2 Scale Routing

- [ ] L / M / S 是按当前画面控制粒度判断，而非按建筑绝对尺寸机械判断。
- [ ] L 没有被桌面物、摊位、单件家具等微观规则污染。
- [ ] M 没有自动膨胀成多层纪念性城市核心。
- [ ] S 没有重新解释整座城市、国家或完整城市规划。

### L
- [ ] city / capital / large complex 有连续区域尺度和多系统关系，不缩水成少量单体。
- [ ] 一级核心可以存在，但没有垄断整座城市身份。

### M
- [ ] 功能空间尺度由实际用途决定，而不是由机构等级自动放大。
- [ ] 一个主要功能空间 + 1–2 个连接方向 + 适量视觉锚点足够时，没有无理由增加巨型台阶 / 平台 / 纪念门。

### S
- [ ] 门窗、工作面、局部通行、功能物和人的使用距离成立。
- [ ] 没有城市级地标来替代近距离世界身份。

## 2.3 Structure

### L
- [ ] 地理、交通、主要系统和历史生长存在因果关系。
- [ ] 当前 Prompt 只保留少量一级关系，而不是把完整城市规划逐项输出。
- [ ] 若强调 junction / gateway / confluence，至少一组汇合关系可见。

### M
- [ ] 功能原型先于建筑壳子。
- [ ] 2–4 个关键工作流节点与邻接成立。
- [ ] 结构柱网、门洞、楼梯、公共 / 限制边界支持功能，不像独立装饰系统。

### S
- [ ] 主操作、主工作面、高频支持、低频收纳关系成立。
- [ ] 2–4 个职业 / 功能锚点足够，没有长物件清单。

## 2.4 World Identity / Set Dressing

仅命中 `18` 时检查：
- [ ] 世界身份进入建筑 / 基础设施 / 公共设施 / 日常物件，而非只靠 banner / emblem / statue。
- [ ] 幻想性是功能化、系统化的，不是随机巨型奇观或大量发光装饰。
- [ ] 不同功能区可以有层级差异，但仍属于同一文明视觉语法。
- [ ] 地编按 Activity Cluster 聚合，而不是均匀撒道具。
- [ ] 高频功能区信息更丰富但受控；主通道与主工作面保持畅通；低频区更安静而不是更破败。
- [ ] 未使用精确微观磨损作为主要真实感控制手段。

## 2.5 Use State

- [ ] 生命周期 / 维护状态正确。
- [ ] Active / Maintained 先读成完整、可用、持续维护。
- [ ] 历史感来自长期生长、替换、材料成熟和有限使用状态，不是全场破损。
- [ ] `ancient / old / historical` 没有自动触发 ruins / debris / weeds / crumbling。

## 2.6 Camera

- [ ] 用户明确 Camera / POV 是硬约束。
- [ ] 高俯 / 低仰 / top-down 通过真实位置与 Pitch 产生几何后果。
- [ ] 没有 `eye-level` 与明显高俯 / 低仰冲突。
- [ ] 景别与焦段没有混为一谈。
- [ ] 构图没有为了“更好看”改变已锁定空间结构。
- [ ] 首读主体、主导视觉关系与视觉终点可读；不过度偏向任何单一机位类型。
- [ ] 信息高频区与视觉休息区均基于场景已存在的形体与空间。

## 2.7 Cinematic Image System

仅明确电影化时检查：
- [ ] `17` 消费已锁定 Camera，没有重新选机位。
- [ ] Viewing Subject 明确，且仍是上游 Scene Read 允许的目标。
- [ ] Visual Route 由已有结构、明暗、重叠和空间层级形成。
- [ ] Occlusion 只在有价值时出现，不是默认前景黑框。
- [ ] Depth Hierarchy 不靠一层前景虚化 + 一层白雾伪造。
- [ ] Light Hierarchy 有真实光源，不要求唯一最亮点。
- [ ] 景深按任务决定，不默认浅景深。
- [ ] 没有自动加入 teal-orange / god rays / heavy fog / film grain / anamorphic / extreme angle 套餐。

## 2.8 风格信号与尺度可见性（仅本轮有风格需求时）

- [ ] **L 大场景**：风格优先通过整体形体概括、主色域、空气透视、细节频率和轮廓节奏成立；没有用眼睛看不清的微观笔触来冒充风格控制。
- [ ] **M 中尺度**：主次形体、设计化材质、明暗组织和边缘节奏可辨。
- [ ] **S 小场景**：风格由近距离形态、材质/表面处理、线条、笔触、纹理和局部光影成立；不照搬宏观地理镜头的控制语汇。
- [ ] **2D/3D/摄影边界**：二维绘画不被真实三维材质覆盖；风格化三维不被纯纪实摄影替代；明确摄影不被 CG 质量词污染。
- [ ] **风格图辅助**：若用户希望原生引用，已明确使用 MJ Style Reference 槽或有效 `--sref URL`；否则以文字提炼实现且不伪称直接引用。

## 2.9 Density / Prompt Integrity

- [ ] 宏观有复杂区 / 过渡区 / 安静区，不全图同频。
- [ ] 局部功能物密度与宏观密度没有重复成两套规则。
- [ ] 质量词没有连续近义堆叠。
- [ ] `--ar` 已控制画幅时正文没有重复宽幅语义。
- [ ] 同一维度没有两个 Reference 同时给出不同答案。

# 3. Conflict Audit

如果发现冲突，按以下顺序处理：

1. 保留 P0 当前用户明确要求；
2. 保留当前参考图 / 资产锁定；
3. 保留任务身份；
4. Scene 时保留 `16` 的 Scale / Structure / Camera；
5. 保留 `18` 的世界身份 / 局部功能地编，但不得越权；
6. 保留 `17` 的电影影像执行，但不得越权；
7. 删除低优先级构图候选、质量词和负面词。

不要把两套冲突规则折中写进同一 Prompt。

# 4. 失败回退

- Style 来源错误或跨域污染 → STYLE_STATE / 媒介转换
- 主导关系模糊、画面平铺 → Design Intent / Visual Organization
- Identity / Scale → Scene Read / Scale Router
- Structure → L/M/S Structural Compiler
- World identity / cultural drift → `18` World Identity
- Random clutter / showroom / dead environment → `18` Set Dressing
- State → Use State
- Camera → Camera Contract
- Composition → Visual Organization
- Cinematic feel → `17`
- Material / physics → `12`
- Prompt overload → Delete Test / Semantic Compression

修复时只使失败层与必要下游失效，已通过层继续锁定。

# 5. 交付前

- [ ] 当前输入与附件已读全。
- [ ] 没有把失败记录、批评、修改理由写进最终 Prompt。
- [ ] 当前参考图编号与职责正确。
- [ ] 最终 Prompt 脱离聊天历史可以独立使用。
- [ ] 用户明确禁止生成图片时没有触发生成。
