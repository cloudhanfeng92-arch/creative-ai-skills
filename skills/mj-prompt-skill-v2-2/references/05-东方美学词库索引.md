## 融合路径（五步）

1. **判定体系**：按主题关键词选词库文件（可多选混合）
2. **读取词库**：提取固定母版、场景元素库、光色公式、构图库、负面词、硬参数；必须使用词库真实词汇，不得凭空替换核心元素
   - **词库未覆盖的主题（11 体系外）**：先外部搜索同风格参考 prompt 与色彩光影参考，再进入组装
3. **元公式九步组装**：镜头取景 → 空间关系 → 固定母版 → 动作叙事 → 场景元素 → 光线两件套 → 风格收尾 → 负面词 → 硬参数
4. **输出规则**：纯英文、因果叙述＋硬参数、区分空间关系与运镜路径、禁止过度完美、配色光影有参考
5. **自检清单**：纯英文无残留、母版元素全部来自词库、空间与运镜分列、主光＋补光两件套、负面词含防翻车项、硬参数完整、因果链通顺

## 词库特色纪律

- **东方女子肤质定词**：温润白皙 / 冷白通透 / 粉嫩透亮
- **神情定气质**：清冷疏离 / 明媚烂漫 / 安静淡然
- **光影永远两件套**：主光（方向＋色温＋性质）+ 补光（青色/金色/暖色）
- **材质点名才有质感**：珠光丝绸 / 棉麻 / 薄纱 / 大理石 / 淡玉 / 哑黑 / 鎏金
- **风格收尾按体系切换**：cinematic film keyframe / stylized realism / painterly gouache / poetic landscape
- **通用负面词**：text, logo, watermark, extra fingers, malformed hands, plastic skin, modern objects, neon
