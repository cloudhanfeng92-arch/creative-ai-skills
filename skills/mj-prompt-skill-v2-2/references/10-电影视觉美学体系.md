# 电影视觉美学体系｜风格坐标库

> 本文件负责**电影类型 / 导演气质 / 综合色彩与氛围方向的风格坐标**，不是摄影机、灯光、景深或曝光的第二执行层。
>
> 场景任务中：`16` 锁定空间与 Camera Contract；`10` 只提供 Style Coordinate；`17` 将该坐标转换为最终 CINEMATIC_IMAGE_STATE。

# 1. 职责边界

本 Reference 可以决定：
- 情绪基调
- 主色域倾向与综合色彩关系
- 光质 / 时间感的大方向
- 氛围介质倾向
- 材质与世界类型的视觉母题
- 特定电影类型 / 导演气质的高层视觉坐标

本 Reference 不直接决定：
- 场景身份、功能、建筑 / 道路 / 节点布局
- Camera Height / Direction / Pitch / Distance / Focal Class
- 最终构图几何
- 最终 Value Structure / Exposure
- 最终 Focus / Depth of Field
- 镜头瑕疵与光学特效

用户明确锁定的任何视觉要求优先于本库。

# 2. STYLE_COORDINATE_STATE

只需要内部形成 3–5 项：

1. **Mood**：冷峻、温暖、压抑、荒凉、神圣、暧昧、梦幻、粗粝等。
2. **Color Family**：单色 / 邻近色 / 互补关系 / 低饱和自然色 / 高彩风格化等。
3. **Light-quality Tendency**：硬 / 柔、自然 / 人工、冷 / 暖、洁净 / 脏杂等方向，不在这里写最终布光。
4. **Atmospheric / Material Motif**：雨、烟、水汽、尘、雪、湿面、粗砺金属、旧石、丝绸等；必须与场景真实条件兼容。
5. **Visual Character**：克制观察、商业洁净、哥特仪式、诗意留白、潮湿都市、粗野主义巨构等。

输出给 `17` 的是这些结论，不是整份词库。

# 3. 上位原则

- 电影感来自关系，不来自术语数量。
- 色彩先统一，再变化；强调色不要求固定比例。
- 光质方向服务情绪，但最终光源、明暗组与曝光由 `17` 执行。
- 雾、雨、烟、尘等首先是环境条件，不是“电影滤镜”。
- 不把某一部电影 / 某一导演的所有标志一次性复制到一张图。
- 一个 Style Coordinate 最多保留最能改变结果的 2–4 个特征。
- 写实、商业、作者化、概念设计是不同目标，不自动互相借词。

# 4. 世界类型坐标

## 4.1 科幻

### Hard Sci-Fi / Realistic Space
- color: cold neutral gray, steel blue, subdued off-white
- character: engineering realism, restrained utility, physical hardware
- material motif: matte metal, composite panels, glass, insulation, seals, cables
- atmosphere: clean or mildly particulate depending on environment

### Cyberpunk / Dense Urban Tech
- color: dark urban base with localized saturated signage / practical light
- character: humid, crowded, layered, infrastructural
- material motif: wet concrete, glass, painted metal, cables, aging commercial surfaces
- guard: do not equate cyberpunk with full-frame neon or floating HUD

### Space Opera / Monumental Sci-Fi
- color: restrained mineral / metallic family with selected warm accents
- character: monumental scale, ceremonial technology, large massing
- material motif: stone-like composites, aged metal, large engineered surfaces

### Wasteland / Used Future
- color: dust, oxidized earth, faded industrial gray
- character: repair culture, survival utility, accumulated modification
- guard: used does not automatically mean collapsed or filthy

### Clean Minimal Future
- color: off-white, pale gray, muted cool accents
- character: precise, quiet, high-maintenance
- material motif: matte composite, glass, brushed metal, controlled joints

## 4.2 Western Fantasy / Gothic

### High Fantasy
- color: natural earth / stone base with restrained symbolic accent
- character: tactile, historical, inhabitable rather than theme-park fantasy
- material motif: timber, stone, iron, leather, woven cloth

### Dark Gothic
- color: deep charcoal / blue-black / aged metal / restrained dark red or warm gold
- character: solemn, oppressive, ritual, vertical
- material motif: weathered stone, forged metal, old timber, dark textile
- guard: darkness is not a mandate for ruin, fog, god rays or one warm beacon

### Magical Realism / Dark Fairy Tale
- color: grounded reality with one controlled tonal deviation
- character: ordinary space containing one impossible but materially convincing element

## 4.3 Eastern Xianxia / Chinese Fantasy

### Ink / Poetic
- color: ink gray, blue-gray, pale mineral colors, limited vermilion or muted gold
- character: restraint, atmosphere, negative space, distance
- material motif: stone, timber, silk, paper, bronze, jade

### Gongbi / Mineral Color
- color: stone blue, stone green, vermilion, muted gold, layered mineral tones
- character: decorative but controlled, formal, crafted

### Dark Zhiguai
- color: ink-black / indigo / old red / pale lantern tones
- character: uncanny, damp, nocturnal, folkloric
- guard: avoid western magic-circle vocabulary unless explicitly mixed

### Cultivation / Energy
- visual motif: flowing qi, haze, ink-like diffusion, silk / hair movement, translucent barriers
- guard: magical energy should inherit the world’s material language rather than default western geometry

# 5. 常用综合色彩坐标

These are candidate relationships, not presets:
- cool gray / desaturated blue: restrained, distant, austere
- warm ochre / brown / amber: memory, age, intimacy, heat
- moss / olive / mineral green: natural, damp, old, subdued
- near-black + restrained warm metal: ritual, authority, tension
- red + dark neutral: danger, ceremony, political force
- desaturated monochrome with one small accent: graphic control
- pastel muted family: gentle, artificial-order, stylized domesticity
- dirty mixed urban color: ambiguity, nightlife, psychological unease

Do not mechanically force one accent color or one brightest point.

# 6. 电影类型 / 导演气质坐标

只提取能迁移的高层视觉关系，不自动复制镜头、景深或构图。

- **Nolan-like large-format seriousness**: restrained palette, practical physical environments, monumental real scale, crisp material weight, controlled spectacle, sober dramatic tone.
- **Deakins-like restrained realism**: motivated natural/practical light tendency, desaturated harmony, simple visual emphasis, atmospheric restraint.
- **Wong Kar-wai-like nocturnal intimacy**: humid urban color contamination, mixed practical colors, emotional fragmentation, tactile night surfaces.
- **Wes Anderson-like formal stylization**: designed pastel relationships, graphic order, curated object rhythm, deliberate theatricality.
- **Zhang Yimou-like color dramaturgy**: strong chapter-level color identity, disciplined large color blocks, ceremonial rhythm.
- **Caravaggio-like dramatic chiaroscuro direction**: darkness as active negative information with selective illumination; final value ratio still belongs to `17`.

Named-style cues are coordinates only. If the user explicitly specifies camera language associated with that style, route the camera request back through the correct Camera authority rather than materializing it here.

# 7. Anti-Formula Gate

Do not automatically translate “cinematic” into:
- teal-orange
- black-gold
- one warm light in a cold frame
- heavy fog / god rays
- extreme contrast
- centered symmetry
- diagonal composition
- shallow depth of field
- foreground obstruction
- anamorphic flare
- film grain

These can be selected only when the current scene and user intent justify them.
