# 负面内容总表（电影向）

> 本表只是一组**诊断候选**，不是执行模板。最终负面词仍服从 `02-负面词库.md` 与当前任务硬约束，通常只选 1–3 类最高风险。任何“电影向常见雷区”都不能被当成全局禁止项。

## 破坏基调（按情绪反选）

- 通用：明亮、鲜艳、欢快、笑容、喜庆色彩、轻松氛围、糖果色
- 压抑/暗黑题材加：暖色调泛滥、明亮通透、希望感、明快、热闹
- 写实题材加：史诗感、悲壮、英雄化、唯美、戏剧化、广告感、仪式感过强、煽情
- 风格化题材加：平淡、记录感、路人感、廉价蓝领、普通、无情绪

## 破坏质感/材质（去塑料、去数字人）

- 塑料光滑皮肤、磨皮、瓷娃娃脸、油光锃亮、满脸高光、水光肌、玻璃肌、塑胶脸
- CG渲染感、3D渲染、游戏实时渲染质感、游戏CG、PBR塑料光泽、材质球感、过度光滑
- 数字人、虚拟人、3A过场质感、崭新塑料感、崭新发亮、物体无痕、过度均匀
- 廉价塑料光泽、整体均匀反光、镜面反射滥用、PBR油亮
- 过度锐化、边缘算法级锐利、过度HDR、HDR感过重
- 均匀做旧、每块板均匀污渍掉漆（＝又脏又旧又廉价）
- 结论词：真实材质、真实金属、真实丝绸、高级质感、精致做工、超精细、超真实、电影级质感、极致细节、masterpiece、best quality、8K、4K、超高清（要么删、要么成因化）

## 破坏光影（治"光影差"）

- 灰蒙蒙、均匀照明、全局大平光、无影柔光箱、环形美颜光、处处都亮、处处都看得清
- 当任务需要明确光影层级时：无主光逻辑、无明暗组关系、均匀补平；**不要求唯一最亮点，也不把低对比本身视为错误**
- 暗部发灰、死黑无层次（按基调反选其一）、光线无衰减、无来源光
- 无介质硬塞体积光、god ray、丁达尔、网红糖水光、唯美光柱滥用
- 过曝一片惨白、奇怪的过亮光、自发光乱入、无意义发光、发光描边
- 硬加熔金边缘、halation滥用

## 构图 / 机位漂移候选

以下只在**与当前任务意图冲突**时才作为负面候选：
- 用户要求观察式 / 非摆拍镜头时：证件照、礼仪摆拍、看镜头、刻意微笑
- 用户要求非对称 / 动态关系时：绝对对称、过度模板化居中
- 用户明确需要遮挡 / 偷看 / 框景时：过度开放的一览无余
- 用户明确需要干净主体时：无关人物、无关元素争抢

平视、中景、居中、完整主体、无前景本身都不是错误，不得作为通用电影感负面词。

## 技术瑕疵（按需）

- 异常畸变（非刻意鱼眼）、模糊一片、全图虚、低清、劣质、噪点满天飞（注意：去AI感不是降画质，一般不写，只在压制模型过度发挥时用）
- 穿模、漂浮、反重力、物体接触无反馈、肢体粘连、多肢、缺指、手指畸形
- 死黑、过曝、焦点全丢、色彩断层

## 风格污染

- 要**实拍电影 / 照片媒介**时：按需排除卡通、动漫、插画、CG 渲染感；若目标本身是 cinematic CG / realistic CG，则不得排除 3D / CG
- 要写实/厚涂时：游戏美宣、婚纱写真、商业立绘感、光滑锐利3D、网红滤镜
- 要东方玄幻时：西式板甲、欧美脸、金发、西式几何法阵硬边能量罩、荧光霓虹
- 要西式魔幻时：东方水墨脸、日式二次元脸乱入
- 混搭时防止东西方建筑/面孔/力量体系同框打架

## 文字/水印/穿帮

- 文字水印、logo、署名乱入、二维码、角标、UI、HUD界面
- 可读乱码文字、伪文字、满屏蓝光UI、悬浮全息、发光环、发光状态灯条
- 服装件数变化、颜色款式漂移、武器变样、坐骑变脸、伤口位置漂移
- 双主体歧义（前景主体局部＋深处完整同类＝两个）
- 跨镜持物手位/形态漂移、实体武器变独立光柱
- 满屏均匀白点贴纸式雪/雨/粒子（要有风向、疏密、景深、落地逻辑）

## 机甲/硬表面专项雷区

- 做成中世纪铠甲：皇冠羽冠、人脸面甲、羽毛翅膀、织金披风、贴合肌肉弧形甲片、浮雕卷草纹、贵族家纹盾牌、中世纪长剑骑枪
- 高达/量产军武感：圆润弧面圆鼓大块、敦实短腿五五身、圆形涡轮风扇背包圆喷口、圆润高达脸圆耳卡通圆V天线、明亮卡通塑料配色
- 质感四不要：整平板缺刻线黑缝、整体均匀反光到处亮、均匀撒脏掉漆、范式A/B之间摇摆
- 悬浮HUD、可读乱码（用编号/条纹/扫描雪花替代）

## 风格化角色（厚涂）专项雷区

- 游戏CG美宣/婚纱写真：3D般光滑锐利、人物完整端正站/坐进清晰实景、清晰美颜正脸、纯净礼服色块、礼服笔挺＋珠宝整齐＋皇冠端正
- 端正站姿、标准坐姿、礼仪摆拍、清晰正脸、锐利珠宝反光
- 空背景单人杵着、无"第二元素关系"

## 胶片慢门人像专项雷区

- 全图糊、无清晰锚点；拖影方向混乱、流动人群里出现第二张清晰人脸
- 高饱和糖水、调色三套之外乱混、无胶片颗粒
- 剪影没压纯黑、背景渐变混入实景杂物、水印二维码

## 负面词编译纪律

本文件不提供“整套直接复制”的通用电影负面尾巴。旧式成套模板会把平视、低对比、CG、完整构图等条件性选择误写成绝对禁项，并与 V2.1 的任务路由冲突。

实际执行：
1. 先用正向 Prompt 锁定正确媒介、Camera、场景状态与世界身份；
2. 再从本表挑 1–3 类当前反复出现的具体漂移；
3. 若负面词开始定义整套审美，回到正向结构重写。
