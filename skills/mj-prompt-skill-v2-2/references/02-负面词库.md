# 负面词库

> 负面词是防止**当前高风险漂移**的锁，不是每条 Prompt 的固定尾巴。先用正向锚点定义正确结果，再挑最少必要的负面项。

## 使用原则

默认只处理 1–3 类当前高风险漂移。普通任务的 `--no` 建议保持短小，通常只保留少量具体概念；如果正向 Prompt 已经清楚钉死状态，就不要再把同一规则反向重复一遍。

优先级：
1. 错误主体 / 空间原型
2. 生命周期或尺度漂移
3. 人数漂移
4. 明确风格污染
5. 当前模型已经反复出现的具体错误

## 常用负面组

### 游戏 / CG 感（只在目标明确要求照片 / 实拍时使用）

```text
3d render, cartoon, illustration, painting, game art, unreal engine
```

### 过度塑料 / 美颜感（按人物或照片任务需要）

```text
airbrushed, glamour retouching, plastic skin, waxy skin, excessive HDR
```

> `perfect / pristine / polished / neat / tidy` 不作为全局默认负面。高维护酒店、医疗、商业空间本来就可能整洁完整；是否排除必须服从场景状态。

### 明信片 / 童话化（只在纪实、生活化环境确实有此风险时）

```text
quaint, picturesque, idyllic, storybook, tourist postcard
```

### 时代 / 场景污染（按任务选）

```text
modern buildings, cars, asphalt, neon, contemporary signage
```

### 火 / 烟

只有“无火且模型容易乱加火”的题材才加：

```text
fire, flames
```

不要为了规则完整，在所有任务里机械加入。

## 场景任务优先的针对性锁

### L｜规模 / 类型漂移

只在有风险时选择类似：

```text
small village, tiny settlement, isolated buildings
```

重点仍然是正向写清请求规模，而不是靠负面词把城市“否”出来。

### M｜错误空间原型

只压最可能的错误类别，例如：

```text
cathedral nave, worship hall, throne room
```

先正向写具体功能原型和可见服务节点。

### S｜杂乱 / 展示化漂移

精密或高维护小空间按需选择：

```text
hoarder room, cluttered work surface, abandoned workshop, showroom
```

先正向写 `uncluttered primary work surface / controlled tool density / organized storage`。

## 异常锁（超现实 / 梦境）

| 异常 | 可选负面锁 |
|---|---|
| 倒置 | normal gravity, upright |
| 逆雨 | rain falling normally, normal rain |
| 融化 | solid, rigid |
| 冻结 | movement, melting |
| 折叠 | flat, unfolded |
| 倾斜 | level horizon, straight horizon |

异常任务优先采用：
**正向异常主体 → 中段再次确认异常状态 → 必要时负面锁正常态。**

## 关键主体名词锚定

抽象概念用具体可见名词承载；重要主体在 Prompt 中保持一致命名。只有真正容易丢失的核心身份才需要重复，不要把所有名词反复重写。

## 空镜 / 人数锁

人物排除必须服从任务与 Scene Human Presence，不把“场景”自动等同“无人”。

- 明确无人 / 空镜 / 纯建筑资产：按需 `--no people, crowd`
- 正常运营城市 / 市场 / 公共空间：可允许低权重环境人物，不使用固定 `--no people`
- 单人主体：按需 `--no extra people, crowd`

## 通用文字污染（按需）

```text
watermark, logo, caption, qr code
```

UI / HUD 只有在当前任务不需要界面时才排除。

## 精简原则

负面词解决“模型会反复错到哪里”，不是“把所有不想要的世界列一遍”。

如果 `--no` 已经明显长于正向场景锚点，优先重写正向 Prompt，而不是继续增加负面词。
