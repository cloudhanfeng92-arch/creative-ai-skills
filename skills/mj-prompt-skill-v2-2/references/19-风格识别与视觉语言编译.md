# 风格识别与视觉语言编译｜V2.2

> **定位**：MJ提示词skill 的内部风格执行模块；**不是独立 Skill，也不是固定画风词库**。服从 `SKILL.md` 的 STYLE CONTRACT 与用户当前约束。本模块只负责将风格证据转换成可影响画面的有限视觉信号，绝不重写 `16` 的场景、`17` 的电影摄影或主体身份。

## 1. 统一输入状态

- `TEXT_ONLY`：只有抽象风格名称、艺术媒介、口头感受或若干具体风格关键词。独立完成，不要求上传图。
- `STYLE_IMAGE`：当前用户指定一张或多张图片用作目标风格；先阅读图的实际表现，再编译视觉语法。
- `HYBRID`：文字媒介/风格约束 + 参考图，同时存在。逐维合并，文字明确硬锁高于不兼容的图像线索。
- `UNSPECIFIED`：既无明确风格，也无授权风格图；保留媒介中性，不暗自写入 CG、胶片、动画、照片或油画。

四种状态调用同一风格编译器，不建立四套 Prompt，也不将图片上传当成任务必需前置条件。用户只要求诊断/提炼时输出风格分析；请求生成 MJ Prompt 时才编译成英文。

## 2. 先区分三类容易混淆的输入

1. **Medium / Media Identity｜媒介身份**：摄影、CG、风格化 3D 动画、二维背景绘制、版画、油画等。这里决定结果本质上“如何产生”。
2. **Rendering / Treatment Grammar｜表现技法**：形体简化、造型比例、边缘软硬、线条密度、笔触颗粒、材质抽象、明暗层级、色域等。这里决定画面的具体观感。
3. **Subject / World Design Grammar｜内容形态设计**：建筑语汇、装饰符号、灾变扭曲规律、机械构成、角色造型等。默认归上游内容/世界身份；不能因为出现在风格图中就自动迁移。仅当用户题目明确授权某种变形/比例/形态表现时，允许提取其**一般化造型语法**，不复制原图对象。

例如“超写实”主要是保真程度而非媒介身份；“动画电影感”单独不足以指定 2D/3D；“史诗感”“高级感”不是可直接执行的技法。必须将含混词翻译为所需形体、光影、色彩和视觉组织后才能出词，不补充用户未授权的世界设定。

## 3. Style Evidence Matrix｜观察维度（候选，不必全部写）

按输入证据强度识别，每个维度均标记 `explicit / clearly visible / inferred / unknown`：

| 风格维度 | 要观察的可见证据 | 可转换成的视觉变化 |
|---|---|---|
| Medium | 平面绘制、照片成像、三维体积与材质反射、混合媒介 | 明确媒介短锚点、阻断跨媒介污染 |
| Shape / Stylization | 比例、转角、几何化程度、轮廓节奏、夸张或写实尺度 | 主体大形和造型概括的变化 |
| Edge / Line | 外轮廓清晰度、内部线条、边缘丢失与强调 | 线条粗细层级、硬边/软边、边缘密度 |
| Mark-making | 笔触、颜料堆叠、排线、色块、纹理方向 | 指定可见绘画痕迹或其缺省 |
| Material / Rendering | 材质真实度、反射粗糙度、表面抽象方式 | 符合指定媒介的材质响应与微细节等级 |
| Light / Value | 光源方向、光比、阴影形状、值域分组 | 光形、暗部保留程度、明暗层次 |
| Color | 主色/辅色/点缀、饱和度、冷暖关系、色彩跨度 | 可辨认的整体色域与局部强调 |
| Atmosphere / Imaging | 雾/空气、焦点、镜头响应或绘画空间退让 | 空间层次、成像/背景处理（媒介允许时） |

**不因参考图存在就推断摄影设备、引擎、真实笔刷、特定艺术家或不存在的工艺。** 如果仅能观察“有画感”，不强迫定性为油画、厚涂、水粉、水彩之一；选能够看见的边缘、笔触和色面事实。识别图中可见的天空、窗户、灯光方向不等于授权复制这些场景内容。

## 4. Visible-Signal Compiler｜词汇选择原则

内部映射链：`用户意图/图像证据 → 关键可见特征 → 适用当前尺度 → 正向英文视觉表达 → 预期画面变化 → 近邻风格误读风险`。

- 选 **一个明确媒介锚点**（若可判定）+ **2–4 个彼此互补的具体视觉信号**。它们可以是形体、边缘、材质、光色、成像中的任意高价值组合，不机械填写各维度。
- **锚点从早、机制从实**：在最终 Prompt 前部用短媒介身份词建立输出媒介，随后把风格落到具体可见的线、边、面、材质和光影。与场景事实同样清楚；长场景描述不得把风格挤到只剩末尾质量词。
- **强信号优先于形容词**："high-quality 2D animation" 如缺少可见的绘制色面/描线/明暗概括，效果可能被照片化细节淹没；"stylized 3D feature animation" 如同时堆 `photographic realism, documentary, microtexture` 可能失去风格化形体。
- **只保留一种成像逻辑**：照片是光学/曝光系统；3D 可描述造型和渲染材质；2D 可描述线与颜料/色层。电影化只在被请求时作为观看和灯光组织，不自动变成胶片特效或电影黑边。
- 真实感、手绘感、游戏原画、奇幻、精细、优雅等高层词必须由当轮上下文编译，不存在全题材通用的固定技法套餐。
- 当用户指定风格非常抽象而不含媒介时，优先保留确定的属性；仅在缺少会导致明显不同媒介的关键区分时再简短澄清。
- 用 **Delete Test** 减少冗余：删掉这个风格词，是否能预期某种可辨认差异？不能则删。

## 5. 风格参考图：角色隔离和可迁移范围

对每张图建立内部 `REFERENCE_ROLE`：`identity / design / geometry / composition / camera / style / palette / lighting / texture / transformation`，允许用户指定多重职责但不得推定全继承。

**纯 Style Reference 的白名单**：媒介、形体概括（非具体对象）、笔触/线条/边缘、材质抽象、明暗组织、整体色域、气氛与成像表现。对于用户明确要求的灾害变形、风格化体量或艺术夸张，`transformation grammar` 可限范围参与，但仍属于用户授权的形态设计任务，不改变主体身份。

**默认不可迁移**：参考图片中出现的建筑、人物、服饰、载具、地标、额外物品、故事剧情、真实地理位置、空间结构、观察机位、裁切比例。除非本轮额外授予对应职责。

混合输入若冲突：先固定用户明示媒介与场景事实；对参考图每个维度判兼容/冲突；兼容项进入正向描述，冲突项忽略，不输出相互抵消的画面条件。不可把“看起来漂亮”当作复制整张参考图的理由。

## 6. Midjourney 原生风格引用接口（按可用性）

**默认路径**：对用户当前聊天上传的风格图做视觉拆解，产出可独立复制的文字 Prompt。文本风格编译不依赖在线 URL。

**可选的 MJ 原生 Style Reference 路径**：
- 在 **midjourney.com** 的 Imagine 输入区把图片指定为 **Style Reference**，而非普通 Image Prompt；此时文字提示词只描述目标内容和必要的风格辨识/冲突校准。
- 在支持对应参数的 Discord 工作流，用户提供真实有效、MJ 可访问的在线图片 URL 时，可用 `--sref <真实URL>`。绝不可虚构 URL、占位 URL、私有沙盒路径、聊天附件文件 ID。
- `--sw` 是风格权重控制，不是通用质量增强；只有用户指定或反馈表明需要校准时才加入，并遵守当前 MJ 版本的兼容与范围。
- 普通 Image Prompt 可能把参考图的物体/构图带进来；纯风格对照时不得因为上传了图，就把它放在普通 Image Prompt 入口。
- 如果不能原生附带风格图，不要宣称 Prompt 已含该图：交付文字风格分析及 Prompt，并用一句说明如何在 MJ 端启用 Style Reference。

**经验边界**：多轮对比显示参考图可能提升难以语言化的风格和形态语法匹配度，但效果非普适保证，也不证明纯文字不能准确控制风格；不能据此禁止文字输入或硬设固定 `--sw`。

## 7. L/M/S：视觉信号的可见程度

此节仅决定“风格控制词是否在当前镜头中可见”，**不重新定义场景尺度**。尺度由 `16` 判定：

- **L｜大范围环境**：优先控制总体大形概括、远近色域、整体明暗分块、空气层级、重复节奏和信息密度。细小笔触或细部表面材质不足以在画面有效识别时省略。
- **M｜建筑及区域空间**：形体比例、边缘层级、结构线密度、表面概括、工作区光影和主材质视觉差异重要。
- **S｜人尺度空间/物体**：材质/纹理、笔触与线宽、边缘处理、器物形态、接触光影和局部颜色关系可成为主要识别证据。

**尺度不是风格强度等级**。大场景依然可以是二维绘画，小尺度可以是超写实CG；只调整信号的可视优先级。

## 8. 三个阻断门 + 失败修复

1. **STYLE READ Gate**：不看 Prompt 中的风格名称，成品是否实际显示指定媒介和 2–4 个核心可见特征？若没有，判风格失败，不能用“已经写了风格词”算通过。
2. **REFERENCE LEAK Gate**：若有风格图，新增元素是用户场景必需，还是来自参考图对象/取景/地理的意外复制？后者失败；若已授权形态变形，只允许抽象规律。
3. **CONTENT & CAMERA Gate**：主体类别、不可变构造、使用因果、镜头位置、裁切/画幅和用户要求是否保持？风格不能靠偷换它们达成。

失败归因：
- 媒介失真 → 检查媒介身份强度和互斥词，压缩冲突描述；
- 风格被场景文本稀释 → 把最强媒介锚点提前，收敛低杠杆内容描述；
- 颜色像但笔触不像 → 单独提升笔触/边缘的可见约束，不增加无关配色形容词；
- 参考对象污染 → 调整参考图职责/入口，删除对参考图物体的叙述；
- 用户要求的形态转译失败 → 重新描述授权的物理/视觉变化规律，不挪用参考图对象；
- 景别无法呈现微观风格 → 换尺度相容的信号，不擅自改变硬锁 Camera；
- 结构功能错误 → 回到 `16` / `18`，不让风格词修理结构。

**只修改失败层**，不要将某次案例的颜色、笔触、建筑、尺寸、器物、镜头和怪物形态永久固定为 Skill 默认。
