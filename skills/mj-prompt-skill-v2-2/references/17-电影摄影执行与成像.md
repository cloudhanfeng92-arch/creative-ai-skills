# 电影摄影执行与成像｜V2.1

> 本 Reference 只在用户明确要求电影感 / cinematic / film still / 导演摄影气质时调用。
>
> 它不设计场景、不重选 Camera。输入必须是已经成立的 Subject / Scene + 已锁定 Camera。输出是一套唯一的 **CINEMATIC_IMAGE_STATE**。

# 0. Activation / Medium Gate｜电影化条件执行

仅在用户明确要求电影感、电影截图、电影摄影语言或导演式观看组织时启用；不能因场景奇幻、画幅很宽、要求高质量而自动触发。保留用户媒介：手绘场景的电影化转换为视线、明暗块、空间显隐与画面张力；真实摄影可以讨论焦点、曝光与镜头响应；不把电影感等同于 CG、film grain、光晕或浅景深。下游影像系统只接受 `16` 已锁定的结构和 Camera Contract。

# 1. 职责边界

本 Reference 唯一负责电影化图片中的：
- Viewing Subject
- Visual Route
- Conditional Occlusion
- Depth Hierarchy 的摄影实现
- Motivated Lighting / Tonal Realization
- Unified Color Field
- Atmospheric Medium
- Focus / Depth of Field
- Exposure / Highlight / Shadow Behavior
- Restrained Optical Response

本 Reference 不负责：
- Scene Identity / Function / Scale
- 建筑、道路、节点布局
- 生命周期
- Camera Geometry
- 世界身份 / Set Dressing
- 传统构图法的强制选择

Scene 任务中，Camera Contract 与 Scene Structure 以 `16` 为准；世界身份以 `18` 为准。

# 2. 核心电影观看链

电影感优先通过以下链路建立：

**Camera Position → Viewing Subject → Visual Route → [optional Occlusion] → Depth Hierarchy → Light Hierarchy → Color / Atmosphere / Imaging**

## 2.1 Camera Position

直接继承上游锁定 Camera。

不得因为：
- cinematic
- dramatic
- immersive
- director style

自动改成低机位、极高机位、荷兰角、长焦窥视或超广角。

## 2.2 Viewing Subject

先回答：

> 观众这一镜真正应该看什么？

可以是：
- 一个主体；
- 一个功能区域；
- 一组空间关系；
- 一条事件路径；
- 一个建筑与环境的关系。

Viewing Subject 必须来自已成立的任务 / Scene Read，不得另造新主体。

## 2.3 Visual Route

再回答：

> 眼睛从哪里进入，经过什么关系，最后停在哪里？

优先利用已有：
- overlap
- perspective
- scale change
- value boundaries
- color contrast
- architecture openings
- natural circulation
- light falloff

Visual Route 是观看结果，不要求所有道路、屋脊、人物、光束机械指向同一点。

## 2.4 Occlusion｜条件变量

遮挡只有在以下情况下使用：
- 解释摄影机实际位置；
- 增强临场观察感；
- 建立必要近中远层次；
- 有叙事上的偷看 / 穿越 / 框景理由。

否则可以完全没有前景遮挡。

不得把所有电影化场景编译成：
`blurred foreground object framing the scene`。

# 3. CINEMATIC_IMAGE_STATE

内部锁定六项：
1. **Viewing Intent**：观看对象与情绪意图。
2. **Visual Route**：视线如何穿过已有画面。
3. **Depth Hierarchy**：空间层次如何被摄影读取。
4. **Lighting & Value**：真实光源如何建立可见层级。
5. **Color / Atmosphere**：综合色域与必要空气条件。
6. **Photographic Imaging**：焦点、景深、曝光与必要光学响应。

最终 Prompt 不逐项抄写，只 materialize 会改变结果的部分。

# 4. Depth Hierarchy

深度先来自真实空间，再来自摄影。

可用：
- structural overlap
- scale recession
- perspective recession
- foreground / middle / background separation when physically present
- atmospheric perspective when medium exists
- focus falloff when task supports it

不要用：
- 一块黑前景 + 一层白雾；
- 极浅景深掩盖空间结构；
- 所有远景都同样糊。

大型 establishing scene 通常应保留足够空间可读性。

# 5. Lighting & Value｜光是观看组织，不是特效

核心：

> **Light decides what is visible, how visible it is, and in what order it is read.**

## 5.1 Motivated Source

先确认真实主光来源：
- daylight / skylight
- window light
- practical lamp
- firelight
- fluorescent / industrial fixture
- screen / signage
- moonlight 等

辅助光必须可以由空间反射、环境漫射、开口或 visible practical 解释。

## 5.2 Light Hierarchy

优先形成 2–4 个大尺度明暗组：
- 主观看区域获得足够分离；
- 次要区域可以进入半暗 / 深影；
- 背景可随距离降低反差；
- 局部高光只服务已有重点。

**不要求唯一最亮点。**

电影画面可以有多个亮区，也可以整体低对比；关键是观看层级清楚且物理上成立。

## 5.3 Light as Route

光可以通过：
- bright-to-dark progression
- contrast edges
- color-temperature shift
- reflections
- falloff

帮助视线流动。

不得为了“引导”新增无来源 spotlight / god ray / hero rim light。

# 6. Unified Color Field

优先形成：

**dominant color family + adjacent variation + limited accents**

规则：
- 材质固有色服从总体综合色域，但保持可识别差异；
- 强调色数量和面积由任务决定；
- 冷暖对比不是默认；
- teal-orange、black-gold、monochrome 都只是候选；
- 风格坐标来自 `10` 时，只取最能改变画面的 2–4 个特征。

# 7. Atmospheric Medium

雾、烟、尘、水汽、雨、雪首先是环境条件，不是电影滤镜。

只有真实条件支持时才显式使用。

体积光必须同时具备：
**directional / localized light + sufficient medium**。

空气介质用于：
- 距离衰减；
- 层级分离；
- 环境状态。

不用于无理由把场景做成“神光海报”。

# 8. Focus / Depth of Field

电影感不等于浅景深。

- L / establishing：通常中等到深景深；远处通过空气、反差和解析力自然衰减。
- M：按功能观看对象使用中等或较深景深。
- S / 明确局部操作：可使用更清楚焦平面和自然前后离焦。
- Close-up / strong subject：可使用浅景深。

焦点衰减应渐进，不做剪纸式“主体锐、其它突然糊”。

**Scene detail density ≠ optical sharpness.**

# 9. Exposure / Tonal Response

真实摄影不要求所有区域同时完美可读。

允许：
- 高光接近或局部达到曝光上限；
- 深暗区域损失非必要纹理；
- 主观看对象保持必要中间调；
- 高光自然 roll-off；
- 远处降低微对比。

不为了“看清全部建筑”使用 HDR 式全局提亮。

# 10. Optical Response｜条件性

只有物理条件和风格语境支持时选 0–2 项：
- subtle highlight bloom
- restrained halation
- mild flare / ghosting
- natural edge softness
- optical falloff
- wet-glass diffusion
- film grain when actual film / film-still language is requested

不自动组合：
`film grain + anamorphic flare + chromatic aberration + bloom + vignette`。

# 11. Narrative State

电影化不要求加入剧情人物。

若需要叙事感，优先通过已有场景状态：
- active / just used / waiting / closing / preparing
- practical lights still on
- doors / chairs / tools / carts in plausible operational states

不得发明会改变场景身份的新事件。

# 12. Anti-Formula Gate

不得自动把 cinematic 翻译为：
- teal-orange
- single warm beacon
- one brightest point
- extreme contrast
- god rays
- heavy fog
- shallow DOF
- foreground obstruction
- anamorphic flare
- film grain
- extreme low / high angle
- letterbox framing

真正必须成立的是：

**locked camera + clear viewing subject + coherent visual route + believable depth + motivated light hierarchy + unified image formation**。

# 13. Materialization

本 Reference 最终通常只贡献一组紧凑电影影像语言：
- Viewing Subject / visual route 的必要可见关系；
- 主光来源与明暗层级；
-综合色域；
- 必要空气；
- 焦点 / DOF / 曝光；
- 0–2 个必要光学响应。

如果删除一项不会改变明确可见结果，删除。
