# 写实照片感档案

> 来自《MJ写实照片感·经验沉淀档案》。写实类任务的核心武器：让 MJ 出"真照片"，不是电影剧照、不是游戏 CG、不是明信片。

## 核心判断

MJ 的默认审美是"好看"，写实照片感是反着来的：用廉价胶卷快照的语境 + 真实曝光 + 镜头瑕疵，把 AI 拉回现实。

## 写实三件套公式（最有效一击）

```
--raw                 降低 MJ 默认风格化，让文本控制更直接
--s 100               低风格化，忠实描述
+ 廉价胶卷快照语境     amateur snapshot / basic compact film camera / Kodak Gold 200
```

> 已实战验证：这套组合是"不够真实"问题时最有效的解法。

## 明暗对比公式（正午光比）

低饱和不是平光——正午光比极大，把以下写进因果链：

- **曝白区**：直射墙面烧白丢细节（blown highlights）
- **死黑区**：北墙/檐下/门洞/窗洞纯黑（crushed shadows, pitch-black openings）
- **硬分割线**：明暗边界垂直落画面（hard light-shadow split line）
- **短硬影**：正午影子短而锐利（short hard-edged shadows）
- **热浪与树影**：远处热浪扭曲、树影斑驳打墙（heat haze, dappled tree shadows）

色彩用晒褪色系：sun-washed / muted / dusty / chalky / dry。

## 中世纪时代锚点（名词锚定）

写"中世纪欧洲"不要空泛，写死识别物：

```
half-timbered, wattle and daub, lime-washed, leaded windows, thatched grey sun-rotted, squat stone chimney, hayrick, stone well, church spire
```

同时负面锁 fantasy, castle（防跑偏成奇幻）。

## 负面四组模板（写实类必带）

1. **游戏/CG 组**：3d render, cartoon, illustration, painting, concept art, game art, stylized, octane render, unreal engine
2. **完美组**：perfect, pristine, polished, airbrushed, symmetrical, neat, tidy, HDR, studio lighting
3. **明信片组**：quaint, charming, picturesque, idyllic, storybook, tourist photo, postcard, fantasy, castle
4. **现代与火组**：modern buildings, power lines, cars, asphalt, neon, saturated, vibrant, oversaturated, fire, flames

## 参数档

- 写实照片：`--ar 3:2 --v 8.2 --raw --s 100`（标准画幅，照片感）
- 电影宽幅没有固定参数套餐；画幅用 `--ar 21:9`，Raw / Stylize / Quality 根据当前电影风格与任务选择，不用参数强行证明“电影感”。
- 镜头瑕疵四件套（写进正文）：轻微糊焦、眩光、暗角、传感器尘点
