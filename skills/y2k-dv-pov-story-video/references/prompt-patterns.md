# 提示词模板

## 角色图提示词

```text
[资产]：C01-v1 角色标准图，来自已确认剧情中的[角色功能]；严格参考用户脸部图。
[身份锁]：脸型、五官比例、肤色、年龄段、发型/发饰、身形、服装各层、鞋和配饰；列出不可漂移字段。
[姿态]：正面或四分之三全身自然站立，双手清楚、无遮挡、无剧情动作，单人，简单中性背景。
[风格]：项目 Y2K 低保真 DV 校准卡；清晰度 2/5、噪点 4/5、糊感 3/5。保留年代感，但脸、服装结构和配饰必须可辨。
[禁止]：换脸、改变年龄段、换装、增加配饰、戏剧化姿势、复杂场景、其他人物、现代高清棚拍、水印文字。
```

## 场景图提示词

```text
[资产]：E01-v1 无人场景锚点，对应镜头 S01–S03。
[空间锁]：门窗、墙地、固定家具、入口出口、前中后景、主机位和反打方向；列出不可漂移字段。
[光线锁]：时间、天气、主光方向、荧光灯/窗光、冷青白平衡、高光溢出。
[美术锁]：真实杂物密度与年代感，不擅自增加醒目标识。
[风格]：清晰度 2/5、噪点 4/5、糊感 3/5、压缩 3/5；无人、无角色、无水印文字。
```

## 道具图提示词

```text
[资产]：P01-v1 关键道具标准图；剧情用途和出现镜头。
[结构锁]：尺寸比例、材质、主辅颜色、图案、磨损、开合状态、正反面与拿取方向。
[画面]：单个道具，三分之四角度，简单背景，结构清楚；继承项目 DV 色彩和噪点，但不因糊感丢失关键造型。
[禁止]：改变品牌/图案、额外附件、多件复制、手持人物、水印文字。
```

## 分镜参考图提示词

```text
[用途与编号]：S01-A-v1 首帧，专用于 S01 Seedance 输入。
[资产配方]：严格引用 C01-v1、C02-v1、E01-v1、P01-v1、STYLE-v1；继承每项不可漂移字段，不重新设计。
[人物锚点]：按 Cxx 角色图锁定脸、发型、发饰、服装和配饰。
[剧情瞬间]：只描述这一帧可见的动作状态、视线和道具关系。
[空间站位]：掌镜者 POV；人物 A 距镜头 X cm、位于画面左前；人物 B 位于右后；背景结构与光源。
[摄影锁]：消费级 2000 年代 DV/CCD 随拍，14–20mm 等效超广角或轻鱼眼，胸口/眼平手持机位，近距离透视夸张，非电影机。
[画质锁]：源画面本身是低保真旧视频质感，不是高清画面套滤镜；清晰度 2/5、噪点 4/5、糊感 3/5、压缩 3/5、拖影 3/5、高光溢出 4/5、冷青色偏 4/5。明显高亮度颗粒和彩色色噪，中度柔化但人物、服装与道具可辨，轻微运动残影、色散、编码涂抹和二次转码痕迹，窗光与荧光灯泛白，窄动态范围，绝不现代高清。
[画幅]：9:16 或 16:9，与项目锁一致。
[禁止]：现代高清、4K/8K、超锐利、毛孔级细节、干净数字画面、现代广告摄影、电影海报、浅景深、精致棚拍、橙青调色、夸张刮痕或重 VHS 故障、日期戳、水印、文字、多人脸混合、额外肢体、手指错误。
```

尾帧需额外写：`严格继承已确认首帧的同一人物、衣着、镜位、空间、光线和画质，只改变动作结束状态。`

## Seedance 单图模式

```text
固定 [X] 秒，[画幅]。以 S01 专属首帧为唯一场景输入并锁定人物身份、服装、人数和空间。
Primary：人物先看向掌镜者，短句说话，随后自然靠近/递出道具/回头回应；动作按时间顺序，只安排一个主要事件。
Secondary：第一人称消费级 DV 手持，小幅呼吸晃动，因人物靠近而轻微后退或抬镜；无稳定器漂浮。
Background：荧光灯轻微曝光呼吸，后景同伴做克制反应，环境物体保持结构稳定。
Style：2000 年代校园低保真复古胶片/CCD/DV 随拍；源画面低清晰度，明显高颗粒和色噪，中度柔化但人物与道具可辨，运动拖影、色散、编码涂抹、二次压缩痕迹，冷青偏蓝，窗光泛白，窄动态范围，超广角近距离透视；绝非高清画面套复古滤镜。
Constraints：严格骨骼结构，脸不漂移，不新增人物或肢体，手和道具稳定，无变形、无随机转场、无慢动作、无电影级浅景深、无水印文字。
Dialogue：[角色名：“短台词”]；只让一人主说，按需要进行自然口型同步。
```

## Seedance 首尾帧模式

```text
固定 [X] 秒，[画幅]。从 S02-A 专属首帧自然连续过渡到 S02-B 专属尾帧；两帧的人物、服装、人数、镜位、空间和光线完全一致。
Primary：0–2 秒 [起始动作]；2–5 秒 [交互升级]；5–X 秒 [结束动作]。动作因果清楚，不插入第二个事件。
Secondary：POV 手持轻跟退/轻抬镜/随人物转身，轨迹短而真实；不环绕、不快速甩动。
Background：同伴与环境只作低幅度连续变化，保持场景结构。
Style：[复制项目固定 DV/CCD 风格锁]。
Constraints：首尾状态准确到达；严格骨骼，脸、手、道具稳定；不增加物体、人物或镜头；无形变、无闪切、无现代商业质感。
Dialogue：[短台词与说话时间；若多人，按顺序不重叠]。
```

## Seedance 全能参考模式

```text
固定 [X] 秒，[画幅]，使用 Seedance 全能参考。
参考职责：R1=C01-v1 主角脸部、全身服装与发饰，身份最高优先级；R2=C02-v1 配角脸部与服装；R3=E01-v1 无人场景空间、机位和光源；R4=P01-v1 道具结构、颜色和材质；R5=S01-A-v1 开场构图和站位；R6=STYLE-v1 低保真复古胶片/CCD/DV 画风。参考图只负责对应职责；角色图不贡献背景，场景图不贡献人物，道具图不改变比例。
剧情起点：[开场构图和人物站位]。Primary：[按时间顺序描述一个主要交互事件]。结束状态：[只描述期望结果，不强制匹配某张尾帧]。
Secondary：第一人称超广角手持，因人物动作轻跟退、抬镜或转身，允许真实微晃和曝光呼吸；不环绕、不稳定器漂浮。
Background：[低幅度环境动态与后景反应]。
Style：严格参考 R6；低清晰度、高颗粒与色噪、中度柔化、运动拖影、泛光、冷青色偏、窄动态范围和早期视频压缩必须从第一帧持续到最后一帧，不能逐渐变高清。
Continuity：严格以 R1/R2 锁定人物，以 R3 锁定空间拓扑与光向，以 R4 锁定道具，以 R5 锁定开场构图；不得融合角色、移动固定门窗家具、改变道具结构，或把无人场景参考中的杂物变成新角色。
Constraints：严格骨骼和物理结构，手与道具稳定，无新增人物、无换装、无随机切镜、无现代高清、无电影级景深、无水印文字。
Dialogue：[短台词与说话顺序]。
```

## 视频输入模式决策

| 情况 | 优先模式 | 原因 |
|---|---|---|
| 单人/双人近景、轻动作、自然发挥 | 单首帧 | 开场构图稳定，动作不易被尾帧束缚 |
| 必须准确抵达一个视觉终点 | 首尾帧 | 明确控制结束构图和动作状态 |
| 多角色、场景和道具必须同时稳定 | 全能参考 | 可为 C/E/P/S 资产分别分配职责，减少融合与重设计 |
| 动作路线自由、结尾不需一模一样 | 全能参考 | 避免首尾帧僵硬插值 |
| 首尾两张图的脸、站位或光线不完全一致 | 单首帧或全能参考 | 不把静态图差异放大成视频形变 |
| 道具交接、短距离转身且尾帧可靠 | 首尾帧 | 有清楚的起止因果 |
| 用户只提供人物参考、没有可用场景首帧 | 全能参考 | 用人物与风格参考建立新镜头 |

每个镜头必须记录：选择模式、选择理由、参考职责、未选模式的主要风险。模式可逐镜不同。

## 高风险镜头降级

- 四人同时走向镜头：改为两人主动作 + 两人后景反应，或拆为群像建立与双人近景。
- 递物同时说长台词：先说短句再递物；手部用中近景并保持道具简单。
- 人物极近贴镜：把最终距离限制在约 15–25cm，避免整张脸占满画面造成结构漂移。
- 走廊长距离移动：若终点构图必须精确且首尾图一致，使用首尾帧；否则使用全能参考锁角色并缩短路径，或拆成两个镜头。
- 车内多人：固定车辆静止或低速感，避免同时要求真实驾驶、多人对白和大幅运镜。
