# 游戏图生视频提示词模式

为单个已确认场景撰写图生视频提示词。每条 150 个中文字符以内，时长只能为 5–15 秒，继承该项目的角色、画风、UI、光影和视角锚点。

## 模式 A：单图转视频

用于登录界面、城镇闲逛、开放区探索、静态氛围与胜利定格。目标是缓慢微动、氛围优先、不修改原始构图。

模板：

`缓慢平滑镜头推进，轻微镜头呼吸晃动，[角色/主体]自然保持姿态，[衣袂/树叶/云雾/水面]轻柔流动，远处粒子微光缓慢漂浮，无剧烈位移，角色外观与 UI 布局稳定，构图不变，稳定[第三人称/对应]游戏实机录屏视角，[锁定画风]，电影级光影，16:9。`

避免：镜头旋转、快速切换、人物长距离奔跑、突然生成新角色或道具、大幅重设界面。

## 模式 B：首尾帧场景过渡

用于登录到选人、城镇到副本、探索到战前准备等空间转变。两张参考图必须风格与角色一致。

模板：

`镜头缓慢向前推进，视角循序延伸，画面从首帧场景柔和过渡至尾帧场景，远景空间缓缓舒展，[云雾/粒子流光]持续流动，环境光照逐步渐变，角色外形、服饰与 UI 布局保持稳定，整体构图平缓变化，稳定[第三人称/对应]游戏录屏视角，运镜流畅，[锁定画风]，16:9。`

## 模式 C：首尾帧战斗状态过渡

用于战前到开战、小怪到 Boss、蓄力到大招。可以提升光效，但维持角色身份、镜头方向和 HUD。

模板：

`镜头稳步向前推进，视线缓缓聚焦战斗核心，[角色]姿态循序变化，能量光效逐步升腾扩散，气流带动环境粒子与碎屑，战斗氛围持续增强并柔和过渡至尾帧，角色造型与 UI 布局维持稳定，第三人称游戏实机画面，运镜沉稳连贯，光影层次自然演变，[锁定画风]，16:9。`

## 选择与校验

- 只有两张画面确实需要连成一条连续过渡时才用首尾帧；同一场景静态展示用单图。
- 先写镜头运动，再写过渡/动作，再写环境动态，最后写锁定约束、游戏视角和画幅。
- 用“缓慢、循序渐进、缓缓、柔和、稳步”等温和词；少用“瞬间、猛烈、急速、剧烈旋转”。
- 如 UI 发生失真，建议在剪辑阶段叠加静态 UI 层，不要用更复杂的提示词强行修复。
