# Typography playbook

Use the reference image's actual typographic signals when they are clear. Otherwise, choose the closest direction below. Name the visual properties in the generation prompt: width, weight, contrast, case, spacing, edge treatment, and placement.

| Source mood or genre | Typography direction | Image treatment |
| --- | --- | --- |
| Literary, historical, luxury | high-contrast editorial serif; refined proportions; generous tracking | tactile paper, quiet palette, restrained framing |
| Thriller, horror, crime | condensed bold sans or sharp display serif; tight tracking; controlled distress | dramatic shadows, grain, selective red or cold contrast |
| Sci-fi, technology, futuristic | clean geometric sans; extended or monospaced accents; precise alignment | dark field or bright minimal grid, luminous highlights |
| Music, club, street culture | expressive display lettering; oversized scale; custom-looking rhythm | energetic crop, bold color, collage, flash, or grain |
| Fashion, beauty, premium product | elegant high-contrast serif or minimalist grotesk; spacious tracking | controlled negative space, polished lighting, limited palette |
| Children, playful, family | rounded, hand-drawn, or chunky friendly lettering | warm saturated palette, soft shapes, clear silhouettes |
| Nature, wellness, craft | organic serif or humanist sans; subtle irregularity | natural materials, gentle contrast, earthy palette |
| Food, café, hospitality | warm humanist serif/sans; hand-lettered accent only when fitting | appetizing texture, warm light, uncluttered title zone |
| Business, education, event | authoritative sans-serif; strong grid; clear weight contrast | modular layout, informative hierarchy, high readability |
| Romance, poetry, wedding | delicate serif, restrained script accent, or light sans | soft light, airy spacing, gentle tones; never over-decorate |

## Layout cues

- Use one dominant title treatment, not several competing display styles.
- Set a short title large enough to define the cover; make supporting copy visibly subordinate.
- Use contrast through scale, color, value, or a quiet backing area. Avoid outlining every letter unless the source style calls for it.
- Preserve approximately 5–8% outer breathing room unless a deliberate full-bleed crop is part of the chosen direction.
- Use all caps for force, clarity, or modernity; use sentence/title case for warmth or editorial restraint. Avoid arbitrary capitalization.
- When text overlays photography, place it over the least busy region or create an intentional, style-consistent contrast field.

## Reference-image extraction

Infer style from the reference image in this order: medium and texture, palette/value contrast, composition, recurring shapes, then typography. Preserve the reference's broad visual language, not its exact branded mark or copyrighted artwork. If there is no existing text, select type based on the image's mood and intended message.

## Type accuracy

Keep the text request short whenever possible. Quote every required string, prohibit extra copy, and inspect character-by-character. For Chinese typography, demand correct Chinese characters, natural line breaks, no pinyin/Latin substitutions, and readable glyph shapes. For bilingual covers, state each language exactly and specify the primary reading order.
