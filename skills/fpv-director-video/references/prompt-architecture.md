# FPV 提示词架构

本文件用于把视觉证据转成可直接提交的视频提示词。先完成图片检查和角色分配，再使用本架构；不要把模板变量或未验证的内容留在最终提示词中。

用户给出的长提示词或案例只定义所需的细致程度与连续镜头逻辑，不定义固定剧情。每次从当前图片重新推导路径；如果画面最适合低空穿梭、建筑飞越、人物环绕、产品内部、道路追随或纯同场景探索，就采用该方案，不必强行寻找电视、屏幕或传送入口。

## 一、先建立证据表

对每张图片分别记录，不要先写故事再倒推图片：

| 证据类别 | 需要记录的内容 |
|---|---|
| 主体 | 数量、位置、外貌、姿势、视线、手势、服装、产品轮廓与关键部件 |
| 空间 | 地面、墙面、家具或建筑关系，可通行间隙，前中后景，遮挡与消失点 |
| 摄影 | 机位高度、视角、透视强弱、景深、焦点、画幅与主体占比 |
| 光色 | 主光方向、色温、明暗比、实景光源、反射、高光和阴影边缘 |
| 材质 | 皮革、金属、玻璃、木、织物、液体、烟雾、皮肤、纸张等可识别表面 |
| 可动项 | 呼吸、眨眼、头发、衣料、烟、火、水、液体、反光、粒子、背景人物或机械件 |
| 稳定锚点 | 脸、手、服装、产品结构、Logo、文字、建筑线条、图案和道具数量 |
| 风险 | 细手指、反射中的第二张脸、可读文字、窄缝、拥挤背景、极浅景深或不一致画幅 |

图片没显示的背面、通道、身份、品牌、地点或因果只能标为推断。不要把推断写成“精确保留”的事实。

先写“角色—属性契约”，再合并证据：开/终场图负责对应时刻的构图与空间，人物图只负责身份，产品图只负责产品事实，场景图只负责环境，风格图只负责视觉处理。图像2若是身份、产品、动作或风格参考，就不能在提示词中被称为目标世界或末帧。

## 二、把构图转成飞行拓扑

先在脑中确定以下六个空间节点：

1. **起始机位**：与图像1一致的相机高度、朝向、焦点和主体占比。
2. **引导向量**：由手势、视线、道路、桌边、墙线、灯带或光束指向真正目标。
3. **揭示弧线**：相机如何绕开主体或前景，既不穿模，又逐步揭示入口。
4. **入口法线**：相机以什么角度接近屏幕、门窗、镜面、缝隙或物体表面，怎样在穿越前对正。
5. **匹配瞬间**：入口表面的图像、色块、轮廓、消失点和目标图如何在同一视角重合。
6. **结束机位**：进入目标世界后的最后移动、减速距离、主体占比、焦点和至少约 1 秒的稳定构图。

在每个可见世界内部，路径必须可以被一台真实的小型飞行相机连续完成。绕过人物或物体时，说明从哪一侧经过。进入屏幕、镜面、液面或微观世界等幻想边界时，不要求现实相机真的穿越材质，但必须说明被选定的入口、表面行为、匹配瞬间，以及进入后怎样延续同一速度向量再减速。不要让相机无解释地穿过非入口实体，也不要突然或无因果地传送。

## 三、默认 15 秒节奏

四段时间轴是动作骨架，不是死板分镜。每段只承担一个主要任务，避免同一秒内同时要求多次转向、变焦、变形和换景。

### 0–3 秒：开场锁定与微漂移

- 第一帧尽量贴合图像1的构图、身份、空间和照明。
- 前 1–2 秒可近乎静止，但画面必须有克制的生命感。
- 相机从静止自然缓入，先有极轻前移或侧漂，不要立即高速冲刺。
- 使用前景边缘建立第一次视差，但不要遮住关键脸、手、产品或文字。

### 3–7 秒：弧线跟踪与入口揭示

- 沿引导向量做一个连续曲线；明确从主体左侧、右侧、上方或下方绕过。
- 保持脸、手、服装、道具和背景几何处于一致透视，不要让参考主体突然转身配合镜头。
- 近景掠过速度最快，中景主体次之，远景最慢，以视差证明相机在三维空间飞行。
- 到本段结束时，入口应清楚可见并成为唯一运动目标。

### 7–11 秒：对正与加速逼近

- 使用缓入缓出的推进、轻微侧倾和自然惯性；运动方向连续，不做急停急转。
- 入口表面逐渐占据画面。焦点、景深、曝光和运动模糊随距离变化，而不是突然跳变。
- 保留入口材质：玻璃深度、边框、反射、尘埃、折射、门框阴影或镜面视差。
- 若目标世界在屏幕或反射中出现，它从一开始就是有细微生命运动的真实场景，不是冻结的贴图。

### 11–15 秒：穿越、匹配与英雄收束

- 延续同一个速度向量穿过入口，入口边缘从画面四周自然掠过。
- 在穿越瞬间匹配目标图的透视、主光、主体位置和大色块，让边界消失而不是用闪白、故障或黑场掩盖。
- 进入目标世界后继续很短的前飞或弧线，再平缓减速，不要一进入就突然停住。
- 最后约 1 秒保持稳定，构图尽量接近末图；主体有自然微运动，但镜头不再漂走。

其他时长按四段约 `20% / 27% / 26% / 27%` 的比例缩放，并为结尾留出约 7%–10% 的稳定时间。若时长太短，优先减少路径复杂度，而不是压缩成不可能完成的多重动作。

## 四、只选与画面相符的入口逻辑

### 屏幕或电视

保留边框、玻璃厚度、环境反射、屏幕亮度与房间曝光差。目标图在屏幕内应表现为活着的场景，人物可呼吸、眨眼、微移视线，液体和高光可轻微变化。接近时屏幕产生自然透视形变；穿越时先对正屏幕图像，再让它扩展为全画幅真实世界。

### 门、窗、拱洞或通道

写清门槛或边框的掠过、室内外曝光适应、气流和环境声变化。入口后必须有可容纳目标世界的空间方向，不要让门后景深与目标图明显矛盾。

### 镜面、反射或液面

反射随视角改变，接近时保留表面反光、轻微波纹或玻璃深度。匹配依靠反射中的目标构图与真实世界重合，不使用镜面突然变成无材质洞口的跳变。

### 物体、纹理或微观世界

先让表面纹理、孔隙、机械缝隙或容器开口成为明确入口，再说明尺度变化。保持运动惯性和材质连续，避免物体无因果地融化成另一场景。

### 遮挡匹配

只有没有真实入口且两图存在强几何、色彩或运动对应时使用。让一个近景实体完整遮住画面，在同一方向、速度、光色和轮廓下揭开目标世界。提示词仍要求连续运动，不把遮挡写成切镜。

## 五、生命运动与稳定锚点

参考图中的人物或动物不要冻结，也不要表演超出原图的复杂新动作。按需要选择少量微运动：

- 柔和呼吸与胸肩起伏；
- 自然眨眼、极小眼球或视线变化；
- 轻微头部、肩部、手腕或手指压力调整；
- 头发、衣料、烟雾、火焰、液体、粒子和反光的低幅运动；
- 与原姿势一致的细微重心变化。

不要同时要求大幅说话、转身、走动、手势变化和高速绕飞。复杂主体动作会与身份稳定和空间连续性竞争。

产品或建筑的微运动只来自合理机制：指示灯、屏幕内容、反光滑动、机械阻尼、气流、液体或环境振动。不要让硬表面像软胶一样呼吸或融化。

## 六、镜头与光学语言

- 把运动写成轨迹：前移多少趋势、向哪侧弧线、绕过什么、何时对正、怎样穿越、怎样减速。
- 使用温和广角或与原图相符的透视。除非画面或用户明确需要，不要添加夸张鱼眼、剧烈桶形畸变、翻滚或竞速无人机抖动。
- “超平滑”不等于无重量漂浮。加入轻微惯性、缓入缓出、受控侧倾和物理可信的运动模糊。
- 景深、焦点和曝光随距离与世界改变连续过渡。不要同时要求全程浅景深和所有远近物体都锐利。
- 光线转换应由真实表面、门槛或环境变化引发；不要用闪白、炫光爆炸或故障特效掩盖匹配失败。

## 七、最终提示词结构

最终提示词写成连贯的导演语言，通常使用以下顺序。先根据实际时长计算四段边界：默认 15 秒使用 `0–3 / 3–7 / 7–11 / 11–15`；其他时长使用上文比例并把实际秒数填入。不要保留尖括号变量：

```text
使用图像1作为精确的开场视觉参考；若已验证使用首尾帧模式，则使用图像2作为受约束的目标世界与结尾帧参考，否则使用图像2作为目标世界与尽量贴合的结尾构图参考；若有更多图片，逐一声明它们仅负责哪些人物、产品、材质或过渡节点。创作一段<时长>、<画幅>、不间断、超平滑但有真实惯性的电影感 FPV 单镜头；不可见的稳定微型镜头沿一个连续、无碰撞的三维路径飞行，没有切镜、跳剪、突然或无因果传送、黑场、突然数字缩放或可见相机。

开始时精确保留图像1：<主体身份、姿势、服装或产品结构>，<场景几何与前中后景>，<主光、色温、材质和关键道具>。只加入<与画面相符的少量微运动>，不得改变<稳定锚点>。

<建立段实际秒数>，<近乎静止到微漂移的起步、前景视差与引导向量>。<揭示段实际秒数>，<绕行侧、曲线轨迹、入口揭示与透视连续>。<逼近段实际秒数>，<对正入口、加速方式、光学变化、入口材质，以及目标世界在入口内的生命运动>。<穿越或抵达段实际秒数>，<穿越表面的因果过程、匹配时刻、进入后的延续运动、减速和英雄构图>。

进入目标世界后，以图像2负责的可见属性为锚点：<主体身份、构图、光线、材质、景深与氛围>，继续<克制微运动>。首尾帧模式下把图像2作为受约束结尾帧；多图参考模式下只要求结尾构图尽量贴近图像2，不声称像素级复刻。最终画面稳定，<焦点和主体占比>清楚，<背景与高光>保持一致。

全片按各图的角色保持<人物/产品/场景锚点>稳定，具有真实视差、惯性、运动模糊、遮挡、对焦和曝光连续性；正确解剖与手部结构，无额外人物或物件，无新增或未请求的文字、Logo、字幕、水印或 UI 叠加，参考图已有的文字、Logo 与界面内容保持稳定，无故障转场、融化、复制、闪烁、抖动或随机换景。
```

若图像2不是目标或末帧，而是人物身份、产品、动作、场景或风格参考，把第一句改为“使用图像2仅锁定<被分配属性>，不采用其构图作为时间节点或末帧”，删除所有“进入图像2世界”和“结尾贴近图像2”的措辞。结尾由图像1世界、文字目标或其他被指定的末帧图决定。

如果只有一张图且没有文字目标，删除目标世界和穿越段，将后两段改写为同一场景内的深入探索、环绕、回到英雄构图。若用户给出文字派生目标，明确写“目标世界来自用户文字与创意推断，不是图像参考”，并只承诺图像1的开场约束。不要虚构“图像2”。

## 八、提交前自检

- 每个强锚点后面都有来自相应角色图片的具体可见事实，没有让身份图或风格图意外接管构图。
- 四段时间轴的速度和方向连续，没有互相冲突的镜头指令。
- 入口在原图中存在，或已明确标注为基于可见遮挡、纹理或几何匹配的合理推断。
- 相机路径有通行空间，不穿过人物、墙体或实体物件。
- 目标世界在入口内和进入后都保持生命运动，不突然冻结或重置。
- 结尾给模型留出了减速与稳定时间。
- 负面约束集中且简洁，没有用几十个同义词淹没主体动作。
- 没有遗留模板变量、图片编号错误或工具不识别的引用语法。
