# 中文提示词规范

独立根据用户需求写中文，不先写英文再翻译。下面的模板和示例均为平台无关的生图文本。

## 风格与中文写法

固定风格为东方矿物设色、精致二维绘画、细腻笔触、柔和电影光线、有机流动曲线、清楚主次和诗意奇幻氛围。默认深青蓝底色，月白或象牙白亮部，适量珊瑚红、玉绿或绿松石色与少量柔金；按白昼、雪景及用户指定配色调整，不必用全色板。

人物、数量、性别、年龄、衣装、昼夜与环境可自由替换。女性、露肩、长发、月夜、莲花、光轮与千手都不是必需条件。

采用“主体动作 → 服装材质 → 场景构图 → 色彩光线 → 奇幻细节 → 绘画质感与情绪”的中文视觉叙述，必要时将构图提前。使用连贯、具体的句子，写清“谁在什么位置做什么”，不堆叠“绝美、顶级、大师级、超高清”等空泛词。常规成稿约250—450字，按需求调整，不为字数丢失约束。

服饰符合身份，手势与道具相容，衣料、发丝、枝叶与雾的流向协调。“月白”是颜色，不要求月亮；“壁画质感”不要求实体墙；“电影感”不等于摄影。宗教形制不明确时使用具体外观描述，如“褪色柔金背光”，不将背光与曼荼罗混为一谈。

## 替换字段

| 字段 | 填写内容 |
| --- | --- |
| 【主体】 | 身份、人数、年龄段、性别或物种 |
| 【外形与姿态】 | 关键外形、表情、动作、手部与道具关系 |
| 【服装与材质】 | 适合身份的衣料、层次与饰品；非人物改为表面材质 |
| 【场景与时间】 | 地点、季节、昼夜、天气 |
| 【景别与构图】 | 画幅、远近、主体位置、视线和留白位置 |
| 【主色与点缀色】 | 主辅色及明度关系，不必用全默认色板 |
| 【光源与照明】 | 合理光源、入射方向、焦点亮度与轮廓光 |
| 【自然动态】 | 按画面选衣料、发丝、枝叶、水面或雾的流动 |
| 【奇幻细节】 | 与环境相关的少量意象；不需要时删除 |
| 【情绪】 | 宁静、疏离、温柔、庄严、沉思等 |

## 中文通用模板

替换字段后直接使用，不需要的句子整句删除。具体成稿不保留字段名、斜杠选项或编辑说明。

```text
东方诗意奇幻插画，【主体】置身于【场景与时间】，呈现【外形与姿态】。主体的【服装与材质】具有清晰的层次与精致细节，与身份及环境相符。采用【景别与构图】，视觉焦点明确，前景、中景与背景自然分层，留白舒展，空间关系清楚。以【主色与点缀色】构成富有层次的矿物设色，亮部柔和通透，暗部保留丰富细节。【光源与照明】，柔和主光照清视觉焦点，细微轮廓光勾勒形体。画面中的【自然动态】形成流畅而有节制的曲线。【奇幻细节】自然融入环境，为主体与空间增添诗意。细腻的二维绘画笔触，矿物颜料的颗粒与层层罩染质感，柔和的电影光线，优雅构图，梦幻而精致的东方意境，整体情绪【情绪】。
```

纯场景开头改为“东方诗意奇幻插画，描绘【场景与时间】”，删除人物、服装与人体约束，让建筑、地形或植物成为焦点。群像补充人物之间的位置、视线与动作，不复制同一种姿态。

## 分支模块

**花庭诗境**：以植物、水岸、石径与建筑建立空间，少量透亮花瓣或饰物映照环境光，薄雾与流动衣料呼应。奇幻感来自自然细节的微妙变化。可用于白昼，不固定月夜。

**壁画神境**：风化的矿物色层、零星残金与局部壁画纹理，和前景衣料、云气形成动静对照。光轮、莲花、寺庙及宗教意象按主题选用，不整组堆砌。千手残影如被要求，明确是背景壁画或背光中的轮廓，不与主体真实手臂混淆。

## 负面约束与参数

需要负面约束时单独成块，按场景删减。用户不要负面提示词时不输出负面块，但明确的排除要求仍保留在正文中，例如“园林空无人物与动物”，不能随负面块一并删掉。可选基础模板：

```text
避免塑料般的三维质感、刺眼霓虹、过曝高光、杂乱背景、遮挡主体的大面积特效，以及无关文字、标志和水印。
```

人物可补“避免肢体结构混乱、手部与道具粘连”；纯场景不加人体约束。用户要求文字时明确目标文字，不用禁止所有文字的规则。无光晕、无铠甲、无寺庙不是通用排除项，必须与当前需求相容。

不默认附加平台命令。比例文字仅表达构图意图。平台参数若被要求，单独提供并按当前支持范围核对，不照搬原图的 `--hd` 等标记。

## 完整中文示例

需求：成年男性琴师，早春清晨的山中水榭，青白长袍，抚琴，横向16:9，无宗教光环。

中文正向提示词：

```text
东方诗意奇幻插画，一位成年男性琴师坐在早春清晨的山中水榭里，神情专注而平和，双手自然落于古琴弦上。青白交领长袍层次清楚，柔软丝料与细密暗纹相互映衬，玉扣与袖缘仅有少量装饰。横向16:9的中远景构图，人物位于画面左侧，右侧留出开阔水面与远山，近处栏杆、人物和远景层层展开。以青蓝、月白与淡玉绿为主色，辅以少量温润柔金。清晨暖光从侧前方落在面容、双手和琴面上，水面的微弱反光照亮衣褶，背景薄雾轻柔。袍角、垂柳与雾气朝同一方向缓缓舒展，水面零星花瓣带有半透明的矿物色泽，自然融入环境。细腻二维绘画笔触，矿物颜料的颗粒与层层罩染质感，柔和电影光线，留白优雅，宁静而清澈的东方梦境。
```

中文负面约束：

```text
无宗教光环、佛像或多余人物；避免手指与琴弦粘连、额外肢体、塑料般的三维质感、刺眼霓虹、遮挡主体的大面积特效，以及文字、标志和水印。
```
