# 东方奇幻插画提示词

编写东方矿物设色与诗意奇幻插画提示词，支持花庭诗境、壁画神境和人物场景替换，中英文按各自规范独立成稿。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/oriental-fantasy-prompter 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/oriental-fantasy-prompter) 安装 `skills/oriental-fantasy-prompter`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $oriental-fantasy-prompter，为一位漫步莲花庭院的女子编写东方矿物设色奇幻插画提示词，分别提供中文和英文版本。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。
