# RunningHub 工作流应用发布

复用图生图工作流制作 AI 应用，完成公开输入、封面、测试与发布，并核验同步AI站、公开试用和结果社区作品。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/runninghub-app-publisher 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/runninghub-app-publisher) 安装 `skills/runninghub-app-publisher`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $runninghub-app-publisher，把这个GPT Image 2图生图工作流做成RunningHub应用，配置输入，测试发布后试用并发布结果作品。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- RunningHub 账号与可用工作流节点
- Google Chrome 与 mcp__cua_repl
- 发布前测试和发布后试用所需授权预算；同步AI站需相应账号条件

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
