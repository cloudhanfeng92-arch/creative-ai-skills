# 浏览器发布操作

2026-10-12 以 Google Chrome 实地观察为基础。每次执行以新状态定位控件，不复用旧 AX 编号或截图坐标。

## 接入与状态

通过 `mcp__cua_repl` 的当前文档操作 Chrome。标签通道可用时优先；若 `createBrowserTab('chrome', ...)` 返回 Browser is not available，可在同一工具中 `cua.getApp('Google Chrome')` 使用原生 AX、截图和键盘操作。不得改用 Cookie、登录令牌、隐藏 API 或浏览器内部存储绕过 UI。

开始记下已有标签，研究/新任务开自己的一页并复用。重要动作后读新 AX；DOM/AX 提供不了画布节点参数时查看截图，用所见控件操作。工具显示旧 URL 而页面正在加载时先等下一次有效状态，不重复点击发布。只关闭能确认由自己打开的多余标签。

## 工作台到发布页

1. 工作流广场是检索入口，实际创建在“工作台”。工作台可见“新建工作流”和“导入工作流”。导入准备好的 UI JSON，核对模型、真实图片和 SaveImage，保存。
2. 完成已授权的发布前运行。点击顶部“发布”若出现“首次发布前请先运行一次工作流”，先满足这个前置步骤；不能直接构造 publish URL 绕过它。
3. 从当前编辑器进入真实发布页，URL 实例形态为 `/publish/<id>`。记录页面返回的地址，不从文件 UUID 推算。
4. “版本与工作流”提示：AI 应用和工作流共用版本；在此管理版本后再从工作台进入可能自动新建版本，达上限会覆盖最近更新版本。制作一个新应用使用独立工作流，更新已有应用先确认版本目标。

## 应用信息

使用“发布AI应用”页签；“发布工作流”是另一项发布对象，未要求公开底层工作流时不额外发布。

观察到的必填项为应用名称、标签、封面、应用介绍&输入建议。页面说明每个作品每站最多 10 张展示图，首张主封面；当前可见中文封面槽。开启同步后本次未出现额外英文输入，未来以实时 UI 为准，不虚构双语必填字段。

富文本说明优先点击编辑区后原生粘贴；修改名称后重新取 AX 再定位其它字段，避免动态索引变化。对用户读得到的实际说明做简要回读，不能仅凭填入工具无异常判断已保存。

## 添加输入节点

“添加”打开“选择节点参数”，含搜索、`节点类型-字段名`、`[节点ID] 当前值`、各行“添加”、底部取消/确定。选定后出现输入卡片，铅笔启用名称编辑，X 移除本张卡片，拖柄控制顺序，右侧“输入预览”显示真实控件。

绑定通过节点 ID 和 field name，不能同名误选。例如 LoadImage-image 是源图上传；生成节点 image1 是图连接口，不应被当成上传 widget。名称本地化为“上传人物照片”“画面分辨率”“画面比例”等。

分辨率和比例应是模型真实下拉选项；模型更换后重查。GPT/Nano 当前节点 resolution 菜单均见 `1k / 2k / 4k`；本 Skill 默认 2k，费用跟随当前选择。不要把 SeaArt 的 `proportion` 当成本模板字段；这里是 `aspectRatio`。

## 范围、同步、提交

“模式与范围”有发布范围、同步AI站开关、Standard/Plus/Ultra 运行模式。发布范围选“发布到社区”；**同步AI站必须 on**；运行模式使用经过测试且适合节点的模式，不能把 Standard 当作图像质量参数。

本次观察同步开关可以切 on/off，但未进行真实跨站发布。后续执行必须核验真实同步结果：记录明确返回状态或 AI 站实际详情 URL；若只有开关和提交结果，就写 `requested` 或 `unknown`，不要声称双站上线。绑定要求以当前账号 UI 为准。

提交只有一次。出现成功提示、跳转或审核状态后记录；遇到超时先核对个人中心中同一应用/版本，防止重复发布。编辑时修复同一应用而不是重新创建。

## 应用试用与结果发帖

公开应用实测页含“立即运行”“我的生成”“历史记录”“作品展示”“发布作品”。运行旁可能显示预估 RH 币；节点顶部也可能单独显示人民币/次，按当前计费说明核对，不能把两种单位相加。

应用发布后使用本次原创源图和必要参数运行一次。只读相同任务的状态，完成后检查实际输出，再进入“发布作品”。

发帖弹窗实测字段：

- 选择作品（0/8），加号打开“我的作品”选择器，可取消/确定；图像顺序可拖拽。
- 作品简介，不超过 200 字。
- 作品标签。
- 发布范围，设为发布到社区。
- “发布”按钮；当前没有独立标题栏。

这个选择器在本次未运行的示例应用中为空，不能据此判断历史作品丢失。实际任务只选该应用本次试用结果，必要时从“我的生成”对应结果进入发布。不要上传本地生成图替代平台试用结果。提交后确认真实帖子与所选结果，保存返回链接；如可见来源应用关联一并记录。
