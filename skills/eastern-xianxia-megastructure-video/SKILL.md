# 东方仙侠巨景视频生成

将用户的一句话、短文或参考图，转化为突出山岳级建筑、天地巨构或超尺度自然景观，并以极小孤独人物强化渺小感的东方仙侠仙境短片。除非用户另行指定，默认一个场景、每场 4–6 秒、16:9 横版、720P；图片优先使用 **Lib Image 或 GPT Image 2**，不可用时使用 **General Image Pro**；图生视频优先使用 **Seedance 2.5**，不可用时使用 **Seedance 2.0**。全程不使用旁白或解说。

## 输入、优先级与边界

收集或合理推断：主题/情绪、主角或主体、参考图（可选）、核心巨构或景观、场景数量、总时长、是否有指定结尾画面。用户提供的参考图和明确要求优先；未指定时默认一个 5 秒场景、16:9、720P。

画风与提示词格式必须锁定为 `references/monumental-xianxia-prompt-library.md` 中的“东方仙侠巨景提示词”体系：宽幅电影远景或超宽幅远景、巨型绝壁/天门/浮岛/神像/遗迹/宫阙/天河等主景、人物如尘埃、冷暗低饱和、少量浅金或银白反光、真实体积雾、空气透视与电影级写实概念艺术。可替换题材元素，但不得让人物成为主视觉，不得漂移为人物近景、西式奇幻、旅游照、普通古风棚拍、动漫或杂乱装饰。

先分析并写提示词；任何会消耗积分或调用生成服务的图片、视频、配乐、重试或最终合成，都必须先展示内容、模型、数量/时长及可用的消耗估计，并等待明确确认。确认只覆盖用户点名的项目；修改和重试视为新的确认项。

## 贯穿全片的风格锁定

在第一次创意输出中固定，下游提示词和素材都遵守：

- 叙事核：极小人物面对、穿越、仰望或朝向天地巨构；人物动作只服务于尺度、孤寂与朝圣感。
- 人物锚点：外貌、服装、道具、人数与位置；原则上只保留一名人物，人物通常不超过画面高度的 1%，必要时仅如单色微点；用户图优先作为身份参考。
- 巨景锚点：先确定唯一主景，再确定平台、桥、亭、古松、云海等尺度参照；主景必须压倒人物与陪衬建筑，占据主要视觉权重。
- 空间锚点：使用狭长天隙、深渊、倒悬大陆、环抱岩壁、云柱、镜面天池、无底云渊等建立前中远三层和不可测深度。
- 构图锚点：每场明确选择宽幅/超宽幅远景与仰视、俯瞰、单点透视、强对称、框景或大面积留白中的一至两种，不混用冲突结构。
- 材质与色彩：风化黑青岩、白玉、旧木、古铜、骨石、琉璃、水体、云雾；以冷灰青、深蓝黑、象牙白为主，只保留克制浅金、银白或灯火点色。
- 摄影锚点：电影级写实概念艺术、真实物理材质、体积雾、空气透视、远景景深和 8K 级细节；避免廉价光效与过度饱和。
- 反向约束：无文字、水印、Logo、人群、现代物件、现代建筑、人物特写、主体人物占比过大、卡通/动漫、西式奇幻、杂乱装饰、喧闹霓虹；按画面再补充特异禁项。

将每个场景的人物、主景、尺度关系、构图、材质、色彩、光向、镜头和首/尾帧关系记录为锚点。后续素材以已确认的同场景图作参考，保持身份、巨构造型和画面体系一致。

## 阶段 1：解析与场景设计（不生成）

1. 从文字或图像提取人物、巨型主景、尺度参照、环境、情绪、色彩、光源和可动元素；说明任何重要的合理推断。
2. 设计一个默认场景；若用户要求多图或多场景，设计连续的场景序列。每场固定 4–6 秒，总长为各场之和。
3. 输出并暂停等待创意确认：
   - 创意概念与风格锁定；
   - 场景总览：编号、标题、叙事功能、巨景/人物尺度、空间构图、时长、建议视频模式；
   - 首尾帧镜头的转场目标（起始状态 → 结束状态）；
   - 每个场景待生成的图片数量。

优先单图首帧模式用于人物凝望或缓慢行走、云雾漫涌、瀑布、天河、松针、衣袂和体积光等氛围动态。首尾帧模式仅用于可清晰定义的状态转变，如云雾揭开孤亭、镜头拉远显露倒悬大陆、天门缓慢开启或天河亮起。禁止用突然变形、随机切镜、剧烈抖动或无因果的大幅运动解决转场。

## 阶段 2：文生图提示词与确认生图

为每张所需图输出一条完整、独立的中文提示词。严格参考 `references/monumental-xianxia-prompt-library.md` 的 19 组原始提示词，保持“构图 → 元素 → 光影色调 → 风格”的单段格式、句法密度与尺度语言，以具体画面描述代替标签堆砌。

格式严格如下：

```text
场景 X｜[首帧/尾帧]｜[Lib Image / GPT Image 2 / General Image Pro]
文生图提示词：构图：……。元素：……。光影色调：……。风格：……。
[尾帧仅列出] 参考图：该场景已确认首帧
反向约束：……
```

- 首选模型池为 **Lib Image / GPT Image 2**：根据当前可用工具、参考图能力和画面连续性选择其一；若两者均可用，首帧默认 Lib Image，需参考已确认首帧的尾帧默认 GPT Image 2。两者不可用时才使用 **General Image Pro**。必须在确认前明确实际选用模型，不得虚构模型可用性。
- 所有图片默认 16:9。提示词不得添加 Midjourney 参数或非目标模型参数。
- 每条提示词必须显式说明：主景占据主要画幅、人物是极小尺度参照；避免只写“宏大”“渺小”等抽象词，使用“人物如尘埃/微点/一粒像素”“建筑山岳级”“桥细若丝线”等可视关系。
- 每场只设一个视觉主景；优先从参考库 19 个母题中选取或组合一至两个互不冲突的空间关系，不照搬与用户主题无关的完整示例。
- 构图段先锁定画幅、景别和机位，再写主景、人物位置与纵深；元素段列出 5–8 个关键对象；光影色调段写主色、点色、光向和雾；风格段写东方仙侠超现实、电影级写实概念艺术、材质与明确禁项。
- 尾帧以同场景已确认首帧为构图和风格参考，只表达阶段 1 的结束状态；保留人物身份、服装、位置逻辑、主景造型、材质、光影和镜头体系，不无故增删巨构。

汇总“图片、专属场景/用途、完整提示词、模型、16:9 画幅、数量、预计消耗”，然后明确等待生图确认。获确认后才调用模型；先生成和检查首帧，再生成需要的尾帧。检查主景视觉权重、人物微小尺度、构图、空间深度、材质、文字伪影及反向约束；不合格时先解释问题与重做方案，再请求新确认。

## 阶段 3：图生视频提示词与确认

只在图片被确认后，为每场写一条图生视频提示词。默认使用 **Seedance 2.5**；不可用时使用 **Seedance 2.0**。使用该场自己的首帧，或自己的首尾帧；若用户提供了适合作尾帧的图，也可用首尾帧模式。提示词参考 `references/monumental-xianxia-prompt-library.md` 的视频模板，强调巨构绝对稳定、人物微小、中式审美与自然连续运动。

格式严格如下：

```text
场景 X｜标题｜固定时长 X 秒｜[首帧参考/首尾帧参考]
参考图：[首帧；尾帧（如有）；用户角色参考图（如有）]
视频模型：[Seedance 2.5 / Seedance 2.0]｜16:9｜720P
图生视频提示词：[运镜 → 人物/过渡动作 → 环境动态 → 巨构稳定和尺度约束 → 画质与画幅]
```

- 先写一个可执行的镜头动作：匀速慢推、横移、轻微上升、慢拉远或锁定构图；单个片段只使用连续、平滑的运镜。
- 再写人物动作和环境动态：极小人物缓慢行走、驻足、抬头或衣袂微动；云雾、瀑布、天河、水面、松针和体积光自然变化。
- 运镜不得把人物推成中近景。优先慢拉远、轻微升高或克制横移，始终维持“巨景主导、人物如尘埃”的尺度关系。
- 首尾帧只描述从起始到结束的渐进变化，不能让人物、建筑、神像、遗迹、山体或构图无故重塑。
- 强制“无抖动、无卡顿、无突变、无切镜、无随机新增人物/建筑/文字”，锁住人物身份、服装、巨构形态、镜头构图与东方电影质感。

完成后展示每场的图片、模式、时长、实际视频模型、16:9、720P、完整提示词和预计消耗，明确等待视频确认；此阶段不得生成视频。

## 阶段 4：按确认生成视频

每条生成前，再展示这条的参考图、模式、时长、实际视频模型、16:9、720P、提示词与预计消耗；得到明确确认后，才调用 Seedance 2.5 或回退到 Seedance 2.0。逐条检查：巨构和人物身份稳定、人物没有被放大、镜头平滑、云雾/水体/衣袂自然、首尾状态符合预设、时长正确、没有新增文字或现代元素。失败重试先给出改写提示词并重新确认。

## 阶段 5：配乐与剪辑合成

视频确认完成后，给出无旁白的音乐和成片方案：

1. 按总时长生成一条配乐提示词：以古琴、箫、埙、低频鼓、钟/磬、空灵人声纹理或弦乐为可选色彩；描述 4–6 秒场景节拍、进入点、情绪曲线和收束。不得加入旁白、念白或歌词，除非用户另行要求。
2. 输出剪辑时间轴：场景起止、视频文件、硬切/叠化/云雾遮罩/匹配剪辑的转场、配乐的进入/渐变/收束。
3. 展示配乐模型（若可用）、成片规格（默认 16:9、720P）、时长和预计消耗，等待对配乐生成及最终合成分别确认。
4. 获确认后生成配乐、对齐已确认视频、执行剪辑合成，交付一段统一的东方仙侠巨景、人物渺小、孤寂空灵短片。

## 交付前自检

- 已以用户输入或参考图为基础，而不是照搬参考库的特定场景。
- 每条图片提示词均使用“构图、元素、光影色调、风格”格式，并明确巨景主导与人物微小。
- 默认一个场景；多场景时每场 4–6 秒、叙事与视觉连续。
- 图片模型为 Lib Image 或 GPT Image 2，General Image Pro 仅作回退；视频优先 Seedance 2.5，Seedance 2.0 仅作回退。
- 默认画幅 16:9，视频默认 720P；模型与规格在每次确认前明确展示。
- 图片、视频、配乐、重试和合成均在实际调用前获得确认。
- 无旁白，配乐与剪辑覆盖整段视频，最终成片维持巨构压迫感、极端尺度、东方仙侠、克制低饱和与电影级写实质感。
