# 百万转场提示词系统

只在阶段 2 和阶段 4 读取本文件。用具体视觉事实替换方括号，不保留占位符；不要机械照抄示例对象。

## 三图共同约束

三图默认 16:9，广告级超写实、电影级 CG、高级商业摄影、真实材质、HDR、干净构图、同一背景世界、同一主光方向、同一色彩体系、同一镜头高度和品牌气质。禁止文字、字幕、UI、水印、虚构 Logo、重复主体、畸形结构、廉价塑料感、杂乱背景和不相关物体；仅保留用户产品已有且非文字的图形标识，默认不生成可读品牌文字。

## Seedance 2.0 全能参考：强制设计规则

1. 只设置一个可被镜头追踪的核心主体：`@image_1`。镜头全程死死跟随它；它通过连续运动和可识别的身份锚点转为 `@image_2`，再闭合为 `@image_3`。身份锚点可用主色、纹理、材质碎片、轮廓片段、能量尾迹或旋转惯性，但不能靠消失后换物。
2. 让所有转场由主体运动触发：飞行、擦边、穿缝、撞击、俯冲、旋转、压缩、展开或接触环境。使用形态渐变、材质过渡、空间透视拉伸和结构重组；禁止硬切、跳剪、黑场、突然变形和无因果换景。
3. 在 15 秒里可视化商业因果链：痛点环境 → 产品/起点物介入 → 使用或接触 → 结果反馈 → 品牌级成品落点。不要用文字、字幕、UI 或旁白解释。
4. 在前 1 秒放置强冲击爆点；2–8 秒连续提升速度、空间和情绪，并设置至少一个二次爆点；13–15 秒从极速骤然凝聚为高级克制的英雄定格。
5. 在 2–11 秒组合使用贴地飞行、低空掠过、贴物跟飞、荷兰角侧倾、俯冲、上扬、甩尾、惯性漂移、擦边穿缝。禁止平稳巡航、无动力漂浮和传统产品陈列式运镜。11 秒后才允许控制性减速。
6. 采用 8K 级细节观感、超写实、电影级光影、HDR、真实液体/金属/玻璃/织物材质、干净克制、无 AI 伪影、无卡通感。8K 描述视觉目标，不覆盖实际 720p 输出规格。
7. 只使用与动作强绑定的环境音、产品音和动作拟音。禁止背景音乐、旁白和歌词。
8. 禁止任何文字、字幕、UI、水印、虚构 Logo、产品漂移、结构穿插、额外主体和随机人物。仅保留用户产品已有且非文字的图形标识；品牌感由产品事实、品牌色、材质、场景和构图表达。

## Seedance 2.0 锁定输出格式

只输出以下一个 PROMPT 块。将方括号替换为具体内容，不保留占位符；根据对象改写变形动词、结构模块和声音，不要给非机械产品硬塞汽车零件。`PROMPT` 内的四个开场段落和六段时间轴必须齐全，不在中间插入解释或候选方案。

```text
图片1（[主题名称]）

PROMPT

[第一段｜整体风格、运镜、结构、主体定义：电影级品牌大片质感，8K 级细节观感，超写实，第一人称主观追随视角，全程单镜头连续完成、一镜到底、无切镜。定义 @image_1 为唯一核心主体，镜头紧贴其边缘跟拍；组合低空贴地、贴物飞行、荷兰角侧倾、穿缝、俯冲、上扬、甩尾和惯性漂移，建立强风压、速度拉扯和动态失衡冲击。明确 @image_1 → @image_2 → @image_3 的连续身份锚点。]

[第二段｜核心主体设定：写清 @image_1 的形状、颜色、材质、纹理、运动方式及可追踪标记；说明所有空间、材质和形态变化都由其运动触发；说明它如何自然展开为 @image_2 的未完成结构，再精密闭合为忠实于用户产品的 @image_3；核心主体不得出画、消失、瞬移或被替换。]

[第三段｜情绪、空间、商业逻辑、品牌调性：写清痛点环境、目标人群可感知的处境、主体介入、接触或使用、结果反馈和品牌级情绪落点；空间按运动自然演化，视觉高级克制；电影级光影、HDR、真实材质、干净画面、无 AI 伪影、无卡通感。全片禁止文字、字幕、UI、水印、虚构 Logo、额外主体和随机人物。]

[第四段｜声音与时长总则：固定 15 秒、16:9、Seedance 2.0 全能参考、720p；只使用与画面动作逐点绑定的环境音、产品音和动作拟音；无背景音乐、无旁白、无歌词。]

【0s-2.0s】（爆点钩子）
→ [0–1 秒用 @image_1 的瞬间弹射、破裂式冲出、极近擦镜、能量触发或等价动作制造强冲击；镜头立即锁定主体，细节清晰、速度猛烈，同时让痛点环境在背景中可读。禁止用切镜制造爆点。]

【2.0s-5.0s】（第一段穿梭）
→ [主体低空贴地或贴物高速飞行，在痛点/使用场景中擦边穿缝、俯冲或侧倾，建立空间、速度和目标人群情境；环境透视由主体运动连续拉伸，镜头不丢失主体。]

【5.0s-8.0s】（第二段穿梭）
→ [升级空间复杂度、速度、情绪和品牌调性；加入至少一个二次视觉/动作/情绪爆点，使用上扬、甩尾、惯性漂移或极限穿缝；主体的材质或纹理只在运动中渐进变化，为产品介入蓄力，不突然变形。]

【8.0s-11.0s】（产品介入）
→ [主体以触地、撞击、穿透、旋入、接触原料/装置或等价使用动作触发转化；@image_1 沿连续轨迹展开为 @image_2，展示真实核心模块的解锁、滑移、编织、聚合或扣合；镜头继续紧贴并环绕推进，明确产品如何介入痛点。]

【11.0s-13.0s】（效果扩散）
→ [@image_2 的结构继续精密生长、折叠、拼接和闭合为 @image_3；环境因产品作用产生可见但克制的结果变化，完成卖点反馈；保持用户产品轮廓、比例、配色、材质、关键结构和已有非文字图形标识位置，镜头开始控制性减速。]

【13.0s-15.0s】（品牌收束）
→ [镜头从高速骤然凝聚到英雄角度，@image_3 稳定落地并至少保持 1 秒；用品牌色、真实反射、轮廓光、环境剪影和高级留白完成情绪闭环，不生成任何文字、口号、字幕、UI 或新 Logo。]

音效设计：
→ [按六个时间段写清关键声音及触发动作：开场低频脉冲/破空；穿梭风切、whoosh、摩擦和场景环境音；转化阶段的接触、流动、解锁、液压、伺服、滑轨、编织、扣合或材质专属声；效果扩散与最终落地收束声。每个声音必须对应画面动作。全程无背景音乐、无旁白、无歌词。]
```
