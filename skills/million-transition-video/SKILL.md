# 百万转场视频

把用户的产品图、物品图或文字描述转化为一段 15 秒、16:9 的连续变形广告：`起点物 → 结构态 → 成品落地`。以用户上传图片为最高事实来源；文字只补充图片看不清或未表达的信息。

## 不可变默认值

- 静态图：GPT Image 2，16:9，三张图。
- 视频：Seedance 2.0，720p，默认 15 秒，16:9，全能参考模式。用户可明确要求 30 或 60 秒，但须先按下方扩展规则检查能力。
- 视频结构：第一人称追随视角、单镜头连续完成、无切镜；单一核心主体高速穿梭并触发 `起点物 → 结构态 → 成品`，最后英雄姿态收束。
- 声音：只保留高质感拟音和机械音效；不加背景音乐、旁白或歌词，除非用户明确要求。
- 画面：广告级、超写实、电影级 CG；三图统一色彩、材质、光向、镜头语言和品牌气质；默认无人物（手持起点物除外）、无文字、无字幕、无 UI、无水印、无虚构 Logo。
- 参考图优先级：用户产品图 > 用户其他参考图 > 用户文字描述 > 合理推断。不要擅自改变产品造型、颜色、材质、非文字图形标识位置或关键结构。

## 工具与模型路由

在实际生成前确认当前可用工具确实支持指定模型、尺寸、时长与全能参考模式；按工具自己的最新帮助或技能说明执行，不要猜参数。

- 使用 GPT Image 2 生成三张静态图。成品落地图必须把用户产品图作为图像参考；起点物和结构态也应引用用户图以继承设计 DNA。若当前工具不支持图像参考，暂停并说明，不要退化成纯文生图。
- 使用 Seedance 2.0 全能参考模式生成最终视频，并按 `@image_1`、`@image_2`、`@image_3` 的顺序绑定三张已确认图片。
- 若通过 Dreamina 执行，先加载并遵守 `$dreamina-cli`；若通过 LibTV 画布执行，先加载并遵守 `$libtv-cli`。如果指定模型不可用，报告实际可用选项并等待用户决定，不要静默换模型。
- 保存生成资产、提示词、任务 ID 和最终状态。异步任务只有达到成功终态才算完成。

### 30/60 秒扩展

仅在用户明确指定 30 或 60 秒时启用。先确认当前 Seedance 2.0 工具是否支持一次生成对应时长且保持全能参考和单镜头连续性：

- 若支持单条长视频，将六段节拍按比例扩展，并在穿梭段增加有因果的空间层级；仍只输出一条 PROMPT，保持一个核心主体和一次连续运镜。
- 若不支持，不要假装能生成真正的一镜到底长片，也不要自动拆片。向用户说明限制，提供“保留 15 秒”或“生成 2/4 个连续 15 秒片段并后期衔接”方案；后者每个片段都要单独列出并走积分确认门。

## 硬性积分确认门

任何生图、生视频、重试、变体、放大或重新生成调用前，必须先展示将使用的内容、模型、数量/时长、规格和可得的积分估计，然后停止等待用户选择。每次固定给出：

1. **确认生成**
2. **调整后生成**
3. **其他要求**

只有用户明确选择“确认生成”或同义的无歧义授权，才可执行本次列出的生成项。“调整后生成”表示先修改并重新展示，不能立即生成；“其他要求”按新要求更新后重新确认。一次确认只覆盖当次列出的项目，不自动覆盖下一阶段、失败重试或新增变体。用户在最初请求中说“直接做”也不能越过生图与生视频两个独立确认门。

## 阶段 1：解析输入并锁定产品

1. 检查用户图片的主体、轮廓、比例、材质、配色、品牌元素、可动结构、使用场景和视角。多图时区分产品主参考、细节参考和风格参考。
2. 提取或合理推断产品信息、核心卖点、使用场景、目标人群、广告风格和时长。只有缺失信息会显著改变成品时才提一个简短问题，否则明确标注推断。
3. 记录不可漂移锚点：产品名称、外轮廓、主色/辅色、材质、关键结构、品牌气质、最终场景、禁止改变项。
4. 将商业逻辑压缩为一条视觉因果链：`痛点环境 → 产品/起点物介入 → 接触或使用 → 结果反馈 → 品牌级成品收束`。不使用旁白、文字、字幕或 UI 解释卖点；必须让环境和动作自己表达。
5. 判断该对象是否适合机械展开。非机械产品也可使用材质剥离、层叠解构、零件聚合、包装展开、织物编织、液体凝聚或粒子铸造成形，但结构态必须可理解、可过渡。

## 阶段 2：设计三态构图与提示词（不生成）

先完整读取 [references/prompt-system.md](references/prompt-system.md)，再设计三张图。

### 2.1 选择起点物

起点物必须和成品存在可解释联系，并且形体简单、便于高速运动、落地和展开。按以下顺序选：

1. 原料或能量来源：咖啡豆 → 咖啡机，金属锭 → 腕表，芯片 → 电脑。
2. 功能或结构同源物：镜片 → 相机，钥匙 → 汽车，齿轮 → 机械产品。
3. 品牌或文化符号：高级扑克牌 → 豪华汽车，潮玩徽章 → 潮玩成品。
4. 包装或核心部件：香水瓶盖 → 香水，耳机充电盒 → 耳机。

解释一句选择逻辑。若联系过弱或只靠外形相似，换一个更强的起点物。起点物不要直接做成成品缩小版。

### 2.2 设计结构态

结构态必须清楚连接起点物和成品，但仍明显“未完成”：展示核心骨架、功能模块、展开轨迹和装配逻辑，保留 30%–60% 未闭合区域。避免完整外壳、完整品牌正脸或已经像最终成品。

### 2.3 设计成品落地

成品图必须贴合用户上传产品，以同一造型、颜色、材质和关键细节进入适合视频结尾的英雄场景。不要仅复刻白底商品图；在不篡改产品的前提下补充地面接触、环境反射、轮廓光和可用于收束的留白。

### 2.4 输出创意板

按以下顺序展示：

- 产品锚点与不可改变项。
- 商业策略：核心卖点、目标人群、痛点环境、产品介入、结果反馈与品牌情绪落点。
- 核心转场概念及起点物的关联理由。
- 三态表：图片编号、形态、构图、主体尺度、环境、动作潜力、与下一态的连接。
- 三条完整 GPT Image 2 提示词及各自反向约束。
- 一致性锁定：画幅、镜头高度、主光方向、主色、金属/玻璃/织物等材质、背景世界、景深和品牌气质。

然后进入第一次积分确认：列明 `GPT Image 2 × 3 张，16:9` 和预计积分，给出固定三个选项并停止。

## 阶段 3：按确认生成并审核三张图

获得生图确认后，按 `image_1 → image_2 → image_3` 生成：

1. `image_1 起点物`：使用用户图提取色彩和品牌设计 DNA，但保持为关联物，不变成成品。
2. `image_2 结构态`：同时参考用户图和已生成的 image_1，锁定光色与空间；保持明显未完成。
3. `image_3 成品落地`：以用户产品图为主要图像参考，同时参考前两图的光色与环境；产品事实必须最接近用户原图。

逐张检查：主体是否单一清楚、三图是否同一视觉世界、起点物联系是否可读、结构态是否真的处于中间态、成品是否忠实、是否有文字/水印/畸形部件/错误 Logo。任何重做都先展示问题、修正提示词、预计积分和固定三个选项，等待新确认。

三图全部合格后，向用户展示并询问是否认可作为视频参考；此认可不消耗积分，可直接收集反馈。

## 阶段 4：编写视频提示词（不生成）

只使用用户已认可的三张图。按 [references/prompt-system.md](references/prompt-system.md) 的视频模板写一条完整中文提示词，并确保：

- 明确绑定 `@image_1` 起点物、`@image_2` 结构态、`@image_3` 成品。
- 将 `@image_1` 定义为唯一可追踪核心主体。镜头全程紧贴并追随它；其变为 `@image_2`、再变为 `@image_3` 时，使用同一纹理、色彩、能量轨迹、轮廓片段或运动惯性维持连续身份。核心主体不能出画、消失后重生或被其他物体取代。
- 严格采用六段 15 秒节拍：`0–2 秒爆点钩子；2–5 秒第一段穿梭；5–8 秒第二段穿梭；8–11 秒产品介入；11–13 秒效果扩散；13–15 秒品牌收束`。
- 0–1 秒必须出现一次强冲击开场；2–8 秒持续刺激并至少再设置一个视觉、动作或情绪爆点；13–15 秒以从极速到凝聚的反差结束。
- 运动连续且因果明确；所有空间、材质和形态变化必须由核心主体的飞行、擦碰、穿缝、俯冲、撞击、旋转或展开自然触发。允许运动中的渐变和结构重组，禁止硬切、跳剪、黑场、突然变形或无因果换景。
- 2–11 秒必须使用低空贴地、贴物飞行、荷兰角侧倾、俯冲、上扬、甩尾、惯性漂移、擦边穿缝中的多种高速运镜；禁止平稳巡航、无动力漂浮和传统陈列式广告运镜。11 秒后可有控制性减速，最终至少稳定 1 秒。
- 在动作中隐性完成 `痛点环境 → 产品介入 → 使用/接触 → 结果变化 → 品牌收束`，卖点必须被看见而不是被文字说明。
- 成品形态、颜色、材质与用户图一致；不新增产品、人物、文字或 Logo。仅保留用户产品上已有且非文字的图形标识；默认不生成可读品牌文字。
- 画面锁定 8K 级细节观感、超写实、电影级光影、HDR、真实液体/金属/玻璃/织物材质、干净克制、无 AI 伪影、无卡通感；最终请求规格仍为 720p。
- 全片禁止任何文字、字幕、UI、水印。品牌收束用产品造型、品牌色、材质、环境剪影和构图留白表达，不要求模型生成文字或额外 Logo。
- 末尾包含独立“音效设计”段，只允许环境音、产品音和动作拟音；每个关键声音绑定对应时间与动作，并明确无背景音乐、无旁白、无歌词。
- 严格按参考文件的锁定格式输出一个 PROMPT 块，不插入解释、多个候选版或额外分镜。

展示参考图映射、完整提示词、`Seedance 2.0 / 全能参考 / 720p / 15秒 / 16:9 / 1条` 和预计积分。进入第二次积分确认，给出固定三个选项并停止。

## 阶段 5：按确认生成视频并交付

获得视频确认后才提交生成。等待异步任务达到成功终态并下载结果；只提交一次，除非用户另行确认重试。

验收以下内容：

- 三态按既定顺序出现，起点物、结构态和成品均可辨认。
- 核心主体全程可追踪，镜头没有丢失或更换追踪对象。
- 变形和换景均由主体运动触发，结构关系可信，无随机切镜、跳剪、黑场、突然变形、融化糊成一团或额外物体。
- 0–2 秒有爆点，2–8 秒保持高速刺激，8–13 秒完成产品介入、结构转化和效果反馈，13–15 秒反差收束。
- 用户痛点、产品使用或接触、结果变化和品牌落点都能从画面读出。
- 成品忠实于用户图片，最终英雄姿态至少稳定 1 秒。
- 默认 15 秒、16:9、720p；无文字、字幕、UI、水印、人物漂移或画幅异常。用户明确选择并确认扩展方案时可为 30/60 秒。
- 声音为高质量破风、撞击、解锁、液压、伺服、滑轨、锁定、电流收束等拟音；无背景音乐。

若不合格，先说明具体问题和最小修复方案，更新提示词，再按积分确认门重新请求授权。合格后交付一段最终视频，并附简短规格与所用三图映射，不把中间任务日志当作最终成片。

## 交付前清单

- 用户图是产品事实来源；文字未覆盖图片事实。
- 起点物与成品联系明确，且不是成品缩小版。
- 结构态未过早成为成品，具有严谨的装配逻辑。
- 三张图风格、背景、光色、材质和构图连续。
- 生图与生视频分别获得明确确认；每次重试也单独确认。
- 视频使用 Seedance 2.0 全能参考模式，720p、15 秒、16:9。
- 视频严格采用六段 Brand Flow 时间轴，且只追踪一个连续核心主体。
- 所有转场由主体运动触发；画面无文字、字幕、UI 或水印。
- 最终只交付一段完整视频，贴合用户产品，并且无背景音乐。
