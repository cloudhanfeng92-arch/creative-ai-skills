# 故事讲解视频

从故事真值分析到角色场景、剧情表演、配音字幕与完整成片。

## 使用方式

先按仓库[安装指南](../../docs/INSTALL.md)安装本目录，再在支持 Skill 的 AI 助手中输入：

```text
使用 $story-explainer-video，把“陶渊明归园田居”制作成约60秒故事讲解短片，先给脚本和分镜。
```

## 输入与结果

示例中的主题、时长、画幅和参考素材可替换为自己的需求。涉及参考图或视频时，请同时提供可访问的素材。具体必填项、默认值与交付格式见 [SKILL.md](SKILL.md)。

## 工具与环境

此 Skill 的流程涉及：LibTV / libtv CLI、FFmpeg、Python。工具、账号、模型权限和额度需要单独准备；安装 Skill 本身不会安装这些服务。部分流程需要先确认提示词与生成费用，请遵循原 Skill 的步骤。
