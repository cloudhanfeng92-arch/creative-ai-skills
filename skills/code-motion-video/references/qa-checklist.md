# 轻量观感检查与按需排错

正式导出后合并做一次轻量规格与观感检查，不单独制作默认样片、评分表或验收报告。通过实际可用的后台媒体读取能力完成；网页辅助观察按需且只用内置浏览器官方工具，不接管桌面、不打开前台播放器或另设审批。

## 正常交付检查

- **静帧用于构图排错。** 使用内置浏览器官方工具实际提供的截图，或已存在无浏览器入口/FFmpeg 输出的代表帧，查看缺字、主体比例、遮挡、空白和溢出。旧 `render-preview.mjs` 已禁用；零散静帧不能证明运动路径、速度、节奏和转场正确。
- **实际连续观察关键变化。** 从正式 MP4 后台抽取核心动作及相邻交界的短段，保留原始时序，通过可查看的短片或带时间的连续帧序列离屏观察起势、重音、收势与落点。覆盖最能体现设计的变化即可，不规定片段数量或逐镜重看，不另渲染一版样片。若只能看到零散静帧，如实说明未检查连续动作，不把推测写成通过。
- **关注设计是否发生。** 注意力能否跟随主体到达新关系；主次动作是否抢戏；物性和产品身份是否稳定；共享对象的方向、速度、尺度及遮挡交接是否跳变；重音后能否读懂结果。结合内容判断产品功能是否可见，或歌词的语义、乐句呼吸是否被字效打断。
- **核对必要规格。** `validate-video.mjs` 默认读取编码、尺寸、帧率、时长和所需音轨，不全片解码，不能据此声称没有坏帧。网页预览与 HTML 播放验证按需，仅通过 Codex 内置浏览器官方工具按实际能力检查，不能假定支持本地文件、任意 seek 或断网验收；能力缺失时注明运行或离线行为未验证。封面确认文字、核心构图与裁切正常。
- **检查对应声音。** 有声音时使用可用的媒体读取能力结合相关短段抽听配乐、音效或明确要求的人声，不自动调用前台播放器或外放系统声音，核对配乐是否支持本片主题、叙事立场与段落情绪，音效是否匹配动作时机、材质、重量和远近，以及音乐、音效、人声是否抢焦点，阅读段是否有留白。音轨存在或峰值正常不代表听感与声画匹配通过；按能力分别说明未试听或未同步观察的部分。默认没有朗读是预期结果，不要求完整重复听审。

只修复实际发现的问题，修改后复查受影响的动作和交界；技术参数通过不能替代观感判断。

## 具体故障再展开

| 情况 | 处理 |
| --- | --- |
| 同一时刻画面变化、随机闪动 | 通过内置浏览器官方工具实际支持的定位，或已有无浏览器入口，比较同一时间的输出；不调用旧渲染器或假定工具支持任意 JavaScript。 |
| 已知转场、文字或动作异常 | 用允许入口输出或从现有视频用 FFmpeg 抽取目标时间窗，观察共享对象、速度和阅读落点；无法连续观察时说明检查范围。 |
| 文件损坏、播放异常或要求严格解码 | 使用 `validate-video.mjs --full-decode`。 |
| 音画不同步 | 核对相关 cue 的音轨起点、动作重音与时长，修复后只复查该段。 |

如实报告实际做过的检查，不因工具存在就运行全套。
