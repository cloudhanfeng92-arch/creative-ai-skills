# 分镜、宏观节奏与母题发展

组织内容、安排整体张弛或展开分镜时读取。先确定必须保留的信息、素材、时长和比例；简单短片用几行即可，不新增长提案或确认关卡。

## 按观众的发现组织段落

决定观众起初知道什么、接下来看到什么改变、最后理解或感受到什么。每段围绕一个主要发现，选择能使发现发生的动作；不要先均分时长，再把文案装进相同版式。关键数字、公式及年份保留简短出处，示意表达与真实测量要区分。

分镜继续使用「镜号 / 文案或歌词 / 文字表现 / 主视觉与动作节拍 / 预计时长」。动作栏写明关键姿态、主要注意力路径、变化结果及下一段承接物；必要的 timing、阅读停留和声音重音直接记在同一栏，不另建复杂表格。细部方法见 [动态设计](motion-design-standard.md)。

文字默认参与构图，不固定在底部；用户指定的完整文案不能缩成几个关键词。没有朗读时按阅读与观察时间编排，不能假设观众只需看图。明确要求配音才生成 TTS 并以实际时长回填；已有歌曲按实际乐句安排。

## 先有全片张弛，再有镜内速度

把关键观点、最大视觉变化和收束的位置放进现有时间轴，判断前后哪段蓄势、哪段展开、哪段需要呼吸。动作强度、信息密度与音乐能量可以配合，也可以有意错开：复杂关系揭示时减少新文字和装饰动作，重音后留出确认结果的空间。

快慢对比来自有意义的状态变化及其停留，不来自固定切镜频率。连续长镜可以经历关系递进，短镜也可以安静。不要每段同样长度、同样入场，或机械循环“快镜加慢镜”；每个局部都追求峰值会让真正的重点消失。

回看整体时判断：中段是否只在重复开场动作；高潮是否改变观众对前面信息的理解；结尾是否在视觉关系上完成收束。依内容调整，不强制叙事段数或效果配额。

## 让母题变化并被回收

选择与内容有关的轮廓、路径、空间关系或动作规则作为母题，第一次出现让观众认识其含义。再次出现时改变角色、尺度、约束或参与关系，带出新信息；保留足够的身份锚点，使观众知道它从哪里来。

结尾可让同一对象或动作回到开场的构图关系，但状态、含义或结果已经改变，使前面的铺垫被看懂。只有几秒的短片可在一次变化内部完成这一过程，不必添加片头片尾。若再次出现只增加装饰或重复结论，删掉重复段或重写其任务。

## 时长服从动作与理解

| 当前任务 | 时间安排的依据 |
| --- | --- |
| 识别动作或产品 | 先建立识别锚点，再完成变化，结果保留到能确认；功能部位不能只在运动模糊中掠过。 |
| 因果、比较或机制 | 依次建立条件、改变变量、显示结果，保留前一步可比较的对象；视线需要往返时增加停留。 |
| 公式或符号关系 | 先建立符号与图解对应，再突出当前变换，最后留出读懂完整结论的时间。 |
| 歌词与节奏文字 | 服从乐句、语义重点和呼吸；重拍强调重要的词，不让每个字都成为视觉重音。 |

阅读停留从必要文字与关系完整就位后开始，不能被入场或转场吃掉。观众推理时让相关对象、正文与公式稳定；内容拥挤就拆分或延长，片长受限先删重复和装饰。字幕可以跨连续镜头保留，关系讲完再换，不能为切镜打断意义。

安排交界时，将下一镜起态放回上一镜末段共同判断，保证承接物的注意力位置、动势和尺度趋势能接续，具体方法见 [动态设计](motion-design-standard.md)。这些选择直接落实到同一时间轴，正式导出后结合关键动作短段做一次轻量观感检查，不增加默认样片或逐镜审批。
