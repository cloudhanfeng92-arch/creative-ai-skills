# 语义文字与歌词编排

设计主视觉文字、动态字幕或歌词时读取。默认把旁白文案变成可见内容，不生成朗读。

## 先确定词句在画面中的作用

区分承担主要变化的词、解释关系的文字和稳定阅读的说明。中文按词义与语法分组，保留句子的完整含义；先决定阅读顺序和构图重心，再安排动作。标题、主体与说明不同时争夺重音，说明文字可以稳定出现。

让字效表达当前语义：词组的距离变化可以呈现关系，笔画或词句形成的结构可以参与主动作，文字也可成为对象的标注与空间基准。选择理由来自内容，不能先选一套效果再给所有词套用。移除装饰后，动作若不能帮助理解这个词或这句话，就简化它。

字形变换保留可追踪的轮廓或合理中间状态，阅读时恢复清楚的笔画、字距和对比度。文字穿插物件时遵守前后遮挡，重要语义不能一直藏在后面。关键词完成主动作后落定，说明利用新的负空间展开，不让整句跟着相机持续漂移。

字体、字重、尺度关系和动作性格共同支持本片母题。叙事文字、技术标注和音乐文字不预设一套配色或位置；参考用于理解层级与节奏，不把具体轨迹、字体组合或物件当通用模板。

## 用同一时间轴驱动文字

将完整文案按意思拆成短句或词组，记录 `text/start/end`，必要时增加词级时间与表现参数。无音轨时按阅读与画面任务定时，后出现的词也要留足理解时间；不用 TTS 测时。

```js
const cue = {
  text: '让文字成为画面', start: 2, end: 5,
  words: [
    { text: '让文字', start: 2, end: 5 },
    { text: '成为', start: 2.4, end: 5 },
    { text: '画面', start: 2.8, end: 5, emphasis: true }
  ]
};
// 在 seek(t) 中按 t - word.start 计算状态；时间仅示意，不是固定节拍。
// emphasis 服从本片语义与构图，不固定为放大或金色。
```

使用 Canvas `fillText`、SVG `<text>` 或 DOM 文本，支持中文字体回退、分行与宽度测量。先为最终可读状态分配空间，再设计进入与离开；按词义选择整句、词组或逐字表现，不用压缩字号解决所有拥挤。

全部文字状态由 `seek(t)` 决定，后台逐帧截图与任意定位得到相同结果；不依赖真实播放进度、TTS 回调、speechSynthesis 或累计定时器。文字进入最终画面，SRT/LRC 只按需附送，不能代替要求的视觉表现。

## 歌词按乐句呼吸，不按每拍换字

先听实际音轨中的乐句起止、停顿、延音、重音与情绪转折，再将完整语义组安排进同一时间轴。已有 LRC/SRT 或词级时间优先复用；只有句级依据时按句编排，不伪造逐字精确对齐。

重点词在演唱重音或情绪落点完成主要变化，其他词维持连贯阅读。快速密集歌词减少字形变化并提前建立阅读顺序；延音可以维持姿态或缓慢发展，不能持续抖动到无法辨认；换气与句间空隙可用于退场、留白或交接，不强行塞满动作。阅读停留可以超过单字发声长度，但不能误导下一句的归属。

重复副歌保持可识别的运动母题，随情绪或结构升级构图、尺度或空间关系，不整段机械复制，也不每次换成无关效果。文字与图形的重音共同服务乐句，不让相机、背景、每个字同时卡拍。

没有歌曲时也可做歌词式动态文字，不自动创作演唱或追加朗读。导出后选择包含重点词、句间交接或复杂变化的实际短段连续观察：能否读懂完整语义、重音是否准确、呼吸是否被动作挤掉；后台检查方法见 [轻量检查](qa-checklist.md)。
