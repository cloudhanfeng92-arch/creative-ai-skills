# 代码绘制封面

默认每条成片附一张 `output/cover.png`，封面与视频同画幅、同分辨率；用户指定平台、尺寸或格式时按其要求重新排版。封面单独交付，默认不插入视频时间轴，不改变片长或声音时序。

## 设计与绘制

- 用 JavaScript + Canvas、SVG / DOM 或已有 WebGL 场景实现，复用本片的字体、色彩、材质和核心图形。针对静态封面重新组织视觉重心、标题和留白，可以基于有表现力的关键画面重排，而不是随手截取动画中过渡未完成的一帧。
- 一个鲜明主视觉配简短主题标题，用字号反差、图文关系与克制的辅助信息建立层级，缩小后仍能认出主题、读清标题。表达与片中内容一致，不用整段解说或完整推导塞满封面。
- 封面延续本片的审美与气质；默认不添加制作标签、技术栈、水印、自我宣传或模板占位文案。只有用户明确要求时才加入署名或品牌信息。

## 单帧导出与交付

1. 复用项目依赖，保留可编辑的封面绘制入口，例如 `src/cover.js`、独立 `cover.html` 或 `cover.svg`，让标题、配色与核心图形可修改；按实际实现选一种即可，不要求多份等价源码。
2. 等字体和素材就绪后，渲染完整静态构图。优先使用 Codex 内置浏览器官方工具实际支持的截图/导出能力；先确认可获得正确尺寸与目标内容，不假定可任意操作 Canvas 或导出文件。能力不足时才复用项目已有、确认不启动浏览器的原生 Canvas/Skia/SVG 等 PNG 输出入口。不得用 Playwright、外部 Chrome/Chromium 或桌面录屏代替；没有兼容入口就保留封面源码并说明 PNG 未完成。
3. 输出一张最终 PNG，随现有预览快速看一眼尺寸、缺字、裁切与标题可读性。封面不需要全片编码，不为它新增多套候选、独立审批或重复视频渲染。
4. 最终并列提供 MP4、可播放 HTML、封面 PNG 与项目源码的可点击路径。封面源码可以包含在项目源码中，无需额外交付一个封面播放器；不能只交付封面代码而漏掉实际图片。
