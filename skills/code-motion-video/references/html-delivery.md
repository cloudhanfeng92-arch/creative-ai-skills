# 可直接播放的 HTML 成品

默认在 MP4 之外再交付 `作品名.html`，像一份可独立打开观看的代码动画作品。用户明确只要其他格式时按其范围。

## 成品形态

- 双击即可打开，动画、主题文字、字幕或歌词实际由代码绘制；保留原动画内容，不用静态截图或嵌入 MP4 代替。
- 优先一个文件：内联 CSS、JavaScript、配置与必要素材，脱离工程目录也能播放，不要求终端、开发服务器、安装环境或登录。
- 保持作品画幅比例并适应窗口。提供轻量播放/暂停、重播和进度操作，有音轨时提供启用声音或静音开关；控件不要抢画面。
- 画面可以直接播放；声音在用户点击后开启并与时间轴同步。默认不朗读的规则同样适用于 HTML。
- 默认原创 BGM 与音效由 JavaScript 离线合成，HTML 接入与 MP4 相同的最终混音；合成源码随项目交付。仅在有交互需求时保留实时合成，不能以网页能发声代替 MP4 的实际音轨，做法见 [原创声音](narration-and-audio.md)。
- HTML 的 `seek(t)` 与可用视频入口共用时间轴和纯绘制逻辑，内容与总时长保持一致；页面接口存在不代表内置浏览器工具可调用任意 JavaScript。视频规格改变时同步项目配置。历史 `?render=1` 接口可以保留用于兼容，但不能据此调用旧外部浏览器渲染器。

## 基础模板导出

```bash
node /path/to/skill/scripts/export-html.mjs --project /absolute/project --out /absolute/project/output/作品名.html
```

该工具只封装基础模板约定的入口、主脚本、配置和配置音轨，不是通用网站打包器；具体参数用 `--help` 查看。修改模板的绘图与文案可继续使用，新增外部依赖时按实际项目处理。

对于扩展项目，使用已有打包方式内联模块和小素材，避免 `file://` 下需要 fetch 本地 JSON、外链模块或 CDN 才能运行。必要图片、音频与字体可嵌入 data URL；大素材不适合内联时，提供 HTML 与 assets 的完整压缩包，并清楚说明需一起解压，不能仅交付资源失效的 HTML。优先保持单文件，不为打包再搭建大型框架。

## 一次轻量确认

网页预览与播放验证按需，不作为制作 MP4 的前置条件；真实视觉检查可用成片关键帧和连续片段完成。浏览器动作只使用 Codex 内置浏览器的官方工具，先核对其实际能力。仅在它支持访问成品与所需操作时检查播放、控件和音轨；不假定它能打开本地文件、任意 seek、下载或验证断网行为，也不自动通过系统 `open` 打开 HTML。无法完成运行或离线验证时，仍保留并交付 HTML 源码，明确哪些部分未验证；静态资源检查不能冒充离线播放通过。无需再次编码或重复整套视频检查。

最终并列给出 MP4、HTML、`output/cover.png` 和源码的可点击路径，封面按 [代码封面](cover-delivery.md) 单独绘制导出。HTML 和 MP4 是两个独立格式，完成其中一份不代表另一份也已完成。
