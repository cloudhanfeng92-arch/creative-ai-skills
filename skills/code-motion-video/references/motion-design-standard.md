# 从视觉论点到动作编排

设计核心场面或修正“画面在动但没有表达”时读取。把判断写进现有分镜或代码草图，自主继续制作，不新增设计报告或审核阶段。

## 让本片有独有的视觉逻辑

先用一句话说清“观众通过什么变化，发现什么关系”。选取主题内部可见的动作与约束，发展成母题。例如，只有当内容涉及传递、损耗或抵达时，“同一束信号经过不同结构后改变”才有表达作用，不能只因它好看便用于所有主题。

让轮廓、空间、字体、材质和运动性格共同支持母题。把主题名和文案替换成另一主题，如果核心动作仍几乎无需变化，说明设计还只是通用模板，应重写核心可见变化；装饰不能成为唯一的主题差异。参考片用于提炼关系和编排方法，不复制具体字效、物件或配色。

## 关键姿态与运动中的构图

先明确动作的起势、信息转变的重音和可读落点，再设计它们之间的运动。每种状态都有明确的视觉重心、正负形、大小关系和阅读顺序；只画好最后一帧，往往会让过程变成拥挤的搬运。

沿主动作路径追踪观众视线：首先看哪里，下一处变化如何被引出，原重心如何退让。主体移动时，留白与注释按空间关系重排，次要元素在主动作完成识别后响应。相机因发现新结构或改变观察尺度而运动，不能让镜头、主体和整段文字同时漂移来填时长。

大胆裁切与遮挡可以制造张力，但重要字义、产品识别特征和当前解释关系必须在需要识别时完整可见。主动作经过文字区域时，提前让出空间、改变层级或延后阅读，不能到导出后只靠缩小字体补救。

## 把动作写到能实现的程度

在动作栏或代码草图中简记：

`表达意图 → 关键姿态 → 主动作路径与速度变化 → 次级响应 → 阅读落点 → 承接物`

- **路径有目的。** 写明对象从哪里出发、受到什么约束、经过何处、最终建立什么关系；先确定轮廓、轨迹和空间基准，再选择实现手段。移除装饰后动作若不成立，先修主动作。
- **区分 timing 与 spacing。** Timing 决定何时发生、持续多久；spacing 决定相邻时刻移动多少。先安排重音与停留，再设计路径上的加减速和疏密，使对象可追踪。总时长相同的对象也不一定共用缓动和相位。
- **次级响应有原因。** 被牵引物随后移动，碰撞产生反馈，说明在结构就位后出现；同一语义组可以协同，背景退让。不用随机延迟制造层次，不让标题、主体、装饰同时达到最大变化。
- **物性约束动作。** 刚体保留形状与连接，厚重物体的起停与惯性一致，柔性对象可有滞后和形变；真实机械、轨道和重力按模型运动。弹性回弹只用于符合材质或明确图形化表达的对象，不能一套弹簧套全片。相机变焦与对象本体变大要区分。

预备、发力、收势和停顿按需要取舍，不机械分四拍。停住要有阅读或动作原因，连续通过时不要在每段曲线末尾默认刹停。声音重音跟随同一个关键事件，保留弱动作和安静时刻。

## 跨镜交接属于动作设计

确定前后镜头构图时就选择观众追踪的承接物：共享对象、局部轮廓、轨迹或观看关系。以它安排交界的注意力位置、方向与速度、屏幕尺度趋势及前后遮挡，不在导出前才套效果。

真正延续同一运动时，以共同时间和空间基准衔接端点与切线，保持速度和尺度趋势可解释；不能前镜刚停稳，下一镜无故重新起步。共享对象保留身份、比例和语义颜色，在重叠时间窗只绘制一次，切换场景索引时不能重置相机或对象状态。

遮挡转场在前景实际覆盖待替换区域后交接，退出时延续原来的动势，不借未覆盖的空隙偷换画面。新关系清晰落定后，旧说明适时退出，避免两套文字堆叠。硬切或叠化要有叙事停顿、动作匹配或构图关系支撑，不强迫每镜形变或整片一镜到底。

## 按作品用途判断落点

产品段落先锁定外形比例、关键材质、品牌与功能部位，让观众在运动中仍能认出同一产品；特写与整体之间保留可追踪的结构位置。功能展示采用资料支持的“输入或操作 → 可见反馈 → 使用结果”，必要时用示意层解释内部机制。转一圈后出现卖点文字不等于展示了功能，不能编造性能。

图解让对象、数据与关系共同推进，比例和公式不能为造型失真。纯动态图形可让字形、轮廓与空间关系承担表达，但需保留可识别的中间状态和阅读落点。文字细节见 [文字动效](text-motion.md)，母题发展见 [分镜与节奏](storyboard-standard.md)。

实现预算优先给主轮廓、关键构图、主动作与交界，再考虑局部质感；性能不足先删装饰，保留构图与叙事主动作。完成后实际观察正式导出的关键短段，方法见 [轻量检查](qa-checklist.md)。
