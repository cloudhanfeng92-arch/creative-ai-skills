# 代码动态视频

按主题选择 Canvas、WebGL、SVG 或 Three.js 制作动态文字与图形动画，提供视频、可播放 HTML、封面和源码。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/code-motion-video 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/code-motion-video) 安装 `skills/code-motion-video`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $code-motion-video，用代码制作一支15秒的几何变形动画，配原创音乐，交付MP4、HTML、封面和源码。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- JavaScript/Node.js 运行环境
- 实际可用的内置浏览器导出能力，或项目已有兼容原生绘制入口与 FFmpeg
- 按画面需要使用 Canvas、WebGL、SVG 或 Three.js

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
