# 商业广告分镜规格

## 先做的分析

输出分镜前，内部完成：

1. **产品事实表**：产品名、类别、可见外观/材质/颜色、真实功能、真实使用流程、可证明卖点、禁用或未知断言。
2. **受众与场景**：核心人群、当下痛点、真实使用情境、情绪变化。
3. **创意主线**：一句核心创意，首三秒钩子，逐幕爆点，产品/动作/镜头如何连贯交接。
4. **生产判断**：列出用户素材能直接复用的镜头，以及必须新增的场景图；只为不可替代的镜头生成新图。

不要把分析过程写成长篇思考。对用户只输出简短“创意假设”和成片规划。

## 输出前置段

先写：

```text
创意假设：
- …
总时长：XX 秒（X 幕 × 15 秒）
广告主线：钩子 → … → 品牌收束
场景资产判断：复用用户素材：…；需生成场景图：…
```

若产品、卖点或时长仍有会改变事实的歧义，先提一个合并问题，不生成虚构分镜。

## 分幕叙事规则

- 15 秒：一个完整微叙事，含钩子、痛点/产品介入、结果/收束。
- 30 秒：幕 1 钩子与痛点，幕 2 真实使用、卖点和结果收束。
- 45–90 秒：按钩子、痛点、介入、强化、反馈、收束顺序展开；每幕仍要可独立成立，并通过一个未完成动作、相同物件、视线方向、光线或环境声连接到下一幕。
- 每幕至少设置一个可见的爆点：真实的开启、触碰、液体/材质细节、动作反差或情绪转变均可。爆点必须由真实产品行为支持。

## 场景图与视频决策

标注每个镜头的资产路径：

| 条件 | 决定 |
| --- | --- |
| 用户图片已覆盖所需产品角度、空间和首帧动作 | 复用用户素材，直接写 image-to-video 提示词。 |
| 缺少真实空间、关键动作、产品角度或一致的首帧 | 生成场景图，先给静帧提示词，再写 image-to-video 提示词。 |
| 产品事实、包装或人物身份无法确认 | 不生成，以一个合并问题确认。 |

生成场景图时，给每张图一个用途和提示词。把用户产品图标为唯一产品参考，重复相同的外观锚点；不得以生成图替代或篡改产品事实。生成视频时，逐镜指定时长，使用相邻镜头末帧/同一场景图来维持连续性，最后按原镜头顺序无跳跃拼接。

## 最终自检

- [ ] 总时长为 15–90 秒且是 15 的倍数；幕数为 1–6。
- [ ] 每幕恰好 15 秒、九个指定时间段、九条镜头和一个收束/转场镜头。
- [ ] 每幕有人物、产品（出现时）、视觉设定、爆点、至少三条真实 SFX、跨幕衔接。
- [ ] 前 3 秒有钩子；全片包含痛点、介入、卖点、使用、结果、品牌记忆。
- [ ] 产品至少清晰露出两次，且每次用法/功能均可由输入支持。
- [ ] 每条镜头都有景别、运镜、连续动作、场景细节、产品露出或合理缺席，以及可选的自然语言音轨。
- [ ] 全程无文字/字幕/水印/可读字符；无 BGM；无极限词、绝对承诺和虚假功能。
