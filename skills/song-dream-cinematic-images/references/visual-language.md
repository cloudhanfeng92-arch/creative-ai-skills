# 宋韵旧梦视觉语言

## 1. 人物锁

人物描述至少包含四层：

1. 身份和年龄层：年轻女子、清俊文士、劳作姑娘、年长茶人等。
2. 可见面貌：脸型、骨相、眉眼、鼻梁、嘴唇、肤色和一处自然差异。
3. 发式状态：半束低髻、松髻、长辫、额侧碎发、轻微凌乱或风吹状态。
4. 衣装和情绪：宋式棉麻或复古缎面、固定色位、衣料重量、动作中的褶皱，以及安静、疏离、专注、默契或克制欣喜。

自然美感来自具体面貌和真实状态。皮肤保留毛孔、绒毛、唇纹、自然肤色变化和轻微不对称；发根、发束和碎发清楚。不要用瓷白、完美无瑕或网红妆作为默认审美。

## 2. 故事构图

- 普通正面半身照容易成为影楼写真。优先使用人物正在做事、侧身或侧躺、镜面或水面反射、门洞观察、窗格窥视、前景遮挡、不完全对称和画外视线。
- 环境人物镜头让人物位于画面中下部或偏侧，建筑、溪水、田野、树荫和远山承担叙事空间。
- 前景遮挡只占边缘小部分，不挡脸、眼睛、双手和器物接触点。
- 多人采用松散弧形、对角线或错落深度；每人拥有不同脸型、发式、色位、动作和视线。
- 一张图只有一个主要视觉句子，装饰物服从人物关系和动作。

## 3. 两种光影母版

### A. 明亮宋韵田园日光（默认）

适用于采茶、洗纱、制豆浆、庭院劳作、春日山居、冬日围炉的日间部分。

- 低角度或中低角度暖金日光作为有方向的侧前光或侧逆光，经槐叶、竹帘、梅枝、木窗或棚架筛入。
- 阳光照亮人物面向镜头的一侧脸、双眼眼神光、双手、动作接触点和象牙白衣褶。
- 天空、白墙、浅色地面、水面或雪地提供宽阔柔和的中性暖灰回填，保住眼窝、下颌、黑发、深木和袖口内部。
- 暖金高光，中性暖灰或轻微橄榄灰阴影，肤色温润，白衣保留织纹，暗部深而有细节。
- 画面明亮、通透、低对比度、低饱和度，有空气感但不是全局泛白。

### B. 低照度旧梦钨丝灯

适用于夜间私密肖像、镜前、卧榻、窗边、旧屋和用户明确要求安静疏离的旧梦感。

- 暖金色钨丝灯从侧面形成局部主光，照亮面部轮廓、眼睛、颈肩、缎面或棉麻高光。
- 环境保持低照度和深色背景，明暗交界清楚；另一侧由墙面、镜面或窗外微弱环境光轻轻托起。
- 局部轮廓光只落在发丝、耳缘、衣领和镜面边缘；高光柔和，黑位保留层次。
- 复古胶片色彩、低对比度、轻微光晕和浅景深共同形成旧梦电影静帧，不把画面做成现代棚拍或橙色滤镜。

不要在同一镜头里同时堆叠日光、月光、炉火、油灯和钨丝灯。一个主光源，加一个有物理来源的环境回填即可。

## 4. 材质和色板

- 衣装：米白、月白、黛绿、茶绿、烟青、灰蓝、浅藕粉、茶褐；棉麻有纤维、厚度、重力褶皱，缎面只保留克制柔亮反射。
- 环境：粉白或灰白墙、青石、旧木、竹器、粗陶、铁板、炭火、水、雪、叶片和蒸汽。
- 水与湿布：倒影服从水面平面；涟漪从接触点开始；湿布颜色加深、向下坠并从最低褶皱滴水。
- 蒸汽与尘粒：必须来自茶壶、炭炉、热水或光束中的空气，不作为无源仙气。

## 5. 镜头语言

- 35mm：全景、茶田、村落、多人劳动和环境叙事。
- 50mm：双人或四人关系、中宽景、门洞观察、桌面劳动。
- 85mm：单人中近景、围炉主角、面部与手部的安静情绪。
- 真实全画幅光学、浅至中浅景深、柔和高光滚降、自然镜头压缩、奶油散景或环境散景、轻微镜头光晕和细腻胶片颗粒。
- Canon EOS R5、RF85mm f/1.4、35mm documentary perspective、Kodak film colors 可在符合场景时作为成像锚点，不必每条机械重复。
