# MJ 风格提示词编译器

## 核心结构

按以下顺序编写，每部分都必须对应可见画面：

`人物身份与服饰 → 具体进行中动作 → 环境与空间层次 → 有来源的光线 → 镜头与构图 → 成像与胶片质感`

人物较多或环境占主导时，可以把镜头与环境前置：

`焦段/景别/机位 → 环境层次 → 人物数量与差异 → 分工动作和视线 → 光线 → 成像质感`

## 格式

- 默认写一段紧凑的中文可视短语，用逗号或分号连接；用户要求英文时写自然英文摄影描述。
- 建议约 180–450 个中文字符；复杂四人劳动场景可适度更长，但每一句都必须改变可见结果。
- 先写最重要的主体、数量和构图，再写装饰细节。
- 使用具体名词和动词：提壶、托杯、压布、拧布、推磨、添豆、接浆、过滤、编扇、剥莲子、采茶。
- 光影必须写成来源、方向、软硬、落点和回填来源，不能只写“暖色电影感”。
- 人物数量、器物归属、接触关系和视线必须清楚，尤其是两人或四人场景。

## 不进入提示词正文

- 参考文件名、路径、标题和时间码；
- 画幅文字和 `--ar`、`--s`、`--v`；
- “严格匹配”“最终强制覆盖”“按评分选择”等工作流语言；
- 通用负面词清单、平台参数、积分和节点说明。

默认比例通过 LibTV `ratio=16:9` 设置。用户提供 P 值时写入 `personalisation` 字段；没有 P 值时留空。

## 单人模板

```text
[焦段、机位、景别]，[季节时段和宋式地点]，一位[年龄层、身份和气质]，[具体脸型骨相、眉眼鼻唇、肤色、发式状态]，[衣装层次、颜色和材料]。[正在发生的动作、双手与器物接触、身体支撑、视线和情绪]。[前景遮挡、中景清晰主体、后景环境和留白]。[主光来源、画面方向、侧前或侧逆、软硬、被照亮的脸手和材料]，[墙面/天空/水面/雪地回填及其提亮部位]。[天然低饱和色、曝光与高光阴影关系]，真实全画幅摄影，[相机或镜头锚点]，自然浅景深，柔和高光滚降，真实皮肤与材料，轻微光晕，细腻胶片颗粒，电影静帧。
```

## 多人模板

```text
[焦段、机位、景别]，[地点和前中后景]，明确[人数]位人物围绕[核心器物或劳动]形成[松散弧形/对角线/错落深度]。[逐人写不同脸型、发式、固定衣色、位置、动作、器物和视线]。[动作产生的液体、蒸汽、布料、枝叶或颗粒反馈]。[主光来源、方向、落点]，[环境回填来源与被托亮部位]。[色板、明亮度和材料]，真实纪实摄影，自然关系感，不完全对称构图，[35/50mm]环境叙事，Kodak胶片色彩，细腻颗粒，电影静帧。
```

## 人物与环境配比

- 人物肖像：人物约占画面 35%–55%，仍保留一处环境叙事锚点。
- 双人生活：人物位于中下部，环境占更大比例，动作关系构成对角线或弧线。
- 四人劳动：场景和器物先建立空间，两前两后或左右错层；不把四张脸排成一行。
- 全景田园：35mm documentary perspective，人物作为中景活动点，村屋、山脉、田垄或水系占据大部分画面。

## 编译自检

- 人物是否由具体面貌、发式、衣料和情绪构成，而不是只有“东方女性”？
- 构图是否包含动作、环境、遮挡、视线和不完全对称，而不是普通正面半身照？
- 光线是否有真实来源、方向、软硬、落点和环境回填？
- 镜头是否明确焦段、机位、景深、成像和胶片响应？
- 提示词是否只包含可成像内容，并排除了文件名、时间码、画幅、参数、元指令和长负面清单？
