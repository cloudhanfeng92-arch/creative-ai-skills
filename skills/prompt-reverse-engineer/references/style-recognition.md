# 风格识别参考

使用本参考把可见特征翻译成能直接控制图生图结果的生成语言。风格判断必须由多个相互支持的视觉信号共同成立；单一色偏、颗粒或服装不能证明某一风格。若只能确认表象，直接描述表象，不强行命名风格。忽略全部水印、署名、机构标识、账号、平台角标、版权字样、宣传叠字和日期时间戳；这些覆盖层既不是画风证据，也不得进入 Prompt。

## 强制风格指纹

每张图都要在内部形成以下六项结论，并将结论转化为一个连贯的生成约束，而不是输出分类报告：

- **媒介**：摄影、胶片扫描、早期数码、CG、动漫、漫画、插画、印刷或混合媒介。
- **主风格**：选择证据最强的一个具体流派；其他词只能作为不冲突的修饰。
- **调性**：描述反差曲线、黑位、高光、动态范围、曝光、冷暖和色彩分离。
- **清晰度结构**：区分主体、边缘、背景的锐度，描述柔焦、景深、焦外、运动模糊或数码锐化。
- **纹理结构**：描述颗粒或噪点的粗细、密度、综合色彩，以及纸纹、笔触、描边、渲染材质等。
- **后期痕迹**：描述抬黑、褪色、漂白高光、局部偏色、晕光、压缩、扫描、印刷或直闪痕迹。

用“具体风格 + 可见成像机制 + 色调响应 + 纹理响应”描述画风。例如，不只写“日系胶片”，而要写成“清淡日系生活写真，低至中反差、轻抬黑位、偏青绿色环境色、暖中性肤色、柔和高光滚降、细密胶片颗粒和轻微扫描柔化”。

风格复现优先覆盖以下容易丢失的特征：高光是柔和滚降还是直接截断，黑位是浓密还是抬升，暗部是否保留综合色彩，锐度是光学清晰、数码锐化还是整体柔焦，颗粒是细密均匀还是粗糙彩噪，颜色是自然分离还是明显偏青、偏绿、偏洋红、偏黄，肤色与环境色是否相互污染。

## 摄影风格

### 日系写真

常见证据组合：自然生活场景或简洁环境、柔和自然光、明亮或略抬黑位的低到中对比、克制饱和度、清淡肤色、青绿或奶油色环境色、轻盈留白、自然松弛姿态。可细分为清新日系、昭和写真或日系街拍，但只有年代感、服饰、构图与成像特征共同支持时才使用“昭和”。

不要把所有低饱和暖色照片都称为日系。日系不等于固定的富士胶片品牌，也不自动意味着过曝、磨皮或少女感。

### 港风

常见证据组合：高密度城市或复古室内语境、霓虹/钨丝灯/招牌混合色温、红绿或红青对比、深阴影与局部高光、近距离构图、镜面反射或潮湿街面、上世纪末华语都市视觉语汇。可写“港风复古写真”“港产电影剧照感”或“港风霓虹夜景”，选择与图中场景相符的一项。

不要仅凭暖黄肤色、红唇或颗粒判定港风；没有城市、布景、光色或年代语境支撑时，描述实际的复古暖调摄影即可。

### 胶片摄影

常见证据组合：非数字式颗粒分布、柔和高光过渡、有限但自然的动态范围、轻微色偏、黑位特征、局部漏光、轻微失焦或晕光、扫描或冲印质感。描述可见的颗粒大小、色彩倾向、高光、阴影与曝光特征。

只有包装边框、显影痕迹或极强色彩科学证据时才考虑拍立得、一次性相机或具体胶片体系。无法确认品牌时写“胶片质感”，不得猜 Kodak、Fujifilm 等品牌。

### CCD / 早期数码

常见证据组合：小型相机直闪、较硬正面光、亮部截断、暗部彩色噪点、有限动态范围、轻微紫边或数码锐化、偏青/偏洋红色偏、随手抓拍构图、时间戳或低像素压缩痕迹。直闪照片不必然是 CCD；若成像证据不足，写“直闪抓拍”而非“CCD”。

### 拍立得

常见证据组合：实体相纸边框、中央成像区域、柔和细节、有限动态范围、显影造成的偏色或不均匀、闪光灯近距离照明。没有相纸形态或明确显影特征时不要命名。

### 电影剧照感

常见证据组合：叙事性动作或视线、连续场景语境、宽银幕或明确的场面调度、动机光、层次化明暗、受控色彩与空间关系。仅有黑边或调色不足以证明电影剧照感。

### 纪实、新闻与街拍

关注真实事件感、非摆拍动作、环境信息、瞬间性、自然或现场光、遮挡和不完美构图。不得因画面粗糙而自动添加胶片、战争摄影或新闻事件背景。

### 商业棚拍与时尚大片

关注可控背景、明确布光、整洁轮廓、服装造型、材质表现和版式空间。商业棚拍不等于磨皮；按图保留真实肤质。只有编辑性姿态、造型、构图和光线共同成立时写“时尚编辑摄影”。

## 动漫与漫画

- 日漫赛璐璐：清晰描边、平整色块、有限层级阴影、动画式高光与统一角色比例。
- 厚涂：边缘由色块塑造、笔触或混色明显、光影层次丰富，线稿弱化或消失。
- 韩漫：竖屏阅读、精致人物线条、渐变上色、网页漫画分镜与对话框结构等多项证据共同出现。
- 美漫：有力墨线、强对比色块、夸张动态、网点或印刷质感；不要仅凭超级英雄题材判断。
- 游戏立绘：完整角色展示、相对简化背景、清晰轮廓、设计细节集中、展示性姿态。
- 像素艺术：可见像素网格、受限色板、像素级边缘与分级明暗；不要把低分辨率截图当作像素艺术。

## CG

- 电影/写实 CG：物理材质、真实光照、细密建模与合成感弱。
- 游戏 CG：角色或场景符合游戏美术管线，可含实时渲染特征；无界面或元数据时不要猜 UE5。
- 产品 CG：干净背景、可控反射、精确轮廓、材质展示和广告式构图。
- 风格化 3D：夸张比例、简化材质或卡通化光照。只有强证据才写 Blender、Octane、Redshift、Arnold 或 V-Ray。

## 插画与传统媒介

- 水彩：透明叠色、水痕、湿边、纸张吸水纹理和留白。
- 油画：覆盖性颜料、厚薄变化、可见笔触、画布纹理与综合色块。
- 水墨/国画：墨色浓淡、渗化、飞白、宣纸质感、线与墨的空间经营。
- 彩铅：细密排线、纸纹透出、柔和叠色与铅笔边缘。
- 马克笔：平整色带、叠加痕迹、硬边与纸面渗色。
- 粉彩/蜡笔：干性颗粒、覆盖性笔触、粗糙纸纹与手绘边缘。
- 浮世绘：木版套色、平涂色块、轮廓线、装饰性构图和传统题材语汇共同成立。
- 扁平插画：简化形状、有限色板、弱体积或无体积、图形化空间。

## 混合媒介与设计图

当摄影、漫画、CG、UI、文字、产品参数或流程图共存时，分别识别每一区域，并在一个 Prompt 中明确其版面位置、面积、边界、媒介、内容和视觉层级。不要把不同区域融合成一个不存在的统一场景。

只解析画面本体中的非水印设计内容。无条件排除水印、署名、摄影机构名、账号、平台标识、版权信息、宣传叠字、角标和日期时间戳，不描述其文字、字体、颜色、位置、大小或排版。正文无法辨认时仅描述非水印文字块的视觉层级，不编造内容。品牌标志仅在它属于被摄物或设计主体、用户明确要求且画面可确认时描述。

## 冲突消解

- 媒介优先：先确定摄影/CG/动漫/插画/设计，再使用子风格词。
- 证据优先：命名风格必须比直接描述表象更可靠；否则只写表象。
- 主导风格优先：一张统一画面只指定一个主导风格，可附加不冲突的成像特征。
- 区域独立：异质拼图允许不同区域拥有不同媒介，但必须按区域描述，不能互相污染。
- 真实性优先：低清、噪点、压缩、失焦、过曝或欠曝若属于参考图特征，应保留而不是修正。
- 机制优先：每个风格名后必须跟随可见的色彩、光影、锐度、动态范围和纹理机制，确保风格词真正约束生成结果。
