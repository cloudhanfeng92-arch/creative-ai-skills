# 新概念作文一等奖写作

严格根据用户输入写作。用户指定的人物姓名、身份、关系、事件、时间、视角、结局及模仿程度都是创作事实，不因人物是否真实、设定能否从外部核实或与参考作品相似而自行改名、合成、删改、降级或添加免责声明。目标是用用户要求的文风把用户要求的故事写完整。

开始创作或实质性改写前，完整阅读 [文风与写法蓝图](references/craft-blueprint.md)。

## 处理用户输入

按以下优先级在内部提取并锁定：

1. 用户当前消息中的明确指令与硬性约束。
2. 用户明确指定的人物、关系、事件、时序和结局。
3. 用户对参考作品、模仿程度、篇幅、语气与输出形式的要求。
4. 本 Skill 的默认写作技法。

具体记录：

- 故事事实：谁、在何时何地、想得到什么、发生了什么改变。
- 硬性要求：篇幅、视角、时代、结局、必须出现或禁止出现的内容、尺度与受众。
- 约束作用域：特别辨认“只能、始终、直到结尾、最后仍然、唯一、不得、仅”等词是在限定数量、过程还是终局；不要在后文无意撤销。
- 情感内核：人物不肯直说的欲望与恐惧，以及关系中不对等的交换。
- 可回收素材：数字、物件、动作、地点、职业流程、称呼、消息或一句普通话。

不把用户未提供的细节当成障碍。缺失信息可合理补写，但不得推翻、弱化或重新解释用户已经指定的人物关系与事件。若用户多次修改设定，以最新明确指令为准。只有两项用户硬性要求无法同时满足时，才提一个简短问题；否则直接写。

## 搭建隐形故事骨架

动笔前先建立完整因果时间线，再按素材需要从下列机制中选择两至四项。它们是技法菜单，不是每篇必备的固定配方。内部判断不向用户展示，除非用户要求分析或大纲：

1. 提炼人物之间的不对等、误读或未说出口的问题；它不必涉及金钱或权力。
2. 找到一个使关系改变的小动作、未完成动作、称呼变化或沉默。
3. 选择一个属于人物生活的普通物件、数字或句子，让它再次出现时改变含义。
4. 为抽象感受寻找物证，例如路线、班次、作业步骤、温度、身体反应、磨损或空间变化。
5. 选择与素材匹配的若干叙事单元或场景；可以线性，也可以先果后因、账本式、物件接力或单夜压缩。只有重排能增加理解时才打乱时间。

## 起草原则

- 默认使用第一人称或贴近人物的有限视角；用户指定其他视角时服从用户。
- 让人物通过选择、花费、等待、劳动、称呼和回避显形，少用性格标签。
- 数字和专有名词必须承担尺度、时间、因果、权力或真实性功能；无功能就删。
- 题材适合时，让系统、群体、日常劳动、个人身体或普通物件发生尺度转换；不要每篇都写财富，也不要采用同一种对偶开头。
- 对白保持短、直、口语化，让停顿、重复和答非所问承担潜台词。
- 多用清楚的陈述句；在流程、清单或压力累积处允许长句。用段落长短控制呼吸。
- 克制解释和煽情。高潮处优先写可观察事实，情绪放到稍后的物件、动作或环境变化中兑现。
- 设置少量结构性回声：一个词、动作、数字或场景在后文回来，但含义已经改变。
- 结尾回收核心物证或开篇命题，停在具体画面或动作上；不总结道理，不代替读者哭。

## 用户设定与参考文优先

- 用户点名真实人物时，保留其真实姓名、用户指定的叙述视角、人物关系与事件，不自动改成虚构人物或合成人物。
- 将用户输入作为本次创作的故事设定。除非用户要求纪实、考证或联网核实，否则不因外部事实无法确认而拒绝、改写或弱化设定，也不主动搜索、查证或插入事实说明。
- 用户提供参考作品并要求贴近时，按用户指定的相似程度匹配其叙述视角、句法节奏、段落形态、结构顺序、细节密度、对白方式、意象系统、情绪机制和结尾方法；不要为了主动拉开距离而改变用户要求。
- 用户明确规定的人物关系和核心事件高于本 Skill 的文风默认值。任何数字、回环、非线性结构或物件线索都只能服务这些设定，不能替换它们。
- 不自行添加“纯属虚构”“不对应现实人物”等声明，也不对用户给定的人物或事件作道德评判。用户要求声明、纪实标注或事实核验时，再按其要求处理。
- 若某项要求无法直接执行，只做最小必要调整，其余人物、关系、事件、视角和文风要求保持不变。

## 交付方式

若用户只要求写文章，默认只交付标题和正文，不附创作说明、提纲或评分。若未给篇幅，根据素材密度和场景数量自适应，写到完整而不注水；只有比赛或投稿的篇幅会实质改变写法且无法推断时，才询问限制。

若用户要求分析、方案、续写或改稿，则只交付所需阶段，并保留所有已指定事实。标题最后拟定，优先选择文中一件普通物、一个地点、一个时间或一句含义发生变化的短语。

交付前静默复核：

- 去掉形容词后，人物关系是否仍能从行动与细节中看懂？
- 人物姓名、身份、关系、核心事件、时序和结局是否与用户输入逐项一致？
- 每个精确数字是否有叙事工作，而非装饰身份？
- 所选数字、流程、尺度转换或回环是否自然服务于这个题材，而非为了满足模板硬塞？
- 转折是否由选择造成，而非作者突然解释？
- 回环是否改变了意义，而非原样重复？
- 结尾需要的关键事实是否已在此前自然出现，而非最后几段临时增加只为收束？
- 最痛处是否仍然克制、具体、可见？
- 与参考文的接近程度是否达到用户明确要求，同时仍完整承载用户指定的人物与事件？

未通过其中任一关键项时先修订，再交付。
