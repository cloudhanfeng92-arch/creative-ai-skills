# 宋式关键帧光影与质感硬锁

本页把用户教程图和参考视频中的提示词、摄影与布光规律固化为生图阶段的不可省略规则。它适用于人物、群像、空镜、庭院、溪流、舟船、作坊、街巷、雨夜与写实武侠动作首帧。主题可以变化，光影逻辑、材料真实性和克制实拍质感不能漂移。先读取 `arvin-lab-light-master.md`；参考视频中的实际光影是最高优先级视觉母版。“明亮”必须来自可解释的太阳、天空、白墙、水面、灯火或雪地反射，不能靠全局抬曝光和均匀棚拍光伪造。

## 0. 参考光影优先级与逐镜光影卡

优先级固定为：**用户指定参考视频的对应镜头光影 > 用户指定参考图片光影 > 本页默认光影**。只继承布光、曝光、镜头与材质观感，不复制参考片中的字幕、Logo、水印、人物身份或剧情内容。

若用户提供视频或明确要求还原某段光影，先从每类代表镜头提取并记录 `LIGHT_REFERENCE_CARD`，再写任何生图提示词：

```text
LIGHT_REFERENCE_CARD
- 参考来源：文件名 + 位于同一个原片连续镜头内的起/中/末时间码；不得跨越参考片剪辑点混合两套光影
- 时段与天气：晴日 / 树荫 / 开阔水面 / 雪地 / 灯火夜景等
- 世界光源锚：太阳/灯火相对建筑、树冠、窗门、水岸或人物的固定方位与高度
- 画面方向锚：主光在画面中从左上/右上/侧后等哪一方向进入；换机位时由世界光源锚推导，不机械固定屏幕侧
- 主光：半硬/柔和程度、低/中/高角度、侧前/侧逆/逆光关系
- 补光：天空、白墙、水面、雪地或室内开口的方向、冷暖与职责
- 轮廓与透光：发丝、耳缘、衣袖、薄布、叶片、蒸汽、水滴或尘粒中的落点
- 遮光载体：树叶、竹帘、窗格、帷幔或屋檐；光斑尺度与软硬
- 曝光锚点：脸、手和主动作接触面清晰明亮；白衣不死白；暗木与绿荫不死黑
- 色温关系：暖阳/暖灯 + 冷天空/冷水/冷雪地填充，或参考片实际关系
- 光学表现：景深、前景遮挡、柔和高光、轻微光晕和胶片颗粒
```

在同一个参考原片镜头内抽取起、中、末三帧，确认光源方向、主体中间调、亮部滚降和暗部层次是该镜真实稳定特征，不把转场闪白、字幕、调色跳点或运动模糊帧误判为布光。若用户指定的时间范围跨剪辑点，先拆成多张光影卡，不能平均成一套不存在的光。选中一张首帧后，同一场景的所有首帧沿用同一世界太阳方位、天气、色温与曝光基准；换景别时重新计算画面入光方向，不能让世界光源无故移动。参考片未给出某项时才按 `arvin-lab-light-master.md` 补齐。每条生图提示词必须包含具体改写后的 `ARVIN_LIGHT_MATCH_BLOCK`，不得只写“唯美、暖光、电影感”。

## 1. 固定提示词骨架

每条 Style Image V8.2 提示词必须按以下顺序写成一个连贯中文段落：

`镜头与场景 → 人数与差异 → 动作与关系 → 光色与质感 → 避错`

对应必须回答：

1. **怎么拍**：16:9、焦段、景别、机位、观察方向与留白。
2. **在哪里**：前中后景和 2–4 个稳定空间锚点。
3. **谁出现**：明确人数；每人具有不同位置、外貌、发式、衣色、动作、器物或视线。
4. **做什么**：主角先写一条可继续的身体—器物—方向动作链；其他人只承担不同的辅助或关系动作。
5. **什么气氛**：主光、补光、反光、遮挡和它们实际照到的表面。
6. **不要什么**：针对本镜最可能出现的数量、肢体、器物、材质、光影和时代错误逐项避错。

镜头和人数是画面的骨架。不得先堆砌“唯美、古风、电影感”等形容词，再把空间和人物关系交给模型猜测。

## 2. 光影必须写成“来源—方向—职责—落点”

每镜至少写一处主光和一处真实补光或反光，并说明它们照到哪里。严禁只写“柔和光影”“氛围光”“电影光”。

### 光型路由

- `REFERENCE_EXACT`：用户指定参考视频时必选；以同一原片镜头的起/中/末三帧和 `LIGHT_REFERENCE_CARD` 为准，不套通用模板覆盖它。
- `PASTORAL_SUN`：默认晴日劳动、群像、田野、水岸；低至中角度半硬暖主光 + 宽阔柔和冷环境填充 + 同一主光形成的轻薄轮廓。
- `PORTRAIT_SOFT`：胸像、近景与写真肖像；来自窗门、开阔天空或树冠漫射的侧前方大面积柔光 + 弱而宽的中性/冷柔填充 + 同一日光的轻微发丝肩线轮廓。
- `COOL_DIFFUSE`：阴雨、雾湖与暮色冷漫射；宽阔低对比冷天光，不强塞暖阳。
- `LOCAL_WARM`：炉火、灯笼、烛火与婚房红纱；可见暖源形成局部光池，环境保持深暗并由极弱冷/中性填充保住结构。

一镜只选一类光型。反打或换景别时优先保持世界光源锚，不能为了固定“左上来光”而破坏真实空间。

### 默认晴日

- 默认还原参考视频中的明亮夏日/春日布光：低角度暖色太阳从画面左上或右上以侧前光、侧逆光或逆光进入，主光方向明确且呈半硬质感，由树冠、藤架、窗格、竹帘或薄布筛成大块亮面与清楚但不过密的碎影；柔和感主要来自宽阔冷填充、低饱和色彩、柔和高光滚降与轻微光学晕，而不是把主光抹平成无影柔光。
- 主体平面必须清透明亮：日光照亮侧脸、眼神光、肩线、手背、动作接触面、米白袖褶和器物边缘；白衣具有半透纤维与柔和亮度，不死白、不剪切高光。
- 开阔天空、白墙、水面或浅色地面提供宽阔偏冷的柔和填充，保住眼窝、下颌、肤色、深色木窗和绿荫层次；暗部干净、通透、可辨材质，不灰死也不抬成雾。
- 发丝、耳缘、薄袖、叶缘、蒸汽、尘粒与水滴可出现一圈很薄的暖色轮廓或透光；禁止粗硬描边、无源发光和商业灯带感。
- 叶影、竹帘影或帷幔影只作为局部层次：边缘柔和、尺度有大小变化，可轻触脸颊和衣袖，但不切割眼睛、鼻唇，不把整张脸压暗，也不让全画面斑驳失控。
- “明亮”指主体面与空气被照亮、冷暖层次分明；不是平均补亮每张脸、压平阴影、使用纯白背景或整体过曝。

### 竹窗与室内

- 窗外暖阳或竹帘筛下的细暖光带为侧前主光，优先照亮脸、双手、蒸汽和工作面；窗口本身不得变成过曝白洞。
- 白墙、门外天空与窗外绿荫提供宽阔冷柔填充，让面部暗侧和米白衣料仍清楚通透。
- 暗木窗、门框和室内深处保留稳定而干净的阴影，形成宋式留白与空间纵深；只允许蒸汽、叶影或人物遮挡造成局部光变化。

### 树荫、瓜棚与庭院劳动

- 树叶或藤架筛下暖斑，形成明亮侧前光或侧逆光，照亮主脸、手、器物、衣袖边缘与动作接触面；主角不能长期埋在暗影里。
- 开放天空、白墙或浅色庭地提供清透冷补光，让白衣和肤色明亮但不发白，保持脸部与双手为清晰视觉焦点。
- 前景叶片可作自然框景；不得大面积遮脸、遮手或遮断器物关系。

### 溪水与舟船

- 暖日光以侧逆光擦过头顶、肩线、袖缘、莲叶或岸边枝叶，主脸由天空和水面反射共同补亮，形成参考视频里的清透明亮水岸感。
- 水面青绿或烟蓝反光轻触下颌、袖口、舟沿和湿布低处；只提亮阴影色阶，不把脸染成绿色。
- 水面高光保持细碎、受波纹控制，禁止整片发白、镜面塑料感或无来源荧光。

### 月夜与灯火

- 月光负责建立白墙、青石、门洞与大面积安静留白。
- 油灯或炉火只温暖手、桌缘、杯沿、壶腹和近处小块面部。
- 不让灯光平均照亮所有人物，不使用霓虹蓝橙或全局明暗呼吸。

### 雪地与冬日

- 低角度暖阳或火炉/灯笼作为有方向主光，雪地和冷天空提供大面积偏蓝灰填充，形成清楚但不过度的冷暖分离。
- 雪面与白衣保留纹理、起伏与层次，不整片剪切；人物脸与手由暖主光或雪地反射提亮。
- 飘雪、蒸汽、炉烟和呼气只在逆光边缘可见，来源与风向明确，不制造无源白雾。

### 纯冷漫射与雾湖

- 参考片为阴雾、水雾或暮色冷漫射时，使用大面积低对比冷天光，人物、山水和衣料靠微弱亮度差、空气透视与材质分离；不得强行加入暖阳或金色轮廓。
- 亮度仍以脸、手、动作面或主要景观结构为锚点，黑位抬到可辨而非洗灰；雾有深度递减，不覆盖成一层白纱。

### 烛火与红纱局部暖池

- 婚房、帷幔或室内烛火场景只由可见烛火/灯盏与红纱透光形成局部暖色光池，照亮近处脸、手、红布纹理和器物边缘；背景继续保留深暗空间。
- 红纱只改变穿透它的局部光色，不把整张脸和全室染成纯红；可由门窗或暗环境提供极弱中性填充，禁止无来源全局亮化。

### 阴雨

- 宽阔冷灰天光建立墙面、湿石、雨丝和人物轮廓。
- 窗内、炉边或灯下只保留小面积暖色。
- 湿地反光有方向且低亮度，禁止全地面镜面化。

若用户没有指定时段与天气，默认使用**树叶或竹帘筛下的有方向柔和日光 + 白墙/天空冷补光**。若用户明确指定夜、雨、雪或阴天，使用相应自然光源，不强行加入阳光。

## 3. 镜头与真实人像光学锁

- 使用高端人物写真与电影剧照的完成度，但保持生活观察而非时尚摆拍。画面应像全画幅摄影机或 Canon EOS R5 实拍，而非手机算法 HDR、CG 渲染或插画。
- 焦段按内容选择：35mm/40mm 用于环境、低机位、水岸和劳动动作；50mm 用于双人/群像关系；85mm 用于胸像、半身与安静人物特写。写清真实镜头压缩感和拍摄距离，不随意混写多个焦段。
- 使用与景别相称的浅景深：脸、眼神、双手和主要接触点保持清晰；前景叶片、窗格、花草或蒸汽可柔化形成层次，远景逐级奶油般柔化。禁止整张脸强柔焦、磨皮糊化或所有景深在同一平面。
- 环境人物镜头优先建立三层纵深：边缘约 5%–20% 的虚化自然前景；面部、双手、接触点和主器物清晰的中景；同伴、白墙、深木、村舍、山坡或水岸仍可辨但逐层柔化的后景。前景不得遮脸、遮手或切断人物—器物关系。
- 柔和高光、干净暗部、自然动态范围和轻微胶片颗粒；逆光边缘允许很轻的光晕与镜头散射，不能吞掉五官、手部或衣料纹理。
- 人脸保持真实皮肤纹理、细微毛孔、细绒毛、唇纹、自然肤色变化、真实眼部反光和轻微面部不对称；发丝有粗细、交叠和受风方向。保留少量生活化瑕疵，不做瓷白、塑料皮肤、强磨皮、过度精修、完美对称或假人脸。

人物镜头须自然包含下列 `EDITORIAL_REALISM_SUFFIX` 的结果；“时尚/杂志”只指摄影完成度，不改变宋式服装、器物与生活状态：

```text
高端纪实人物写真与杂志级电影剧照完成度；按景别选择 50mm 或 85mm 人像镜头，浅景深、自然镜头压缩和真实光学焦外；来自真实窗门、天空或树冠的侧前方大面积柔光，弱而宽的冷柔补光，同一日光形成轻微自然轮廓光；柔和高光、干净暗部、连续色阶与轻微胶片颗粒；自然真实人脸，真实皮肤纹理、细微毛孔、细绒毛与唇纹，轻微面部不对称和自然肤色变化，眼神与眼部反光匹配主光方向，发根、发束和零散发丝自然，保留细微瑕疵；避免塑料皮肤、磨皮、美颜、过度精修、脸部过度对称、假人感、CGI 感与 AI 生成感。
```

## 4. 质感必须可触摸

- **皮肤**：真实温润肤色、细微纹理和自然轻微不对称；不过度磨皮，不瓷白，不网红妆，不塑料皮。
- **棉麻**：可见细纤维、经纬和自然褶皱；宽袖受手臂、重力与风影响；湿布颜色加深、重量增加并从最低褶皱滴水。
- **竹木**：旧木和竹器为哑光，结构、连接点、磨损与受力关系可信；不油亮、不像塑料道具。
- **石陶**：青石、石磨、素陶和粗陶保持颗粒、磨损、重量与低反光；边缘不融化。
- **水**：波纹从手、布、桨、莲梗、船体或水滴接触点开始；倒影随波纹同步破碎；水滴遵守重力。
- **空气**：蒸汽、烟、尘与雨必须有可见来源并服从同一风向；不做无源雾效和仙气。
- **摄影**：真实镜头景深、连续色阶、克制锐度、自然动态范围和轻微电影颗粒；不使用 CG 高光、游戏渲染、HDR 炫光或过度锐化。

## 5. 可动画化首帧

- 首帧优先停在主动作已经开始约 15%–40%、但尚未完成的进行态，而不是僵硬待机、纯摆姿或完成态。
- 手、器物、接触点、支撑脚、重心与运动方向必须清楚，沿运动方向保留继续空间。
- 根据场景让水弧、水滴、蒸汽、落谷、尘粒、豆浆流、湿衣下坠、枝叶回弹、发丝或衣摆中的至少一项已经出现，但不得虚构首帧中没有来源的特效。
- 进行态仍须结构稳定：液体、颗粒、布料和发丝服从重力、惯性和同一风向，不以大幅运动模糊掩盖手部或器物错误。

## 6. 群像与动作首帧

- 闭合群像必须写“明确只有 N 人”，并为每人分配一个不同任务；不得让所有人做同一件事。
- 先写主角动作，再写辅助者的承接、注视、等待、整理或回应。
- 手、器物、接触点和运动方向要可见；首帧停在动作已开始但尚未完成、仍可继续的进行态。
- 若题材为写实武侠动作，首帧仍保持同一光影和材料体系；只增加重心、支撑脚、武器方向、对手距离和运动空间，不加入仙术、发光能量、漂浮或 CG 奇观。

## 7. 固定光影与质感锚点

每条提示词都要自然包含以下视觉结果，不必机械逐字复制：

```text
克制写实的宋式中式生活美学，高端人物写真与电影剧照完成度，真实全画幅实拍摄影；暖金侧前光、侧逆光或逆光从真实开口、树冠或薄布间隙进入，宽阔中性暖灰天空、白墙或水面反射保持脸、手和主动作面清透明亮，发丝、衣缘、蒸汽和水滴出现轻薄同源轮廓，暗木与绿荫保留干净层次；肤色温润真实并保留毛孔、细微纹理与自然不对称，象牙白棉麻呈现纤维和重力褶皱，旧木竹器、青石粗陶和水面反馈清楚；35/40/50/85mm 按景别选择，主体与动作接触点清晰，前后景自然柔化，低饱和天然色、柔和高光滚降、连续明暗层次、安静留白、轻微光学晕光与克制电影颗粒。
```

## 8. 生成后排错清单

## 9. 关键帧自检

生成确认包前逐镜回答：

- 焦段、机位、景别、留白和空间锚点是否具体？
- 人数是否钉死，人物差异和关系是否可读？
- 主动作是否已经开始约 15%–40% 但尚未完成，手与器物接触、物理反馈和继续空间是否清楚？
- 主光来自哪里、向哪里、照到什么？补光和反光分别解决什么？
- 若有参考视频，太阳/灯火方向、主补光比例、冷暖关系、光斑软硬和曝光锚点是否与指定时间码一致？
- 脸、眼神、双手和主动作接触面是否清晰明亮，白衣是否不死白，暗木和绿荫是否不死黑？
- 是否只有前后景柔化而主体细节清楚，焦段、景深与镜头压缩感是否可信？
- 皮肤、棉麻、竹木、石陶、水和空气是否符合真实材料？
- 是否仍是低饱和、温润、明亮、有呼吸的真实宋式摄影，而非滤镜化古风、全局发灰或暗沉压抑？

任一项答不出来，提示词尚未完成。生成后必须用 `arvin-lab-light-master.md` 的 `LIGHT_MATCH_SCORECARD` 逐候选评分；任一硬项为 0 或总分低于 14/16 都不得选中，即使人物面容漂亮或构图讨喜。
