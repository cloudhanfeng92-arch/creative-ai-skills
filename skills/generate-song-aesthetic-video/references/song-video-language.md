# 宋式视频视觉与动态语言

## 1. 视觉母版

目标不是历史考据复原，也不是“古风关键词”堆砌，而是克制、写实、明亮、可触摸的宋式生活观察：人物像在生活，不像为镜头表演；空间有呼吸，材料有重量，光从真实开口或自然环境进入。允许高端时尚写真和杂志大片级的摄影完成度、光学与肤质，但人物行为仍是自然生活或真实行动，不采用现代奢华造型、影楼闪光或广告式摆拍。

### 建筑与环境

- 粉白或灰白石灰墙、青灰石板、深色旧木、低调瓦檐、竹帘、竹架、朴素窗格。
- 小院、廊下、门洞、溪边、莲塘、低矮木舟、茶棚、作坊、桥边、城中窄巷。
- 允许城市、节庆、雨雪、夜景、劳动和无人物景观；不局限于晴日田园。
- 不自动出现宫殿、牌楼、金饰、巨大雕塑、仙山云海或荒废遗迹。

### 材料

- 棉麻衣料有纤维、褶皱、厚薄与重力；湿后颜色加深、下坠并从最低点滴水。
- 素陶、粗陶、石磨、青石、竹器与旧木保持哑光和磨损，不做塑料亮面。
- 水只从接触点产生水纹；蒸汽与烟必须有壶口、灶火或香炉等来源。
- 舟、桨、长篙、格栅、竹篮、织物与工具结构完整，连接关系可解释。

### 色彩

主色从米白、月白、暖灰、苔绿、竹青、烟青、茶褐、墨褐中选 3–5 个；莲粉、杏黄、暗朱只作小面积点色。控制饱和度和对比度，让肤色、白墙、水面和衣料清透明亮而仍有层次；禁止全局发灰、暗沉压抑、浓重橙黄滤镜与过曝奶白。

### 光影

每镜选择一套光源逻辑：

- 有用户参考视频时，先锁定指定时间码的太阳/灯火方向、冷填充来源、轮廓落点、光斑载体与曝光锚点；它高于下列默认逻辑。
- 默认晴日采用参考视频式的明亮暖色侧前光、侧逆光或逆光，穿过树冠、竹帘、窗格或帷幔；白墙、开阔天空或水面提供宽阔冷柔填充。
- 竹帘暖色条带为局部主光，白墙与窗外绿荫作冷色补光；光带不切割五官。
- 树叶筛下的大块暖亮面与少量碎影落在脸、手、白衣和工作面，开阔天空提供冷柔阴影；人物主体不能长期埋暗。
- 水面青绿反光只轻触下颌、袖口和舟沿，不把肤色染绿；日光在发丝、衣缘、水滴和莲叶边缘形成轻薄轮廓。
- 月光建立白墙与青石，油灯只温暖手、桌缘、杯沿和近处面部。
- 雪地和冷天空作为宽阔冷填充，低角度暖阳或炉火照亮脸、手与蒸汽，白衣和雪面均保留纹理。
- 雨天或阴天使用宽阔冷灰天光，窗内或炉边只保留小面积暖色。
- 街巷夜景依赖灯笼、窗纸与湿石反光，禁止霓虹和夸张蓝橙调色。

所有模式都遵守：脸、眼神、双手与动作接触面清楚；白衣亮而不死白，暗木和绿荫深而不死黑；柔和高光、干净暗部、轻微逆光晕与胶片颗粒。太阳或灯火方位与基准曝光在同镜及同场景内固定，只有叶影、水反光、蒸汽、尘粒或人物遮挡产生局部变化。

## 2. 动态原则

宋式动态的核心是让动作有真实因果，同时让环境持续呼吸：人物做一件事，器物给出重量与接触反馈，单一风向带动画面的花草树木、发丝和衣料，镜头依据人物关系观察。画面可以安静，也可以在内容要求时出现快速、干练的写实武侠动作；运动强度变化不能改变宋式自然光、低饱和色板和可触摸材质。

每个原生 3–5 秒单首帧镜头只安排：一个主运镜、一条主要动作链、最多一个关系反应、一个统一环境驱动力和最多一处局部光线变化。视频使用 Dreamina Canvas `seedance_2.5`，默认原生 4 秒或 5 秒，用户明确要求且实时 schema 支持时可用 3 秒，所有通过片段完整进入成片。画面灵动来自“主动作立即启动 + 同伴错峰反应 + 前景视差 + 风吹衣发草木 + 一种材料或空气反馈”的分层因果，但不能堆满：4 秒近景/复杂手部/多脸镜头最多主动作 + 关系反应 + 1 个轻量层；4 秒简单中景或 5 秒中宽景最多 2 个轻量层，短运镜也计一层。花草、树叶、发丝和衣料可响应同一阵风，但必须按重量产生不同幅度和迟滞；单镜至多一次宽缓风脉冲，随后自然衰减，不像同一图层同步往复摇摆。

动态优先级从稳定到可动：

1. 人物身份、人数、服装色槽、建筑格局、器物结构、场景轴线与宋式留白绝对稳定。
2. 手—器物—方向—结束状态形成可见闭环。
3. 同伴承接、注视、侧头或辅助，且与主动作错峰。
4. 水、布、烟、蒸汽、叶片、灯焰按材料和来源反馈。
5. 镜头只服务观察，不抢过动作与空间。

### 立即启动—发生—缓冲

- 前约 4%–6%：从唯一首帧立即自然启动，不冻结摆姿，让方向、身份和关系可读。
- 中间约 79%–84% 是完成上限，不是必须填满：以正常实拍速度或题材要求的快速速度完成唯一主要动作链、错峰关系反应和必要短对白；可提前收势，不加入第二轮动作，不为填时长做梦幻慢动作。
- 最后约 10%–15%：主体已经收势且不再大位移，但不能冻结；至少保留一项自然呼吸、视线微调或逐渐衰减的水纹、衣角、发丝、尘叶、蒸汽、叶影、檐滴余韵。
- 4 秒镜头可按约 00:00–00:00.20 启动、00:00.20–00:03.45 发生、00:03.45–00:04.00 缓冲。
- 5 秒镜头可按约 00:00–00:00.25 启动、00:00.25–00:04.35 发生、00:04.35–00:05.00 缓冲。
- 全段都是最终素材；不设计待裁掉的安全段，不裁剪、不变速，也不使用结束图。

## 3. 运镜选择

- 精细手作、多人复杂接触：50mm 锁定机位或极短幅推近，可用一次柔化前景掠过制造轻微视差。
- 单人松弛活动：85mm 三分之二侧脸中近景，短幅推近或轻跟，主体脸与双手清晰。
- 群像关系：50mm 平视中宽景，锁定或短幅横移，用人物前后层次而非整齐排队建立景深。
- 水边、舟上、低处劳动：35mm/40mm 水面低机位，短幅侧移，允许芦苇、莲叶或水光在近景形成自然遮挡与视差。
- 城市街巷：50mm 门洞框景或沿街短移。
- 无人景观或收束镜头：50–65mm 锁定或短幅拉远。
- 写实武侠动作：根据运动方向选择低机位短跟、横向追拍或一次由主体驱动的快速摇摄；动作收势后镜头重新稳定。

单镜禁止同时推、摇、升、环绕；禁止无因甩镜、随机变焦、无人机式穿越和随机切镜。允许低幅、稳定、有人操作感的摄影机微响应与前景视差，但不能变成抖动。写实武侠允许与主体速度一致的轻微真实手持和运动模糊，但脸、建筑锚点、光向与空间轴线必须可读。

短推默认主体尺度变化不超过约 8%，短横移/短跟默认构图位移不超过约画面宽度 10%；始终让木柱、屋檐、墙边、桌缘、岸线或桥体中的至少一个锚点保持可追踪。快速主体行动可突破默认幅度，但必须由动作驱动，不能成为无因大运镜。

采用短跟拍或动作驱动摇摄时，取消额外前景掠镜，避免运镜与遮挡同时抢画面。写实武侠每镜只容纳一个攻击、闪避、接住或落地原子动作、一次接触反馈和一个主运镜，不在同镜并发第二次攻防。

## 4. 场景动态模板

### 人物与群像

锁定或短幅推移；明确只有 N 位主要人物。主角位于固定位置，以具体手或身体部位接触具体器物，向明确方向完成一个动作；同伴只做承接、注视、回应或辅助。动作错峰，视线落在器物或同伴。呼吸、发梢与袖缘随同一风向自然响应，脸、发式、服装、人数和位置关系全程稳定。

闭合群像必须钉死总人数。开放市井只锁定 1–3 位主要人物，背景人群用稀疏/适中密度、共同流向和不同速度概括。

### 水面、溪流与舟船

40mm 水面低机位短幅侧移。水纹只从手、布、桨、莲梗或船体接触点向外扩散；湿布颜色加深并受重力下坠，水滴从最低褶皱落下；舟体只轻微起伏；岸、船、长篙结构不变；倒影随水纹同步破碎再恢复。

### 风

明确从左向右、右向左、前向后或后向前的一种风向，强度轻微。叶片与竹帘先响应，发梢和袖缘稍后响应，厚衣摆只轻轻偏移；烟、蒸汽与雨丝遵守同一风向。建筑、器物和人物重心不晃动。

### 雨

镜头置于檐下或门内锁定。细雨稳定斜落，檐口形成连续滴水，石地逐渐变暗并出现局部同心涟漪；室外衣料按受雨位置变深，室内保持干燥。冷灰天光稳定，窗内或灯下只有小面积暖色。

### 夜景

月光固定建立白墙、青石和留白；油灯或烛火只在手、桌缘和杯沿产生低幅局部闪动，不能让全画面明暗呼吸。蒸汽缓慢上升，纸灯轻摆，湿石返回少量暖光；背景深静，无霓虹和商业蓝橙色。

### 城市街巷

50mm 平视沿街短幅横移，以桥、店门、纸屏、木柱、瓦檐为稳定空间锚点。锁定 1–3 位主要人物的工作、衣色和移动方向；背景行人稀疏、速度各异但总体遵守一个流向。招牌不承担可读文字，店铺格栅、桥体和摊具稳定，背景脸不得复制主角。

### 无人景观

锁定或短幅拉远；画面保持无人、无剪影。允许同一阵风下的花草树叶、竹帘、叶影，以及有来源的蒸汽、檐滴或水纹形成自然环境呼吸；不能互相逆向或抢过空间主体。半开的门、未收器具或温茶可作为生活痕迹，但不得自动生成装饰性女子，也不默认成为荒废遗址。

## 5. 多镜头连续性

- 四张图像候选只用于选片，不能充当四镜头。
- 选中的单张图重新上传为独立首帧资源节点，并声明它控制身份、衣色、器物或空间中的哪些内容；每镜只连接这一张图。
- 相邻镜头保留至少两个可识别空间锚点，并遵守视线方向、人物行进方向和 180 度轴线。
- 器物状态只能向前发展：杯中水量、布料湿度、篮筐归属、莲蓬数量、扇面完成度不得重置。
- 同一地点可以换景别，但不可同时大幅改变机位方向、焦段、时间、天气和服装。
- 多镜头推荐节奏：环境建立 → 主要劳动/行为 → 人物关系或材质细节 → 安静收束。
- 四季、晨昏或天气变化必须在阶段 1 计划；人物母版、材料真实性和色彩克制度仍保持一致。

## 6. 时间性负面约束

统一禁止：模型在单首帧原生镜头内部无因切镜、随机抖动、卡顿、突变、速度跳变、无因运镜、长时间冻结摆姿、身份漂移、脸部融化、年龄/性别变化、服装换色、新增或消失人物、复制脸、肢体增生、手指融合、器物生成/变形、建筑弯曲、格栅爬动、现代物件、参考片文字、Logo、字幕、伪水印，以及全局曝光闪烁、色温漂移、光源换边、过度柔焦、水墨化、动漫化、仙侠发光、CG 游戏感、宫廷大戏、现代奢华造型、影楼硬光或广告式时尚摆拍。相邻原生片段之间按分镜自动切镜。

专项禁止：

- 水：逆流、上升水滴、整片沸腾、倒影与水面不同步。
- 风：不同物体逆向飘动、厚重衣料像旗帜狂甩。
- 雨：雨穿屋顶、雨滴倒飞、室内无因湿透。
- 夜：全局灯光闪烁、每盏灯同频、霓虹或强蓝橙。
- 城市：人群复制、主角被背景替换、乱码招牌、建筑网格变形。
- 无人：人物、剪影、脸形云雾或自动开门走出的角色。
- 群像：人数漂移、全员同步、工具换主人、长杆穿体或关系动作断裂。
