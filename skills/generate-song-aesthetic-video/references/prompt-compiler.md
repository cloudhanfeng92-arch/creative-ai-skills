# 宋式视频提示词编译器

本页把简单主题编译成连续分镜、Style Image V8.2 首帧提示词、Dreamina Canvas Seedance 2.5 视频提示词、声音设计、配乐 Cue Sheet 和执行确认包。

## 1. 制作简报

从输入提取或合理推断：叙事核、人物与关系、地点、时段天气、唯一主要动作、空间轴线、器物状态、环境动态、情绪与人声、参考光影、镜头数、每镜原生时长、总时长和交付规格。

逐镜记录：

```text
SXX｜镜头名｜原生 D 秒｜唯一首帧
叙事功能：
人物/空间/轴线：
焦段/景别/机位/唯一运镜：
首帧进行态：动作已开始 15%–40%
主动作受力链：支撑→发力→方向/速度→接触→惯性/减速→落点
关系反应与表情触发：
LIGHT_REFERENCE_CARD：来源文件和同一连续镜头的起/中/末时间码
ARVIN_LIGHT_LOCK：主光、冷补光、脸手、白衣、暗部、轮廓、焦点
环境与材料动态：
对白/人声/环境声：
结尾缓冲：
切入/切出匹配：
```

## 2. Style Image V8.2 提示词

每镜写一个紧凑中文 MJ 风格段落：

`焦段/景别/机位 → 前中后景和空间锚点 → 人数、人物差异、位置与视线 → 已开始 15%–40% 的动作进行态 → 衣料、皮肤、器物和环境材料 → 具体自然光源、主补关系与落点 → 色彩曝光 → 真实光学与肤质`

实际提交给 Style Image V8.2 的提示词只包含可见画面语言，不包含参考视频文件名、参考标题、时间码、画幅文字、模型参数、比较命令、质量评分、选图要求或长串负面词。`16:9` 仅通过 LibTV 节点 `ratio` 字段设置。把内部参考拆解翻译成太阳方向、光线软硬、被照亮表面、环境反射来源、阴影颜色、曝光层次和镜头响应，不在提示词中说明这些视觉事实来自哪里。

模板：

```text
[35/40/50/85mm]，[景别与机位]，[宋式地点、季节和时段]，[少量虚化自然前景、清晰中景主体、逐层柔化后景和留白]，[明确人物数量、外貌、发式、衣色、位置与视线]，[已经开始约 15%–40% 的动作、支撑、手与器物接触、可继续方向]，[棉麻、皮肤、竹木、石陶、水和空气的真实材料反应]，[低角度暖金日光的画面方向、侧前或侧逆角度、软硬、遮光载体、脸手与动作接触点落光]，[天空、白墙、水面或浅色地面的宽柔中性暖灰环境回填及其提亮部位]，[温暖自然肤色、象牙白织物、黛绿与暖木色、明亮中间调、柔和高光滚降、清楚暗部]，高端纪实人物电影剧照，真实全画幅光学，自然压缩，稳定浅景深，真实皮肤纹理，细微面部不对称，轻薄发丝轮廓，克制胶片颗粒。
```

节点参数以 LibTV 实时 schema 为准。默认 Style Image V8.2、16:9、count=4；四张只是同镜候选。先按 `LIGHT_MATCH_SCORECARD` 评分，再检查人物美感、解剖、构图、时代和可动画性。只有通过者可重新上传为独立首帧资源。

## 3. Seedance 2.5 视频提示词

读取 `seedance25-native-shot.md`，按顺序编译：

`原生 D 秒 → Dreamina Canvas seedance_2.5 → 唯一首帧/无尾帧 → 身份空间器物锁 → 0.25 秒内启动 → 完整身体动力链 → 一个错峰关系反应 → 一次风脉冲与材料反馈 → 唯一运镜 → ARVIN_LIGHT_LOCK 和焦点稳定 → 可见声音/短对白或人声 → 末段缓冲 → 时间性负面约束`

视频提示词只描述首帧之后的时间变化，不重新发明人物、服装、建筑、器物、光向或色板。

## 4. 音乐与终剪编译

Picture lock 后测量精确时长，再输出：

```text
Picture-lock 时长：
Cue 01 时间段/叙事目的/配器/强度：
Cue 02：
对白与关键动作声避让区：
音乐进入方式：
音乐结尾方式：
配乐完整提示词：
混音优先级：对白 > 关键动作声 > 环境声 > 音乐
```

默认配乐轻快、清透、温暖、松弛、原创纯器乐；不做沉重史诗、悲苦古装剧、廉价 MIDI、密集鼓点或人声哼唱。

## 5. 执行确认包

平台需要积分确认时，按实际调用分别展示，不得猜消耗或扩大授权：

### 生图

```text

完整首帧提示词：
模型/参数：Style Image V8.2｜16:9｜每镜 4 候选
节点数、候选数、平台报价：
```

### 视频

```text
镜头与唯一首帧：
完整视频提示词：
模型/模式：Dreamina Canvas seedance_2.5｜single first frame｜无尾帧
参数：16:9｜原生 D 秒｜count=1｜声音设置
声明：全段保留，无裁剪、变速或时间重映射
平台报价：
```

### 音乐与终剪

```text
Picture-lock 精确时长：
Cue Sheet 与完整音乐提示词：
音乐服务、模型、数量和平台报价：
终剪：无配乐母版 + 原创配乐 + 最终混音版
```

纯本地分析和 FFmpeg 合成不消耗生成积分。平台调用的确认以实际 CLI/服务要求为准。

## 6. 编译自检

- 生图提示词是否只含可成像的 MJ 视觉语言，并具体写出暖金主光、环境补光、脸手、白衣和暗部？
- 生图提示词是否排除了参考文件名/时间码、画幅文字、模型参数、比较或强制覆盖指令，以及通用负面长清单？
- 四候选是否先过光影硬门，再比较漂亮程度？
- 视频是否明确 Dreamina Canvas `seedance_2.5`、唯一首帧、无尾帧？
- 人物是否有完整身体动力链、触发型表情和错峰环境动态，而非机械摆动？
- 对白或人声是否短、自然、有对象且无字幕？
- Picture lock 是否先于音乐，音乐是否按实测时长生成并避让对白？

任一项不满足，确认包尚未完成。
