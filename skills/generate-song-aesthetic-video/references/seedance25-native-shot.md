# 即梦 Seedance 2.5 单首帧镜头编译器

本页只负责把通过选片的唯一首帧变成 3–5 秒原生镜头。视频必须通过 Dreamina Canvas `seedance_2.5` 生成，不得调用 LibTV 视频模型。运行时 schema 高于本页快照。

## 1. 单首帧契约

- 每个最终镜头只对应一个被选首帧和一次视频生成。
- 即梦 CLI 的图生视频入口可能名为 `first_last_frame`；本技能只传一个 image reference，使其成为单首帧模式。不得传尾帧、第二图或多图参考。
- 结束状态只写在提示词中，不生成结束图。
- 默认 4 或 5 秒；用户明确要求且实时 schema 原生支持时可选 3 秒。
- 生成时长就是最终时长，全段保留，不裁剪、不变速、不时间重映射。

## 2. 生动而不乱的运动预算

每镜只包含：一个主要动作、一种主运镜、至多一个人物关系反应、一个统一环境驱动力，以及至多两层轻量材料/空气动态。

- 首帧后约 0.25 秒内启动。人物不能先静止凝视再机械抬手。
- 生活动作也要有动力链：重心先变化，躯干与肩胛带动上臂，肘腕和手指完成接触；走路由髋、膝、踝和脚底支撑，衣摆稍后响应。
- 动作节奏直接、清楚、正常实拍速度；不以慢动作填满时长。
- 关系反应必须被事件触发，例如同伴递物后才抬眼、听见呼唤后才回头、看到水滴后才轻笑。
- 灵动来自不同层的时间错峰，不是所有花草、头发、衣服和镜头同时摇动。

## 3. 风与材料因果

- 单镜只允许一次宽缓风脉冲，方向全程一致。
- 细叶和花梗先小幅响应；碎发与薄袖稍后；厚衣摆、长裙和湿布幅度更小、迟滞更明显；随后自然衰减。
- 水纹只从手、桨、莲梗、布或水滴接触点扩散；蒸汽只从壶口或热物升起；尘粒、花粉、雪粉必须由动作或风触发。
- 环境动态不得遮断脸、双手和器物接触点。

## 4. 运镜

每镜只选一种：

- 锁定：复杂手作、多人接触或需要清楚表演时。
- 短推：人物情绪或细节逐渐成为重点；主体尺度变化宜克制。
- 短移：庭院、桌边、溪岸的空间层次和前景视差。
- 短跟：人物行走、乘舟、采摘或写实动作，速度匹配主体。
- 动作驱动摇摄：仅用于快速明确的运动方向，动作收势后镜头稳定。

禁止无因环绕、无人机穿越、随机变焦、多轴并发、镜头乱抖和单镜随机切构图。

## 5. 光影与焦点连续

- 严格继承首帧的世界太阳方位、画面入光方向、暖金主光、冷中性填充、轮廓落点、肤色和基准曝光。
- 全段脸、双眼、双手和动作接触点清楚；米白衣料亮而有纹理；暗木和树荫深而不黑。
- 只允许同一阵风推动叶、帘、发丝，使局部光斑缓慢滑动。不得出现全局曝光呼吸、亮度泵动、色温跳变、光源换边或无原因闪烁。
- 焦点锁在眼睛或关键手—器物接触点；快速部位可有自然方向性运动模糊，脸和空间锚点仍可读。

## 6. 表情、对白与人声

- 表情写成触发链：目光先落到事件或对象，呼吸与肩颈放松，嘴角再出现细小真实变化。
- 笑容自然、松弛、克制；不做广告式持续微笑、夸张大笑或空洞凝视。
- 一镜最多一句短对白，且只在叙事确有关系时加入。写明说话者、对象、语气、音量、距离和明确时段；缓冲前说完，口型同步，不生成字幕。
- 若一句话会让动作变僵，改为一个自然人声反应：轻笑、短促应答、轻呼、叹息或吸气。
- 视频节点不生成背景音乐、吟唱或旁白；只保留画面可解释的环境、动作与人声。

## 7. 结束缓冲

最后 10%–15% 之前完成主要动作、接触、减速、落点和对白。缓冲段不开始新剧情、第二动作或新运镜，也不冻结；只保留自然呼吸、目光落定、发丝衣角回落、水纹扩散、蒸汽消散、树叶余摆或灯火微动。

## 9. 自检

- 是否明确 Dreamina Canvas `seedance_2.5`、唯一首帧、无尾帧？
- 是否在约 0.25 秒内启动，且有完整身体动力链而非机械局部动作？
- 是否只有一个主动作、一个主运镜、至多一个错峰关系反应？
- 环境是否由统一风或材料因果驱动，并按重量错峰？
- 暖主光、冷补光、脸手、白衣和暗部是否全段稳定？
- 对白/人声是否短、自然、有对象、在缓冲前完成且无字幕？
- 末段是否有自然余动而非冻结？

任一项缺失，提示词尚未完成。
