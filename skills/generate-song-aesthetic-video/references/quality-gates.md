# 宋式中式美学视频质量门

质量门必须逐级通过。失败只返工对应镜头和故障轴；不得用裁剪、变速、尾帧、多图参考、后期全局提亮或强调色掩盖失败。

## Gate 0：模型、映射与时长

- 图片模型是 LibTV Style Image V8.2；视频模型是 Dreamina Canvas `seedance_2.5`，职责不混用。
- 每张动画目标图或选定首帧恰好对应一个视频节点和一个最终镜头。
- 每镜 exactly one image reference，无尾帧、第二图、多图或参考视频输入。
- 每镜时长受实时 schema 支持，生成时长即成片时长；全段保留，无裁剪、变速、重映射或补帧。

## Gate 1：首帧光影硬门

先用 `arvin-lab-light-master.md` 的 `LIGHT_MATCH_SCORECARD` 评分。任一硬项为 0 或总分低于 14/16，直接淘汰；不得因人物漂亮、构图好或其他候选更差而放宽。

附加硬判据：

- 参考时间码来自同一连续镜头；主光来源、方向、高度、软硬和叶影载体匹配。
- 低角度暖金主光有方向，冷中性环境补光真实；不是全局黄滤镜或平均棚拍平光。
- 缩略图下双眼、鼻唇、双手和动作接触点清楚；脸不成剪影，叶影不横压双眼。
- 米白衣料与白墙明亮但保留纹理；黑发、暗木、树荫和室内仍有层次。
- 暖高光与冷中性阴影清透分离，肤色自然，不偏黑、偏冷、灰脏或橙黄。
- 焦段、景深和前景遮挡可信；脸、手和接触点不被强柔焦。
- 人脸、手指、器物、建筑和人数稳定；无文字、乱码、字幕、Logo、水印或现代穿帮。
- 首帧动作已开始 15%–40%，重心、接触点、方向与继续空间清楚。

任一失败，首帧不得进入视频生成。

## Gate 2：Seedance 2.5 全段动态

逐镜用 `ffprobe` 记录模型、首帧、真实时长、尺寸、帧率、帧数和音轨，并查看起、中、末：

- 约 0.25 秒内从首帧自然启动，无海报式冻结。
- 一个主动作具有完整躯干—肢体动力链、支撑、重量、惯性、接触、减速与落点；不只机械抬手或摇头。
- 至多一个人物关系反应，且由事件触发并与主动作错峰。
- 同一阵风只出现一次宽缓脉冲；花叶、碎发、薄袖、厚衣摆按重量错峰并自然衰减。
- 水、蒸汽、尘粒、花粉、雪粉只从真实触发点出现。
- 只有一种主运镜；无乱切、环绕、随机变焦、无人机穿越、多轴并发或不必要抖动。
- 人物身份、人数、服装、器物、建筑、空间轴线和焦点稳定；无脸手器物变形。
- 暖金主光、冷补光、脸手曝光、白衣高光和暗部层次全段稳定；无曝光呼吸、色温跳变、光源换边或闪烁。
- 最后 10%–15% 主动作完成但画面不冻结，只留低幅自然余动。

## Gate 3：表情、对白与同期声

- 表情有明确触发；眼神、呼吸、肩颈和嘴角顺序自然，笑容真实克制。
- 对白只在必要时加入，一镜最多一句；说话者、对象、语气、距离、时段合理，缓冲前说完且口型同步。
- 若用轻笑、短应答、呼唤、叹息或吸气，必须与人物状态和画面距离一致。
- 环境声、动作声和呼吸能从画面解释并与时点同步。
- 视频节点无背景音乐、旁白、吟唱或字幕。

## Gate 4：Picture lock

- 所有通过片段完整保留，以不重叠、不断时的干净硬切拼接。
- 尺寸、SAR、像素格式、帧率和采样率统一；标准化不改变叙事时长。
- 总时长等于所有镜头实测时长之和，仅允许封装时间基的微小误差。
- 人物、地点、器物、光向、运动方向、轴线和声音空间连续。
- 导出完整环境声/对白的无配乐母版。

## Gate 5：原创配乐

- 音乐在 picture lock 后生成，长度与画面精确匹配；不改变画面时长迎合音乐。
- 音乐轻快、清透、温暖、松弛，配器真实且留白；无沉重史诗、悲苦慢板、廉价 MIDI、密集鼓点、人声哼唱或可识别仿写旋律。
- 前奏迅速进入；段落与 Cue Sheet 对齐；结尾自然收束，无硬切和尾部越界。
- 对白和关键动作声出现时音乐平滑降低；环境声仍可感知。
- 无削波、爆音、响度突跳、抽吸、相位问题或混响尾巴截断。

## Gate 6：最终交付

- `picture_lock_no_music.mp4`、原创配乐无损文件、`final_music_mix.mp4` 均存在且可播放。
- 最终混音中的对白、动作声、环境声和音乐层级正确。
- 无字幕、画面文字、Logo、水印、现代物件、AI/CG 感或崩坏帧。
- 附分镜、两类提示词、实测时长、时间线、Cue Sheet、模型参数和质量报告。

## 故障归因

| 故障 | 唯一修复轴 |
| --- | --- |
| 偏黑偏冷、脸无光 | 重写首帧暖主光落点和冷填充职责，重做并重选首帧 |
| 白衣死白 | 降低局部高光、写明纤维与滚降；保持脸部中间调，不做全局压暗 |
| 暗部死黑 | 增强来自天空/白墙/水面的宽柔填充，不改变太阳方向 |
| 叶影压眼 | 改变遮光载体尺度和落点，不取消整体方向光 |
| 人物漂亮但光影不匹配 | 淘汰；不得以颜值替代参考还原 |
| 人物动作僵 | 减少动作，补躯干到末端的动力链和事件触发反应 |
| 所有元素同频 | 固定一个环境驱动力，按重量和触发时点错峰 |
| 曝光闪烁或光源换边 | 锁定基准曝光和世界光源，只允许局部遮挡变化 |
| 对白生硬 | 缩短、明确对象和语气，或改为自然轻笑/短应答 |
| 音乐太沉重或俗套 | 保留 picture lock，只重写音乐情绪、节奏、配器和负面约束 |
| 音乐压对白 | 重做自动化/手工音量曲线，优先对白和关键动作声 |
| 平台模型不可用 | 报告实时限制并等待新选择，不静默替换模型 |

## 最终报告模板

```text
镜头映射：N 首帧 → N 个 Dreamina Canvas seedance_2.5 节点 → N 镜
图片：Style Image V8.2；LIGHT_MATCH_SCORE 每镜 ≥14/16，无硬项 0
视频：唯一首帧、无尾帧，逐镜实测时长，全段保留
光影：暖金低角度主光、清透冷补光、脸手可读、米白有纹理、暗部不黑
动态：0.25 秒内启动，完整动力链、错峰环境、唯一运镜、末段余动
声音：环境/动作/对白合格，视频节点无背景音乐
配乐：原创轻快纯器乐，精确时长，Cue 对齐，避让对白
交付：无配乐母版 / 原创配乐 / 最终混音版
禁项：无崩坏、字幕、文字、Logo、水印、现代穿帮、AI/CG 感
结论：通过 / 失败镜头与唯一返工轴
```
