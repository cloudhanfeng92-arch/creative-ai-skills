# 海艺快应用模板发布

通过 Chrome 搭建 SeaArt Flow，补齐演示素材与封面，配置节点、输入输出及按需文本示例，发布后核验真实页面。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装对应 Skill 的完整目录：

```text
请从 https://github.com/cloudhanfeng92-arch/creative-ai-skills
安装 skills/seaart-flow-publisher 目录中的 Skill。
```

可在 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/seaart-flow-publisher) 安装 `skills/seaart-flow-publisher`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $seaart-flow-publisher，把这个图像效果制作成海艺快应用，配置上传图片入口、封面和简介，发布后核验详情页。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- Google Chrome 与 mcp__cua_repl
- SeaArt 账号及 Flow 使用权限
- 内置图像生成能力；节点测试需所选模型权限和授权预算

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
