# SeaArt 快应用发布步骤

页面标签以当前观察为准。2026-10-09 实测完成了双图工作流、一次生成测试、封面上传、第二步输入输出绑定、5组英文示例配置、快应用发布和简介修正；以下是可复用的操作经验，节点号、字段名和界面能力仍需现场确认。

官方入口：[SeaArt Flow](https://www.seaart.ai/zhCN/sub-app-flow)。不要保存带认证参数的内嵌 Flow 链接。

## 第一步：完善信息

1. 在项目“分享与发布”中选择“发布为SeaArt快应用”。“分享作品到SeaArt”发布的是作品，不能替代快应用。
2. 输入应用名称。当前实测输入框显示 80 字符限制；执行时以最新计数为准。
3. 简介默认用用户语言写5行“emoji＋一句说明”，适合快速阅读。依次说明上传素材、可选主题或调整方式、生成效果、保留特征、成像或动作风格；没有某项能力时合并或改写，不凑出不存在的控件。用户给的是其他应用的格式范例时沿用格式，内容改成当前应用的真实功能。只承诺实际模型与测试能支持的效果，不虚构速度、免费使用、百分百一致或商用授权。

   富文本简介的输入与保存按 [chrome-operation.md](chrome-operation.md) 操作。编辑器读回全文后才进入下一步；最终以刷新后的公开详情和个人列表中的实际内容证明保存，不能只凭输入框截图。
4. 展开分类标签，选择 **3–5个**当前平台真实存在且相关的选项，覆盖应用功能、主体或成像风格。读回已选标签及数量，不能仅填写搜索词、只选一个主分类或添加无关标签凑数。平台最多可选数或相关选项不足3个时记录实际限制，不编造标签；用户另有明确数量要求时遵从用户。
5. 页面下方包含应用封面，当前显示“上传图片”“上传视频”。按 [cover-design.md](cover-design.md) 用内置生图制作3:4竖版封面，包含英文应用名大标题和明确的玩法画面；人物演示优先欧美面孔。3:4是本 Skill 的用户偏好，即使平台仅写“建议”也执行该比例。上传后确认缩略图、裁切与标题完整，检查必填提示消失。
6. 默认保持无额外订阅；用户要求定价时使用其价格和周期。不要因为界面显示默认价格就认定订阅已开启。
7. 活动入口按用户明确要求处理，模板制作不自动报名活动。
8. 滚动左侧表单，而非误滚右侧预览。填写完成后点击“下一步”；失败时读取具体错误，纠正缺项。

## 第二步：选择输入输出参数

1. “添加输入参数”打开来源列表。展开真实节点，选择真实字段。用户图示的媒体输入为 `[2]媒体上传1 - urls`；数字、名称和字段都需现场核实。
2. 编辑用户显示名称，如“选择或上传主体”“输入修改要求”。标签可用用户语言，文本框中的默认内容与示例默认用英文；回查来源文本节点，避免绑定后把中文 `userInput` 原样展示给用户。按当前设置面板配置必填、默认值、描述和允许类型；页面没有的配置就记录为不可设置，不能仅改标签来宣称某字段可选。
3. 需要多输入时按使用顺序排列，例如先上传素材，再选择主题，再填写附加要求。
4. 内置提示词默认不作为公开输入。固定效果应用不增加用户提示词入口或主题示例；只有可调玩法需要时才绑定附加创意文本。用户要求完整编辑时才能开放内置提示词字段。平台不支持独立附加文字时，明确限制或调整结构，不把本地占位符当功能。

   对已经公开的中间提示词或创意文本参数，点击该卡片齿轮进入“高级设置”，按 [input-examples.md](input-examples.md) 填入5组英文示例。这一步发生在发布界面选定输入节点字段之后，不是在画布节点中添加5份默认文本。实测“文本附加”可绑定 `userInput`，高级设置提供示例文本框和“添加(最多添加5个)”；其他节点需核实实际字段。将已有有效示例纳入5条总数，去除不相关的继承示例，不盲目追加到超额。关掉设置并重新打开，核对持久化的5条；预览若支持点击示例，验证其填入对应参数。
5. “添加输出参数”选择最终生成节点；有多个输出时按用户需求选择并核对，不混入上传原图。
6. 右侧“用户预览”检查控件、标签和顺序。预览里的“创作”可能消耗积分；只有运行预算内才点击。
7. 核对“显示自定义节点名称”和输出标题，避免技术名称影响用户理解。
8. 检查底部选项。用户截图显示“加入SeaArt创作者激励计划”和“将AI APP发布到社区”为默认勾选：前者涉及单独计划，未经要求不自动加入；后者按此次公开发布范围设置。查看“增益设置”实际作用再操作，不凭名称猜测收费方式。若平台强制加入或接受条款，记录实际情况并按工具规则处理。

## 提交与证据

提交前摘要包括应用名、简介要点、3–5个已选相关标签、3:4英文标题封面、公开输入、适用时的5组创意文本示例、输出、模型、测试状态和特殊选项；固定效果应用不要求提示词入口或主题示例。已获得该具体发布任务授权时继续发布；用户限制预览时保留在此。

点击底部“发布”后记录页面反馈。获取实际返回或个人列表中的详情链接，然后打开详情核对同一应用的名字、封面、输入输出和发布状态；可访问不等于审核完成，以现场状态为准。

实测提交时按钮会禁用并显示加载，随后跳到个人中心；跳转本身不证明全部资料保存。个人页若仍展示“概览”，按现场入口切到“AI应用”核对同名卡片。Flow 项目 ID、最初发布页 ID、实际应用 ID 可能不同，记录各自观察到的值，链接从真实卡片打开。

发布或编辑后的核验包括：

- 刷新实际详情页后核对名称、完整简介、3–5个分类标签和封面；旧标签页可能仍缓存更新前的空简介。简介或标签的“查看更多”只影响展示折叠，展开后读回全文或全部标签。
- 核对上传控件的角色与顺序、文本框的英文默认值，并从同一应用的编辑入口核对最终输出绑定与5条示例。
- 在公开页用“随机”或当前示例入口，确认至少一条英文示例填入正确文本框；不触发生成。无交互能力时只报告配置读回。
- 简介或其他字段丢失时，使用该应用的“进入发布页”或实际编辑入口修正、再次发布更新，再刷新核验。不要为修正资料重新创建应用，也不要重复运行生图。

| 实际观察 | 可报告状态 |
| --- | --- |
| 已配置，未点发布 | ready_to_publish |
| 请求已提交，未返回明确结果 | submitted 或 unknown |
| 页面明确显示审核中 | pending_review |
| 成功提示已观察，列表尚无记录 | submitted，记录成功提示与待核验项 |
| 发布状态成功，详情和本人列表对应同一应用 | published |
| 明确字段、权限、网络或审核错误 | failed，附实际原因 |

发布超时或结果不明时先查本人 AI 应用列表、同名项目和详情，不能立即重复提交。字段问题可修正后重试；相同操作连续两次无进展时保存现场和记录，换定位方法或报告具体阻塞。预算耗尽时停止运行，已完成的静态配置仍可继续整理。
