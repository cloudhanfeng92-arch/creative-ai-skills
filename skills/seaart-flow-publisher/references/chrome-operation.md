# Chrome 控制与观察

## 通道选择

所有 UI 动作使用 `mcp__cua_repl.js`。首次调用遵守工具初始化要求，一次仅执行指定入口 API；读取返回的文档再继续。

1. 已指定 tab @-mention 或标签 ID 时，用文档规定的 `cua.getTab` 绑定它。
2. 新任务可用 `cua.createBrowserTab("chrome", url, {sessionName:"🧩 海艺快应用"})` 打开独立标签。仅使用当前工具文档允许的参数。
3. 若返回 Chrome browser unavailable，用 `cua.getState()` 检查。Chrome 原生窗口可用时用 `cua.getApp("com.google.Chrome")`，通过 AX、截图和原生输入操作同一个浏览器。不要把浏览器标签通道失效当成原生窗口也不可用。
4. 原生新任务通常通过 `pressKey("super+t")`、`paste(url)`、`pressKey("Return")` 打开新标签；已有目标任务则继续对应标签。仅使用当前已读取文档支持的 API。

2026-10-09 本机检查中，Chrome 标签通道不可用，原生 Google Chrome 窗口可用；这是观察记录，不代表以后固定如此。

## 控件定位

- 每批确定的动作后重新获取 AX 状态，再决定下一步。旧 AX 编号可能在节点侧栏、弹窗或新页面里被复用。
- 有 AX 控件则按名称、状态与父级关系识别。原生 AX 不可编辑或没有控件时，获取最新截图并用该截图坐标点击；不得套用用户旧截图坐标。
- DOM 通道只使用该浏览器返回文档中的 locator API，选择器来自已观察 DOM。不要猜测内部字段、执行抓包脚本或注入网站私有状态。
- 节点连线：从最新截图辨认输出端口与输入端口，拖动后读回新连线或引用名。缩放和移动画布后重新截图。
- Flow 主页面可能是嵌套页面，观察整个 Chrome 窗口的 AX 或按浏览器文档进入已观察的 frame。发布向导可能在新标签打开，不能继续操作原来的节点画布。
- 页面仍显示 Loading 时，观察一次新的截图/AX 来确认加载结果；不要用点击多次来替代等待，也不靠反复生成解决加载问题。

## 文本和文件

多行提示词和简介优先粘贴为文本，再读回内容。区分普通表单字段与富文本编辑器：

- 普通文本框或示例 textarea 可用当前文档支持的 `setValue` 或 locator `fill`；必要时离焦提交，然后关闭重开检查持久化。
- 原生 Chrome 的富文本简介优先在最新截图中点击正文编辑区取得真实光标，再 `paste(text, {format:"text"})`。实测 AX `click` 显示聚焦不一定能插入文字；此时换正文区域的截图定位，不继续盲贴。替换已有段落时可在真实正文中使用原生选区；整段替换后核对没有残留旧文案。
- 不用原生 AX `setValue` 改写富文本简介来代替正常输入。实测它能让 AX 与截图显示新文案，但提交后简介仍空；随后追加字符也不能可靠补救。遇到这种情况，保留本地文案，重新加载同一编辑页恢复编辑器，再在完整的原生正文中粘贴，不在已被改写的编辑器上反复试按键。
- 字段有文字、失焦或“下一步”成功都不足以证明富文本已保存。发布后刷新详情页并读回全文；发现空简介再通过同一应用的编辑入口修正。

同一文本输入方式连续两次无变化时，重新观察当前页面、光标和控件类型，切换定位或输入方法；不要反复发布来测试未验证的输入。用户切换了 Chrome 标签时，先重新读取当前状态并定位目标标签，停止使用旧元素编号。以上为本次实测恢复方法，后续优先使用当前文档允许、能验证持久化的通道。

图片或视频上传使用观察到的上传控件与文件选择器。原生 macOS 文件选择器可使用路径定位功能，输入确实存在的绝对路径，再确认文件名及上传后的缩略图。不要输入 `file://` 代替实际上传，也不要将图片路径写进提示词当作图片引用。

## 脱敏

Flow 内嵌 URL 可能携带登录 token。原生观察时优先使用 `{emit:false}`（仅当当前工具支持），先在返回字符串内删除敏感查询参数、JWT 和账号标识，再 `nodeRepl.write` 输出局部相关结构。不要直接输出完整对象、原始 URL 或 AX 树；截图输出前确认地址栏和可见区域不含敏感参数。

脱敏匹配需覆盖 AX 中省略协议的 URL、`?token=` / `&token=` 查询片段，以及独立出现的 JWT，不能只匹配 `https://` 开头的完整地址。仅输出当前步骤所需的脱敏行；完整读取仅用于确实缺少定位信息时。

能力中断时保存本地记录；恢复后先核对项目、保存状态和个人应用列表，再继续。会话状态或登录凭据不能写入 Skill、示例、证据或压缩包。
