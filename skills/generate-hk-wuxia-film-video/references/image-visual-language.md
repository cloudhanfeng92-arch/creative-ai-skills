# 90年代港式胶片武侠视觉语言

把本文件作为稳定的电影视觉语法，不当作装饰关键词集合。系列镜头保持共同画风，具体色彩、光源、构图和材料表现仍随用户场景调整。

## 共享画风

- **年代与类型：** 90年代香港经典古装武侠电影静帧，具有金庸式江湖情绪，不是宫廷排场、现代仙侠奇观或泛化的“古代中国”。仅在用户明确要求神怪时扩展为克制的港式神怪武侠。
- **光化学成像：** 35mm复古胶片、可信的物理显影、细腻而明显的胶片颗粒、平缓的明暗过渡、轻微拍立得式朦胧柔光、雾面空气感与柔和边缘漫射光晕。颗粒融入成像，不像均匀覆盖的数码噪点。
- **情绪：** 古朴、温润、克制、孤寂、神秘与宿命感；可以表现温柔、重逢、等待、离别和坚定，但表演不过度煽情。
- **空间：** 前中后景分层、不对称平衡、有效留白、自然前景遮挡；背景压缩为柔和色块、光斑、薄雾、雨幕或剪影。
- **材料：** 旧棉麻、粗布、薄纱、竹、麻绳、风化木材、哑光石材、湿土、旧砖、氧化金属、纸灯与褪色旗帜。只选用场景相关材料，写清风、雨、重量和光如何影响它们。
- **静中有动：** 选择一个悬而未发的动作前态或情绪瞬间；发丝、斗笠系带、衣摆、衣袖、帘幕、雨、烟、尘、马匹或灯笼提供克制的动态。

## 色彩语法

色彩是低饱和冷暖关系，不是一套强行复制到所有镜头的固定调色。

- 可选基色包括大地棕、暖棕、苍青、蓝灰、冷灰、暗绿、风尘墨黑、褪色砖红、灰调藏蓝和泛旧暖黄。
- 暖金、暖橙、烛火琥珀与旧黄通常对应具体用途：夕阳、灯火、肤色温度、轮廓光、窗光或一个小的叙事点缀。
- 苍青、冷蓝与灰蓝自然用于阴影、雨、夜、雾、远景或石面反光。
- 红、绿、蓝、白、黑的衣物和建筑颜色应泛旧、经风雨或融入环境；避免纯黑、糖果色、霓虹青紫和现代青橙广告调色。
- 每镜把颜色对应到具体物件，并解释冷暖对比的视觉作用；保持用户指定的服装色，不强行把白衣改成米黄、肤色改成赭褐或草木统一改成枯黄。

不再把六七十年代邵氏或胡金铨、暖褐褪色老照片、粗粝大颗粒、强制暗角和轻微过曝设为默认综合锁。当前默认恢复原版90年代细腻胶片；只有用户另行明确指定时，才对特定任务调整画风。

## 光影语法

交代一个主光源、方向、被照亮的对象、空气介质，以及最多一两个有来源的次要光效。高光柔和温润、不过曝，暗部保留胶片纹理与层次。唯美来自真实光源、细腻明暗与空间空气感，不靠洗白面部或无因光束。

| 场景条件 | 有依据的布光方式 |
| --- | --- |
| 黄昏山林、庭院、园林 | 暖色侧逆光或单侧轮廓光穿过枝叶或建筑间隙，正面极柔辅光；薄雾或微尘承接疏落光束。 |
| 夜间室内 | 暖灯或烛火从侧面照亮面孔、手、桌面和道具；窗外冷光或月光勾勒发丝与肩部，帘幕或薄烟柔化过渡。 |
| 雨中或古寺石阶 | 宽广冷色侧光或逆光塑造雨丝与湿地反射，少量寺内暖光增加纵深，面部只有轻微柔和辅光。 |
| 月夜屋顶、桥、山野或城镇 | 冷色月光从侧后方勾勒头发、衣袍、兵器、绳索或屋檐，远处旧暖灯火在夜雾中形成克制光晕。 |
| 城墙、战场或动作将起 | 略硬的冷侧光和清晰明暗交界，极少正面辅光；尘烟、乱发、弓弦或剑刃边缘受光。 |
| 雪景或阴天 | 大面积冷色漫射光，雪地或天空提供浅色反光；肤色或远处庇护所保留克制暖色，不能无因复制夕阳光柱。 |
| 清晨或水边 | 柔和斜射晨光配冷色环境辅光，水面、薄雾或浅色墙面提供可信的次级反射。 |

不使用无来由的神光、四面轮廓光、亮滑影棚主光、大片过曝高光、死黑暗部或平板全局照明。夜雨与封闭室内不能凭空增加阳光；面部和眼神的细微层次不能被雾光吞没。

## 镜头与构图

- 肖像与人物关系镜头默认中长焦、大光圈、浅景深或极浅景深，以中近景、半身或中景为主。
- 适当用竹叶、湿屋檐、他人肩膀、发丝、花枝、绳索、旧砖、旗、烟或雨形成柔和前景。
- 主体略偏离中心，保留安静留白；石阶、桥绳、古琴、弓箭、屋脊或小径可以形成真实的引导线。
- 两人情绪交流可用过肩构图，前景人物虚化，对面人物的面孔与目光成为焦点。
- 环境、骑兵或用户明确要求的大型神怪场面可采用有压缩感的中远景或远景；轮廓、尺度关系与大块留白清楚，避免现代超广角畸变。
- 系列镜头改变景别与空间处理，不只更换名词而重复同一张肖像。

## 人物、服装与表演

- 先写身份与生活经历，再写天气影响下的头发、面部结构和眼睛、目光以及克制的内心状态。
- 可表达平静警觉、疲惫、疏离、温柔、犹疑、坚定、隐忍悲伤或决战前的专注。无明确要求时不使用夸张喊叫、模特姿态或直视镜头的商业美颜。
- 古风武侠袍服、长衫、交领层次、襦裙、斗篷和骑装使用粗棉麻、柔软织物或薄纱，表现自然重量、松弛褶皱、局部湿痕、磨损、灰尘与旧感。
- 默认不加现代剪裁、奢华刺绣、塑料反光、全新租赁戏服感、浓重美妆、磨皮、宫廷华冠和时装摆拍。
- 道具归属及动作明确：哪只手持、拔、按、扶或松开，每人只保持一项主要动作。

## 场景与叙事铺垫

每镜交代清楚地点、时间、天气、前中后景标志和一个含蓄叙事线索。虚化远人、半开窗、空座、将熄的灯、遗落剑鞘、远处聚落灯火、尚未现身的来客或半隐神怪，都只在故事需要时使用。

环境服务人物关系与动作，不为了显得“中式”而堆积寺庙、灯笼、竹林、山峰、人群与雾。范例里的人物、道具和天气不是固定配置。

## 神怪与动作适配

- 神怪仅在用户明确要求时加入；呈现90年代光学合成、微缩模型、威亚、绘景或实体特效的触感，部分隐藏在云、雾、黑暗或剪影中，不是高清亮滑CG。
- 动作定格在一个可读瞬间，接触链、力量方向和衣发环境反馈明确。保留合理支撑、重心与后续运动空间，避免现代超级英雄姿态、能量圈、过多粒子或游戏技能特效。

## 排除边界

排除锐利数码边缘、HDR观感、过度锐化、现代商业或时装摄影、光滑三维渲染、动漫、水墨插画、霓虹青紫、高饱和数字特效、塑料皮肤、洁净角色扮演服装、随机文字、字幕、边框、标志、签名和伪水印。平台要求的AI标识不属于可规避的画风缺陷。
