# 港风武侠视频风格

将用户的故事或参考图转化为连续的港式武侠镜头。生图阶段恢复原版八段长篇写法，规则说明与提示词正文统一中文；视频继承关键帧的90年代港片画风、人物和光源，再加入真实动作、风与表演。

## 核心约定

- 生图模型：LibTV `Style Image V8.2`。默认横屏 `16:9`，`quality=auto`、`stylize=150`、`weird=0`、`chaos=0`；当前每节点输出四张候选，需选定一张供视频使用。
- 生图提示词：呈现给用户、保存的文件和实际发送给模型的正文都必须是中文。每镜恰好八个自然段，顺序固定；仅允许 `35mm`、`CG`、`LED` 等必要技术缩写，不另写英文版，不混入英文风格词或字段模板。
- 默认画风：90年代香港经典古装武侠电影、金庸江湖美学、35mm真实物理显影、细腻而明显的胶片颗粒、轻微拍立得式朦胧柔光与雾面质感、柔和边缘漫射光晕。整体古朴、温润、克制，肤质与衣料真实，不强制粗粝颗粒、暗角或褪色老照片滤镜。
- 色彩随每场戏的低饱和冷暖关系设计；大地色、苍青、暖棕、灰蓝与少量泛旧暖黄分别对应实际物件和光源。高光柔和温润、不过曝，暗部保留胶片纹理与层次；阴雨、夜景和室内使用各自真实光源，不把所有场景刷成夕阳。此次恢复的是旧版90年代画风，不再默认叠加邵氏六七十年代暖褐粗颗粒综合锁。
- 视频模型：LibTV `Seedance 2.0 VIP`，一张已确认图片对应一个 `singleImage2video` 节点，`720p`、`count=1`，音频开启用于现场声和必要对白，联网搜索关闭。
- 每镜 **4–5秒，优先4秒**，交付30fps；时长落在 `F/30`、`120 ≤ F ≤ 150` 的帧边界。新生成还必须满足模型原生时长步长。
- **不裁切视频**：原生生成时长 `S` 必须等于批准交付时长 `D`，整段保留首帧、动作和片尾。禁止生成更长后截短、删除尾段、时间变速、循环、冻结或补视频来凑时长；也不裁掉画面边缘。
- 2026-09-08查询的Seedance原生时长步长仍为1秒，因此当前新生成只选4或5秒。4.5秒等帧对齐值仅在模型实时接口原生支持，或用户已有完整且合格的源片时使用。不可将“30fps帧对齐”表述成模型支持任意小数秒。
- 结尾缓冲属于完整视频内部：`F=round(30D)`，`B_f=min(15,max(11,round(0.12F)))`，`E=(F−B_f)/30`；主要动作和对白在 `E` 前完成，后面的约0.47–0.50秒保留收势、呼吸和环境余韵，不剪掉。
- 镜头之间默认硬切，镜头内部连续。无音乐、旁白、吟唱、字幕和场景内文字；必要对白仅存在于音轨。
- 同一任务支持多组独立短片；每组单独输出，除非用户要求合并。

每次付费生成前通过官方 `libtv model search` 和 `libtv model <modelKey>` 复核模型与参数。保留用户指定模型，不静默替换；不能支持所需时长时，先给出可执行的4/5秒方案。

## 授权与呈现

先呈现可审阅的内容和调用范围，沿用本任务已有的明确授权；用户只要文案、提示词或方案时不生成媒体。

1. 创意阶段给出故事分析、人物空间关系、镜头数、每镜完整时长、总时长与分镜表。
2. 生图前展示全部中文八段式提示词、参考图用途、模型参数、节点数、每节点候选数，以及能查到的积分消耗；取得该范围的生图确认。
3. 用户选定或授权代选关键帧后，展示每镜完整的中文视频提示词、原生时长等于交付时长的参数、参考图与音轨策略，取得该范围的视频生成确认。
4. 合成前给出片段顺序、每段完整时长和总时长；已有合成授权时直接执行，否则取得合成确认。

新增付费镜头、重试、更多候选、换模型或超出已授权范围时，先展示变化再取得相应授权。确认仅覆盖列出的操作。

## 1. 分析故事与连续性

提取主题、关系、情绪推进、人物数量、服装兵器、场景时间天气、用户参考图用途、动作和对白需求。每镜一个叙事目的、一条主要动作链、一个主运镜。没有要求时不擅自增加关键死亡、恋爱、背叛、命名角色或超能力。

建立人物、服装、道具归属、空间位置、光源、风向、银幕运动方向与声音约束。让脚部支撑、重心、接触、惯性和落地构成可读的动作关系。正常旅途、相遇和恢复可以松弛微笑，危险或伤痛需要场景合理的表情。

## 2. 设计4–5秒分镜

单一事件默认4秒；同一动作或对白确实需要完整反应与收势时用5秒。不同地点、视角、事件和关系变化可分镜，避免为拉长时长增加空转动作。约20秒可优先规划5镜×4秒，剧情只需4镜时也可4镜×5秒；先决定叙事需要再冻结节点数。

用户提供N张待动画图片默认对应N镜。保持180度轴线、眼神、进出方向、空间地标与道具状态。自动切镜指完整片段之间的硬切，不要求单图模型随机内部切镜。每组使用唯一的 `GROUP_XX_SHOT_XX` 节点与文件标识。

分镜表至少包含：
`组/镜号｜完整时长D=S｜叙事目的｜人物动作｜主运镜｜空间/轴线｜光/风｜表情/对白｜完整片尾状态与下一镜衔接`

## 3. 编写并生成中文关键帧

每镜展示标题 `### SHOT_XX｜主体·场景或动作`，正文严格按以下顺序分成八个中文自然段：

1. 90年代香港武侠与江湖美学、35mm物理显影、细腻可见颗粒和柔和雾面光晕；
2. 低饱和色彩、具体物件的颜色与冷暖关系；
3. 合理的主光源、方向、硬度、散射、辅光及受光表面；
4. 焦段、景别、景深、机位、前景遮挡和构图留白；
5. 人物身份、面容发丝、目光与事件引起的克制表情；
6. 旧衣料、兵器和器物归属、动作准备姿态与物理支撑；
7. 场景空间层次、时间天气、旧材料与叙事铺垫；
8. 情绪、复古画风重申、具体视觉重点和反数码约束。

按原始八组范例的行文节奏书写：每段通常一至三句，首段以长句定调，色彩、光影和构图通过因果关系展开；不要压缩成关键词或字段模板。每镜自包含，不使用“同上”；不把斗笠、白衣、薄纱、弓箭或模糊远人变成所有镜头的固定配置。具体顺序、起句和收束方式见生图编译器。

使用 [run_image_node.py](scripts/run_image_node.py) 发送中文正文；该脚本检查八段和基本中文格式，画风与场景正确性仍须人工式语义检查。模型参数和镜号标题不作为提示词正文发送。下载四个候选、逐张检查，再按用户选择或明确代选授权确定一张；上传为独立 `GROUP_XX_SHOT_XX_SELECTED` 单图节点，视频仅连接该节点。

## 4. 编写中文视频提示词

先检查实际图片，再沿用首帧的人物、衣物、道具、空间、光线、低饱和冷暖关系、细腻胶片颗粒与柔和光晕。每镜说明完整4/5秒时长、严格单图参考、一种运动模式、一条动作链、一个运镜、风与物理反馈、表情和对白、片尾缓冲、现场声及排除项。

风按材料重量产生不同幅度与延迟：草叶先动、发丝袖口随后、厚衣摆和重物响应更迟更小。动作明确支撑、发力、重心转移、速度、路径、接触、回弹、减速与落地；快速而干练，收势可读。环境自然舒服，激烈动作仍保持真实速度和力量。

对白只在内容需要时出现，写明说话者、对象、语气、具体短句和时间窗。普通对白约10–12字，高能动作对白约4–8字；在片尾缓冲前结束，不生成字幕。

## 5. 生成并检查完整源片

使用 [run_video_node.py](scripts/run_video_node.py) 运行批准的每镜节点。检查开头、约25%/50%、动作截止点与最后实际帧，听取完整音轨。确认总时长符合4–5秒、人物和道具连续、动作有物理依据、全片细腻胶片质感与光源稳定、高光不过曝、无音乐和文字。

若源片比批准时长长或短，不裁切修复；保留原片并说明差异。若仍在4–5秒内，可提出按完整实际时长更新分镜/总时长；必要重生成须取得付费授权。其他失败按质量门处理。

## 6. 完整片段合成与交付

使用 [assemble_video.py](scripts/assemble_video.py) 按批准顺序连接完整源片。可规范到1280×720、30fps、H.264和48kHz AAC，尺寸不匹配时等比缩放留边；不裁时间、不裁画面、不用转场重叠缩短镜头。源视频速度和首尾内容保留，源音轨完整保留，无音轨时补同长静音。

可选 `--shot-duration` 仅验证整段预期时长，不是截取指令；省略则读取完整源视频时长。总时长为各完整镜头之和。保存逐镜时长、帧数与首尾检查结果，通过验收后交付最终视频、准确路径、分镜/提示词、镜头与素材对应关系。失败时保留原素材，不自动裁切、补帧或改速。
