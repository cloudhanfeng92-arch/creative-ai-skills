# 中国古港市井绘卷视频生成

将用户的一句话、短文或参考图，转化为描绘中国古代沿海港口、河岸城市、庭院仪式、寺庙街区或繁华市集的动态风俗绘卷。画面以 19 世纪中国城市风俗画的繁密叙事为主体，融合传统水墨画的简洁线条、大地底色与现代高分辨率数字精修；建筑、服饰、船只、摊位和日常生活细节丰富，红、绿、金与蓝瓦形成鲜明点色。除非用户另行指定，默认一个场景、每场 4–6 秒、16:9 横版、720P；图片优先使用 **Lib Image 或 GPT Image 2**，不可用时使用 **General Image Pro**；图生视频优先使用 **Seedance 2.5**，不可用时使用 **Seedance 2.0**。全程不使用旁白或解说。

## 输入、优先级与边界

收集或合理推断：主题/情绪、城市或港口类型、核心建筑、人物活动、船只/摊位/仪式等生活内容、参考图（可选）、场景数量、总时长、是否有指定结尾画面。用户提供的参考图和明确要求优先；未指定时默认一个 5 秒场景、16:9、720P。

画风与提示词格式必须锁定为 `references/chinese-cityscape-prompt-library.md` 中的“中国古代城市风俗绘卷提示词”体系：中远景或高位全景、层次丰富的中国古典城市空间、繁忙但组织清晰的人群叙事、木船与碧绿水面、石桥或石板街、木石建筑、红绿建筑构件、金色屋顶或蓝瓦宝塔、条纹遮阳篷与彩色摊位、晴日明亮光线和清晰阴影；使用传统中国绘画的轮廓线、平面色块、轻微水墨纸本质感和现代数字精修。可替换题材元素，但不得漂移为日式建筑/和服/神社、纯浮世绘复制、写实摄影、3D 游戏画面、西式奇幻、现代城市、空旷无人景观或低幼卡通。

先分析并写提示词；任何会消耗积分或调用生成服务的图片、视频、配乐、重试或最终合成，都必须先展示内容、模型、数量/时长及可用的消耗估计，并等待明确确认。确认只覆盖用户点名的项目；修改和重试视为新的确认项。

## 贯穿全片的风格锁定

在第一次创意输出中固定，下游提示词和素材都遵守：

- 叙事核：以中国古代城市日常生活为主，人物交易、搬运、交谈、行舟、过桥或参加仪式，共同构成可阅读的群像叙事。
- 人物锚点：固定时代、人数密度、服装轮廓、长袍/短褂/头饰、职业与动作；人物必须是中国传统服饰，不出现和服、现代服装或含混异域装束。
- 建筑锚点：每场确定一个核心地标，如塔式航标、华丽寺庙、蓝瓦宝塔、牌楼、临水楼阁或庭院正殿；保持屋顶、斗拱、木柱、石基、门窗和彩绘构件造型稳定。
- 城市锚点：使用河岸/海港、石桥、石板街、码头、木船、摊位、院墙和远层屋脊建立前中远三层；繁密但保持道路、水道和核心建筑可读。
- 构图锚点：每场选择高位斜俯视、中远景横卷式展开、单点街巷透视、石桥引导线或庭院中轴中的一至两种，不混用冲突机位。
- 材质与色彩：旧木、青石、灰砖、彩绘梁柱、瓦片、布幡、竹筐、漆器和水面；大地色为底，朱红、松石绿、金色、蓝瓦、碧绿水面和彩色商品为点色。
- 绘画锚点：19 世纪中国城市风俗画气质，传统中国绘画轮廓线，简洁而准确的线描，平面色块与轻微水墨晕染，纸本纹理，现代高分辨率数字精修，细节丰富但不照片化。
- 光影锚点：晴朗日光、明亮通透、阴影边缘清晰但不过分写实；用光线凸显城市生机、屋顶层次与水面反光。
- 反向约束：无文字、水印、Logo、乱码招牌、现代物件、汽车、电线、玻璃幕墙、日式建筑、神社鸟居、和服、武士、纯日漫、纯浮世绘复制、照片写实、3D 渲染、塑料材质、霓虹赛博朋克、西式奇幻、人物畸形、拥挤粘连、建筑透视崩坏；按画面补充特异禁项。

将每个场景的人物群、核心地标、街道/水道结构、建筑、船只、摊位、材质、色彩、光向、镜头和首/尾帧关系记录为锚点。后续素材以已确认的同场景图作参考，保持城市结构、人物服饰、地标造型与绘画体系一致。

## 阶段 1：解析与场景设计（不生成）

1. 从文字或图像提取时代、地点、核心地标、人物群、日常活动、建筑、水域、船只、摊位、情绪、色彩、光源和可动元素；说明任何重要的合理推断。
2. 设计一个默认场景；若用户要求多图或多场景，设计连续的城市动线。每场固定 4–6 秒，总长为各场之和。
3. 输出并暂停等待创意确认：
   - 创意概念与风格锁定；
   - 场景总览：编号、标题、叙事功能、核心地标、人物活动、空间构图、时长、建议视频模式；
   - 首尾帧镜头的转场目标（起始状态 → 结束状态）；
   - 每个场景待生成的图片数量。

优先单图首帧模式用于人群缓慢穿行、船只轻移、旗幡摆动、摊贩招呼、水波荡漾、炊烟和树叶变化。首尾帧模式仅用于可清晰定义的状态转变，如镜头沿河拉远显露宝塔、木船驶过石桥、仪仗穿过庭院或阳光逐步照亮金顶。禁止用突然变形、随机切镜、剧烈抖动、快速穿越人群或无因果的大幅运动解决转场。

## 阶段 2：文生图提示词与确认生图

为每张所需图输出一条完整、独立的中文提示词。严格参考 `references/chinese-cityscape-prompt-library.md`，保持“构图 → 元素 → 光影色调 → 风格”的单段格式、句法密度与中国城市风俗语言，以具体画面描述代替标签堆砌。

格式严格如下：

```text
场景 X｜[首帧/尾帧]｜[Lib Image / GPT Image 2 / General Image Pro]
文生图提示词：构图：……。元素：……。光影色调：……。风格：……。
[尾帧仅列出] 参考图：该场景已确认首帧
反向约束：……
```

- 首选模型池为 **Lib Image / GPT Image 2**：根据当前可用工具、参考图能力和画面连续性选择其一；若两者均可用，首帧默认 Lib Image，需参考已确认首帧的尾帧默认 GPT Image 2。两者不可用时才使用 **General Image Pro**。必须在确认前明确实际选用模型，不得虚构模型可用性。
- 所有图片默认 16:9。提示词不得添加 Midjourney 参数或非目标模型参数。
- 每条提示词必须显式写出中国古典建筑、中国传统服装与中国古代城市生活，并至少加入一个核心地标、一个水陆动线、三类生活细节和明确的前中远景关系。
- 每场只设一个核心视觉地标；围绕地标组织人群、道路、水道、船只和摊位，不得让细节堆积破坏空间可读性。
- 构图段先锁定画幅、景别和机位，再写核心地标、人群动线与纵深；元素段列出 6–10 个关键对象；光影色调段写大地底色、红绿金蓝点色、光向与清晰阴影；风格段必须完整写出固定绘画锚点。
- “浮世绘式”只可用于平面化构图、轮廓线和色块组织的辅助描述；内容身份必须明确为中国，禁止生成日式建筑、服装与文化符号。
- 尾帧以同场景已确认首帧为构图和风格参考，只表达阶段 1 的结束状态；保留人物群身份、服装、地标造型、建筑结构、船只类型、摊位布局、材质、色彩和光影体系。

汇总“图片、专属场景/用途、完整提示词、模型、16:9 画幅、数量、预计消耗”，然后明确等待生图确认。获确认后才调用模型；先生成和检查首帧，再生成需要的尾帧。检查中国文化身份、核心地标、人群可读性、城市空间、建筑透视、服饰、绘画线条、色彩、文字伪影及反向约束；不合格时先解释问题与重做方案，再请求新确认。

## 阶段 3：图生视频提示词与确认

只在图片被确认后，为每场写一条图生视频提示词。默认使用 **Seedance 2.5**；不可用时使用 **Seedance 2.0**。使用该场自己的首帧，或自己的首尾帧；若用户提供了适合作尾帧的图，也可用首尾帧模式。提示词参考 `references/chinese-cityscape-prompt-library.md` 的视频模板，强调绘画线条、建筑结构、人物服饰、群像密度和中国文化身份稳定。

格式严格如下：

```text
场景 X｜标题｜固定时长 X 秒｜[首帧参考/首尾帧参考]
参考图：[首帧；尾帧（如有）；用户角色或场景参考图（如有）]
视频模型：[Seedance 2.5 / Seedance 2.0]｜16:9｜720P
图生视频提示词：[运镜 → 人群/船只/过渡动作 → 环境动态 → 建筑与画风稳定约束 → 画质与画幅]
```

- 先写一个可执行的镜头动作：匀速慢推、克制横移、轻微上升、沿河慢拉远或锁定横卷构图；单个片段只使用连续、平滑的运镜。
- 再写分层动态：前景行人或摊贩做微小动作，中景船只或仪仗缓慢位移，远景旗幡、树叶、炊烟与水面自然变化。
- 避免全体人物同步、快速奔跑和大幅肢体动作；人物脸部不应被推成近景，防止群像畸变和绘画风格破坏。
- 首尾帧只描述从起始到结束的渐进变化，不能让人物、桥梁、寺庙、宝塔、灯塔、庭院、船只或街区布局无故重塑。
- 强制“无抖动、无卡顿、无突变、无切镜、无随机新增人物/建筑/船只/文字”，锁住中国传统服饰、建筑形态、城市布局、轮廓线、平面色块、纸本纹理与现代数字精修质感。

完成后展示每场的图片、模式、时长、实际视频模型、16:9、720P、完整提示词和预计消耗，明确等待视频确认；此阶段不得生成视频。

## 阶段 4：按确认生成视频

每条生成前，再展示这条的参考图、模式、时长、实际视频模型、16:9、720P、提示词与预计消耗；得到明确确认后，才调用 Seedance 2.5 或回退到 Seedance 2.0。逐条检查：中国文化身份稳定、建筑与桥梁无变形、人物服饰与群像密度稳定、船只和人群运动自然、镜头平滑、绘画线条与色块没有融化、首尾状态符合预设、时长正确、没有新增文字或现代元素。失败重试先给出改写提示词并重新确认。

## 阶段 5：配乐与剪辑合成

视频确认完成后，给出无旁白的音乐和成片方案：

1. 按总时长生成一条配乐提示词：以琵琶、古筝、笛、箫、堂鼓、木鱼、锣钹或轻弦乐为可选色彩；可加入克制的水声、橹声、脚步、叫卖声纹理和旗幡声，但不得形成可辨识对白。描述每个 4–6 秒场景的节拍、进入点、繁华程度、情绪曲线和收束。不得加入旁白、念白或歌词，除非用户另行要求。
2. 输出剪辑时间轴：场景起止、视频文件、硬切/叠化/桥洞遮挡/旗幡遮罩/水面匹配剪辑的转场、配乐与环境声的进入/渐变/收束。
3. 展示配乐模型（若可用）、成片规格（默认 16:9、720P）、时长和预计消耗，等待对配乐生成及最终合成分别确认。
4. 获确认后生成配乐、对齐已确认视频、执行剪辑合成，交付一段统一的中国古代城市风俗绘卷短片。

## 交付前自检

- 已以用户输入或参考图为基础，而不是照搬参考库的特定场景。
- 每条图片提示词均使用“构图、元素、光影色调、风格”格式，并明确中国古典建筑、中国传统服饰、城市生活与前中远景。
- 全片锁定 19 世纪中国城市风俗画、传统中国绘画线条、大地底色、红绿金蓝点色和现代高分辨率数字精修。
- 默认一个场景；多场景时每场 4–6 秒、城市动线与视觉连续。
- 图片模型为 Lib Image 或 GPT Image 2，General Image Pro 仅作回退；视频优先 Seedance 2.5，Seedance 2.0 仅作回退。
- 默认画幅 16:9，视频默认 720P；模型与规格在每次确认前明确展示。
- 图片、视频、配乐、重试和合成均在实际调用前获得确认。
- 无旁白；最终成片无日本文化元素、现代物件、照片写实或 3D 塑料感，始终保持繁华、细腻、明亮而具有历史文化质感的中国古代城市绘卷画风。
