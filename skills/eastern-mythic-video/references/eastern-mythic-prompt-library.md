# 东方幻想提示词参考库

编写本技能的文生图与图生视频提示词时使用。本库以用户提供的十组东方幻想提示词为唯一格式和风格基准。可提取其空间关系、构图和语言密度以服务新创意；不得把完整示例或固定场景强加给用户。

## 使用规则

- 首帧：使用 **MJ**；写一段中文自然语言画面描述，末尾固定加上 `--ar 16:9 --raw --s 90 --c 3`。
- 尾帧：使用 **GPT2image**；引用已确认的同场景首帧，继承其风格、主体、构图、镜头与光影，只描述有因果的结束状态；不添加 MJ 参数。
- 提示词顺序：主体与尺度 → 空间/建筑/自然物 → 构图与留白 → 光影与配色 → 镜头与写实质感 →（仅 MJ）统一参数。
- 每场从下列母题选一至两个互不冲突的结构。保留其空灵、庄严、陌生、静谧或禅意的气质，避免拥挤建筑、密集人物、文字、Logo、水印、现代物品、卡通、动漫和西式奇幻符号。

## 十组东方幻想母题与提示词格式

### 01｜双天城

三十三重天之上，两座大陆级天空神城悬于云海两侧，以超长白玉拱桥连接，巨型瀑布坠入下界，低位金白日光勾亮云层与建筑，超广角史诗远景，冷灰蓝、象牙白、浅金，电影级写实巨物美学。

适用：双主体对峙或连接、史诗开场、桥梁和瀑布带来的纵深与宏大尺度。

### 02｜云中巨城

庞大东方浮空巨城嵌入白色云团，下方无限镜面完整倒映天空与城市，远处悬挂巨大弯月，一侧以飞檐、山石、苍松框景，大面积留白，静谧超然。

适用：静止凝望、倒影、侧向框景与不对称留白。

### 03｜白玉天河

巨大弧形镜面天河悬于云海，白玉回廊环绕水面，远方矗立宏伟天门，近景巨柱飞檐框景，人物极小作尺度参照，深蓝镜水与象牙白建筑，庄严纯净。

适用：仪式感、圆弧引导线、前中远三层空间和极小人物尺度。

### 04｜通天之桥

一条无法估量长度的白玉天桥穿过万里云海，连续拱券与高柱直达世界尽头，远处消失于天光，桥下是云海、水域与遥远大地，极强透视与无限延伸感。

适用：朝圣、行进、单点透视和从远到近的连续镜头运动。

### 05｜云海仙山

庞大东方宫殿群依仙山层层升高，飞檐、塔楼、悬空长廊分布于不同高度，瀑布穿过山谷，右侧无边云海留白，宋代山水“高远、深远、平远”空间结构。

适用：纵向层叠、山水叙事、多层建筑与右侧留白。

### 06｜倒悬大陆

大陆级巨型陆地倒悬于天空顶部，中央巨瀑如天柱贯穿云层坠向下界，下方可见微型大地与城市，巨大尺度反差，陌生、庄严、超现实。

适用：超现实揭示、仰视、上下颠置空间与渐进式镜头拉远。

### 07｜一树一岛

极简浮空孤岛，一棵巨大苍老白花树独立于岛上，两名白衣人物极小，远方仅有少量浮岛与云团，下方天镜倒影，主体偏侧，大面积纯净留白，孤寂禅意。

适用：人物情绪、小动作、孤岛主景与极简偏侧构图。

### 08｜天地折叠

山川、宫殿、瀑布与城市从画面四周向中央弯曲翻卷，中央裂开通向深蓝宇宙与银河的巨大空间通道，天地失去正常方向，东方山水与非欧几里得空间融合。

适用：仅用于主题明确的空间异变或世界转场；首尾帧必须限定为缓慢、有因果的弯曲或开启，禁止随机重塑。

### 09｜白玉月门

纯白天界，巨型白玉圆环与细长天门从云海升起，巨大弯月从其后方出现，形成双弧构图，天空漂浮淡粉白丝带状天河，低饱和、高通透、神圣极简。

适用：纯白天界、神圣极简、双弧构图和月亮渐现。

### 10｜天上镜湖

城市尺度圆形天池悬于无边云海，深蓝镜面完整倒映天空与太阳，白玉环形平台围绕湖面，仅少量亭台点缀，高位俯瞰，大面积留白，宁静肃穆。

适用：高位俯瞰、环形主体、镜面倒影与安静收束。

## 图生视频提示词模板（Seedance 2.0）

先写单一且平滑的运镜，再写主体和环境的连续变化，最后锁住首帧的视觉锚点。提示词按 4–6 秒设计，不塞入多段动作。

```
[第三人称]，[超广角/高位俯瞰/远景]镜头[匀速慢推/轻微横移/缓慢升起/慢拉远]，全程丝滑连续、无切镜；[人物/核心主体] [单一连续动作]；云雾、瀑布、镜水、丝带状天河或花枝呈现细微自然动态；保持首帧的[主体、建筑、空间尺度、构图、光向与色彩]，无抖动、无卡顿、无突变、无随机新增人物/建筑/文字；东方幻想电影级写实巨物美学，大面积留白，真实空气透视。
```

首尾帧模式只描述从首帧到尾帧的渐进变化；不得无故替换人物身份、服装、主要建筑、月亮、时间或镜头语言。
