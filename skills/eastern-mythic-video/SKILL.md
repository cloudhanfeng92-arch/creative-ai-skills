# 东方神话幻想视频生成

将用户的一句话、短文或参考图，转化为具有中式美学、东方神话幻想与超现实空间感的完整短片。除非用户另行指定，默认一个场景；每场 4–6 秒；首帧图用 **Midjourney（MJ）**，尾帧图用 **GPT2image** 参考已确认首帧生成；图生视频统一使用 **Seedance 2.0**。全程不使用旁白或解说。

## 输入、优先级与边界

收集或合理推断：主题/情绪、主角或主体、参考图（可选）、场景数量、画幅、总时长、是否有指定结尾画面。用户提供的参考图和明确要求优先；未指定时默认一个 5 秒场景、16:9 横版。

画风与提示词格式必须锁定为 `references/eastern-mythic-prompt-library.md` 中的“东方幻想提示词”体系：天界巨构、云海、白玉、镜面水域、极端尺度对比、深蓝/象牙白/浅金或低饱和高通透配色、大面积留白与电影级写实巨物美学。可替换题材元素，但不得漂移为西式奇幻、旅游照、普通古风棚拍、动漫或杂乱装饰。

先分析并写提示词；任何会消耗积分或调用生成服务的图片、视频、配乐、重试或最终合成，都必须先展示内容、模型、数量/时长及可用的消耗估计，并等待明确确认。确认只覆盖用户点名的项目；修改和重试视为新的确认项。

## 贯穿全片的风格锁定

在第一次创意输出中固定，下游提示词和素材都遵守：

- 叙事核：主体的目标/动作、情绪弧与场景之间的视觉因果。
- 主体锚点：人物外貌、服装、道具、人数与相对尺度；用户图优先作为外形参考。
- 空间锚点：天桥/天河/天门/天池/浮空城/倒悬大陆/云海仙山等主体关系；大面积留白、单点透视、严谨对称或框景构图，人物通常极小以衬托宏大。
- 材质与色彩：白玉、镜面深蓝水域、象牙白建筑、云雾、少量苍松或白花树；按场景选冷灰蓝、浅金、低饱和粉白或高通透纯白体系。
- 摄影锚点：超广角、强透视或高位俯瞰须明确选择；电影级写实巨物美学、真实物理材质、体积雾、空气透视与干净留白。
- 反向约束：无文字、水印、Logo、现代物品、人群、普通建筑、旅游照、卡通/动漫、喧闹霓虹与廉价仙侠特效；按画面再补充特异禁项。

将每个场景的主体、场所、色彩、光向、镜头和首/尾帧关系记录为锚点。后续素材以已确认的同场景图作风格参考，保持主体和画面体系一致。

## 阶段 1：解析与场景设计（不生成）

1. 从文字或图像提取主体、象征物、环境、情绪、色彩、光源和可动元素；说明任何重要的合理推断。
2. 设计一个默认场景；若用户要求多图或多场景，设计连续的场景序列。每场固定 4–6 秒，总长为各场之和。
3. 输出并暂停等待创意确认：
   - 创意概念与风格锁定；
   - 场景总览：编号、标题、叙事功能、主体/空间构图、时长、建议视频模式；
   - 首尾帧镜头的转场目标（起始状态 → 结束状态）；
   - 每个场景待生成的图片数量。

优先单图首帧模式用于缓慢行走、凝望、云雾、月光、衣袂等氛围动态。首尾帧模式仅用于可清晰定义的状态转变，如人物从廊道远端走近天门、云雾揭开月宫、门洞中的月亮升起。禁止用突然变形、随机切镜、剧烈抖动或无因果的大幅运动解决转场。

## 阶段 2：文生图提示词与确认生图

为每张所需图（单图为首帧；首尾帧为首帧和尾帧）输出一条完整、独立的中文提示词。严格参考 `references/eastern-mythic-prompt-library.md` 的 10 组原始提示词的单段格式、句法密度与构图语言；以具体画面描述代替标签堆砌。

每条提示词按以下次序，不能只堆风格关键词：

```
场景 X｜[首帧/尾帧]｜[MJ / GPT2image]
文生图提示词：[一段完整的中文画面描述；主体 → 空间与尺度 → 构图 → 光影与色彩 → 镜头与写实质感 → MJ 参数]
[尾帧仅列出] 参考图：该场景已确认首帧
反向约束：…
```

- 首帧一律使用 **MJ**。提示词为自然语言单段描述，末尾必须逐字附加统一参数：`--ar 16:9 --raw --s 90 --c 3`。除非用户明确修改，不能省略、替换或重复这些参数。
- 明确场景用途、唯一主体、环境、空间层次和关键道具；优先从参考库十个母题中选取或组合与用户主题最匹配的构图关系，但不照搬完整示例。
- 以“大陆/城市/天体/天河尺度 + 极小人物或少量亭台”建立超现实感；用超广角史诗远景、强透视、俯瞰、框景、双弧、镜像或留白中的一至两种清晰结构，避免互相冲突。
- 明确光向、时间、镜头与写实质感；按意图选择低位日光、月光、高位俯瞰或高通透纯白天界，不将所有场景强行写成同一光色。
- 尾帧一律使用 **GPT2image**，以同场景已确认首帧作为唯一风格和构图连续性参考；提示词准确表达阶段 1 的结束状态，保留同一主体、空间、光影与镜头体系。GPT2image 尾帧不附 MJ 参数。

汇总“图片、专属场景/用途、提示词、模型、画幅、数量、预计消耗”，然后明确等待生图确认。获确认后才调用 MJ；先生成和检查首帧，再将该首帧传给 GPT2image 生成同场景尾帧。检查主体一致性、尺度、构图、镜头、风格、文字伪影及反向约束；不合格时先解释问题与重做方案，再请求新确认。

## 阶段 3：图生视频提示词与确认

只在图片被确认后，为每场写一条 Seedance 2.0 图生视频提示词。使用该场自己的首帧，或自己的首尾帧；若用户提供了适合作尾帧的图，也可用首尾帧模式。提示词参考 `references/eastern-mythic-prompt-library.md` 的视频模板，强调中式审美、稳定镜头和自然连续的运动。

格式严格如下：

```
场景 X｜标题｜固定时长 X 秒｜[首帧参考/首尾帧参考]
参考图：[首帧；尾帧（如有）；用户角色参考图（如有）]
图生视频提示词：[运镜 → 主体/过渡动作 → 环境动态 → 风格和稳定约束 → 画质与画幅]
```

- 先写一个可执行的镜头动作：匀速慢推、横移、轻微上升、慢拉远或锁定构图；单个片段只使用连续、平滑的运镜。
- 再写主体动作和环境动态：缓慢行走、回眸、衣袂/飘带、云雾、松针、香烟、水面、月光与体积光；动作与时长匹配。
- 首尾帧只描述从起始到结束的渐进变化，不能让角色、建筑、月亮或构图无故重塑。
- 强制“无抖动、无卡顿、无突变、无切镜、无随机新增人物/建筑/文字”，锁住人物身份、服装、镜头构图与东方电影质感。

完成后展示每场的图片、模式、时长、Seedance 2.0（720p）、完整提示词和预计消耗，明确等待视频确认；此阶段不得生成视频。

## 阶段 4：按确认生成视频

每条生成前，再展示这条的参考图、模式、时长、Seedance 2.0（720p）、提示词与预计消耗；得到明确确认后，才调用 Seedance 2.0。逐条检查：人物和建筑稳定、镜头平滑、云雾/衣袂自然、首尾状态符合预设、时长正确、没有新增文字或现代元素。失败重试先给出改写提示词并重新确认。

## 阶段 5：配乐与剪辑合成

视频确认完成后，给出无旁白的音乐和成片方案：

1. 按总时长生成一条配乐提示词：以古琴、箫、埙、低频鼓、钟/磬、空灵人声纹理或弦乐为可选色彩；描述 4–6 秒场景节拍、进入点、情绪曲线和收束。不得加入旁白、念白或歌词，除非用户另行要求。
2. 输出剪辑时间轴：场景起止、视频文件、硬切/叠化/云雾遮罩/匹配剪辑的转场、配乐的进入/渐变/收束。
3. 展示配乐模型（若可用）、成片规格、时长和预计消耗，等待对配乐生成及最终合成分别确认。
4. 获确认后生成配乐、对齐已确认视频、执行剪辑合成，交付一段统一的东方神话幻想、中式美学、超现实感视频。

## 交付前自检

- 已以用户输入或参考图为基础，而不是照搬参考库的特定场景。
- 首帧提示词采用参考库的单段格式，且均含精确的 MJ 统一参数；尾帧使用 GPT2image 并参考同场景确认首帧。
- 默认仅一个场景；多场景时每场 4–6 秒、叙事与视觉连续。
- 首帧生图为 MJ，尾帧生图为 GPT2image；视频为 Seedance 2.0；仅用首帧或首尾帧参考。
- 图片、视频、配乐、重试和合成均在实际调用前获得确认。
- 无旁白，配乐与剪辑覆盖整段视频，最终成片维持东方神话、克制留白和写实超现实质感。
