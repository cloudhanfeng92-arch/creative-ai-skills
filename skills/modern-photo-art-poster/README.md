# 现代艺术摄影对照海报

将真实照片转成摄影与现代主义印刷艺术的对照海报，两区保持相同取景，依据照片方向安排版式并配克制英文排版。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装对应 Skill 的完整目录：

```text
请从 https://github.com/cloudhanfeng92-arch/creative-ai-skills
安装 skills/modern-photo-art-poster 目录中的 Skill。
```

可在 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/modern-photo-art-poster) 安装 `skills/modern-photo-art-poster`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $modern-photo-art-poster，把这张街景照片制作成现代艺术摄影对照海报，两区保持相同取景范围，使用简洁英文排版。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- 原始摄影图片
- 内置 image_gen 图像编辑能力
