# 完整输入示例

每次选择一个主题制作一条视频。以下示例默认连续执行；网页预览按需，所有浏览器动作仅用 Codex 内置浏览器官方工具的实际能力，不用外部 Chrome/Chromium 或旧浏览器采帧脚本。内置无法导出时仅复用已有无浏览器入口；缺少入口则保留源码和已有产物并说明视频未完成，不新增审批。

## 1．科学机制与主题动态文字

```text
$topic-motion-video

制作一条“雨后为什么会出现彩虹？”的原创科普动画，面向普通成年人，约90秒，16:9、1080p、30fps。
视觉由你按主题选择，简述方向后直接继续。用太阳光进入雨滴、内部反射和不同颜色出射方向的变化解释彩虹，并交代观察位置；核对关键事实，保持解释准确。
解说文案默认呈现为字幕、关键词和动态文字，不生成TTS、不朗读。文字样式跟随画面和主题，不加入无关英文标签或演示编号。
按内置浏览器实际导出能力或现有无浏览器入口制作视频，复用code-motion-video的非浏览器校验与HTML打包工具，将关键构图、核心解释动作与交界的连续变化纳入一次轻量检查，可复用正式导出结果后台观察；出现明确问题再局部修复，不为这条视频重装或重复测试可用环境。
连续完成并交付实际MP4、可双击离线播放的单文件HTML和可编辑源码，不自动发布。
```

## 2．指定风格的文明史解释

```text
$topic-motion-video

制作一条“人类为什么需要统一长度单位？”的原创知识动画，中文，普通成年观众，约90秒，16:9、1080p、30fps。
采用明亮纸质插画与尺规几何风格。通过不同人的身体尺度、交易中的测量误差和共同标准的建立展开，核对关键事实，保留原意并区分确定事实与解释性概括。
将解说写成随物体和刻度变化出现的主题文字，字体、颜色、位置与纸质画面统一，不添加无关标签。默认不配音、不生成TTS；可按节奏使用适当配乐。
无需我逐次确认风格、脚本或样片，直接连续制作；结合代表构图和核心动作的短时连续输出做一次轻量检查。沿用现有内容与时间轴，浏览器仅用内置官方工具实际能力；不用Remotion等间接启动外部浏览器。
交付MP4、可双击离线播放的单文件HTML、源码和简短来源说明。
```

## 3．已有歌曲与歌词动效

```text
$topic-motion-video

围绕“水的循环”制作一条原创知识动画，约90秒，16:9、1080p、30fps，配乐使用我提供的【本地歌曲路径】，需要展示的歌词为【我提供的歌词】。
按水滴、蒸发、凝结与降水的形态变化安排画面，核对科学解释。歌词按真实乐句、呼吸与语义重点编排，让词组与水滴的变化呼应；说明文字在机制清楚后稳定呈现，颜色与位置随构图变化，不把每个音节做成同样的弹跳，不加入无关标签。
保留歌曲已有歌声，不额外生成TTS或朗读；知识文案以动态文字呈现，并给观众足够阅读时间。
复用可用工程与非浏览器HTML打包工具，视频导出遵循内置浏览器限制，连续完成并做轻量检查，交付MP4、可双击离线播放的单文件HTML和源码，不自动上传发布。
```

## 可选：明确要求朗读时

需要口播时，在任一示例末尾加：

```text
本片明确需要配音：请朗读已定稿的解说文案，使用【已有授权音色或指定音色】。按实际音频时长同步字幕与动画，并在MP4和离线HTML中接入同一音轨。
```

未加这类明确要求时，旁白或解说文案仍只作为屏幕文字。
