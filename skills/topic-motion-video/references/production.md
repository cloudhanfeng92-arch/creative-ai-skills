# 制作与交付：按需读取

本 Skill 负责主题、事实与解释性叙事，代码制作复用已安装的 `code-motion-video`。从当前技能目录或清单解析其实际路径，只读当前操作需要的说明，不重复做创意提案或加载全部资料。

## 工程与时间轴

一个项目目录对应当前一条视频，复用已有工程。新项目可复制 `code-motion-video/assets/project-template/`，按本主题改写内容与美术，并将配置时长更新为用户要求或本 Skill 的约 90 秒，不沿用模板的 15 秒。

必要文件是动画源码、`video.config.json`、实际素材与输出。关键事实可简记为 `docs/sources.md`：具体论断、可追溯来源、必要日期与支持范围即可。已有 `video.project.json` 可继续记录真实阶段、文件和待办；不强制建立候选方案、审批版本、长质检报告等整套文档。

在现有分镜或项目记录中保留本片的视觉论点，以及核心动作的关键构图、路径与速度变化、次级响应、阅读落点和跨镜承接。实现时先保证能解释主题的变化，再补装饰；这些记录服务代码编排，不构成新的提交物或确认节点。

默认把文案拆成 `text/start/end` 的文字 cue，按可读停留、镜头与音乐安排；词级动画可增加词组的起止和强调参数。旁白文案不等于配音请求。歌词有现成音轨时优先使用提供的时间标记，缺少时按实际音轨安排，不虚构精确对齐。

字幕、图形和转场使用同一时间轴。Canvas / SVG / DOM 文字可叠加到 WebGL 主视觉，也可作为文字纹理参与场景，一并渲染进入 MP4；单独的 SRT 或 LRC 仅按需附送，不代替要求的视觉效果。需要详细字效指引时读取 `code-motion-video/references/text-motion.md`。

## 实现与素材

- 按主题与画面选择 JavaScript + Canvas 2D / WebGL、SVG / DOM 或 Three.js，选型依据见本 Skill 入口。HTML 保留 `window.seek(t)` 与 `window.__VIDEO_READY__`，资源就绪后按时间绘制，与可用视频入口共用内容和时间轴；这些页面接口不代表内置工具支持任意 JavaScript 或直接 seek。
- 随机效果固定 seed，模拟可预计算；不要让累计状态或独立计时器影响导出。可播放 HTML 用播放时钟调用同一 `seek(t)`，渲染器逐帧定位；默认无需重复定位审计。
- 核心对象、标注和相机按同一动作时间轴协同，主次响应按因果错时；不要用相同的缓动统一处理真实物理运动与抽象图形。跨镜连续对象保留身份、坐标关系与速度趋势，重叠期间只绘制一次；跨尺度展示保留可理解的观察锚点或示意说明。实现负担过高时先减少装饰，保留解释机制。
- 网页预览按需，不是 MP4 必需步骤。需要浏览器时，只用 Codex 内置浏览器官方工具，并先确认其实际访问、操作与导出能力；禁止外部 Google Chrome、Chrome for Testing、独立 Chromium、个人 profile/CDP、修改浏览器路径、系统 `open`、桌面录屏，以及 Playwright/Puppeteer/Remotion 间接启动。无头或后台不构成例外。
- 内置工具不能完成视频导出时，才复用项目已有、确认不启动浏览器的原生后台入口，如 Node 原生 Canvas/Skia/SVG 输出帧，再由 FFmpeg 编码与混音。原生库不视为预装，不保证 DOM/WebGL 无需改写即可兼容；复杂效果只在实际允许入口支持时实现。没有兼容入口就保留源码与已有产物，说明 MP4 未完成。FFmpeg 不会直接渲染 HTML。
- 已有工程保留内容、时间轴与可复用绘制逻辑，调用导出入口前核对底层是否启动浏览器，不因工程已安装就默认可用。扩展库、纹理与模型按 HTML 实际加载方式打包，不依赖 CDN；必要时读 `code-motion-video/references/rendering-standard.md` 与 `html-delivery.md`。默认单任务、保守编码线程，内置浏览器也使用本机资源，不保证原生路径更省 CPU/GPU。
- 优先程序图形、用户已有素材与已可用资源。图表数据、单位、公式和中文排版准确；实际图片保留来源，艺术表现不冒充历史照片或实测结果。只为本任务必要的缺口寻找素材。
- 只有依赖未知或执行失败时才运行 `scripts/doctor.py`、检查对应依赖或做短测试；环境已经可用就直接复用，不反复运行全套检测。

## 声音：JavaScript 原创合成，朗读可选

默认用 JavaScript 合成原创 BGM 与适配音效。先结合题材、叙事情绪、时代文化和视觉语言选择音色、音域、和声、节奏与空间感：同一科学主题可以表现好奇、理性推导或尺度震撼，不自动等于电子脉冲；文明史也不统一套“古风”。声音应支持本段的解释意图。用户要求静音或指定现成歌曲时遵循其选择，保留要求使用的歌声，不另叠冲突配乐。

让少量可辨认的音乐动机随知识推进发展，通过配器、密度、音域和停顿对应画面的展开、比较与结论，不机械循环一个短乐句。逐段决定听觉主次：机制变化可由关键音效突出，情绪段由音乐推进，公式与长句阅读减少瞬态和新旋律，必要时留白；有朗读或歌声时让其清晰居前。音乐与音效不同时争抢重音，也不要求每次切镜都卡拍。

音效从画面事件出发，按物件的材质、重量、速度、距离和空间选择声音；抽象图形则建立与意义对应的声音规则。同类事件保持一致，可随强弱或远近变化。按实际动作安排起音、重音与余音，对应动作开始、关键接触或结果、收势；有叙事目的时可预示或延后，不让整段音效仅凭文件起点机械对齐。无表达作用的运动可以无声，不给每个字加提示音，也不每镜套 whoosh。

知识解释中的提示音不能替代可见因果或制造不存在的机制。区分设计音、数据声化和真实录音：数据声化需说明数值到音高、节奏等的映射并保持一致，不为音乐好听改变数据关系；合成碰撞声、天体运动提示或历史氛围均不能冒充实测声音、历史原音或事实证据。需要防止误解时简洁说明其示意性质。

把配乐段落与音效 cue 写入现有分镜的声音栏，与画面共用时间轴；记录对应事件、起止或重音时刻、声音意图及听觉主次即可，不另建审批表。实现前按需核对所用合成器或混音脚本实际读取的字段，将设计记录映射到支持的参数；需要的新控制要实现后再使用，不能只写配置便假定生效。

音符与音效事件使用同一时间基准，随机噪声固定种子。复用环境，优先通过 Node.js 直接计算 PCM 并编码 WAV；`OfflineAudioContext` 仅在内置浏览器官方工具实际支持运行并取回音频，或现有无浏览器实现兼容时使用，不假定任意 JavaScript/下载能力，不为音频启动外部浏览器、不实时录音，也不默认调用外部音乐服务。音色包络、混音余量与尾音按片长处理，合成源码与 cue 表随项目保留。具体实现方法读 `code-motion-video/references/narration-and-audio.md`。

仅有“旁白”“字幕”“歌词”等文案，不启动 TTS；默认无口播不等于无配乐。`seek(t)` 不逐帧重新触发声音，HTML 播放时同步同一最终音轨，渲染模式关闭实时发声。

用户明确要求配音、口播或朗读时，才使用可用且获准的工具生成音频。按要求选择声音；无指定音色时可用沉稳、略慢的中文男声。逐句生成则测量实际长度、加自然停顿并回填时间；整段音频按可用时间标记对齐。文本只改一句时复用其余音频。

有朗读时保证数字、专名和公式读法正确；旁白响度可参考约 -16 LUFS，配乐退到不遮挡人声的位置。无口播或音乐主导作品按曲风处理，不能把语音目标和衰减幅度强加给所有音乐。详细操作按需读 `code-motion-video/references/narration-and-audio.md`。

将最终混音保存为真实本地音轨，如 `audio/mix.wav`，通过 `video.config.json` 的 `audio` 接入；用户要求静音时才设为 `null`。MP4 用 FFmpeg 实际混流，HTML 优先内嵌或打包相同混音并通过用户点击开启声音。HTML 能合成声音不代表 MP4 自带声音；合成失败或指定音源不可用时如实报告，不能声称缺失音轨已完成。

声音检查并入正式输出的一次轻量检查：有实际音画观察能力时，选含关键事件或段落转折的短段，核对曲风是否贴合主题与画面、音效重音是否对应事件、阅读是否被抢占、主次与尾音是否自然。发现具体问题只修受影响部分，不新增样片、审批或量化评分。无法实际试听时注明未试听，音轨存在、时长和峰值等技术结果不能证明听感或音画匹配通过。

## 预览、渲染、HTML 与封面

以下 `/path/to/code-motion-video` 要替换为当前安装的真实路径；复用其现有依赖与脚本，不复制出另一套待维护工具。

```bash
node /path/to/code-motion-video/scripts/validate-video.mjs --project /absolute/project --video /absolute/project/output/final.mp4
node /path/to/code-motion-video/scripts/export-html.mjs --project /absolute/project --out /absolute/project/output/作品名.html
```

旧 `render-preview.mjs` / `render-video.mjs` 已在 `openRenderer` 拒绝外部浏览器调用，不执行、不改路径或关闭保护。上列命令仅校验已有 MP4 与打包 HTML，不生成视频。实际可用的内置导出或已有无浏览器入口完成一次 MP4 输出后，在一次轻量检查内结合少量代表帧与短时连续输出，观察核心解释动作及关键交界；可由 FFmpeg 从正式导出抽取，不强制打开网页。重点查看视线接力、变化原因、阅读落点、物性与空间连续性，静帧和元数据不能替代动作观察。不另设默认短样片、低清全片、逐镜检查或多轮导出。

代表帧、连续输出和封面用允许入口的输出或 FFmpeg 抽取检查，不接管桌面、不自动打开前台播放器、不播放系统声音。网页预览和 HTML 控件验证按需，仅用内置浏览器官方工具实际提供的能力，不假定本地访问、任意 seek、批量采帧、下载或离线验收。缺少能力或未执行时明确未验证；检查静音不删除交付音轨，音画关系使用可用媒体读取能力观察。

HTML 默认是可双击离线播放的作品，包含真实代码动画、动态文字和所需声音，可播放/暂停、重播、拖动进度，并通过点击启用声音。优先内联 CSS、脚本、配置和必要素材；不是嵌入 MP4 的播放器，也不要求启动服务；保留 HTML 源码，不自动在系统浏览器打开。打包完成不代表播放或断网行为已验证。

基础模板用 `export-html.mjs` 打包；它只支持约定的模板结构和配置音轨，不是通用网站打包器。扩展模块或素材按现有项目方式封装，具体读 `code-motion-video/references/html-delivery.md`。大素材不宜内联时提供 HTML 与 assets 的完整压缩包并说明解压方式。两种成品内容和总时长一致，命令行临时覆盖规格时同步配置。

默认另交付一张代码绘制的 `output/cover.png`，与视频同画幅、同分辨率，用户指定平台尺寸时按其要求调整。复用本片字体、配色、材质与主视觉，针对静态封面重新安排简短主题标题、视觉重心和留白，让缩略图也清楚有吸引力；不直接截取过渡帧，不添加制作标签或无关文字。

用本片代码与素材绘制，字体和资源就绪后使用内置浏览器官方工具实际支持的单帧导出；能力不足才复用现有、确认不启动浏览器的原生 PNG 输出入口。没有兼容入口就保留封面源码并说明 PNG 未完成；不调用外部浏览器采集。仅查看一次封面，不新增候选审批、不重新编码视频，也不把封面默认插入时间轴。详细方法读 `code-motion-video/references/cover-delivery.md`。

如果当前环境找不到 `code-motion-video`，复用项目已有且符合浏览器限制的等效入口；找不到内置可用导出或现有无浏览器兼容入口时，继续保留源码和可完成的 HTML/音轨，明确 MP4 等实际缺口，不能捏造入口已存在或自动安装全套框架。

## 轻量检查与恢复

媒体检查任选 `code-motion-video` 校验器或本 Skill 的辅助脚本，不重复运行。已有其他工程可用：

```bash
python3 /path/to/topic-motion-video/scripts/probe_video.py /absolute/project/output/final.mp4 --width 1920 --height 1080 --fps 30 --video-codec h264 --pixel-format yuv420p
```

默认原创配乐成片应有音轨，使用本辅助脚本时加 `--require-audio`；用户要求静音时不加，已有渲染工具检查了配置音轨则无需再跑一次。需要核对片长时加 `--duration`。默认不加 `--decode`；全片解码、逐镜首中尾、边界穷举和详细听审只在具体故障或用户要求严格检查时使用。核心动作及关键交界的短时连续观察属于前述同一次轻量检查，无须等到怀疑故障后才进行；不因此追加完整审核流程。

发现缺字、遮挡、空白、注意力混乱、过程失读、空间突跳或事实错误时修复相关位置，再检查受影响部分。技术测试不能自动证明知识、美术与运动观感正确，没有实际观察时明确未检查。无口播是正常完成形态；尚未完成的默认交付或用户要求应说明具体缺口。如实说明做过的检查，给出 MP4、HTML、封面 PNG 与源码的真实路径及简短来源。

局部修改先保留原版本，只更新受影响的镜头、文字、音频和时间段；不重做整条选题与资料核查。恢复时读取当前项目状态和必要文件，从未完成部分继续，不重复请求已经给出的授权或安排创意审批。
