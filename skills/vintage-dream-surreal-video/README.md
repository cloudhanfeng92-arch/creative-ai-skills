# 复古梦境超现实视频

将日常物件与复古空间转为连贯的超现实短片，配合缓慢运动与音乐。

## 使用方式

先按仓库[安装指南](../../docs/INSTALL.md)安装本目录，再在支持 Skill 的 AI 助手中输入：

```text
使用 $vintage-dream-surreal-video，制作一个老式房间漂浮在海面上的复古梦境短片。
```

## 输入与结果

示例中的主题、时长、画幅和参考素材可替换为自己的需求。涉及参考图或视频时，请同时提供可访问的素材。具体必填项、默认值与交付格式见 [SKILL.md](SKILL.md)。

## 工具与环境

此 Skill 的流程涉及：悠船 / Midjourney。工具、账号、模型权限和额度需要单独准备；安装 Skill 本身不会安装这些服务。部分流程需要先确认提示词与生成费用，请遵循原 Skill 的步骤。
