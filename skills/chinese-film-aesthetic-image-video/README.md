# 中式胶片美学·生图与视频

将人物、古装与中式场景需求转为35mm胶片电影画面，先提供候选图，再按选图制作克制的微动效视频。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/chinese-film-aesthetic-image-video 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/chinese-film-aesthetic-image-video) 安装 `skills/chinese-film-aesthetic-image-video`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $chinese-film-aesthetic-image-video，设计一位雨夜竹林中的白衣剑客，先给我中式胶片电影风生图提示词，确认后再生成。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。
