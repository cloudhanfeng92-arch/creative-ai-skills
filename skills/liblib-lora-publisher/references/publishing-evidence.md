# 发布资料与证据映射

## 已知入口与证据边界

2026-10-16 编写此技能时，用户提供的截图显示：官网侧栏“发布”下有“模型模板”；创建类型包括“模型”“图片模板”“视频模板”。“模型”说明为基于开源模型训练的图片/视频微调模型。官网为 https://www.liblib.art/ 。

这些证据仅确认入口和类型，未展示 LoRA 具体上传表单。不能据此断言当前文件容量、格式列表、底模列表、必填字段、许可默认值、收费规则或审核时长。每次执行以当前账号可见页面为准；将实际观察的字段、限制、选项和日期记入 `ui_observations`。

## 发布资料清单

下列是为了准确发布与复现而收集的资料，不是已证实的平台必填字段。只有在实际表单中观察到必填标记或校验错误，才能记录为平台必填。

| 资料 | 核对与处理 |
| --- | --- |
| 模型和版本身份 | 新建还是更新；现有链接/ID、目标版本；更新沿用原资产，不重复创建 |
| 模型来源 | 本地文件绝对路径或平台已训练资产；记录用户提供、训练产物或其他真实来源 |
| 文件完整性 | 文件字节数、SHA-256、平台上传/处理反馈；平台资产无本地文件则不填写虚构哈希 |
| 架构和底模 | 以模型说明、可信元数据、训练记录或用户确认核对，实际选项与兼容性仍需读取 UI |
| 使用参数 | 触发词（如有）、建议 LoRA 权重、实际示例的尺寸、采样器、步数、CFG、seed 等已知参数；不适用的参数省略 |
| 名称和说明 | 作用、适用场景、使用方法、限制、版本变化；不编造数据集和指标 |
| 许可与可见性 | 用户已授权范围及模型来源限制；准确映射实际字段，不默认开启独家、商业授权、付费或允许下载 |
| 封面和示例 | 该模型该版本的真实输出、原文件、后期处理记录、任务或来源关联、实际生成参数 |
| 测试和预算 | 平台、币种/单位、允许次数和金额/额度上限、预估与实际开销分开、失败次数也计入 |

本地文件可用 `shasum -a 256 <正确引用的文件路径>` 计算哈希；读取模型元数据时只用安全的数据解析方法，不为“验证模型”执行来源不明的 Python 或 pickle 内容。

## 界面映射与读回

每个实际字段记录：`observed_label`、`required_observed`、选择值或上传文件、限制文本、所在页面与读取时间。未出现的字段不通过猜测 selector、隐藏 API 或修改页面状态强行写入。控件变更时根据当前页面定位，不依赖固定坐标。

上传完成后分别核对：文件/资产是否处理成功、保存的版本是否正确、预览是否为本次封面和示例。文本编辑器或缩略图仍显示旧内容时，先保存并刷新同一详情页，再判断持久化是否成功。

## 最小效果验证

- 测试先核对目标 LoRA 与底模确实加载；输出应能对应本次任务和参数。
- 只检验当前发布说明承诺的核心效果；不要求与用途无关的随机主题、多比例或全部权重组合。
- 记录历史示例为 `user_supplied_historical` 或其他真实来源；不得将其时间和任务号伪装成本次测试。
- 若需要生成新的效果图，使用该 LoRA 的兼容执行入口；通用生图工具仅能辅助排版等独立素材任务，不能替代效果测试。
- 失败后检查原因和剩余预算；需要超过预算、换底模或改变发布承诺时先完成可做部分，说明具体依赖。

## 状态证据规则

| 记录项 | 可以支持的结论 | 不能支持的结论 |
| --- | --- | --- |
| `prepared` | 本地资料已准备 | 已上传、已发布 |
| `uploaded` | 文件/资产上传或关联已确认 | 模型可运行、审核通过 |
| `test.passed` | 记录的具体版本和配置产生了已查看的合格结果 | 所有配置均可靠、模型已公开 |
| `submitted` | 已观察提交回执 | 审核通过、公开可见 |
| `pending_review` | 页面明确审核中 | 已上线 |
| `published` | 平台明确上线且当前详情页核对一致 | 匿名可见或可运行，除非另外核验 |
| `rejected` | 有明确审核退回状态/原因 | 上传失败 |
| `unknown` | 证据不足或提交响应不明 | 可以立即重复提交 |

分别填写 `detail_verified`、`list_verified`、`public_visibility` 与 `online_run_verified`。公开可见性的核验范围使用 `anonymous`、`signed_in_only` 或 `unverified`，描述实际观察，不把登录作者视角当成匿名访问证明。

提交异常时先读取同一模型及版本的详情与列表，匹配名称、ID 和文件/版本信息；确认未完成才再次提交。拿不到真实链接时保留 `null`，交付已知状态与阻塞原因。
