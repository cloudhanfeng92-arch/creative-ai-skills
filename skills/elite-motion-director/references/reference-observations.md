# 本次参考学习：复用方法，不复刻作品

范围：对本次20条新上传视频做分时抽帧；对若干运动段落密集抽帧。以下是可见画面方法的归纳，不据此断言原片模型、提示词、源工程、素材版权或所有画面都是代码生成。静帧不能证明精确速度曲线；没有把未经试听的声音写成已分析结果。

## 抽取出的设计方法

**户型展示片约11.2—15.5秒**：平面线框转到斜向空间，多个相关图层展开，镜头再集中于单一结构。值得学习的是同一几何基准、视角变化和关注范围的缩放，而非照搬界面、标题或具体房间。

**方形代码演示片**：可见大字与小注释的显著反差、黑白场面的节奏转换、几何物体和密集颗粒不同尺度的连续展示。抽帧显示点阵、落下颗粒和环形布置；可借鉴“单个元素→群体结构→空间秩序”的组织，不复制品牌词或作者标签。

**文字与角色节奏片**：文字有时是舞台中心，有时与简化角色、线条、对话形状共同组织关系；画面会改变重心、色块面积和尺度。学习文字承担动作和语义，不把其白底黑字、具体角色和字效做成通用模板。

**粒子诗意片约20.8—24.85秒**：密集对象的近景逐渐转为更远的聚合形态，可见空间占比与形体轮廓的变化；关键不只是粒子多，而是观看尺度和整体轮廓被有计划地揭示。

**双形体传播段约11—14.6秒**：两组形体从较疏关系逐步扩展、交叠，建立方向和对照。抽象形变可以有自定义规则，不应把它误称为严格流体或碰撞模拟。

**随机游走、混沌、策略模拟类参考**：数据、轨迹、局部对象和群体分布可以交替承担主角。学习“运动累积出结果”，而非先画结果再淡入。具体数学结论和模拟参数须重新核查。

**网页展示型参考**：大面积字、立体主物体、滚动/分栏状态、近远切换能形成连续的视觉重心。网页交互速度与影片时间轴不同，转为MP4时需要固定时间演出，不能依赖人工滚动。

**歌声/歌词参考**：屏幕文字能够围绕语义和节拍组织；本Skill不继承其署名、品牌、歌词或音乐。默认无朗读不排斥使用用户明确提供并要求使用的已有歌声。

## 转为Skill的执行原则

1. 物件和文字都可作主角，但每一时刻有明确焦点；构图由内容变化推动。
2. 空间运动以共同几何和相机为基础；二维图形可有强烈动态，不必所有场面3D化。
3. 密集→稀疏、大→小、近→远、快→停的反差比“全程都动”更重要。
4. 场面间继承可追踪对象或动作，避免每页重置。
5. 借鉴动感与美感，不复制某一作品的字效、标识和表达。

参考原视频不打包进Skill；这些记录让后续主题不必重新读取所有参考。新上传的地球—卫星问题被归纳为独立空间/物理契约，不能仅凭截图估计实际轨道高度和尺寸。
