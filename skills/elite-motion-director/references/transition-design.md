# 连续转场与高表现力镜头

## 转场不是两张成品之间的特效

先设计“上一镜怎样变成下一镜”，再分别实现镜头。默认把转場当作影片里有目的的一段动作：观众能追踪同一对象、同一轮廓、同一运动趋势或同一个知识关系，注意力被自然带到下一处。全片共享一种视觉逻辑，但具体表现必须随主题原创。

内部动作句只需写在已有 `direction.md`，不建立新审核表：
> 当前焦点沿什么路径离开？哪一个锚点保持可追踪？下一场景何时开始显露？位置、速度、尺度或轮廓如何对齐？读到哪一句时镜头落稳？

## 可选择的高表现力方法，不是固定模板菜单

| 方法 | 具体实施 | 避免的粗糙做法 |
| --- | --- | --- |
| 共享对象接力 | 保持同一对象身份，沿曲线路径穿越构图、触发下一组图形生长；共享对象放在跨场景层，只画一次 | 两个副本交叉淡入，重叠穿帮，尺寸和位置突然跳动 |
| 形状与负形通道 | 由主题对象的孔、字形负空间或几何边界接近镜头；下一场景从此区域揭示 | 每条视频都用同一个圆形擦屏或独立转场贴纸 |
| 遮挡切换 | 前景真实物件或设计图形自然覆盖关键区域，在遮挡充分时交接场景，随后延续方向退出 | 先清空舞台，再用黑帧掩盖加载；遮挡没覆盖完全就更换背景 |
| 路径/信息接力 | 上一段轨迹延伸成为下一段图表、边界或字符笔画，视觉角色与因果一起延续 | 无关联地把任何字硬变成任何图形，或改变真实数据 |
| 连续尺度揭示 | 推近局部或拉远展开结构，维持可追踪基准与合理视差；必要的示意尺度切换应能看懂 | 单独放大真实模型，突然改变焦距与物体大小，整页平移冒充空间 |
| 匹配动作切换 | 在同向运动、近似屏幕位置/大小或重音瞬间接上下一动作；不要求形态完全一致 | 两镜停住后再同时淡入淡出、每镜起步和刹车一样 |
| 受控聚散与重构 | 粒子按确定路径在有意义的边界聚集，形成新的数据结构/图形；字在可读状态与图形态间转换 | 随机粒子满屏飞、所有字幕粉碎、无阅读停顿 |

按主题挑少数方法发展出变化，不要求每条全部出现。更炫酷的目标是空间、结构、尺度与时间的精细变化，不是更多泛光、旋转、闪白和震动。

## 让设计落到代码上

整个影片只有一个绝对时间源。跨镜头运动不能在进入下一镜时重置为0；出入镜同时使用同一状态函数或连接端点，必要时预计算到同一轨迹。

每个连续转场有明确的 `start` 和 `duration`；在该时间窗内维持前后场景重叠可绘制，使用遮罩/遮挡/共享层完成交接。过渡前后允许保持静止；窗口长短随动作和阅读需要，不强制每镜0.5秒。典型短动作可先尝试约0.35—1秒，复杂空间展开更长；这是创作起点，不是质量判据。

同一个对象跨镜头承接时，保持屏幕锚点、方向、尺度趋势、轮廓或材质角色。连续同轨迹尽量做到位置连续与速度连续；不能拿“曲线缓动”代替端点匹配。相机position/target、视场角与遮罩也受此约束。上一镜向右快速运动，下一镜不能突然静止、反向或瞬移，除非画面给出了碰撞、停顿、遮挡或叙事理由。

DOM节点预建并复用；Three.js场景、材质和纹理预加载；Canvas用当前t计算整帧。在遮挡真正完成前不要卸载上一场景。共享对象不能被两个scene各画一次。资源等待只发生在 `ready`，不得转场过程中突然请求网络。

渲染顺序的一个可行方式是：出场景底层 → 被遮罩的入场景 → 跨场景共享对象 → 必要的稳定文字层。不是每条都用这个层序，真实三维深度遮挡优先于人为图层。

## 可复用数学原语

`engine/motion.mjs`提供：

- `hermiteAt()` / `vectorHermiteAt()`：连接值与速度，用于目标/相机/抽象图形的连续轨迹。入出速度以单位/秒指定，不能误当位置控制点。段外线性延续端点速度，因此不会自动刹车；需要停止时设计好端点速度。
- `handoff2D()`：位置、正值对数尺度、角度与速度一起衔接。仅适合二维图形/相机设计，不允许改变真实物体的世界尺寸。三维相机姿态应使用正确的四元数/视向处理，不把二维旋转函数当完整3D相机。
- `bridgeState()`：确定性转场窗口，指出什么时候绘制出入场景，不直接选择转场风格。
- `coveringCircleRadius()`：仅在确实选用圆形遮罩时保证覆盖舞台边角。它是可选几何辅助，不是默认转场。
- `smootherstep()` / `staggerProgress()`：可控启停和语义组错时。不要所有镜头/每个字都套同一条缓动。

在已有构建流程中按需导入，并和画面代码打为离线可用的单包；不能让最终HTML用file://外部import该模块。物理求解与图形缓动分开：卫星轨道、自由落体和刚体约束仍由符合设定的模型控制。

## 高潮、阅读与性能

设计主要视觉事件：可以是大范围的空间揭示、从稀疏到秩序的群体变化、文字与实体形成新结构。根据时长安排少数强记忆点，不每三秒强行开一场烟花。主事件之前建立预期，重音时集中注意力，随后留出短的稳定状态供理解；静止是节奏，不是退回PPT。

局部运动模糊、景深、粒子、着色器等仅在主题和性能适合时使用；只影响该影响的图层，重要文字最终要清晰。性能不足先减少无意义粒子和后期分辨率、复用几何与材质，不把连续空间和主动作删成卡片轮播。

把关键交界前一帧、交界帧、后一帧及转场中段纳入既有轻量自检，必要时短区间顺序观察。检查突跳、黑闪、双份共享物体、文字重叠、视点骤变和节拍抢占。发现问题直接修复，不新增用户样片审核。数学连续性通过不等于美感通过，不声称自测自动评出了“高级”。
