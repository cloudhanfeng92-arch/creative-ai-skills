# 内置浏览器、媒体导出与离线交付

## 浏览器边界与能力确认

网页只使用Codex内置浏览器的官方工具。禁止启动外部Google Chrome、Chrome for Testing、独立Chromium，或通过Playwright、Puppeteer、Remotion间接启动浏览器；已有外部流程、无头模式与远程运行都不能绕过这条限制。

需要网页预览或HTML交互检查时，先读取当前内置浏览器工具返回的文档，再使用实际支持的操作。不猜测CDP端口、可执行路径、调试配置或内部接口，不把内置浏览器冒充成本地Playwright。不根据“能打开网页”推断支持逐帧截图、批量采样、录制或视频导出。

内置工具的只读`evaluate`仅用于其允许的读取；不得借它调用`seek()`、`render()`、`cover()`、合成点击、修改DOM或改变播放状态。要播放、暂停、定位或重播，使用作品页面真实控件及官方交互工具；没有所需控件时先在作品源码中正常实现控件。

网页预览按需，视觉QA仍必需：可以检查正式成片、关键帧或连续片段，不必为检查重复打开网页。不使用桌面录屏、系统键鼠、外部播放器或剪辑GUI作替代。非浏览器的音频合成、编码、抽帧和打包继续使用受管理的后台命令行会话。

## HTML渲染不等于MP4编码

HTML、DOM、SVG和WebGL画面需要兼容的渲染能力。FFmpeg负责已有帧、视频和音轨的编码合成，不能直接执行HTML动画。内置浏览器的网页预览也不自动构成可用于MP4的逐帧导出接口。

按实际能力选择：

- 内置浏览器官方工具若明确提供所需采集或导出能力，按工具文档执行并核验真实文件；不编造API、批量截图支持或下载路径。
- 能力不足时，仅复用项目**已有兼容原生后台绘制入口**生成帧或媒体，再由FFmpeg编码。确认它支持本片字体、材质、时间轴与资产；不能把任意DOM/WebGL无修改交给原生Canvas，也不强制所有项目重写为原生。
- 两者都不可用时，保留并完成可完成的源码、音轨和HTML，明确MP4未完成以及缺少的具体能力；不把预览、HTML、历史视频或partial文件说成新成片。

`scripts/render.mjs`已禁用，直接以`EXTERNAL_BROWSER_DISABLED`拒绝旧的外部浏览器采帧流程。不要运行它尝试回退、安装外部浏览器或修改路径变量。后台过程保守设置并发和线程，不保证本机零负载；只管理本次进程，不使用killall结束用户应用，不默认上传素材或购买远程服务。

## 统一命名与作品时间轴

通过`motion.project.json.title`与`scripts/artifacts.mjs`解析整组名称，见 [输出命名](output-naming.md)。`bundle-manifest.json`记录标题、名称和配置摘要；修改标题、代码或混音后更新HTML包。`artifact-index.json`登记归属，保护其他项目的同名文件，需要并存时整组统一`outputRevision`。

HTML作品可继续使用纯JS画面或已打包为IIFE的现有库。复用已有构建工具，将运行所需脚本和资源打入交付包，不引入未处理的外部import或动态分块。作品入口保持：

```js
window.createScene = (stage, config, assets) => ({
  ready: Promise.resolve(),
  render(t) { /* t为绝对秒数；同一输入与时刻得到同一状态 */ },
  cover() { /* 可选：专门设计的静态封面构图 */ }
});
```

舞台尺寸等于config.width/height；播放器只缩放显示，不改世界几何。`assets`使用内嵌数据，图片设src、模型从字节解析，不依赖file://下fetch。`ready`等待字体、图像、模型、纹理和预计算；动画状态来自绝对时间，随机初始化使用固定seed。

`engine/player.js`的`__motion.ready/render/cover`和`window.seek(t)`属于作品实现契约，保留源码可编辑性；它们不是Codex内置浏览器的官方工具API，不授权通过只读执行能力触发操作。交互使用真实控件。

## 可继续运行的非浏览器命令

这些步骤使用Node.js和必要的FFmpeg/FFprobe，不安装或启动浏览器。以下按需执行，不是一个已经包含视频导出的全链路：

```sh
# 仅检查Node/操作系统/FFmpeg等环境，不探测或证明内置浏览器能力。
node /真实Skill路径/scripts/doctor.mjs /当前项目

# 为本条编写visual.js、score.json和motion.project.json；示例不是正式作品。
node /真实Skill路径/scripts/synth-audio.mjs score.json audio/mix.wav
ffmpeg -y -nostdin -threads 2 -i audio/mix.wav -threads 2 -c:a aac -b:a 192k -ar 48000 audio/mix.m4a
node /真实Skill路径/scripts/pack-html.mjs motion.project.json
node /真实Skill路径/scripts/package-source.mjs motion.project.json

# 仅当已有对应真实媒体与清单时执行；不生成视频或验证HTML播放。
node /真实Skill路径/scripts/verify.mjs motion.project.json
```

无音轨时跳过音频两步并配置`audio:null`；已有最终音轨直接复用。`doctor`仅作环境探测，缓存不能证明本次导出成功。实际媒体通过内置浏览器可用能力或已有兼容原生入口生成，在项目运行说明中记录真实命令和输出；本包没有为这两种能力伪造统一导出接口。修改后只执行受影响步骤。

## 自包含HTML与按需交互检查

`pack-html.mjs`把visual.js、可选CSS、允许分发的资产和最终混音内嵌到`视频名称.html`。HTML运行动画代码，不能用嵌入MP4冒充；播放器提供播放、暂停、拖动和重播。

保留单文件离线设计目标：无CDN、网络字体、远端图片、外部脚本import或独立JSON fetch；模型外部纹理也要内嵌，WASM、worker与分块只有处理为自包含后才能依赖。不得分发字体文件，包括base64字体；可使用系统字体fallback或本片实际使用的矢量字形路径。

需验证HTML时，在内置浏览器官方工具支持的情况下打开实际交付文件，并通过真实控件检查功能。工具若不支持本地文件、断网控制或相关交互，明确对应项目未验证；禁止用猜测的setContent/CDP接口代替，也不能把本地服务器的成功预览说成断网双击验证。不得修改管理员策略或关闭安全防护。

资产过大先优化；确实无法单文件交付则说明限制，用户明确要求单文件时不能擅自降级为目录。跨平台字体和GPU可能有细小差异，目标是内容、时序与构图一致，不保证任意平台逐像素一致。

## 封面、视觉QA与源码

封面按本片主题重组标题、主视觉与留白，尺寸默认同影片。用内置工具实际支持的能力、已有兼容原生绘制入口，或已经生成的合适媒体帧输出；`render.mjs`不再自动生成封面。不能把不存在的图片登记为完成，也不能只挑黑帧或过渡帧。

视觉QA按 [轻量质检](quality-check.md) 执行：每镜一张信息完整的关键帧总览，加最终MP4的一次原速连续观察（约1–3分钟短片），只对疑点慢看或补帧；较长片按连续区间分块覆盖。结合少数主题约束检查画面崩坏、文字、物性、数量与转场连贯，修复后回看相关片段和两侧转场。工具不支持实际连续观察时记录未检范围；间歇截图或仅让视频播放一遍不能声称全片动态通过。

`verify.mjs`复用一次解码检查已有媒体规格、bundle/config/hash和相关文件关系，视觉记录放在同一份 `verification.json` 中；不启动浏览器，不验证HTML播放、离线交互或画面观感。即使它通过，也不能声称HTML按钮、拖动、音频播放或断网双击已验证。实际试听与音轨技术检查也分别说明；只改检查记录不需要重跑整片解码。

`package-source.mjs`使用Node内置压缩能力输出`视频名称_源码.zip`，根目录为`视频名称_源码/`。包括源文件、配置、合成事件、允许分发的资产、真实运行说明和依赖锁；额外文件通过`sourcePaths`声明。它不跟随符号链接、不打包输出目录或ZIP自身，排除密钥、缓存、node_modules、浏览器二进制、字体和源参考片。独立重建需要的工具源码保留在项目中，不能只提供指向个人安装目录的路径。

交付真实存在的文件链接，分别说明MP4、HTML、封面、源码及检查状态；未完成项保留原因与现有成果，不以历史验证冒充本次完成。
