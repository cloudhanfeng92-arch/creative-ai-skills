# 直接参考生成：二十秒迈巴赫多镜头示例

本例只是一份创意与待提交计划，**没有实际绑定图片，没有生成视频**。假定用户已认可一辆由其图片定义的迈巴赫、车辆四视图、真实前后排内饰资料及相连的门廊与道路场景；这是假定条件，不表示这些资产已经存在。具体车款、年款、车漆、格栅、灯形、轮圈、左右舵和座舱配置均以用户确认的参考为准，不从“迈巴赫”一词补全。

不生成分镜图。将用户原图、车辆四视图，以及本例需要的内饰和场景多视角资料作为直接参考，规划一个包含十六个明确剪辑镜头的连续二十秒视频段 `CAR_CLIP_01`。模型、参数、资产绑定与提交检查单独记录在下方“执行记录”，不混入模型提示词。

## 简短剧本

一秒夜驶预告先给出优雅行进的结果，随后切回同夜门廊。灯形、轮圈和完整车姿交代汽车身份；漆面与车门细节自然引入真实座舱。前排与后排的短暂留白之后，轮胎开始滚动，整车驶出门廊进入相连道路。最后十秒逐步放慢切镜，以前侧、完整侧面、后侧远行和完整前侧车姿结束，回扣开场。

无必需人物、手部、对白或旁白；不虚构音乐节拍速度。声音开关与后期声音安排见执行记录。
