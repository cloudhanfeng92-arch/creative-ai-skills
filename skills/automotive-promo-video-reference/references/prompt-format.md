# 纯视频时间轴提示词格式

每段交付可单独复制的模型正文，并另存同内容的 `.txt`。执行说明放在代码块外或独立文件，禁止随正文提交。下列方括号是模板填写位置，实际交付时填实；无内饰、人物或声音内容时直接省略相应段落。

## 模型正文模板

```text
CAR_CLIP_01｜[段名]

主体参考：
U01：[主体身份的首要图片引用及其可见特征]。
CAR_EXT_4V：[同一辆车四视图的图片引用]。四个角度均为同一辆车。保持[车身轮廓、车漆分界、格栅、灯形、轮毂、窗框、车标]一致。

内饰参考：
CAR_INT_01：[内饰图片引用及固定的方向盘、屏幕、座椅、门板、饰面和灯色]。外观与内饰属于同一辆车。

场景参考或设定：
SCN_01：[地点、空间锚点、出入口、车位与路线、主光方向、摄影机观察侧]。
SCN_02：[第二地点的空间关系与光线；在哪一镜切入]。

参考图的不同角度表示同一主体或同一地点，不是多个汽车实体。画面中不显示资料卡边框、分格、标签、平面图、图片轮播或重复车辆。

起始状态：
[车辆位置、朝向、灯门状态，相机方向与景别。]

CAR_SHOT_001｜[镜名]｜0.0—[a]秒
画面：[具体可见构图、车辆及环境状态。]
运镜与动作：[相机方向、幅度、主体运动；必要时写本镜内的半秒动作窗口。]
衔接：[切出事件及下一镜的构图、动作或光线关系。]

CAR_SHOT_002｜[镜名]｜[a]—[b]秒
画面：[下一镜的具体画面。]
运镜与动作：[主体及相机动作。]
衔接：[与下一镜的具体关系。]

统一风格与物理控制：
[实拍汽车摄影方向、光比、反射、色调、景深。]车漆分界、轮毂、灯组和内饰布局保持一致；轮胎正确接地，滚动方向与行进一致，玻璃和金属反射符合环境。按时间轴明确切镜，不随机变换车型、增加车辆、穿透车体或出现图卡版式。不添加字幕、价格、水印或参考板文字。

声音内容：
[需要呈现的台词、环境声或无对白/无旁白要求。]

结束状态：
[末镜车辆位置、方向、速度、灯门状态与构图落点。]
```

实际段落必须列出全部镜头，不能以模板的两镜示意代替完整交付。时间戳使用本段局部时间，连续覆盖该段；这些时间戳属于视频动作编排，应保留。不要在正文解释半秒网格、全片时间换算、模型执行误差或验收办法。

## 独立执行记录

以下内容存入 `execution-settings.md`、资产表或工具参数，不能进入模型正文：

- 模型名与模式、任务数、总生成时长、画幅、分辨率、帧率、声音开关。
- “拟用”“尚未提交”、生成或验收状态、待绑定项、费用与重试范围。
- 实际本地文件链接、资源上传与节点绑定状态、工具参数核验。
- 全片与段内时间换算、精度解释、实际切点检查、后期剪辑与配乐安排。
- 来源证据等级、尚未确认的实车配置、参考图缺陷和待修正事项。

例如，正文可写“无对白、无旁白”“轮胎驶过湿润路面时发出轻微水声”，不能写“生成声音 off”“后期统一配音”或“正式执行前核对模型参数”。正文可写“同一辆车的不同视角，不出现拼图格线”，不能写“图片尚未上传，提交前请绑定”。

## 参考绑定与构图

参考ID与视觉职责保留在正文；实际文件、来源和状态在外部资产表中对应。没有图片时可以写文字草案，并在执行记录中标缺失；不能把占位ID当成已上传图片。执行层将ID替换为模型真实支持的图像引用，不把本地路径发送给远程模型。

人物、音色参考不是必需项。需要驾驶员或人手时只写与画面相关的身份及动作。不展示人物特写时，可用自然驾驶者暗影交代正常驾驶。

没有逐镜静帧时，用方位、机位高度、完整或局部范围、主体位置和运动方向说明构图。只要时间轴设计有切镜，末尾就不能再写“一镜到底、禁止切镜”。
