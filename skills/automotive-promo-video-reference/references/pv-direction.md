# 汽车PV：让速度与豪华同时可见

仅在用户要求高端汽车PV、速度激情或更强商业摄影动势时使用本分支。用户若明确要静谧展厅、慢赏车身或低速巡游，保留其选择；“高端”一词本身不强制改成激烈驾驶。本分支仍使用车辆与场景参考直接生成整段多镜，不新增逐镜图像流程。

## 先选一条运动主线

优先让汽车在开头就处于运动中：给约一秒的近景经过、前侧追近或低位路面视差，不花开头数秒等车辆启动。将汽车安排在开场即可读的近中景，一秒内只完成一个清楚的事件；不要要求它从遥远消失点抵达镜前、绕过相机又驶离。

以“正在行驶”的时间线贯穿时，内饰段窗外仍在移动，切回车外继续同向行进。若确需回看停车状态，应明确这是时间省略或回看剪切。豪华轿车不必通过开门、脚踩踏板、换挡或人物表演才能完成广告。

可按片长与主题组织：**运动钩子 → 短细节组 → 完整车姿 → 座舱静谧反差 → 行驶高潮 → 英雄车姿收尾**。这是一种节奏关系，不是固定镜数或唯一镜序；根据已选参考与用户偏好调整。完整车姿可以在多组之间反复出现，避免直到结尾才看清汽车。

## 具体摄影动作

| 目的 | 画面与相机的实际关系 | 切点依据 |
|---|---|---|
| 开场抓住注意 | 轮轴以下的前侧机位，汽车从近中景向镜侧经过；或跟拍相机稍慢，汽车在画面中逐渐变大。保持车灯与车身可读 | 前灯、前轮或车身折角经过明确画面位置时切 |
| 细节短组 | 灯组、轮毂、立标或车身折线分别承担一个识别任务。行驶镜可让主体稳定、背景流动，轮辐有适量运动模糊 | 灯边高光、反光带或路面接缝到达画面边缘；不靠圆形器件连续变形匹配 |
| 交代完整车姿 | 完整侧面或前侧全车跟拍，两轮、车顶线与接地关系同时可读；近处护栏比远处楼群移动更快 | 车进入干净背景、反光离开门板或车身轮廓最清楚时切 |
| 强化座舱反差 | 座舱保持安静、相机近乎固定，只有窗外灯光和少量饰面反射流动。宽一点的座椅/中控关系优于连续按键演示 | 材质细节进入完整座舱后停留，再以硬切返回外部动势 |
| 动态高潮 | 在追近、恒距同行、路侧经过、后侧拉开中选择有层次的两三种关系。汽车与摄影机的相对位置必须发生可见变化 | 一次经过或接近动作完成后换独立机位；不能靠车辆变形把机位连起来 |
| 英雄收尾 | 前侧或侧面完整车姿，摄影机与汽车匹配速度，构图逐渐收稳；背景仍流动，车辆继续行进 | 收在车头、轮圈与车侧清楚的画面，最后不再被细节快切打断 |

速度感来自轮胎滚动、相对距离变化、低机位和前景视差，不要求每镜都加速。需要加速时，只写连续、物理可达的车身位移与摄影机关系；不要用飞跳、离地、滑行不转轮或突然伸长车身表示提速。全片禁止失控的机械错误，不把自然加速本身列为错误。

车辆左右按自身朝前定义，并和屏幕方向分别记录。常规直立、未镜像的前右/右侧构图适合车头朝屏右；不要同时写“前左视图、车辆左侧朝镜头、车头朝屏右”。选择同一观察侧后，用独立硬切换前侧与后侧机位，避免跨轴反向或凭空镜像。灯光方向和道路位置锁定在场景空间，换机位后不强求它们仍位于同一屏幕角落。

## 形成快与静的差别

- 短细节组可用半秒边界，每镜一个清楚部件，少做复杂动作；随后放回完整车姿，使观众知道细节属于哪辆车。
- 剧本需要且参考足够时，给座舱约二至三秒的整段反差，可由少量材质短镜与一个较宽座舱镜组成。这里降低镜头运动与信息密度，车窗外的位移继续证明汽车在行驶。
- 没有内饰来源时，先补真实参考或记录用户接受的创意内饰设定；不根据品牌常见配置编造功能。用户未要求内饰且缺少依据时，可用完整车姿、城市尺度或材质留白承担静谧段；用户明确要求内饰时保留需求并补充参考，不默默删掉。
- 高潮不等于全程快切：让一次完整的追近或经过有足够时间完成，再插短细节，最后拉长英雄镜头。最后一镜应能看清产品，不能只剩车尾出画或速度拖影。
- 镜数、细节数量与段落时长按片长和可读性决定，不固定套用二十秒十六镜。没有听辨和选定音乐时不写BPM；取得音轨后再让视觉事件与实际重音配合，不迫使每镜都卡同一节拍。

## 商业用光与真实重量

黑漆要能读出曲面、门缝和轮拱，以长条环境反光勾勒体积；不能把暗部压成黑洞或把整块车漆照成灰色。镀铬保留亮度但不溢出，车灯亮而结构仍在。暖色座舱与中性偏冷的城市可以形成反差，不把每个镜头都染成不同颜色。

近处路面、护栏和灯光可以有方向一致的运动模糊，主体车身、轮圈中心与身份锚点保持足够清楚。汽车重心稳定，悬架和接地符合重量；道路和车辆速度关系连续。用真实反射、侧后轮廓光和城市尺度提升质感，不堆漂移、白闪、火花、烟雾、剧烈甩镜、穿车或每镜环绕。

## 写入模型的内容

把上述选择落实为参考语义、场景、起始状态、逐镜时间/画面/运镜/切点、风格物理要求及结束状态。例如“摄影机略慢于车辆，完整车身在画面中向前移动；前轮越过地面接缝时硬切侧面全车”比“极致豪华、激情澎湃、电影大师级运镜”更可执行。

遵循 [纯提示词格式](prompt-format.md)：模型名、模式、分辨率、画幅参数、帧率、声音开关、资源状态、审批、费用、后期安排和验收说明仅放在独立执行记录。真实台词、具体声音或“无对白、无旁白”属于作品内容时可以保留。本分支不改变已有生成授权范围，也不因追求速度自行增加生成任务。
