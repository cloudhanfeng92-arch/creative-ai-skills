# 汽车宣传片导演·无分镜图版

以剧本、文字分镜和车辆四视图直接组织多图参考视频，按需补充内饰与场景资料卡，无需逐镜生成分镜图。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/automotive-promo-video-reference 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/automotive-promo-video-reference) 安装 `skills/automotive-promo-video-reference`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $automotive-promo-video-reference，用这辆车的照片制作20秒宣传片，采用车辆四视图直接生视频，不生成逐镜分镜图。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- libtv-cli 与可用的 LibTV 账号
- Lib Image 2.5 Pro、Seedance 2.5 多图参考能力
- 本地剪辑按需使用 ffmpeg-skill

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
