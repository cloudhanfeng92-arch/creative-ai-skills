# 固定镜头矩阵

每个资产只能承担一个主要转化职责。套系之间可以改变策略和视觉语言；资产顺序、比例和消费者问题固定。缺少事实证据时，按本表规定把内容职责替换为最接近原消费者问题的安全版本，不得空缺或换序。

## 主图共同要求

- 五张均为 1:1；每张发布级成图必须实际排入一条卖点标题和一条解释性描述，二者都不得覆盖包装或食品证据。
- 包装只按上表职责出现；`optional` 必须说明识别价值，`omit` 不得为了统一模板而擅自加入。发生证据安全替换且新职责确实需要包装结构、开合或从包装到上桌动作时，可把该槽位改为 `optional` 或 `required`，但必须记录替换原因、避免与 `09` 重复，并通过整套包装频率与自然融合 QA。包装出现时完整、清晰、不变形并自然融入场景。
- 画面以真实商业食品摄影为基础：漫射柔光、自然接触阴影、真实食材肌理、合理浅景深、高食欲但不过度油亮。
- 每张图只用一个主卖点；视觉证据和文字必须相互支持。
- 不做促销、价格、囤货、库存或倒计时信息。

## 详情页共同要求

- 六张均为 3:4，且都是独立可投放的电商详情模块；纵向阅读层级清楚，不能六张都做成同类氛围图或同一角落标题模板。
- 每张详情图都必须是完成的电商模块，至少具备标题、解释层和视觉证据；需要事实或步骤时增加第三层精确说明。发生自动替换时，图片标题必须使用真实交付职责，不得沿用缺证据的“原料优势”“制作工艺”“多角度”等说法。
- 从价值到证据逐步建立信任；图片之间共享品牌色、光线和材质语言，同时保持镜头内容不同。
- 详情页不是 PPT：禁止大面积扁平色块、密集图标、伪证书、矢量插画和无实物证据的信息堆叠。
- 六张合计至少使用三种不同内容结构；具体模块与字体规则见 [visual-layout-typography.md](visual-layout-typography.md)。

## 品类适配

根据真实食品选择质感动作，不要机械套模板：

- 酥脆食品：真实碎屑、断裂边缘与层次，避免爆炸式飞散。
- 烘焙或乳酪类：可用断面、绵密、熔化或拉丝，但只在产品确有该状态时使用。
- 饮品：冷凝水、气泡、液体层次或冲调过程，不制造固体食物质感。
- 冲泡或速食：重点展示冲泡前后和真实食用状态，不夸大份量。
- 调味品：突出蘸取、浇淋、附着和菜品搭配，不伪造原料比例。
