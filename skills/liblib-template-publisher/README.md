# 哩布图片模板发布

创建和发布哩布图片模板，默认采用玩法模式，完成输入设计、固定参考配置、测试、示例和详情页核验。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/liblib-template-publisher 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/liblib-template-publisher) 安装 `skills/liblib-template-publisher`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $liblib-template-publisher，把这个人物变手办效果做成哩布玩法图片模板，配置上传入口和示例并发布。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- Liblib.art 账号与模板发布权限
- 可用浏览器工具
- 所选图片模型与测试预算

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
