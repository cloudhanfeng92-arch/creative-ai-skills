# 剧本短剧制作模板

在编写资产锁、Gate 1 方案和实际生成提示词时读取。填写具体内容，不把空字段直接提交给模型。
保持剧本原文与导演补全可区分；每个 Prompt 应能独立执行，不依赖模型看到“上一条提示词”。

## 1. 资产清单与锁

```text
PROJECT：片名、题材、画幅、计划时长、时长来源（用户指定/估算）、视觉风格
SCRIPT：剧本来源、版本、不可改动项、待解决冲突
REFERENCE：参考图路径 → CHAR/SCENE/PROP ID → 用途（身份/环境/道具/画风）
CHARACTER_LOCK — CHAR_A
  剧中名字/别名、身份/关系、文化背景、年龄/性别、身高/体型
  脸型/肤色/眉眼鼻唇、发型/发色、妆容
  服装/颜色/材质、鞋、耳饰/项链/戒指/其他首饰
  气质/身体状态、音色/口音/习惯语速、参考图与来源
  剧本明确的换装/年龄/伤势版本（无则写无）
SCENE_LOCK — SCENE_A
  地点/时代/室内外/大小、墙地顶、门窗、家具、装饰、主要道具
  空间坐标、前中后景、时间天气、光源坐标/方向/色温、主色调/材质
  主摄影方向、表演轴、视角图坐标/朝向、剧情内环境状态变化
SPATIAL_LOCK
  人物世界位置/朝向/视线 → 各机位对应屏幕位置
  门窗桌椅及核心物件坐标，允许发生的剧情移动及时间点
PROP_LOCK — PROP_A
  形状/尺寸/材质/颜色/纹样/数量、初始位置、持有者/左右手、状态变化
DIALOGUE_LOCK — LINE_001
  原剧本段落、说话者、完整原文、顺序、画内外、绝对/CLIP局部时间
  语气/语速/停顿/重音/音量、听话人反应、固定音色
STORY_CONTINUITY_LOCK — CLIP_01 → CLIP_02
  人物位置/朝向/表情/视线/手势/持物/衣服/伤势
  门窗/家具/核心道具状态、最后一句/最后动作、下一段开始状态
```

## 2. 角色四视图生图提示词

```text
任务：生成 CHAR_A（具体名字）的一张专业影视角色四视图资料卡。
实际设置：横向16:9，2K，中质量medium（通过工具支持的参数传递）。
输入参考：具体文件/资产ID，仅将其用于身份/服装参考，逐项说明用途。
人物依据：逐项填入CHARACTER_LOCK，明确沿用参考图的五官、年龄和发型。
若没有参考图：依据剧本描述完成该角色原创定妆，写明已确认制作补全。

构图：同一张图四个整齐分区，从左到右依次为
①正面全身 ②左侧90度全身 ③背面全身 ④正面面部特写。
前三格头顶与脚底对齐、同一人物比例、全身含鞋完整可见；
第四格清楚展示双眼、眉鼻唇、发际线和耳饰，无遮挡。
四格都必须是同一个人的同一造型，服装细节、颜色、材质与饰品位置一致。
人物自然站姿，手臂略离身体以展示衣服轮廓，不进行剧情表演。
中性浅灰背景，均匀柔光，真实影视肤质，年龄感符合角色。
只保留简短分区标签；不生成长篇设定文字。
禁止：多人物身份、四张不同脸、四格服装互换、四个头像代替三视图、
裁掉脚/头、无关道具、复杂房间、额外配饰、脸型漂移、过度磨皮、水印。
```

验收：完整四分区、三个全身加面部特写、身份/造型跨视角一致、手脚与侧背服装结构可信、
尺寸和质量参数已核验。镜像产生的首饰左右错位需要修复。

## 3. 单张多视角场景资料卡提示词

```text
任务：SCENE_A（具体地点）的专业影视 Location / Scene Bible，一张图完成。
实际设置：横向16:9，2K，中质量medium（通过工具支持的参数传递）。
依据：用户剧本与场景参考；填入完整SCENE_LOCK、固定坐标和PROP_LOCK。
统一空间：给出可执行房间几何、入口、窗、主要家具和道具世界位置；
例如仅在已确认设计中约定“南入口、东窗、北侧背景墙、中央桌”，不可直接套用例子。

排版：主视角大格，另外五个视角清楚可读，必要时同卡加入小型俯视布局图或道具细节区。
主视角：具体摄影机世界位置、朝向、视高与景别。
反打视角：具体反向机位，注明与表演轴关系。
前视角：入口向室内，具体位置/朝向。
后视角：背景向入口，具体位置/朝向。
左视角：空间左侧向内，具体位置/朝向。
右视角：空间右侧向内，具体位置/朝向。
新增区域（仅必要时）：具体名称、用途、角度与裁切范围。

六个视角不是六个房间；同一门、窗、家具与道具始终在相同世界坐标。
保持准确数量、材质、尺寸、颜色和同一时间天气；相机旋转只改变投影。
光源固定在世界坐标中，不能每一格都把光重设为画面左侧。
默认纯空场景，无演员、无人体剪影、无镜面人物倒影。
动作区如需标注仅显示空白活动区域。简短可读分区标签，不画长篇说明。
禁止：空间镜像、家具瞬移、窗门增减、菜品/道具数量改变、不同装修、
不合理透视、拼入其他地点、水印。最终只输出这一张多视角场景资料卡。
```

验收：必要六视角齐全、主视角可用于摄影参考、视角方向能与平面布局对应、固定物体与光源一致、
没有演员、没有重复生成的独立场景图。检查反打时屏幕左右变化是否符合世界坐标。

## 4. 视频生成段表

| CLIP | 故事时间 | 计划/实际模型秒数 | SHOT / LINE | 角色 / 场景参考 | 起止状态 | 分段理由 |
|---|---|---|---|---|---|---|
| CLIP_01 | 起点—终点 | 规划秒数；调用前核实 | 完整覆盖对应ID | 仅本段需要 | 明确动作和情绪 | 完整对话或动作单元 |

总计划≤15秒时表中只有一项。长片优先12—15秒并以对白完整为先。
所有LINE覆盖一次；有意的重复台词应具有独立LINE ID，避免误删或重复拼接。

## 5. 每段完整视频提示词模板

```text
生成CLIP_具体编号：实际支持的秒数、画幅、清晰度、画风、音频开关。
人物参考：具体资产ID对应具体人物；四视图是同一人的多角度，不是四个人。
环境参考：具体场景卡ID；它是同一地点的多视角资料，不是拼贴画面。
主镜头采用卡内具体分区/方向，视频不显示卡框、标签、平面图或四视图排版。
如MODE B：具体首帧仅作为构图锚点，身份与环境继续遵循已确认参考。

角色锁：展开本段每位人物的身份、年龄、五官、发型、服装、首饰与身体状态。
场景锁：展开房间结构、门窗家具坐标、道具、材质、光源与色调。
空间锁：具体人物位置/朝向/视线/屏幕左右、摄影机位置和表演轴。
仅允许实际出镜的角色列表；列明只在台词提及但不得出镜者。
起始状态：明确继承上一段的情绪、动作、持物、位置，不从初始姿态重置。

按0至本段结束的局部时间轴完成（下面每项写真实时间，不保留占位）：
时段 / SHOT ID：
  景别、焦段感、机位高度/方向、构图与前中后景、硬切或连续运镜。
  角色表情、视线、身体重心、手部动作、微反应与停顿。
  动作按准备→发力→执行→接触→对方反应→结束状态描述。
  LINE ID，说话者：“剧本逐字对白”。明确语气、语速、重音和声音大小。
  只有指定者开口，其他角色嘴巴闭合并作具体反应；
  如画外音：说话者声音继续，当前画面人物不对口型。
  同步动作音、环境音、必要音乐与转场。
结束状态：明确给下一段继承的人物、道具与环境状态。

角色一致性：全段同脸、同年龄、同发型、同服装鞋饰妆容，剧情明确变化除外。
场景一致性：硬切只改变摄影机，不重建房间，不移动家具，不改变世界光源。
声音：对应角色固定音色；对白顺序、文字与时间完整，禁止错配和漏句。
禁止：角色复制/融合/换装、无依据新人物、道具增殖或消失、姿势重置、
四视图拼贴出现在视频中、标签、水印、未经要求的字幕和旁白。
```

## 6. 可选关键首帧

```text
强参考已经确认的具体角色四视图和场景资料卡。
严格继承角色五官、年龄、发型、体型、衣服、鞋饰和妆容，不重新设计人物。
严格继承场景空间坐标、门窗、桌椅、主要道具、材质、光源与整体色调。
只按已确认时间轴中CLIP起点构建人物站位、持物、表情、动作准备和摄影机构图。
列明实际出镜人数、每人的准确位置/朝向、相机高度/方向/景别及遮挡关系。
输出单幅完整剧情画面，2K、中质量，画幅与视频一致；不输出分格资料卡。
```

## 7. 验收记录

每个CLIP记录：计划时长/实际时长、LINE逐句覆盖、可听对白/音色/错字、
说话角色与口型、可见角色造型、空间和道具、动作因果、情绪、开始/结束状态、
跨段衔接、实际检查方式（抽帧/完整回看/听音/转写）、未验证项及修复建议。
不要把“提交成功”“生成成功”“媒体规格有效”“剧情验收通过”混成同一状态。
