# 完整剧本转 AI 短剧

解析完整剧本与对白，建立角色四视图和场景资料卡，规划连续时间轴与生成段，经确认后制作并按需求剪辑成片。

## 安装

把下面的请求发给支持 Skill 安装的 AI 助手，安装仓库完整内容：

```text
请安装 https://github.com/cloudhanfeng92-arch/script-to-short-drama 中的 Skill。
```

也可从 [总仓库](https://github.com/cloudhanfeng92-arch/creative-ai-skills/tree/main/skills/script-to-short-drama) 安装 `skills/script-to-short-drama`。保留 `SKILL.md` 及所有配套文件；同名本地版本应先备份再替换。详见[安装指南](https://github.com/cloudhanfeng92-arch/creative-ai-skills/blob/main/docs/INSTALL.md)。

## 使用示例

```text
使用 $script-to-short-drama，把这份完整剧本制作成竖屏短剧，保留全部对白，先整理角色四视图、场景卡和分段生成方案。
```

主题、规格与素材可以替换；具体输入、默认值、流程与交付要求见 [SKILL.md](SKILL.md)。

## 工具与环境

- 完整剧本
- 用户选定平台的图像与视频生成能力
- 使用 LibTV 时需 libtv-cli 与 VIP 无水印下载能力；成片需可用剪辑导出工具

安装 Skill 不会自动配置外部工具、账号、模型权限或额度。依赖项及可选功能以执行说明和实际宿主能力为准；生成或发布按用户的明确要求和授权范围进行。
