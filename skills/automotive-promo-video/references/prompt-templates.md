# 汽车提示词模板

方括号提交前替换为实际信息；例子不代表用户车型已有配置。按镜头写具体摄影关系，少用空泛质量形容词。

## A. 多视角总览

```text
根据参考 U01、U02、U03，生成同一辆汽车的一张多视角参考总览，不是广告海报。
U01 约束外观前侧，U02 约束侧后部，U03 约束真实内饰。保持[轮廓/车漆/双色边界]、[格栅/灯组/轮毂]、[方向盘/屏幕/座椅/饰板]一致，不替换年款或车型。
布局：[行列与每格视角]。外观与内饰分区，每格一个视角；全车格完整容纳车头、车尾、车轮、车顶，格间干净留白，无大标题、文字说明或水印。
外观使用中性背景和柔和大面积侧顶光，漆面与玻璃有合理反射，结构清晰，避免极端广角。内饰自然柔光，正常透视，忠实保留现有配置。
所有格展示同一辆车，原有徽标位置形状不变，不能新增屏幕、天窗、排气管或饰件，不能擅自补写无可靠来源的字标。
```

缺内饰时删去 U03 和内饰生成要求，明确外观先行、内饰待补。用户选择概念内饰时，在档案和提示词中均标明概念设定。

## B. 独立内饰板（需要时另列数量）

```text
依据 U03、U04 的真实内饰，生成一张 2×2 内饰参考板：前排中央视角完整仪表台；驾驶位方向盘/仪表；后排座椅与扶手；门板与饰板细节。
固定[左右舵]、[屏幕数量形状位置]、[方向盘]、[皮革/缝线]、[饰板/氛围灯路线]。正常透视和真实比例，不新增大屏、星空顶或其他车型座椅。
柔和清楚照明，真实材质，无人物、无叠加文字，四格保持同一配置。
```

## C. 单镜头静帧

```text
镜号[Sxx]，一张完整[画幅]汽车摄影画面，无分格、无字幕。
使用[原图 ID]与[确认参考 ID]中的同一辆车，锁定[可见的 3–5 项身份特征]。
场景：[地点/昼夜/天气]；车辆[状态/姿态]，前轮[方向]，灯光[状态]，轮胎准确接地。
构图：[景别/左右前后视角/相机高度/透视/主体位置/裁切安全边界]。
光线：[光源方向/软硬/亮部位置/环境反射源/阴影层次]；材质[本镜重点]，景深[需求]，背景[约束]。
保持[身份锁]，避免[本镜具体风险]；无多余人物、文字、价格或性能说明。
```

## D. 首帧工作流视频

```text
使用 Sxx_FRAME 为起始画面依据，生成[支持时长]秒单一连续镜头。
主体：[图中现有汽车和景别]；固定[身份锚点]、场景几何和光源方向。
车辆：[静止或具体运动]；摄影机：[起点/终点、方向、幅度、速度变化]。
0–[t1]秒：[进入动作]；[t1]–[t2]秒：[持续运动]；末段：[可剪结束状态与稳定余量]。
[路沿/地砖/车轮接地/柱子]维持正确视差，反射随视点与实际光源变化，车漆本色不变。
车身、轮毂、灯组和徽标不变，不增加车轮/门缝，无漂浮、滑动或材质游动。无自动切镜、转场、新增字幕。声音：[具体需求或不生成配乐]。
```

静车就写车轮不转、车体不平移；行驶就写方向和正常滚动。不要同时要求静止和高速旋转。实际首帧是否满足构图需要，下载后检查。

## E. 多图参考视频

```text
参考1约束本镜构图和灯光；参考2约束同一车侧面身份；参考3约束[本镜需要的另一外观/内饰结构]。这些图是同一车的不同依据，不是要按图序切换场景。
生成[时长]秒连续镜头：[动作与时间段]。
按参考1的[位置/景别/场景]构图，保持参考2/3的[具体结构]，摄影机只在结构依据覆盖的范围内运动。
不出现拼图格线、静图依次切换、车型替换或内外饰融合。[追加本镜物理/身份/声音约束]
```

只在当前模式真正支持多图参考时用，首帧＋尾帧不是多图身份参考。

## F. 完整示例：已确认双色轿车，夜间静车

以下为虚构制作例，不是对参考视频真实配置的鉴定。假设用户确认上银下黑长轴轿车、竖向格栅、多辐银轮毂。

**静帧：**

```text
一张16:9横屏实拍汽车摄影画面。严格使用U01和CAR_EXT_FRONT_LEFT中的同一辆上银下黑长轴轿车，双色分界沿车肩线连续，保持竖向格栅、细长灯组、多辐银轮毂和左侧门窗形状。汽车静止于酒店门廊深灰石材地面，前轮回正。前左侧低机位中景，完整容纳车体，车头位于左下三分点，车尾与后轮可见，透视不拉长车身。左上方柔和暖白门廊灯勾出银色机盖和肩线，远处少量冷白城市灯光，黑色车门暗部保留层次。湿润地面仅有浅反射，无暴雨。重点呈现格栅和侧面双色线条，玻璃反射环境而非另一辆车。无人物、无字幕、无额外车标、无虚构牌照文字。
```

**视频：**

```text
以验收后的S03_FRAME为起始画面依据，生成当前模式支持的5秒连续镜头。汽车全程静止，车轮不转，前轮回正。摄影机在车头左前方沿短滑轨平稳向画面右侧移动约半米，高度和观察距离基本不变，只出现轻微侧向视差，不绕到车后。前0.6秒平稳进入，中间约3秒均匀侧移，末段1.4秒缓慢收住。门廊立柱、地砖线和轮胎接地点关系稳定；暖白条形灯反射随视点滑过银色机盖和黑色车门，双色边界、轮毂辐条保持。无车身漂移、车头膨胀、格栅改写或徽标变化。单一镜头，无字幕、变焦跳动或自动剪辑，不生成背景音乐。
```

若模型不支持5秒就重写时间段；示例长度不是平台永久能力声明。
